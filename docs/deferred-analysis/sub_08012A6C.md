# sub_08012A6C - deferred (register-rotation + dead-`sl` coloring plateau)

204 bytes @ 0x08012a6c, asm slice `asm/disasm_0x08012a6c.s`, dest
`src/engine/sub_08012a6c.c`. `classify_unmatchable.py` verdict: **ATTEMPT_MATCH**
(advisory only: one high register held across the blit call; NOT a NAKED class).
NAKED is therefore inappropriate — this needs a true pure-C match.

This is an animated tile-blit tick handler. Reads a sentinel flag at
`gIwram_3610` (0x03003610); if `== 1`, throttles on a per-descriptor timeStep
against `gGameStuff._unk00`, then blits one animation frame via
`sub_0801025C(rows, cols, x, y, bank, frame, dst)` and finally always calls
`sub_0800E7D4()`. Descriptor is a 24-byte record embedded in
`sSpriteAnimBlock_06838` at 0x08306E64 (see field map in the C below). Coords
`x`/`y` come from signed halfwords at `gEntities` base 0x03003720 + 0x692/0x694,
each `* 3` then truncated to u16. `dst` is 0x0600E000 or 0x0600E800 per
`(field_08 >> 4) & 1`. Control flow (important): `*flag != 1` -> jump to the
sub_0800E7D4 tail (0x12afe); timeStep-not-elapsed -> **plain return WITHOUT
calling sub_0800E7D4** (0x12b02). The sibling sub_0801288C (already in C, heavily
pinned) consumes the same 0x08306E64 region with a DIFFERENT field view, and the
sibling sub_08013040 is the same animator family over an array — both are useful
references but both are plateau-style pinned matches, not clean.

## Drift

This Opus session re-derived from scratch and reached **byte_diff 86,
diff_count 41** — better than the prior **101/37**. The structure is now FULLY
correct (prologue/epilogue/control-flow/instruction-selection all match,
including the `mov r7,sl; mov r6,r9; mov r5,r8; push {r5,r6,r7}; sub sp,#16`
high-reg-save prologue and the matching epilogue). What remains is a single
**coordinated register rotation + a dead-`sl` allocator artifact** that neither
manual pins nor the permuter escape.

The clean 86/41 base (in "Best-effort C" below) uses exactly two pins:
`register const u32 *frames asm("r8")` and a `register u32 one asm("r1")` block
for the `bank & 1` mask. The single decisive structural insight that took the
clean body from ~176 to 86 was **hoisting `rows = desc->rows; cols = desc->cols;`
to BEFORE the coords computation** (the target loads rows->r0 and cols->r1 early
and they survive the coords block which uses r2-r5). Without that hoist the diff
sat at 171-176.

Remaining mismatch is a 3-cycle role rotation plus a frame-size delta:

| value | target | 86/41 build |
|-------|--------|-------------|
| flag  | r9     | **sl**      |
| dst   | ip     | **r9**      |
| bank  | **spilled `[sp,#12]`** | **ip (register)** |
| state | r6     | **r7**      |
| desc  | r7     | **r6**      |
| frames| r8     | r8 (pinned) — matches |
| sl    | **saved-but-DEAD** | live (holds flag) |
| frame | sub sp,#16 | sub sp,#12 |

ROOT CAUSE (analyzed via `old_agbcc -dg` global-reg dump + REG_ALLOC_ORDER in
`tools/agbcc-src/gcc_arm/config/arm/arm.h`): the ARM call-saved alloc order is
`r4,r5,r6,r7,r8,sl(r10),r9,r11`. With frames pinned to r8, the next free high reg
is **sl**, so the first high-priority cross-call value (the flag pointer) lands in
sl. The target instead leaves **sl saved-but-unused (dead)** and puts flag in r9.
That only happens if an EXTRA pseudo grabbed sl during global_alloc and was then
eliminated, which simultaneously denied `bank` a register home (forcing the
`[sp,#12]` spill -> 16-byte frame) and rotated dst into ip. I could not reproduce
that dead-sl pseudo from clean source.

Levers RULED OUT this session (all measured on OLD_AGBCC, the TU default):
- Clean C, no pins, various statement orders: **171-176 / 57-73**.
- New agbcc for this TU: identical shape (176).
- `register u8 *flag asm("r9")` pin: reintroduces a `mov r8,r1; mov r2,r8`
  shuffle; **90 / 42** (worse than the unpinned 86).
- `register u32 dst asm("ip")` pin (alone or with flag=r9): no help, **87-90**.
- `register *state asm("r6")` pin: agbcc already chooses r6 for state — no-op.
- `register *desc asm("r7")` pin: forces desc=r7 but emits `adds rN,r7,#0; ldrb`
  copy-out overhead (explicit local register vars are excluded from normal
  base-through reads); **138 / 62**.
- `volatile u32 bank`: DOES force the `[sp,#12]` spill + 16-byte frame, but every
  `bank` use reloads from the stack (target keeps it in r3 for the `&1`), and it
  damages state coloring; **142 / 63**.
- A `register u32 slHold asm("sl")` dummy (assigned + `asm volatile("")` barrier)
  to occupy sl and push flag to r9: emits real `slHold=0` code, doesn't become
  dead; **135 / 51**.
- Moving the dst-select block AFTER coords: **146 / 89** (target computes dst
  BEFORE coords).
- Hoisting `frameCount = desc->frameCount` before the call: **99 / 44** (target
  reads frameCount AFTER the call as `ldrh r7,[r7,#10]`).
- decomp-permuter from the 86/41 base, ~600 iters over 5 min at -j3: base score
  1365, best 1300 — barely moved. The score is dominated by per-instruction
  register-role mismatches; the rotation needs a coordinated change the
  permuter's local mutations don't find.

## Next likely useful step

Reproduce the dead-`sl` pseudo. Two concrete ideas not yet tried:
1. Instrument a PRIVATE `old_agbcc` (copy `tools/agbcc-src`, NEVER rebuild the
   shared symlink) in `global.c`/`reload1.c` to log which pseudo grabs sl and why
   `bank` is refused a register, then find the source shape that creates a
   short-lived 8th pseudo overlapping `bank`'s range (candidate: an intermediate
   in the `frames[frameIndex]` index arithmetic, or a redundant copy of `desc`
   that CSE later kills but whose sl reservation persists in `regs_ever_live`).
2. Drop the `frames asm("r8")` pin and instead find a source structure where
   agbcc naturally puts frames in r8 AND a second high value in sl — the natural
   (unpinned) allocation may distribute the dead-sl differently than the pinned
   one does.

Passes implicated: `regclass.c` (pseudo preferences), `global.c`
`allocno_compare`/`find_reg` (priority = refs/live_length, lower hard-reg number
to higher priority), `reload1.c` (spill/reload register choice). The 86/41 base
proves everything except the allocation distribution is correct.

## Best-effort C

```c
#include "game.h"
#include "types.h"

struct ScaleBlitDescriptor {
    u16 field_00;
    u16 field_02;
    u8 cols;       /* +4  -> arg1 */
    u8 pad_05;
    u8 rows;       /* +6  -> arg0 */
    u8 pad_07;
    u8 bankNibble; /* +8  -> bank = (>>4); (&1) selects dst */
    u8 pad_09;
    u16 frameCount;/* +10 (halfword) */
    u8 timeStep;   /* +12 */
    u8 pad_0D[3];
    const u32 *frames; /* +16 */
    u32 pad_14;
};

struct ScaleBlitState {
    u8 pad_00[4];
    u32 lastTick;   /* +4 */
    u8 pad_08[2];
    u8 frameIndex;  /* +10 */
};

extern u8 gIwram_3610;
#define sScaleBlitDesc_6E64 (*(const struct ScaleBlitDescriptor *)0x08306E64)

extern void sub_0801025C(u8 rows, u8 cols, u16 x, u16 y, u32 bank, u32 frame, u32 dst);
extern void sub_0800E7D4(void);

void sub_08012A6C(void)
{
    u8 *flag;
    GameStuff *gs;
    struct ScaleBlitState *state;
    const struct ScaleBlitDescriptor *desc;
    u32 tick;
    u32 bank;
    u32 dst;
    register const u32 *frames asm("r8"); /* held across coords -> r8 */
    u8 *coords;
    u16 x;
    u16 y;
    u8 rows;
    u8 cols;
    u8 frameIndex;

    flag = &gIwram_3610;
    if (*flag != 1)
        goto done;

    gs = &gGameStuff;
    state = (struct ScaleBlitState *)0x030064C0;
    tick = gs->_unk00;
    desc = &sScaleBlitDesc_6E64;
    if (tick - state->lastTick < desc->timeStep)
        return;

    state->lastTick = tick;

    bank = desc->bankNibble >> 4;
    {
        register u32 one asm("r1"); /* fresh `movs r1,#1` mask for `bank & 1` */

        one = 1;
        dst = 0x0600E000;
        if (bank & one)
            dst = 0x0600E800;
    }

    frames = desc->frames;
    rows = desc->rows;  /* HOISTED before coords: target loads rows/cols early */
    cols = desc->cols;
    coords = (u8 *)0x03003720;
    x = *(s16 *)(coords + 0x692) * 3;
    y = *(s16 *)(coords + 0x694) * 3;

    frameIndex = state->frameIndex;
    state->frameIndex = frameIndex + 1;
    sub_0801025C(rows, cols, x, y, bank, frames[frameIndex], dst);

    if (state->frameIndex >= desc->frameCount)
        *flag = 0;

done:
    sub_0800E7D4();
}
```
