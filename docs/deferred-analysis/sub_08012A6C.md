## What the function does

Single-channel scale-animation stepper — the simplified, no-loop sibling of
`sub_08013040` (which loops the same idiom over 8 entities and matches via 13
pins). It shares the descriptor table (`sScaleAnimDesc_6e64` @ 0x08306e64,
ScaleAnimDescriptor shape), the blitter `sub_0801025C(rows,cols,x,y,bank,src,vram)`,
the VRAM dst pair 0x0600e000 / 0x0600e800, the `gIwram_3610[0]` armed flag, and the
post-step `sub_0800E7D4()` tail call.

- `gIwram_3610[0] != 1` → just `sub_0800E7D4()` and return (the `end:` label).
- gate: `if (gGameStuff._unk00 - state(0x030064c0)->lastTick < desc->timeStep) return;`
  (returns WITHOUT calling sub_0800E7D4 — distinct early exit).
- else: store lastTick; `nibble = desc->field_08 >> 4`; `dst = (nibble&1)? 0x0600e800 : 0x0600e000`;
  read `frames = desc->frames`; `x3 = (u16)(gEntities[30].x * 3)`, `y3 = (u16)(.y * 3)`
  (the 0x692/0x694 entity-pool offsets, same as sub_08012664); increment
  `state->frameIndex`; blit `sub_0801025C(desc->field_06, desc->field_04, x3, y3,
  nibble, frames[oldIndex], dst)`; if `frameIndex >= desc->frameCount` clear the
  armed flag; fall through to `sub_0800E7D4()`.

Linker symbol needed (was added & reverted): `sScaleAnimDesc_6e64 = 0x08306e64;`
in linker.ld next to `sAnimDesc_6e08/6e28`.

## Drift

Best clean result: **byte_diff 174, diff_count 69** (default OLD_AGBCC,
`GameStuff *gs` anchor). With `CC = $(AGBCC_BIN)` (the sub_08013040-family
compiler) it's 174; with `+ -fforce-addr` it's 175 but **fixes state→r6** (one
of the three coloring bugs). diff_count never drops below ~62.

The match needs an exact agbcc allocation that no clean source/flag reproduced:
- **r6 = state(0x030064c0), r7 = desc(0x08306e64)** — every clean build swaps
  these (state→r7, desc→r6). `-fforce-addr` flips state→r6 but then mis-promotes
  the heavily-read `desc` pointer into r8 (target keeps it in low r7).
  Responsible pass: `gcc_arm/local-alloc.c` `qty_compare` tiebreak between two
  equal-priority callee-saved pointers — not controllable from source order
  (tried: decl order, assign order, gs anchor, reading timeStep first).
- **sl is saved/restored but UNUSED in the body** (phantom over-save): target
  prologue is `mov r7,sl; mov r6,r9; mov r5,r8; push {r5,r6,r7}` + `sub sp,#16`;
  clean builds only engage r8,r9 (`push {r6,r7}` + `sub sp,#12`). The only lever
  that engaged sl was `register u32 nibble asm("sl")` — but that KEEPS nibble in
  sl, whereas the target SPILLS nibble to `[sp,#12]` (sl stays empty). So the sl
  is a reload artifact from `reload.c`, not a real value.
- **nibble spilled to [sp,#12]** (target reserves the 4th stack slot, `sub sp,#16`);
  clean builds keep nibble in a callee-saved low reg (r5/r7). Root: the target
  uses BOTH r4 and r5 as scratch for the x3/y3 register-offset addressing
  (`ldrsh [r2,r4]`, `ldrsh [r4,r5]`), starving nibble; clean builds use the
  precompute form (`adds r0,r1,r2; ldrsh [r0,#0]`) freeing r5 for nibble.
- minor: target `frameIndex` index lowers to `(x<<24)>>22` (an `(u8)int << 2`),
  clean build uses `lsls #2`; and target's `nibble&1` reloads a fresh `movs r1,#1`
  vs clean reusing the cmp's 1.

## Levers tried (all fail to reach 0)

- compiler: OLD_AGBCC (174) vs AGBCC (174). AGBCC is the sub_08013040-family choice.
- flags: `-fforce-addr` (175, fixes state→r6), `-fno-gcse` (176), `-fno-expensive-optimizations`
  (174), `-fno-strength-reduce`/`-fcaller-saves`/`-fno-schedule-insns` (no change vs -fforce-addr).
- pins: state→r6 + desc→r7 (180, breaks prologue without -fforce-addr; 175 with),
  dst→ip + frames→r8 (no-op, already there), nibble→sl (157 but wrong semantics,
  heavy pin), nibble→sl + -fforce-addr (164).
- register-offset addressing for x3/y3 via runtime offsets — folded back to constants
  by CSE; an `asm("")`-fenced offset would be needed (untried, likely a dead-end given
  the phantom sl still wouldn't appear).
- permuter: base score 4045 (target.o HAS $t/$d — the inflation is real stack/symbol
  scoring, not the mapping bug), 4781 iters / 90s → 2295. Not converging; the global
  r6/r7 swap + phantom sl is beyond statement-reorder mutation.
