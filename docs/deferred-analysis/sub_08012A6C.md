## Drift

Best new result: **byte_diff 101, diff_count 37** with OLD_AGBCC, no inline asm,
and two narrow register locals:

- `flag` pinned to `r9`, matching the baserom sentinel pointer.
- `one` pinned to `r1` in a small block to force a fresh `mov r1, #1` mask for
  `bank & 1`.

This improves the previous local minimum (174/69) but still does not converge.
The remaining mismatch is allocator/reload shape, not value semantics:

- Target uses `sub sp,#16` and stores `bank` to `[sp,#12]` immediately after
  `desc->field_08 >> 4`; best C uses `sub sp,#12` and keeps `bank` in `ip`.
- Target uses `ip` for VRAM dst and `r8` for `desc->frames`; best C uses `r8`
  for dst and `sl` for frames. This is the core three-way rotation.
- Target coordinate loads use `ldrsh r3, [r2,r4]` for X and `ldrsh r4, [r4,r5]`
  for Y; best C still emits an address pre-add for X.
- Target initial sentinel read is `ldrb r1, [r0]`; the `r1` mask pin causes
  best C to use `ldrb r0, [r0]`. Widening or narrowing the pin scope did not
  change that.

Passes implicated: `local-alloc.c` chooses the long-lived call-live pseudos and
`reload/reload1.c` decides whether `bank` receives a stack home while `r2/r3`
are needed for the blit coordinates.

Additional levers ruled out in this attempt:

- Source load-order rewrite with `GameStuff *gs` anchor improved the best score
  from 129 to 127 before the `r1` mask pin.
- `register const u32 *frames asm("r8")` repeatedly swaps state/descriptor
  (`state -> r7`, `desc -> r6`) and worsens the diff.
- `register u32 dst asm("ip")` keeps dst in `ip` but leaves `bank`/frames wrong
  and does not improve the score.
- Explicit `state asm("r6")` + `desc asm("r7")` is worse: it loses the desired
  high-register save shape and inserts extra descriptor copies.
- `register u32 bank asm("r3")` is worse (155/63).
- Address-taken `bankPtr = &bank; *bankPtr = bank;` is optimized away.
- `volatile u32 bank` creates a stack slot but damages the prologue and reloads
  bank before the branch (148/54), so it is not a viable keep.
- Flag sweep on best base: default 101/37; `-fforce-addr`, `-fno-gcse`,
  `-fforce-addr -fno-expensive-optimizations`, and the dispatcher flag bundle
  all regress to 133/55; `-O1` regresses to 163/59.
- Fixed-register sweep: `-ffixed-r8` no change; `-ffixed-r9`, `-ffixed-r10`,
  `-ffixed-r5`, and combinations regress.
- New agbcc (`CC=$(AGBCC_BIN)`) does not improve over OLD_AGBCC.

Next likely useful step: instrument a private `old_agbcc` in `reload1.c` around
reload-register allocation for the `bank` pseudo and the frame-table pseudo.
The no-rebuild `.greg` dump shows the useful pseudos but not why reload refuses
the target stack-home/`r8` combination.
