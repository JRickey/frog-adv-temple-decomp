## Progress this session (Opus round 18): 79/31 -> **68/26**, BOTH named walls SOLVED

The prior 3 sessions plateaued at 79/31 (`docs` Walls A+B). This session SOLVED both and got
to 68/26 (diff_count 26). The remaining gap is a single reload-pass coloring decision.

### Wall A (frames<->dst swap) — SOLVED by `register u8 *coords asm("r4")`
Natural agbcc gives frames=ip, dst=r8 (the swap). Pinning the COORDS BASE to r4
(`register u8 *coords asm("r4")`) adds exactly the register pressure that flips the
allocation to the TARGET's frames=r8, dst=ip. (Pinning frames=r8/dst=ip DIRECTLY also works
but composes badly with the other pins; the coords=r4 pin is cleaner and is what the 68/26
base uses.) This is the key new finding — Wall A is NOT a copy-preference problem, it is a
pressure problem, and the coords base is the pressure knob.

### Wall B (`<<24>>22` frame-index idiom) — SOLVED by `frames[(u8)(state->frameIndex++)]`
The target re-narrows the freshly-`ldrb`'d u8 index: `lsls r4,#24; lsrs r4,#22` = `(u8)idx<<2`.
Writing the subscript as **`frames[(u8)(state->frameIndex++)]`** (postfix-increment INSIDE a
`(u8)` cast, inline in the call) emits exactly `ldrb r4; adds r5,r4,#1; strb r5; lsls#24;
lsrs#22`. The prior sessions' subtraction trick (`state->frameIndex++; idx = ...-1;`) gives
`subs r4,#1` instead and is now OBSOLETE — drop it. (A separate `u8 idx` temp or a
`u32 fi` cast both regress to `lsls #2`; only the inline postfix-in-cast form works.)

### Root cause (confirmed with an instrumented agbcc — global.c allocno dump)
NOTHING global-spills (no hardreg=-1). bank (pseudo 27, refs=3, ll=27) gets r5 in
global_alloc; the "spill" to `[sp,#12]` is a RELOAD-pass arg-setup spill, not a global one.
The target loads the coords base LATE (r4 is free during the dst-select, so dst literals use
r4/r5), which leaves bank without r5 -> reload spills it to `[sp,#12]`. **My `coords asm("r4")`
pin reserves r4 across the WHOLE function (from its assignment), so during the dst-select r4
is unavailable -> dst literals fall to r1/r2 and bank keeps r5 -> bank is NOT the reload
spill candidate.** The pin fixes Wall A but simultaneously prevents the bank spill. The two
are coupled through r4.

    u16 field_02;

    u32 lastTick;   /* +4 */

void sub_08012A6C(void)
{

    GameStuff *gs;

}
