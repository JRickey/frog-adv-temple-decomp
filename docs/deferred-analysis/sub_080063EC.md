# sub_080063EC — deferred (Round 13)

`sub_080063EC` itself is **fully matchable in pure C (byte_diff 0)**. The blocker
is the *dead* second function that shares the same peel slice
`[0x080063ec, 0x0800658c)`.

## Slice structure (critical)

The slice contains **two** functions:
- `sub_080063EC` @ 0x080063ec — the real target (many callers). MATCHES in clean C.
- an unnamed dead function `sub_08006516` @ 0x08006516 — **no callers, not in any
  pointer table**. Dead code.

They **cannot be split into separate .o files**: `sub_080063EC`'s last literal
pool word `0x06010000` lives at 0x6514-0x6517, and `sub_08006516`'s first
instruction `lsls r1, r0, #24` (`0601`) is at 0x6516-0x6517 — i.e. the high half
of that pool word and the next function's first opcode **physically overlap**.
That interleaving is only produced when both functions are in the same C TU and
agbcc lays the pool out contiguously with the following function. Peeling
`sub_08006516` to its own asm slice shifts the downstream `.rodata`
(`sSpriteAssetTable` linked to 0x082f8adc instead of 0x082f8ad8) and adds a 2-byte
align pad to `sub_080063ec.o`, breaking the match. So **both must be real
compiled C in one TU.**

## sub_080063EC — SOLVED (keep this)

Pure-C match, no NAKED, one register pin. Key findings:
- `void sub_080063EC(u32 slot)` — returns void; the trailing `ldr r0,[r4,#8]` is a
  `(void)REG_DMA3.cnt;` hardware read-back, NOT a return value (the epilogue
  `pop {r0}; bx r0` reuses r0, so a non-void return mis-colours the bx scratch to r1).
- Entity pool: `gEntities[slot]` (0x03003720, stride 0x38). Access the asset table
  by **recomputing** `sSpriteAssetTable[field_00].anims[field_1A]` inline at each
  use (do NOT cache an `anim` pointer) — baserom recomputes; a cached pointer drifts
  the registers.
- Use `REG_DMA3` (the volatile macro) directly for the FIRST DMA group (agbcc
  re-materialises the &REG_DMA3 address per group, matching the baserom's two
  separate DMA3SAD pool loads).
- For the SECOND DMA group, pin a local pointer to r4:
  `register volatile DmaChannel *dma asm("r4");` — without it the count/dma2
  register colouring swaps (count lands in callee-saved r4, dma2 in r3; baserom is
  the reverse). The pin is the one required lever.
- The (shape, size) tile-byte-size table is `switch (shape) { case 0: switch(size)…
  default: goto shape12; case 1: case 2: shape12: switch(size)… default: 0xFFFF }`.
  Declare the `shapeA` struct field as **u8** (so the load is `ldrb [r0,#9]`, not
  `ldrsb`) and `switch(shape)` over a signed `s32` (agbcc's switch range-check emits
  the signed `cmp #0/blt; cmp #2/bgt`). The count is u16; park it early as
  `count <<= 16;` right after the switch, finish with `count >>= 17;
  dma->cnt = DMA_ENABLE | count;` — that reproduces the baserom's split
  `lsls r3,#16 … lsrs r3,#17` (an interrupted `(u16)count >> 1`).

## Drift — sub_08006516 (the blocker)

`sub_08006516(a, b)` baserom prologue:
```
lsls r1, r0, #24    ; r1 = a << 24
lsls r0, r0, #24    ; \ shape = (u8)a   (UNSIGNED widen: lsrs, even though dispatched signed)
lsrs r0, r0, #24    ; /
lsls r1, r1, #24    ; \ size = (u8)((a << 24) << 24)  == always 0
lsrs r1, r1, #24    ; /
```
So `size = (u8)((shapeArg << 24) << 24)` — provably **0** (ignores the 2nd arg). The
dispatch body is identical to sub_080063EC's (case 0 → 0x20, case 1/2 → 0x40, else
0xFFFF), always taking the size==0 branch. Buggy dead clone.

**Unmatchable cause:** `(u8)(x << 24)` is provably 0, and old_agbcc's `combine.c`
`nonzero_bits` pass folds it to a constant `movs r1,#0/#32` (the switch collapses).
The baserom build did NOT fold it — it kept the runtime double-shift. No clean C
survives the fold under our old_agbcc. Best diff: **byte_diff 4** (only the 5-insn
prologue; the whole dispatch body + epilogue + pool are byte-identical).

Levers tried that all fold to a constant `size`:
- `(u8)(shapeArg << 24)`, `((shapeArg<<24)<<24)>>24`, `(u8)((shapeArg<<24)<<24)`,
  multiply form `(u8)(shapeArg * 0x1000000)`, intermediate `s32 t = shapeArg<<24;
  size=(u8)(t<<24)`, size-declared-first, `int`/`u32`/`u8` param types.
- `volatile s32 t` / `*(volatile u8*)&raw << 24` — defeat the fold but add a
  `sub sp,#4` stack frame (wrong shape) and STILL fold `(u8)(x<<24)`.
- Per-TU CFLAGS `-fno-gcse`, `-fno-cse-follow-jumps`, `-fno-expensive-optimizations`,
  `-fno-cse-skip-blocks` — none disable the combine.c nonzero_bits fold (gcc 2.x has
  no `-fno-combine`).
- Newer agbcc (`CC = $(AGBCC_BIN)`): adds a `push {lr}` prologue to sub_08006516 AND
  breaks sub_080063EC (byte_diff 291). Not it.
- Corpus history search `lsls +r1, r0, #24` --require-c: 0 hits across all 23 mirrors.
- decomp-permuter: unavailable in this worktree (.venv missing on main; symlink loops).

**Next ideas for a future attempt:**
1. Build a private instrumented old_agbcc (codegen-notes "Instrumenting agbcc") and
   trace combine.c's nonzero_bits at the `(char)(ashift)` simplify to find a C form
   (or a `-fXXX`) that suppresses just this fold.
2. Try the permuter from the byte_diff-4 base once its .venv is restored — it may
   find a statement/scope shape that keeps the shifts.
3. If genuinely irreducible, the honest ship is NAKED+NON_MATCHING for sub_08006516
   *inside the same TU as the matched sub_080063EC* — but the NAKED asm must
   reproduce the pool/instruction overlap at 0x6514 exactly (the `0x06010000` pool
   word's high half IS sub_08006516's first opcode), which my first NAKED attempt
   did not (it shifted the data symbol +4). Solve the overlap before shipping NAKED.

## Best-effort C (sub_080063EC matches byte-for-byte; sub_08006516 is byte_diff 4)

```c
#include "iwram.h"
#include "macros.h"
#include "types.h"
#include "gba/dma.h"

#define OBJ_PLTT_BASE 0x05000200
#define OBJ_VRAM_BASE 0x06010000

struct SpriteAnim {
    const void *frames; /* +0x00 */
    const void *pltt;   /* +0x04 */
    u8 _pad08;
    u8 shapeA; /* +0x09 (u8 load; switch range-checks signed) */
    u8 shapeB; /* +0x0A */
    u8 _pad0B;
};
struct SpriteFrame {
    u8 _pad00[4];
    const void *tiles; /* +0x04 */
    u8 _pad08[8];
};
typedef struct SpriteAssetEntry {
    u32 id;
    const void *anims;
} SpriteAssetEntry;
extern const SpriteAssetEntry sSpriteAssetTable[];

#define ENTITY_ANIM(e) (((const struct SpriteAnim *)sSpriteAssetTable[(e).field_00].anims)[(e).field_1A])

void sub_080063EC(u32 slot)
{
    register volatile DmaChannel *dma asm("r4"); /* keeps count(r3)/dma2(r4) colouring */
    s32 shape;
    s32 size;
    u32 count;

    gEntities[slot].status |= 0x400;

    REG_DMA3.src = ENTITY_ANIM(gEntities[slot]).pltt;
    REG_DMA3.dst = (void *)(OBJ_PLTT_BASE + gEntities[slot].field_16 * 32);
    REG_DMA3.cnt = DMA_ENABLE | 0x10;
    (void)REG_DMA3.cnt;

    shape = ENTITY_ANIM(gEntities[slot]).shapeA;
    size = ENTITY_ANIM(gEntities[slot]).shapeB;

    switch (shape) {
    case 0:
        switch (size) {
        case 0: count = 0x20; break;
        case 1: count = 0x80; break;
        case 2: count = 0x200; break;
        case 3: count = 0x800; break;
        default: goto shape12;
        }
        break;
    case 1:
    case 2:
    shape12:
        switch (size) {
        case 0: count = 0x40; break;
        case 1: count = 0x80; break;
        case 2: count = 0x100; break;
        case 3: count = 0x400; break;
        default: count = 0xFFFF; break;
        }
        break;
    default: count = 0xFFFF; break;
    }

    count <<= 16;

    dma = &REG_DMA3;
    dma->src = ((const struct SpriteFrame *)ENTITY_ANIM(gEntities[slot]).frames + gEntities[slot].field_1B)->tiles;
    dma->dst = (void *)(OBJ_VRAM_BASE + gEntities[slot].field_14 * 32);
    count >>= 17;
    dma->cnt = DMA_ENABLE | count;
    (void)dma->cnt;
}

/* sub_08006516: dead clone @ 0x08006516. size = (u8)((shapeArg<<24)<<24) (==0),
   ignores 2nd arg. old_agbcc folds the provably-zero size -> byte_diff 4 (prologue). */
u32 sub_08006516(u8 shapeArg, u8 sizeArg)
{
    s32 shape = (u8)shapeArg;
    s32 size = (u8)sizeArg; /* baserom uses (u8)((shapeArg<<24)<<24), which folds in clean C */
    u32 count;

    switch (shape) {
    case 0:
        switch (size) {
        case 0: count = 0x20; break;
        case 1: count = 0x80; break;
        case 2: count = 0x200; break;
        case 3: count = 0x800; break;
        default: goto shape12;
        }
        break;
    case 1:
    case 2:
    shape12:
        switch (size) {
        case 0: count = 0x40; break;
        case 1: count = 0x80; break;
        case 2: count = 0x100; break;
        case 3: count = 0x400; break;
        default: count = 0xFFFF; break;
        }
        break;
    default: count = 0xFFFF; break;
    }
    return count;
}
```
