# sub_080112C0 — deferred analysis

Blit helper at 0x080112C0 (296 bytes). Copies a `cols x rows` block of u16
pixels from a triple-indexed ROM pointer table into one of three EWRAM banks,
then tail-calls sub_0801025C to flush the bank to VRAM (0x0600E000 /
0x0600E800 / 0x0600F000 selected by `bank`).

Args (all zero/sign-extended in the prologue):
- frame  (u8)  -> r9   : middle index into the cell table
- rows   (u8)  -> r8   : block height
- cols   (u8)  -> ip   : block width
- dstX   (u16) -> [sp,#12] (spilled): horizontal offset into the bank
- dstY   (u16) -> sl   : vertical offset (multiplied by stride)
- bank   (u8)  -> r5   : 0/1/2 selects EWRAM dst base + VRAM flush target
- cell   (u8)  -> r6   : innermost index into the cell table

Cell-table lookup (3 dependent loads):
  src = gFrameCellTable_08307EAC[(gGameStuff.pendingMode - 1) * 5][frame][cell]
The row stride is 20 bytes = 5 `u16**` entries per mode row.

Stride source: `*(u16 *)0x030060A0` offset 26 (`state->stride`), same IWRAM
blit-state struct used by the near-twin sub_08012BC4.

## Drift

Best reached: **byte_diff 28, diff_count 12** (structurally CORRECT — verified
dst stays in r7 through the loop, stride read from the saved state pointer in
r4, no aliasing). All 12 remaining diffs are a single tightly-coupled
register-coloring difference: the baserom uses **r0 and r6** as the dominant
back-half scratch registers (cell->dstX->cols-temp recycled through r6; the
src load flows r0 -> r9 -> r2 with a `mov r2, r9` round-trip), whereas agbcc
gives us r2/r3/r1 for the same temporaries.

Concrete residual diffs (target vs built):
- +0x7c  cell-deref `ldr r0,[r0]` then `mov r9,r0; mov r2,r9`  (we: `ldr r2,[r0]; mov r9,r2`, no round-trip)
- +0x8a  dstX read `ldr r6,[sp,#12]`                          (we: `ldr r3,[sp,#12]`)
- +0x92  extra `mov r6,r8` from our rowCount cache; baserom `cmp r0,r8` direct
- +0xb4  stride-temp `ldrh r1,[r4,#26]; mov r6,ip; subs r0,r1,r6` (we: r0/r1)
- +0x100 call src arg `mov r0,r9; str r0,[sp,#4]`             (we: `mov r2,r9; str r2,[sp,#4]`)

## Levers already tried (DO NOT repeat — pick a DIFFERENT one)

KEY FIXES that got us from 233 -> 28 (keep these):
- `switch (bank)` with **signed** `s32 bank` -> matches the baserom's
  `cmp/beq/cmp/bgt` binary-search switch with `bgt` (signed).
- Declared the cell table as a **linker-assigned symbol**
  `gFrameCellTable_08307EAC = 0x08307EAC;` (added to linker.ld) and a local
  `const u16 ****table = gFrameCellTable_08307EAC;` assigned BEFORE the
  gGameStuff read -> loads the table base into r2 ahead of the pendingMode
  read, matching baserom pool/register order (the documented
  gHandlerTable_08308028 idiom). This was the single biggest win.
- `register ... state asm("r1")` pin is REQUIRED for correctness: without it
  agbcc puts `state` in r7 and clobbers `dst` (the `dst += dstY*stride`
  computes off the state base instead of the EWRAM base — a real miscompile,
  byte_diff ~66 that LOOKS close but is wrong). Always verify `adds r7,r7,r0`
  adds to the EWRAM dst, not 0x030060A0.
- Do NOT pin `dst` to r7 — that triggers an agbcc local-alloc aliasing bug
  where `col` and `dst` both land in r7 (col=0 destroys dst, pixels written to
  address 0). Pin only `vram` to r7 (it reuses dst's register AFTER the loop);
  `dst` then floats to r7 naturally and the col loop is clean.
- Pin args: frame=r9, rows=r8, cols=ip, dstY=sl, bank=r5 (required — high regs
  come from the prologue). src=r2 (loop source). stride=r3, row=r0,
  nextRow=r3. loopState=r4 INSIDE the row loop (`= state` each iteration ->
  baserom's `adds r4,r1,#0`); cell UNPINNED (pinning it to r6 forces the
  destructive `lsls r6,r6,#2` cell-scaling).
- rowCount cache: outer `if (row < rowCount)` + inner `while (row < rows)`
  (rowCount = rows) -> 28. The other three combinations are worse (86/30/33).

FAILED levers (waste of time to retry):
- dstX `asm("r6")` pin: size 284-292, conflicts with cell's r6 liveness.
- col `asm("r1")` pin: conflicts with state(r1), 81-237 byte_diff.
- Hoisting loopState into the row-loop PREHEADER (C-level): size 292, breaks
  the `r4=state` shape (must stay inside the do-while body).
- Re-deriving src from frame (`frame=(u32)...; src=(const u16*)frame`) to force
  the `mov r2,r9` round-trip: 300/146 or no-op.
- Reordering `dst += dstX + dstY*stride` operands: agbcc commutes, no change.
- Per-TU CFLAGS: tried -fforce-addr/-fno-expensive-optimizations (304),

  rerun-cse-after-loop,force-mem,function-cse,peephole,thread-jumps,
  delayed-branch}, -fcaller-saves, -O1, CC=old_agbcc -> ALL still 28 (no flag

- Permuter (3 runs, ~3 min, across the 89/33/28 bases): base score 260-295,
  best ~255-280. It only ever suggested the rowCount placement (already

## Next ideas (untried)

- The unifying need is to make agbcc prefer r0/r6 as back-half scratch over
  r2/r3. Consider whether `src` should NOT be pinned at all and instead the
  loop pointer derived so agbcc keeps src in r0 until the `mov r2,r9` reload —
  but every reorder of the table-lookup block regressed the (matching) table
  base ordering, so this needs the lookup kept verbatim while only the
  src-handoff changes.
- The baserom `mov r2,r9` round-trip strongly implies the original source
  reuses the `frame` parameter variable to carry src across the stride/dst
  setup and only materializes the loop pointer (r2) right before the loop —
  but doing that at C level moved the table base load (regression). A version
  that splits the table lookup so the `[cell]` deref is the LAST thing before
  the loop (keeping the base-anchor intact) might reproduce it.

## Best-effort C (byte_diff 28, structurally correct)

Requires `gFrameCellTable_08307EAC = 0x08307EAC;` in linker.ld.

```c
#include "game.h"
#include "macros.h"
#include "types.h"

extern void sub_0801025C(u32 rows, u32 cols, u32 dstX, u32 dstY, u32 bank, const u16 *src, u16 *vram);
extern const u16 ***gFrameCellTable_08307EAC[];

struct BlitState {
    u8 _pad00[26];
    u16 stride;
};

void sub_080112C0(u32 frameArg, u32 rowsArg, u32 colsArg, u32 dstXArg, u32 dstYArg, u32 bankArg, u32 cellArg)
{
    register u32 frame asm("r9");
    register u32 rows asm("r8");
    register u32 cols asm("ip");
    u32 dstX;
    u32 rowCount;
    register u32 dstY asm("sl");
    register s32 bank asm("r5");
    u32 cell;
    u16 *dst;
    register const u16 *src asm("r2");
    register struct BlitState *state asm("r1");
    register u16 stride asm("r3");
    register u32 row asm("r0");
    register u32 nextRow asm("r3");
    register u16 *vram asm("r7");

    frame = (u8)frameArg;
    rows = (u8)rowsArg;
    cols = (u8)colsArg;
    dstX = (u16)dstXArg;
    dstY = (u16)dstYArg;
    bank = (u8)bankArg;
    cell = (u8)cellArg;

    switch (bank) {
    case 0: dst = (u16 *)0x02000000; break;
    case 1: dst = (u16 *)0x02010000; break;
    case 2: dst = (u16 *)0x02020000; break;
    }

    {
        const u16 ****table = gFrameCellTable_08307EAC;
        u32 idx = gGameStuff.pendingMode - 1;
        const u16 **frameTable = table[idx * 5][frame];
        src = frameTable[cell];
    }
    frame = (u32)src;

    state = (struct BlitState *)0x030060A0;
    stride = state->stride;
    dst += (dstX + dstY * stride);

    rowCount = rows;
    row = 0;
    if (row < rowCount) {
        register struct BlitState *loopState asm("r4") = state;

        do {
            u8 col;

            col = 0;
            nextRow = row + 1;
            if (col < cols) {
                do {
                    *dst++ = *src++;
                    col++;
                } while (col < cols);
            }
            dst += loopState->stride - cols;
            row = (u8)nextRow;
        } while (row < rows);
    }

    switch (bank) {
    case 0: vram = (u16 *)0x0600E000; break;
    case 1: vram = (u16 *)0x0600E800; break;
    case 2: vram = (u16 *)0x0600F000; break;
    }

    sub_0801025C(rows, cols, dstX, dstY, bank, (const u16 *)frame, vram);
}
```
