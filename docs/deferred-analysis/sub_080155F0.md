### The recipe (this is the load-bearing discovery)
1. **Model the selector as a struct OVERLAY over the `gEntities` SYMBOL**, not a
   raw-address cast. `#define gSceneSel (*(struct SceneSel *)gEntities)` where
   `struct SceneSel { u8 _pad[0xb70]; union { s16 s; u16 u; } sel; };`.
   - extern SYMBOL base → agbcc emits `ldr =gEntities; movs #0xb7; lsls #4; adds`
     (arithmetic, matches). A raw-address cast `(struct*)0x03003720` or a
     `(u8*)0x03003720 + 0xb70` CONSTANT-FOLDS to `.word 0x03004290` (wrong).
   - the `union { s16 s; u16 u; }` gives the SIGNED read1 (`gSceneSel.sel.s` →
     `ldrsh`) and the UNSIGNED read2 (`gSceneSel.sel.u` → `ldrh`) from the same
     field. `*(u16*)&gSceneSel.sel` instead FOLDS read2 to `.word base+0xb70`.
2. **Explicit `if (gSceneSel.sel.s == 0) src=low; else src=high;`** (NOT the
   ternary, NOT `!= 0`).
   - `== 0` → `bne →high`, LOW on the fall-through (matches target branch sense).
   - explicit if/else → low/high stored DIRECTLY (`str r4`/`str r3`); the ternary
     funnels through one reg AND hoists read2 above the DMA (the old CSE hold).
   - reading `gSceneSel.sel.s` TWICE at source level (compare + inner if) is what
     produces the `adds r0,r1,#0` sel-copy. A pre-read `s16 sel = …` local kills
     the copy (`cmp r1,#0` direct).
3. **`-fno-gcse` on this TU** (`src/engine/sub_080155f0.s: CFLAGS += -fno-gcse`).
   This is the UNIQUE sweet spot: it makes the entity-ptr live in caller-saved
   r2 (dies immediately → recompute, narrow prologue). Plain -O2 keeps the base
   in callee-saved r7 (CSE hold, `push {r4,r5,r6,r7,lr}`, recompute via the hold).
   ANY other flag added alongside (-fno-schedule-insns, -fno-regmove,
   -fno-strength-reduce, -fcaller-saves, -O1/-O3, the newer AGBCC_BIN, …) RE-widens
   the prologue. -fno-gcse ALONE.
4. Register pins are NOT needed — agbcc naturally picks low=r4, high=r3, cache=r5.
5. The tail's `gEntities + 0x1a60` / `+0x1a5b` need the SAME struct-overlay trick
   to materialise arithmetically (`movs #0xd3; lsls #5; adds` for 0x1a60).
