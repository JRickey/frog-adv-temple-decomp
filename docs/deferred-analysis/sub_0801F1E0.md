# sub_0801F1E0 — deferred (near-match, byte_diff 24 / 568)

Save-slot summary drawer. Iterates the 4 save slots (`i = 0..3`); for each
populated slot (bit `i` set in `gSaveData.header.slotMask`) it builds an OAM
attribute word, draws the slot name + two numeric fields + a completion
percentage via the text helpers; for empty slots it draws a placeholder.

`VERDICT: ATTEMPT_MATCH` (classify_unmatchable). NOT NAKED-eligible — the body
is clean readable C and matches 564/568 bytes. The residual 24 bytes are two
agbcc register-coloring / operand-canonicalization minima that no source shape
or `-fXXX` flag in the OLD_AGBCC surface steered, and the decomp-permuter
`.venv` is absent on this checkout (main lacks it), so the last-mile mutation
lever was unavailable.

## Key facts nailed down (reuse these on the next attempt)
- `attr` is a `u32` OAM-attribute local at `[sp+16]`; built with the same
  mask-chain idiom as `sub_0801F8BC` (`(attr & 0xffffff00) | 2`, etc.).
- DMA fill of screenblock 0x0600f000: `*(vu16 *)&dmaSrc = 0;` (the **volatile**
  store is load-bearing — it forces address-first eval and dropped byte_diff
  207 -> 25 in one step), `REG_DMA3.src = &dmaSrc; REG_DMA3.dst =
  (void*)0x0600f000; REG_DMA3.cnt = 0x81000400;` then a dummy read. `cnt` is the
  literal `0x81000400` (bit 24 has no dma.h macro — sibling `sub_0801b154.c`
  uses the same literal); `DMA_ENABLE | 0x400` is WRONG (gives 0x80000400).
- Slot record stride 12 = `gSaveData.slots[i]`; fields read are `._field5`
  (+13), `._field6` (+14), `._field0` (+0 word), `.name` (+8).
- Field6 dispatch: `>99 -> C2B4(...,18,...)`, `>9 -> C2B4(...,19,...)`,
  else `C2B4(...,20,...)`. Each branch RELOADS `_field6` (don't cache it).
- Percentage: `percent = (u8)((100 * sub_0801B188(slot._field0)) >> 4);`
  `>> 4` MUST be arithmetic (`asr`) -> the product stays signed `int`.
  Branch must be `if (percent != 100) { CF18(...,23,...) } else { C2B4(100,22,...) }`
  (gives baserom's `beq` to the C2B4 block).
- The second-mask byte must be staged through a temp:
  `tile = (u16)(((i << 2) + 3) << 8); attr = (attr & 0xffff00ff) | tile;`
  (writing it inline lets agbcc schedule the `& 0xffff00ff` before the byte;
  the temp forces byte-first and matched that whole block). `col = (u8)((i<<2)+4)`.
- `attrPtr`/`&attr` must NOT be an explicit local — letting agbcc auto-CSE
  `&attr` into `[sp+24]` matches the prologue ordering (`i=0` before the
  `&attr` materialization). An explicit `attrPtr = &attr;` reorders the
  prologue and regresses (47).
- Empty branch uses `gIwram_3480._unk14 == i` gate and
  `sub_080196EC(&attr, (const void *)((const u32 *)0x08308EF4)[gIwram_34B0._data], 2)`.

## Drift (the 24 residual bytes, both register-coloring)
1. **+0x168/+0x16b (2 bytes) — `100 * funcret` multiply operand order.**
   baserom: `lsls r0,#24; lsrs r1,r0,#24` (truncated bitIdx -> r1), `movs r0,#100;
   mul r0,r0,r1`. Built: truncates into r0, `movs r1,#100; mul r0,r0,r1`.
   agbcc canonicalises the commutative `(mult reg const)` with the CONST last,
   so the call-result reg becomes `rd`; baserom loads 100 into `rd` and keeps
   bitIdx in `rs`. Tried (all byte_diff 24, no change): `x*100`, `(s32)x*100`,
   `x*0x64`, separate `int bitIdx` / `u8 bitIdx` locals, two-step
   `u32 product = 100*x;`. Pinning `register u8 bitIdx asm("r1")` REGRESSED to 201.
2. **+0x1da..+0x1eb, +0x22c..+0x233 (22 bytes) — empty-branch eval order.**
   baserom computes `col` (value) THEN `add r4,sp,#16` (the `((u8*)&attr)[1]`
   store address, reused as the 196EC arg); built computes `add r4` first.
   AND baserom loads the table const `0x08308ef4` into r1 BEFORE the index
   `gIwram_34B0._data` (so the literal pool orders table-then-ptr); built
   evaluates the memory-index first (pool ptr-then-table -> the +0x22c..0x233
   word swap). agbcc consistently evaluates the memory index before a constant
   base for `const_base[mem_index]`, independent of source form. Tried (no
   change / regressions): `const void *src=` temp (52), `u32 idx=` temp (24),
   fresh `u8 y=` temp for col (122), assigning the shared `col` (107),
   `*(const u32*)(0x08308EF4 + idx*4)` (24), function-scope `progressTable`
   pointer hoist (24), swapping the two byte-store statements (24), `vu8` byte
   stores (25). `-fforce-addr/-fforce-mem/-fno-gcse/-fno-cse-*` all 24.
