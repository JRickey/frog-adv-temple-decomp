# sub_08005D10 — deferred analysis

Entity-pool animation-advance loop at 0x08005d10..0x08005ed8 (456 bytes,
asm slice asm/disasm_0x08005d10.s, dest src/game/sub_08005d10.c).

## What it does (confirmed)

`void sub_08005D10(s32 slot, s32 endSlot)` — iterates the entity pool
`gEntities[slot..endSlot]` (stride 0x38) advancing each entity's animation
frame. Cousin function: `sub_08020F3C` (src/engine/sub_08020f3c.c), which
shares the exact subsystem (sub_08006830 bitmask gate, gEntities, the
gGameStuff._unk00 stamp, the 0x2c/0x20 stamp field) and MATCHES — read it for
the idioms.

- Gate: `if (sub_08006830(&gIwram_6110, slot, endSlot) == 0) return;`
  sub_08006830 returns a 64-bit bitmask; the baserom tests the LOW word
  sign-extended (`asrs r1,r0,#31; orrs r0,r1`). REPRODUCED by declaring the
  callee `extern s32 sub_08006830(...)` (NOT long long) in this TU and assigning
  to an `s64` local before the `== 0` test — the s32->s64 widen-on-assign emits
  exactly `asr r1,r0,#0x1f; orr r0,r0,r1` in r0:r1. (Declaring it `long long`
  gives `orr r0,r0,r1` using the real high word — 1 insn, wrong.)
- `now = gGameStuff._unk00;` held in `sl` (agbcc allocates sl naturally; no pin
  needed).
- Loop body per entity `e`:
  - status bit 2 set: load AnimDesc = sSpriteAssetTable[e->field_00].ptr +
    e->field_1A*12; copy the 16-byte frame `*desc->frames`; set field_1C[0]=
    frameCount, field_18[1]=sub_08005ED8(state,dir), field_18[0]=
    sub_08005F50(state,dir), field_1B=0; apply frame deltas (x+=dx, y+=dy,
    field_24, field_26, field_28, field_29, field_1C[1]=delay); stamp=now;
    status = (status|0x100)&0xFFFD.
  - status bit 2 clear AND (now - stamp) < field_1C[1]: status &= 0xFEFF.
  - else: nextFrame = field_1B+1; if == field_1C[0] set status|=0x8000, else
    advance to frame nextFrame (same delta-apply as above) + status|=0x100;
    stamp = now.

Types defined inline (promote to a header on the matching pass):
`SpriteAssetEntry {u32 id; const u8 *ptr}` (== sSpriteAssetTable in
src/data/sprite_asset_table.c), `AnimDesc {const u8 *frames; u32 _unk04;
u8 frameCount; u8 state; u8 dir}` (12 B), `AnimFrame` (16 B: dx,dy@0/1,
delay@8, field_09@9, field_0A@0xa, field_0C@0xc, field_0E@0xe, field_0F@0xf).

The structure is FULLY CORRECT — induction vars match the baserom exactly
(r9=i +1, r8=offset +0x38, r5=entity ptr +0x38, [sp,#20]=field28 ptr +0x38;
the stamp uses a SECOND symbol `gEntities_03003720` so `-fno-gcse` keeps the
three per-branch pool loads separate, matching baserom).

## Drift

Best: **byte_diff 261, diff_count 48** (per-TU `CFLAGS += -fno-gcse`).
The whole logic/control-flow/struct-layout is right; the residual is THREE
agbcc instruction-selection / register-coloring local minima that no source
rewrite (~25 tried) flipped:

1. **`symbol + 0x20` constant-fold (the stamp store, 3 sites).** Baserom keeps
   the BARE `gEntities_03003720` pool literal (0x03003720) and adds `#0x20` at
   runtime (`adds r0,#32; add r0,r8; str sl,[r0]`). agbcc ALWAYS folds
   `symbol + const` into the pool literal (0x03003740), dropping the `adds #32`.
   Verified unfixable inline: `[i].field`, `(u32)sym + 0x20 + off`,
   `stampBase = sym + 0x20`, grouped `(off + 0x20)`, and a separate
   `u32 stampOff = offset + 0x20;` var all either still fold or break the
   per-branch reload. The cousin (sub_08020F3C) escapes this only because it is
   NOT a loop — its `base` is a single hoisted register; here baserom reloads
   the bare symbol per branch. Contributes 3 wrong pool words + 3 missing
   `adds` + BL-offset cascade.

2. **field28/e preheader ordering.** Baserom computes field28 first as
   `(offset + 0x28) + base` REUSING the strength-reduced offset still live in r0
   right after `mov r8, r0`, then e = `base + offset` via the high-reg add
   `adds r5,r1,#0; add r5,r8`. agbcc instead reloads base into r0 (clobbering
   offset), computes e = base+offset first, then field28 = e+0x28 with an extra
   copy. Tried: field28-first (`base+(offset+0x28)`, `(u8*)(offset+0x28)+(u32)base`,
   split-statement `u32 f=offset+0x28`), e split into base-then-+=offset — all
   either reassociate or emit `subs #40` to recompute e. The offset-lingers-in-r0
   behavior is a loop.c strength-reduce + local-alloc scheduling artifact not
   reachable from C.

3. **Asset-table-base register coloring (r3 vs r4) cascade.** Baserom colors the
   AnimDesc lookup temps r2(field_00)/r3(asset base)/r4(field_1A->desc); agbcc
   shifts to r3/r4/r7, forcing an extra `adds r2,r7,#0` to preserve field_1A and
   `ldr r4` where baserom has `ldr r1`. Downstream of #2's register pressure.

Levers tried that did NOT help: every per-TU flag combo (`-fforce-addr`,
`-fno-expensive-optimizations` both made it 453; `-fno-strength-reduce`,
`-fno-schedule-insns`, `-finline-functions` no change from 261);
`register now asm("sl")` pin (agbcc picks sl anyway — dropped); base2 local for
the second symbol (hoisted → 380); `e->field_28` direct vs cached field28 ptr
(339, baserom caches). Permuter NOT attempted: byte_diff 261 is far above its
~40 effective range, AND the worktree permuter venv is missing the `attr` dep.

Next pass: this is a genuine coloring/folding plateau, not a structural miss.
The path forward is (a) reduce byte_diff into permuter range by cracking #2
(read tools/agbcc-src/gcc_arm/loop.c strength-reduction + local-alloc.c to see
why offset is not kept live in r0), then (b) permuter from there. Or instrument
a private debug agbcc to watch the reload choice at the field28/stamp sites.

#include "game.h"
#include "iwram.h"
#include "macros.h"
#include "types.h"

extern s32 sub_08006830(struct IwramAt6110 *p, s32 lo, s32 hi);
extern u8 sub_08005ED8(u8 state, u8 dir);
extern u8 sub_08005F50(u8 state, u8 dir);

/* Each 8-byte sSpriteAssetTable entry is {u32 id, u8 *ptr}; ptr points at an
 * array of 12-byte AnimDesc records indexed by the entity's animation id. */
typedef struct SpriteAssetEntry {
    u32 id;
    const u8 *ptr;
} SpriteAssetEntry;
extern const SpriteAssetEntry sSpriteAssetTable[];

extern struct Entity gEntities_03003720[];

/* A descriptor record (12 bytes). */
typedef struct AnimDesc {
    const u8 *frames; /* +0x00: stream of 16-byte frame records */
    u32 _unk04;       /* +0x04 */
    u8 frameCount;    /* +0x08 */
    u8 state;         /* +0x09 */
    u8 dir;           /* +0x0A */
} AnimDesc;

/* One 16-byte animation frame. */
typedef struct AnimFrame {
    s8 dx;        /* +0x00 */
    s8 dy;        /* +0x01 */
    u8 _pad02[6]; /* +0x02..+0x07 */
    u8 delay;     /* +0x08 */
    u8 field_09;  /* +0x09 */
    u16 field_0A; /* +0x0A */
    u16 field_0C; /* +0x0C */
    u8 field_0E;  /* +0x0E */
    u8 field_0F;  /* +0x0F */
} AnimFrame;

void sub_08005D10(s32 slot, s32 endSlot)
{
    struct Entity *e;
    u8 *field28;
    u8 *base;
    u32 offset;
    u32 now;
    s32 i;
    AnimFrame frame;

    {
        s64 ret = sub_08006830(&gIwram_6110, slot, endSlot);
        if (ret == 0)
            return;
    }

    now = gGameStuff._unk00;
    i = slot;
    if (i > endSlot)
        return;

    offset = i * 0x38;
    base = (u8 *)gEntities;
    field28 = base + offset + 0x28;
    e = (struct Entity *)(base + offset);
    do {
        if ((e->status & 2) != 0) {
            const AnimDesc *desc = (const AnimDesc *)(sSpriteAssetTable[e->field_00].ptr + e->field_1A * 12);

            frame = *(const AnimFrame *)desc->frames;
            e->field_1C[0] = desc->frameCount;
            e->field_18[1] = sub_08005ED8(desc->state, desc->dir);
            e->field_18[0] = sub_08005F50(desc->state, desc->dir);
            e->field_1B = 0;

            e->field_01 = frame.field_09;
            e->x += frame.dx;
            e->y += frame.dy;
            e->field_24 = frame.field_0A;
            e->field_26 = frame.field_0C;
            field28[0] = frame.field_0E;
            field28[1] = frame.field_0F;
            e->field_1C[1] = frame.delay;
            *(u32 *)((u8 *)gEntities_03003720 + offset + 0x20) = now;
            e->status = (e->status | 0x100) & 0xFFFD;
        } else if (now - *(u32 *)((u8 *)gEntities_03003720 + offset + 0x20) < e->field_1C[1]) {
            e->status &= 0xFEFF;
        } else {
            u8 nextFrame = e->field_1B + 1;

            if (nextFrame == e->field_1C[0]) {
                e->status |= 0x8000;
            } else {
                const AnimDesc *desc;

                e->field_1B = e->field_1B + 1;
                desc = (const AnimDesc *)(sSpriteAssetTable[e->field_00].ptr + e->field_1A * 12);
                frame = ((const AnimFrame *)desc->frames)[nextFrame];

                e->field_01 = frame.field_09;
                e->x += frame.dx;
                e->y += frame.dy;
                e->field_24 = frame.field_0A;
                e->field_26 = frame.field_0C;
                field28[0] = frame.field_0E;
                field28[1] = frame.field_0F;
                e->field_1C[1] = frame.delay;
                e->status |= 0x100;
            }
            *(u32 *)((u8 *)gEntities_03003720 + offset + 0x20) = now;
        }

        offset += 0x38;
        field28 += 0x38;
        e = (struct Entity *)((u8 *)e + 0x38);
        i++;
    } while (i <= endSlot);
}
