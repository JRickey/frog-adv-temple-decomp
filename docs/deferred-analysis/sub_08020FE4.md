## ROOT CAUSE (new this round — the prior note only said "coloring")

The entire residual is the **reload-pass round-robin scratch register** for
materializing high regs into low regs, desynced by the `flags asm("ip")` pin.
This is exactly `docs/codegen-notes.md` §"`register asm("ip")` pin can DESYNC
reload's round-robin (sub_08032094)".

The target keeps `&gIwram_35E0` in `ip` across the loop and re-materializes it
each iteration with **real reloads** (`mov r5, ip`, `mov r7, ip`,
`mov r7, r8`), alternating r5/r7 — `allocate_reload_reg` (reload1.c) picks
spill regs round-robin from `last_spill_reg`, and each genuine reload advances
the pointer one step, producing the r5/r7/r5/r7 spread + the y-temp/field_D/
gGameStuff temps in r7.

My C cannot reproduce this:
- WITH `flags asm("ip")`: the per-iter `mov rX, ip` becomes an allocator COPY
  (`movsi_insn`), which does NOT advance `last_spill_reg`. Every downstream
  reload register rotates by one → the materializations land on r0 (and the
  y-temp on r5) instead of r7. byte_diff 20.
- WITHOUT the pin (plain `struct IwramAt35E0 *flags`): agbcc has enough low-reg
  headroom at the flags-read point (r0/r5 are free after the x/y updates) to
  keep flags in a LOW reg (r5), so it never uses `ip` at all → no reload, and
  gGameStuff migrates into `ip` instead of r8. byte_diff 110–164.

So the target's natural "flags in ip + per-iter reload" behavior depends on a
register-pressure profile agbcc-via-this-C does not hit: my coloring always
leaves a low reg free for flags, so the pin is the only way to force ip — and
the pin is precisely what desyncs the round-robin. Catch-22.

## The residual diffs at byte_diff 20 (all one root cause)

- `off` → r7 instead of target r3 (0x26,0x2c,0x34): a knock-on of xyPtr being
  pinned r3 (the pin reserves r3 for xyPtr's whole inner-block range, so off —
  whose live range overlaps the loop-pointer setup — can't take r3). off and
  xyPtr DO coalesce into r3 in the target (off dies as xyPtr is born), but
  every attempt to force that here (`off asm("r3")` and/or unpinning xyPtr)
  drops a callee-saved save (r7 or r8) from the prologue or moves gsHi off r8.
- loop-setup operand order (0x4a-0x52): `(mover+const)+off` vs target
  `(off+const)+mover` — minor reassociation, follows the off-register choice.
- y-temp r5 vs r7 (0x66,0x68); field_D `mov r0,ip` vs `mov r7,ip`
  (0x78-0x7c); gEntities[0].y r0 vs r5 (0x86-0x8a); gGameStuff `mov r1,r8`
  vs `mov r7,r8` (0x8c,0x8e) — all the reload round-robin desync.

## Levers ruled out this round (so the next agent picks a DIFFERENT one)

- `off asm("r3")` (alone): byte_diff 164 — collapses the prologue save set
  (drops r8/r7); `find_free_reg` walks REG_ALLOC_ORDER {r3,r2,r1,r0,ip,lr,
  r4,r5,r6,r7,...} so a pre-loop r3 pin reshapes the global decisions.
- `off asm("r3")` + `gsHi asm("r8")` + `xyPtr asm("r3")`: byte_diff 26–30 —
  off lands in r3 correctly BUT the gsHi→r8 pin drops pressure so r7 is never
  saved/used; loop scratch then uses r0/r5 not r5/r7.
- unpin xyPtr (+gsHi r8): byte_diff 37 — off→r3 but xyPtr→r5 (no coalesce),
  r7 not saved.

  byte_diff 22 — the C var lands in r7 but the `mov rX, ip/r8` RELOAD that
  feeds it still uses r0 (reload scratch is not the C variable), and it
  pushes the dx-temp off r5.
- plain `flags` + `gsHi asm("r8")`: byte_diff 110 — flags never uses ip.

extern long long sub_08006830(struct IwramAt6110 *p, s32 a, s32 b);

void sub_08020FE4(s32 start, s32 end)
{
    register EntityMover *base asm("r5");
    GameStuff *gsLo;
    GameStuff *gsHi;
    register s32 idx asm("r4");
    register s32 last asm("r9");
    u32 off;
    u32 arg8;
    u32 elapsed;
    u8 interval;

    idx = start;
    last = end;
    if (sub_08006830(&gIwram_6110, idx, last) == 0)
        return;

    gsLo = &gGameStuff;
    base = (EntityMover *)gEntities;
    arg8 = idx << 3;
    off = (arg8 - idx) << 3;

    {
        u8 *stampBase = (u8 *)base + 0x2c;
        elapsed = gsLo->_unk00 - *(u32 *)(off + (u32)stampBase);
    }

    interval = *(u8 *)((off + (u32)base) + 0x32);
    gsHi = gsLo;
    if (elapsed < interval)
        return;
    if (idx > last)
        return;

    {
        register EntityMover *mover asm("r6");
        register u32 *stampPtr asm("r2");
        register struct IwramAt35E0 *flags asm("ip");
        register u16 *xyPtr asm("r3");

        mover = base;
        flags = &gIwram_35E0;
        stampPtr = (u32 *)((off + 0x2c) + (u32)mover);
        xyPtr = (u16 *)((off + 2) + (u32)mover);

        do {
            register s32 dx asm("sl");
            register s32 dy asm("r1");

            dy = ((u8 *)stampPtr)[5];
            dx = ((s8 *)stampPtr)[4];
            xyPtr[0] += dx;
            dy = (dy << 24) >> 24;
            xyPtr[1] += dy;

            {
                u32 active;

                active = 2;
                active &= flags->_field_10;
                if (active != 0 && idx == flags->_field_D) {
                    mover->x += dx;
                    mover->y += dy;
                }
            }

            *stampPtr = gsHi->_unk00;
            stampPtr = (u32 *)((u32)stampPtr + 0x38);
            xyPtr = (u16 *)((u32)xyPtr + 0x38);
            idx++;
        } while (idx <= last);
    }
}
