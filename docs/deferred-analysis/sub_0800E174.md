# sub_0800E174 — deferred analysis

Per-slot tile blitter at 0x0800E174 (840 bytes). Lives in
`src/engine/sub_0800e060.c`, after `sub_0800E060`. Dispatched from
`sub_0800E6A8`.

## What it does (fully decoded — semantics are correct, only register
coloring blocks the match)

Loops `idx = 0..4` over five control bytes at `0x03005370` (stride 4,
written by `sub_0800E060` as [0]=1,[4]=3,[8]=1,[12]=9,[16]=9). Each
control byte's high bit (0x80) = "already drawn / skip"; its low nibble
selects a blit mode for the matching 12-byte FrameDescriptor record
{u16 x; u16 y; u16 w; u16 h; const u16 *tile_data}. The record array is
`((const FrameDescriptor *const *)0x08306824)[gIwram_34B0._data]`
(= sSpriteAnimFrameSet_06824[...]). Records for index 0 live at
0x080C1128.

Blit shape per record (into OBJ-VRAM screenblock 31, 0x0600F800):
  dst = 0x0600F800; for (n=0;n<rec.y;n++) dst += 32;     /* row-skip LOOP, NOT y<<5 */
  for (row=0; row<rec.w; row++) {
      dst += rec.x;
      for (col=0; col<rec.h; col++) *dst++ = <tile>;
      dst += 32 - rec.x - rec.h;
  }

Modes (low nibble):
  1: tile = *src++;                       then ctrl[idx*4] |= 0x80
  2: tile = *src++ & 0xEFFF;              then ctrl[idx*4] |= 0x80
  3: gated on (gGameStuff._unk04 & 7)==0; tile = *src++; *dst = tile;
     if ((_unk04 & 0xF)==0) *dst = tile & 0xEFFF;   (no skip-bit set)
  9: tile = 0xF039 (blank);              then ctrl[idx*4] = 0
  default / 0x80 set: skip.

After the loop: if `*(u8*)0x03005328 == 0`, DMA3 halfword-fill 0x400
halfwords of 0x0600F800 with 0 (from a stack-local seed; cnt
0x81000400 = DMA_ENABLE|DMA_SRC_FIXED|0x400), then call sub_08016A40().

### Root cause (confirmed by instrumenting agbcc global.c `find_reg`)

Built a private `old_agbcc` with an fprintf at the
`reg_renumber[...] = best_reg` site. For sub_0800E174:
  - records base  -> pseudo 22, n_refs 32 -> **r8**  (MATCHES baserom)
  - idx           -> pseudo 23, n_refs 45 -> **r9**  (baserom wants sl)
  - idx*4 (ctrl off) -> pseudo 216, n_refs 14 -> **ip** (baserom SPILLS to sp+16)

`find_reg` iterates hard regs in NUMERIC order (`for (i=0; i<FIRST_PSEUDO_REGISTER; i++)`),
NOT in REG_ALLOC_ORDER — so it grabs the lowest-numbered FREE callee-saved
reg. When idx (pseudo 23) is allocated, r9 is free, so it takes r9 (9 < sl=10).
In the baserom, r9 was already consumed by a higher-priority case-body
scratch value, so idx fell through to sl(10) and idx*4 had no register left
(=> spilled, giving the baserom's `sub sp, #20` vs our `sub sp, #16`).

The baserom case bodies therefore hold MORE values live in high regs across
their inner loops (case2 caches sl*2 in r9 and 0xEFFF in ip; case3 caches
0xEFFF in r9), raising register pressure enough that idx->sl, idx*4->stack.
Reproducing that exact per-case high-reg pressure profile is what's needed.

## Best-effort C

```c
typedef struct {
    u16 x;
    u16 y;
    u16 w;
    u16 h;
    const u16 *tile_data;
} FrameDescriptor;

extern const FrameDescriptor *const sSpriteAnimFrameSet_06824[];

/* Per-slot tile blitter into OBJ-VRAM screenblock 31 (0x0600F800). The five
 * control bytes at 0x03005370 (stride 4, written by sub_0800E060) each select
 * a blit mode for the matching FrameDescriptor record; bit 0x80 marks a slot
 * already drawn. Records come from the 0x080C1xxx descriptor array selected by
 * gIwram_34B0._data. After the loop, an empty handshake byte at 0x03005328
 * triggers a full VRAM clear + sub_08016A40().
 *
 * Mode 1: blit verbatim.
 * Mode 2: blit each tile masked with 0xEFFF (clear the palette-bank-high bit).
 * Mode 3: gated on (gGameStuff._unk04 & 7) == 0; blits verbatim, and when
 *         (gGameStuff._unk04 & 0xF) == 0 re-stores the masked tile.
 * Mode 9: fill the rect with the blank tile 0xF039, then reset the slot byte.
 *
 * Matching note: the row advance to the record's y origin is a `dst += 32`
 * count-up loop (not a `y << 5` shift), and the per-row x indent is re-added
 * inside the outer loop so the trailing skip is `32 - x - h`.
 */
void sub_0800E174(void)
{
    const FrameDescriptor *records;
    u8 idx;

    records = sSpriteAnimFrameSet_06824[gIwram_34B0._data];

    for (idx = 0; idx <= 4; idx++) {
        u8 ctrl = ((u8 *)0x03005370)[idx * 4];

        if (ctrl & 0x80) {
            continue;
        }

        switch (ctrl & 0xF) {
        case 1: {
            const u16 *src = records[idx].tile_data;
            u16 *dst = (u16 *)0x0600F800;
            u16 row;
            u16 n;

            for (n = 0; n < records[idx].y; n++) {
                dst += 32;
            }
            for (row = 0; row < records[idx].w; row++) {
                u16 col;
                dst += records[idx].x;
                for (col = 0; col < records[idx].h; col++) {
                    *dst++ = *src++;
                }
                dst += 32 - records[idx].x - records[idx].h;
            }
            ((u8 *)0x03005370)[idx * 4] |= 0x80;
            break;
        }
        case 2: {
            const u16 *src = records[idx].tile_data;
            u16 *dst = (u16 *)0x0600F800;
            u16 row;
            u16 n;

            for (n = 0; n < records[idx].y; n++) {
                dst += 32;
            }
            for (row = 0; row < records[idx].w; row++) {
                u16 col;
                dst += records[idx].x;
                for (col = 0; col < records[idx].h; col++) {
                    *dst++ = *src++ & 0xEFFF;
                }
                dst += 32 - records[idx].x - records[idx].h;
            }
            ((u8 *)0x03005370)[idx * 4] |= 0x80;
            break;
        }
        case 3: {
            const u16 *src;
            u16 *dst;
            u16 row;
            u16 n;

            if ((gGameStuff._unk04 & 7) != 0) {
                break;
            }

            src = records[idx].tile_data;
            dst = (u16 *)0x0600F800;
            for (n = 0; n < records[idx].y; n++) {
                dst += 32;
            }
            for (row = 0; row < records[idx].w; row++) {
                u16 col;
                u32 lowMode = gGameStuff._unk04 & 0xF;
                u16 mask = 0xEFFF;
                dst += records[idx].x;
                for (col = 0; col < records[idx].h; col++) {
                    u16 tile = *src++;
                    *dst = tile;
                    if (lowMode == 0) {
                        *dst = tile & mask;
                    }
                    dst++;
                }
                dst += 32 - records[idx].x - records[idx].h;
            }
            break;
        }
        case 9: {
            u16 *dst = (u16 *)0x0600F800;
            u16 row;
            u16 n;

            for (n = 0; n < records[idx].y; n++) {
                dst += 32;
            }
            for (row = 0; row < records[idx].w; row++) {
                u16 col;
                dst += records[idx].x;
                for (col = 0; col < records[idx].h; col++) {
                    *dst++ = 0xF039;
                }
                dst += 32 - records[idx].x - records[idx].h;
            }
            ((u8 *)0x03005370)[idx * 4] = 0;
            break;
        }
        default:
            break;
        }
    }

    if (*(u8 *)0x03005328 == 0) {
        vu16 seed;
        vu32 *dma;

        seed = 0;
        dma = (vu32 *)0x040000D4;
        dma[0] = (u32)&seed;
        dma[1] = 0x0600F800;
        dma[2] = DMA_ENABLE | DMA_SRC_FIXED | 0x400;
        (void)dma[2];

        sub_08016A40();
    }
}
```

## Round 8 (Opus) — agbcc global-allocator instrumentation

Re-derived the C from scratch (did NOT tweak the prior near-match). Landed on

### The swap (confirmed exact)
  - baserom: records→r8, idx→**sl**, idx*4→**spilled (sp+16)**, idx+1→spilled
             (sp+12); r9/ip used by case-body helpers. `sub sp, #20`.
  - mine:    records→r8, idx→**r9**, idx*4→**ip**,  idx+1→spilled (sp+8).
             `sub sp, #16`. (One fewer spill slot — that is the ONLY frame
             delta; everything else is the idx/idx*4 register cascade.)

### NEW: built a private instrumented old_agbcc and dumped global_alloc
Copied tools/agbcc-src → /tmp, patched gcc/global.c to fprintf the post-qsort
`allocno_order` and every `reg_renumber[]=best_reg` assignment under
`getenv("AGBCC_DUMP_ALLOC")`, rebuilt `gcc/old_agbcc` with gcc-15
(`make -C gcc old CC=gcc-15 BASE_CFLAGS="-g -std=gnu11 -w -fcommon"`), compiled
ONLY this TU with it. (Recipe reusable; do NOT rebuild the shared symlinked
tools/agbcc-src.) For sub_0800E174 (block 2) the high-reg assignments are:
  - pseudo 22 (records) → r8,  refs=32 live_len=361  priority 0.443
  - pseudo 23 (idx)     → r9,  refs=45 live_len=676  priority 0.333
  - pseudo 216 (idx*4)  → ip,  refs=14 live_len=80   priority 0.525
  - pseudos 184/266 (case-2/3 idx*2 helpers) → sl, refs=5 live_len=45/47, prio 0.222

`allocno_compare` priority = `floor_log2(n_refs)*n_refs/live_length`.
**idx*4 (0.525) is the HIGHEST-priority high-reg pseudo and is allocated
FIRST; it takes ip via a copy-preference. records (0.443) takes r8. idx (0.333)
is allocated next and takes the lowest free callee reg = r9. The case helpers
(0.222) come last and take sl.** So idx→r9 is **priority-forced**: idx's 45
refs guarantee it outranks the 5-ref case helpers for r9 under ANY natural
shape. The baserom's idx→sl must come from a register-PREFERENCE chain (its
`mov sl, idx` init+increment copies bias idx toward sl) that does not arise
without a pin, AND its idx*4 SPILLS (longer/more-conflicting live range than
mine's 80).
