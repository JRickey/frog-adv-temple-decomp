# Deferred: sub_0802C910

Entity-22 (`&gEntities[22]`, base `0x03003bf0`) state dispatcher. Switches on
`entity->field_1A` with cases 0, 3, and 4. Case 0 refreshes motion from the
state shadow at entity-relative offset `0x6aa`; cases 3/4 ping-pong between
states 4 and 3 based on `entity->x` (state 3 -> 4 when `x > 0x77`, state 4 -> 3
when `x > 0xc0`). All paths tail-call `sub_080059C4(entity)`. Shared tail
("set_state") writes `field_1A` + the `0x6aa` shadow from the same register,
then re-reads `field_1A` for `sub_08021F1C` and motion via `sub_0800A580`.

`classify_unmatchable.py sub_0802C910` returns `ATTEMPT_MATCH`, not
`STRONG_UNMATCHABLE`; do NOT ship NAKED.

## Drift (best byte_diff 2, diff_count 2)

The Phase-1 C below (in "## Best-effort C") compiles BYTE-IDENTICAL to the
baserom EVERYWHERE except a single instruction pair: the case-4 (state 4, the
`x <= 0xc0` branch) signed-halfword load picks `r1` as its index scratch where
the baserom uses `r2`:

```asm
+0x00c0  target: movs r2, #2            built: movs r1, #2
+0x00c2  target: ldrsh r0, [r5, r2]     built: ldrsh r0, [r5, r1]
```

Case 3 (the structurally-identical `x > 0x77` branch) ALREADY matches with
scratch `r2`. The two case bodies are byte-identical to each other and to the
target except for this one scratch register. Mine: case3=r2, case4=r1. Target:
case3=r2, case4=r2.

## Root cause (CONFIRMED via instrumented agbcc + greg dump)

This is NOT a user-pseudo coloring problem and NOT fixable by source shape.
The `*extendhisi2_insn` pattern in `tools/agbcc-src/gcc_arm/config/arm/thumb.md`
emits `mov %scratch, #2; ldrsh r0, [r5, %scratch]` for a `REG+const` halfword
address; `%scratch` is a `(clobber (match_scratch:SI "=&l"))` whose hard reg is
assigned by reload's **round-robin spill-register allocator**
(`allocate_reload_reg` in `tools/agbcc-src/gcc/reload1.c`, the
`i = last_spill_reg; ... i++` loop).

`last_spill_reg` carries across ALL reloads in program order. The reload
sequence in this function is: case-0-tail ldrsb (x2), case-3 ldrsh, case-4
ldrsh, set_state ldrsb (x2). `last_spill_reg` after case 3 is r2 in both mine
and the baserom. At case 4 the round-robin's `reload_reg_free_p(r2,...)` reuse
check diverges: the baserom reuses r2; my build finds r2 not-free-for-reuse
(the fall-through merges case 4 with set_state, whose `0x6aa` shadow load also
wants r2) and advances to r1. `spill_regs` index order is `[r1, r2]`
(i=0 -> r1, i=1 -> r2), confirmed by the instrumented trace.

So the divergence is a reload spill-register *round-robin / reuse* artifact in
the merged case-4 -> set_state reload window, driven by the FIXED physical body
layout (case 3 branches to set_state; case 4 falls through). It is independent
of any C-level expression, type, or statement order.

## Levers tried THIS pass (all confirmed not to flip the case-4 scratch)

- **NEW cracking levers that DID work** (took byte_diff 22 -> 2, and produce
  cleaner C than the prior pass): (a) staged `status |= 2; status &= 0x7fff;`
  inside the `if`, with status HOISTED out of the `if` condition so it is read
  once; (b) `register u16 t asm("r0")` on the status-update temp to thread the
  `(2|status)&0x7fff` accumulator through r0 (matches the baserom's
  `movs r0,#2; orrs r0,r1; ldr r1,=0x7fff; ands r0,r1`); (c) reading
  `entity->field_1A` into a `u8 dir` local BEFORE the `register s8 *outY
  asm("r4")` pin so the field read sequences before the r4 setup. These three
  are kept in the best-effort C.
- Permuter: 3 min @ -j4 --stop-on-zero, base score 10 (=5x2), plateaued, no
  output-* (matches the prior pass's 20k-iter plateau). It is a reload artifact
  the permuter's statement mutations cannot reach.
- Flag sweep (~30 old_agbcc `-f` flags incl. `-fregmove`/`-fno-regmove`,
  `-foptimize-register-move`, `-fcaller-saves`/`-fno-caller-saves`,
  `-fno-cse-follow-jumps`, `-fforce-mem`, `-fno-function-cse`,
  `-fmove-all-movables`, `-freduce-all-givs`, `-fno-strength-reduce`,
  `-fno-peephole`, `-fdefer-pop`, `-fbranch-count-reg`): none flip the scratch;
  `-fno-expensive-optimizations` / `-fno-force-mem` are catastrophic (151).
  old_agbcc has NO `-fschedule-insns*`/`-freorder*` (gcc-2.x).
  `-ffixed-r1` regresses to 27 (disrupts whole-function alloc).
- Source shapes: `2|status` vs `status|2` vs `t=2;t|=status`; fused
  `(status|2)&0x7fff` (regresses to 140 — fused materializes 0x7fff in r2 +
  move); caching `x`; `s32 x`; `!(x>0xc0)`; deriving `nextState` from
  `field_1A +/- 1` (129); pinning `status`/`nextState` to r1; `asm("":::"r1")`;
  reordering the shadow store / `dir` source in set_state (13). ALL either stay
  at the 2-byte scratch plateau or trade it 1:1 for an equal diff elsewhere.
- **EARLY `nextState` (the zero-sum proof):** writing `nextState = 3;` BEFORE
  the case-4 `x` comparison DOES flip the scratch to r2 (by keeping r1 occupied
  across the ldrsh) — but it hoists the `movs r1, #3` to before the ldrsh,
  exactly offsetting the win (byte_diff 10, the `movs` is at the wrong
  position). This proves the 2-byte diff is a true zero-sum local minimum: you
  can move the scratch off r1, but only by emitting r1's occupant early.
- Swapping case 3/case 4 source order (to flip which one falls through):
  regresses to 10 (changes physical body order, which the baserom fixes).
- Instrumented a PRIVATE debug `old_agbcc` (copied gcc/ to /tmp, added an
  fprintf in `allocate_reload_reg`): confirmed `spill_regs=[r1,r2]` and the
  round-robin mechanism, BUT the host-gcc-15 rebuild of reload1.c is NOT
  byte-faithful to the shipped old_agbcc (it even swapped the two scratches),
  so its per-insn trace numbers are not trustworthy for the shipped compiler.
  Mechanism is nonetheless confirmed from the source + greg dump. (Shared
  tools/agbcc-src was NOT modified — all edits were in the /tmp copy.)

## Asm-slice note (for whoever resolves this)

The original `asm/disasm_0x0802c910.s` incbin spans [0x2c910, 0x2ca54) and
contains TWO functions: `sub_0802C910` (0x2c910-0x2ca20) and a small
record-copy loop `sub_0802CA20` (0x2ca20-0x2ca54). To land the C, split the
tail off (`peel.py --start 0x802ca20 --end 0x802ca54 --mode thumb` ->
`asm/disasm_0x0802ca20.s`), delete `asm/disasm_0x0802c910.s`, and in linker.ld
replace the single `disasm_0x0802c910.o` line (between `src/game/sub_0802c7ec.o`
and `disasm_0x0802ca54.o`) with `src/game/sub_0802c910.o` + the
`disasm_0x0802ca20.o` tail. (This pass reverts all of that for a clean defer.)

## Best-effort C (byte_diff 2 — clean, one explained pin)

```c
#include "game.h"
#include "iwram.h"
#include "types.h"

struct MotionDesc {
    u8 _pad00[0x2a];
    u8 sel;
    u8 _pad2b[5];
    u8 dx;
    u8 dy;
    u8 mode;
};

extern void sub_0800A580(struct MotionDesc *m, s8 sel, s8 a, s8 b);
extern void sub_08021F1C(u8 dir, s8 *outX, s8 *outY);
extern void sub_08020F3C(u8 idx);
extern void sub_080059C4(void *p);

void sub_0802C910(void)
{
    struct Entity *entity = &gEntities[22];
    s8 out[2];
    u8 nextState;

    switch (entity->field_1A) {
    case 0:
        sub_0800A580((struct MotionDesc *)entity, 0, 0, 0);
        if ((entity->status & 0x8000) == 0)
            goto done;

        entity->field_1A = *((u8 *)entity + 0x6aa);
        entity->status |= 2;
        {
            u8 dir = entity->field_1A;
            register s8 *outY asm("r4") = &out[1];
            sub_08021F1C(dir, &out[0], outY);
            sub_0800A580((struct MotionDesc *)entity, 2, out[0], *outY);
        }
        entity->status &= 0x7fff;
        goto done;

    case 3: {
        u16 status;
        sub_08020F3C(22);
        status = entity->status;
        if (status & 0x8000) {
            /* r0 pin threads the (2|status)&0x7fff accumulator through r0,
               matching `movs r0,#2; orrs r0,r1; ldr r1,=0x7fff; ands r0,r1`. */
            register u16 t asm("r0");
            t = 2;
            t |= status;
            t &= 0x7fff;
            entity->status = t;
        }

        if (entity->x > 0x77)
            goto done;
        nextState = 4;
        break;
    }

    case 4: {
        u16 status;
        sub_08020F3C(22);
        status = entity->status;
        if (status & 0x8000) {
            register u16 t asm("r0");
            t = 2;
            t |= status;
            t &= 0x7fff;
            entity->status = t;
        }

        if (entity->x <= 0xc0)
            goto done;
        nextState = 3;
        break;
    }

    default:
        goto done;
    }

    entity->field_1A = nextState;
    *((u8 *)entity + 0x6aa) = nextState;
    {
        u8 dir = entity->field_1A;
        register s8 *outY asm("r4") = &out[1];
        sub_08021F1C(dir, &out[0], outY);
        sub_0800A580((struct MotionDesc *)entity, 2, out[0], *outY);
    }
    entity->status |= 2;

done:
    sub_080059C4(entity);
}
```
