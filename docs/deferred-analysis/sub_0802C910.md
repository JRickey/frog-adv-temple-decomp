# Deferred: sub_0802C910

Entity-22 (`&gEntities[22]`, base `0x03003bf0`) state dispatcher. Switches on
`entity->field_1A` with cases 0, 3, and 4. Case 0 refreshes motion from the
state shadow at entity-relative offset `0x6aa`; cases 3/4 move between states
4 and 3 based on `entity->x`. All paths tail-call `sub_080059C4(entity)`.

`classify_unmatchable.py sub_0802C910` returns `ATTEMPT_MATCH`, not
`STRONG_UNMATCHABLE`; do not ship NAKED for this target.

## Drift

Best byte_diff remains 2, diff_count 2. The only mismatch is the scratch
register chosen for the case-4 signed halfword load:

```asm
+0x00c0  target: movs r2, #2            built: movs r1, #2
+0x00c2  target: ldrsh r0, [r5, r2]     built: ldrsh r0, [r5, r1]
```

The Phase-1 clean C below generates a 272-byte `sub_0802C910` with all other
instructions matching. The original `asm/disasm_0x0802c910.s` incbin also
contains trailing bytes at `0x0802ca20..0x0802ca54`; during probes I split that
tail to `sub_0802CA20` so the C function could occupy `0x0802c910..0x0802ca20`.
Restore the asm slice if deferring.

RTL/`-da` findings from this pass:

- The two `entity->x` reads lower to `*extendhisi2_insn` in
  `tools/agbcc-src/gcc_arm/config/arm/thumb.md`.
- That pattern emits `mov %scratch, #2; ldrsh r0, [r5, %scratch]` for constant
  offsets. The scratch is a reload `match_scratch:SI "=&l"`.
- In the `.greg` dump, case 3 becomes:

```rtl
(clobber (reg:SI 2 r2))
```

- Case 4 becomes:

```rtl
(clobber (reg:SI 1 r1))
```

So the remaining drift is reload scratch selection for the `extendhisi2`
scratch, not a normal user pseudo for `x`.

## Levers tried

Previously known failed levers still apply:

- CFLAGS: `-fno-gcse`, `-fforce-addr`, `-ffixed-r1`, `-ffixed-r2`,
  `-fno-schedule-insns`, `-fno-schedule-insns2`,
  `-fno-cse-follow-jumps`, `-fno-expensive-optimizations`,
  `-frerun-cse-after-loop`, `-fno-rerun-cse-after-loop`,
  `-fno-peephole`, `-fno-peephole2`, `-fno-thread-jumps`,
  `-fcaller-saves`, `-fno-caller-saves`, `-fomit-frame-pointer`,
  `-fno-function-cse`, `-Os`, `-fno-force-mem`.
- Newer `AGBCC_BIN` for the TU stays broadly wrong; `OLD_AGBCC_BIN` is the
  correct compiler here.
- Register pins for the state value and the loaded `x` value did not affect
  the reload scratch.
- Source variants around cached `x`, direct `entity->x`, `&entity->x`,
  `((s16 *)entity)[1]`, raw byte pointers, early `nextState`, explicit
  `goto set_state`, and declaration-order permutations stayed at the 2-byte
  plateau.
- Permuter previously ran about 20k iterations and never escaped the plateau.

Newly ruled out in this pass:

- Manual label/`goto` dispatcher instead of `switch`: worsened to byte_diff 99
  and still used `r1` for the case-4 scratch.
- Side-effect condition `if ((x = entity->x) <= 0xc0)`: compiled identically.
- `s32 x` instead of `s16 x`: compiled identically.
- Declaration order `nextState` before `x`: compiled identically.
- `register u32 xOffset asm("r2"); xOffset = 2; ...`: not load-bearing;
  reload still picked `r1`.
- Initialized `register u32 xOffset asm("r2") = 2`: made agbcc compute
  `entity + 2` in `r2`, adding instructions and worsening to byte_diff 85.
- Halfword index `register u32 xIndex asm("r2") = 1; ((s16 *)entity)[xIndex]`:
  emitted shift/address materialization and worsened to byte_diff 82.
- Flag sampling:
  - `-ffixed-r1` makes case 4 use `r2`, but changes case 3 to `r3`.
  - `-ffixed-r0`, `-ffixed-r3`, `-ffixed-r4`, `-fno-gcse`,
    `-fno-expensive-optimizations`, and `-fforce-addr` did not isolate the
    desired scratch choice.
- `corpus_asm_search.py` could not run in this worktree because
  `tools/agent/corpus-mirrors/` is not populated.

Next useful move: instrument a private copy of `old_agbcc` at reload scratch
selection for `*extendhisi2_insn` and compare why the first load gets `r2`
while the structurally parallel second load gets `r1`.

## Best-effort C

```c
void sub_0802C910(void)
{
    struct Entity *entity = &gEntities[22];
    s8 deltaX;
    s8 deltaY;
    s16 x;
    u8 nextState;

    switch (entity->field_1A) {
    case TEMPLE_FROG_STATE_INIT:
        sub_0800A580(entity, 0, 0, 0);
        if ((entity->status & ENTITY_STATUS_TRANSITION) == 0)
            goto done;

        entity->field_1A = *((u8 *)entity + TEMPLE_FROG_STATE_SHADOW_OFFSET);
        entity->status |= ENTITY_STATUS_DIRTY;
        sub_08021F1C(entity->field_1A, &deltaX, &deltaY);
        sub_0800A580(entity, ENTITY_STATUS_DIRTY, deltaX, deltaY);
        entity->status &= ENTITY_STATUS_VISIBLE_MASK;
        goto done;

    case TEMPLE_FROG_STATE_LEFT:
        sub_08020F3C(TEMPLE_FROG_STATE_CHECK);
        if (entity->status & ENTITY_STATUS_TRANSITION) {
            entity->status |= ENTITY_STATUS_DIRTY;
            entity->status &= ENTITY_STATUS_VISIBLE_MASK;
        }

        x = entity->x;
        if (x > 0x77)
            goto done;

        nextState = TEMPLE_FROG_STATE_RIGHT;
        break;

    case TEMPLE_FROG_STATE_RIGHT:
        sub_08020F3C(TEMPLE_FROG_STATE_CHECK);
        if (entity->status & ENTITY_STATUS_TRANSITION) {
            entity->status |= ENTITY_STATUS_DIRTY;
            entity->status &= ENTITY_STATUS_VISIBLE_MASK;
        }

        x = entity->x;
        if (x <= 0xc0)
            goto done;

        nextState = TEMPLE_FROG_STATE_LEFT;
        break;

    default:
        goto done;
    }

    entity->field_1A = nextState;
    *((u8 *)entity + TEMPLE_FROG_STATE_SHADOW_OFFSET) = nextState;
    sub_08021F1C(entity->field_1A, &deltaX, &deltaY);
    sub_0800A580(entity, ENTITY_STATUS_DIRTY, deltaX, deltaY);
    entity->status |= ENTITY_STATUS_DIRTY;

done:
    sub_080059C4(entity);
}
```
