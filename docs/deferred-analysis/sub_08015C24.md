# Deferred analysis: sub_08015C24

Range: [0x08015c24, 0x08015cbc) — 152 bytes, Thumb. Pure leaf, 0 callees.

Verdict: `ATTEMPT_MATCH` (NOT `STRONG_UNMATCHABLE`). It is a pure tile-buffer blit:
`sub_08015C24(u8 bank, s16 dstX, s16 dstY, u8 cols, u8 rows, const u16 *src)` — copies a
`cols x rows` rectangle of u16 tiles from `src` into one of three EWRAM banks
(0x02000000 / 0x02010000 / 0x02020000) at offset `dstX + dstY * tileWidth`, advancing
`dst` by `tileWidth - cols` between rows. `tileWidth` is the u16 at offset 26 of the scene
state struct at IWRAM 0x030060A0 (the same `state[13]`/offset-0x1a field the whole
0x0800F-0x08014 blit family reads). The single pool literals are 0x02010000, 0x02020000,
0x030060A0 — case 0's 0x02000000 is materialized as `0x80 << 18` (movs #128; lsls #18).

## Drift

The ENTIRE loop body is byte-identical to the target (col->r2, nextRow->r1, row->r0, the
inner u16 copy, the u8 col/row masks, the outer/inner branch displacements). The state base
correctly lands in r2 at setup and is copied to r7 for the loop (`adds r7, r2, #0`) via the
block-scoped `st asm("r2")` pin. Only 3 residual diffs remain, all confirmed to be
combine / local-alloc / scheduler TIE-BREAK decisions (not structural):

```text
+0x0048  SCHEDULE: built emits `ldr r2,=state` BETWEEN the two y-extend insns
         (`lsls r0,r2,#16` / `asrs r0,r0,#16`); target loads the state literal AFTER the
         y sign-extend completes. The scheduler fills the post-lsls slot (r2=dstY is dead
         after the lsls) with the independent literal load. -fno-schedule-insns(2),
         -fno-peephole, both compilers — none move it. Not scheduler-pass driven; it is
         RTL emission order.
+0x0050  ADD OPERAND ORDER: target `adds r0, r1, r0` (x=r1 as rn, product=r0 as rm,
         result r0); built `adds r0, r0, r1` (product as rn). Both have result in r0.
         `y += x` is the ONLY source form that puts the result in r0 (the right register);
         `y = x+y` / `x += y` / `x + y*tw` / single-expr all put the result in r1 (worse).
         The rn/rm swap is reload.c's commutative-operand trial (thumb.md addsi3 op1 is
         `%`-commutative): for `(set r0 (plus r0 r1))` the non-swapped order matches alt 0
         (`add %0,%0,%2`) with 0 reloads, so reload never picks the swapped alt-2 form the
         target uses. No C expression flips this without moving the result off r0.
+0x0078  LOAD-REGISTER SPLIT: target `ldrh r2,[r7,#26]; subs r0,r2,r3` — tileWidth loaded
         into r2 (reusing col's just-freed register), subtract result in r0. Built
         `ldrh r0,[r7,#26]; subs r0,r0,r3` — agbcc COALESCES the load and the subtract
         result into ONE r0 quantity. Every attempt to split them (separate `u32 tw` local,
         `register u16 stride asm("r2")`, `register u32 skip asm("r0")`, reusing the `col`
         variable) either coalesces back to one register or keeps the whole chain in r2
         (`subs r2,r2,r3`, byte_diff 8). REG_ALLOC_ORDER is {3,2,1,0,...} so an UNsuggested
         scratch would pick r2 — the load is pulled to r0 by a downstream copy-suggestion
         from the offset chain (`lsls r0; adds r5,r5,r0`). Could not break the suggestion
         from C.
```

## Best-effort C

byte_diff 7 / diff_count 5. The entire loop body matches; the 3 residuals are at +0x48
(schedule), +0x50 (add rn/rm), +0x78 (load-reg split).

```c
#include "types.h"

struct SceneTileState_15C24 {
    u8 _pad00[26];
    u16 tileWidth;
};

#define SCENE_TILE_STATE ((struct SceneTileState_15C24 *)0x030060A0)

void sub_08015C24(u8 bank, u16 dstX, u16 dstY, u8 cols, u8 rows, const u16 *src)
{
    u16 *dst;
    struct SceneTileState_15C24 *state;
    register s32 x asm("r1");
    register s32 y asm("r0");
    register s32 xScratch asm("r0");
    register u32 row asm("r0");

    switch (bank) {
    case 0:
        dst = (u16 *)0x02000000;
        break;
    case 1:
        dst = (u16 *)0x02010000;
        break;
    case 2:
        dst = (u16 *)0x02020000;
        break;
    }

    xScratch = dstX << 16;
    x = xScratch >> 16;
    y = (s16)dstY;
    {
        register struct SceneTileState_15C24 *st asm("r2") = SCENE_TILE_STATE;
        y *= st->tileWidth;
        y += x;
        dst += y;
        state = st;
    }

    row = 0;
    if (row < rows) {
        struct SceneTileState_15C24 *loopState = state;
        do {
            register u8 nextRow asm("r1");
            u8 col = 0;
            nextRow = row + 1;
            if (col < cols) {
                do {
                    *dst++ = *src++;
                    col++;
                } while (col < cols);
            }
            dst += loopState->tileWidth - cols;
            row = (u8)nextRow;
        } while (row < rows);
    }
}
```
