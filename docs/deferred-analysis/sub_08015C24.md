# Deferred analysis: sub_08015C24

Range: [0x08015c24, 0x08015cbc) — 152 bytes, Thumb.

## Summary

EWRAM tilemap blit — copies a rows×cols block of u16 tiles from a caller-supplied
src pointer into one of three EWRAM buffers (0x02000000/0x02010000/0x02020000)
at (dstX, dstY) scaled by the scene tile stride. The stride is
`SceneScrollState.tileWidth` at IWRAM 0x030060A0 offset 26 (this is the SAME
struct as `SceneScrollState_F2F8` / `SceneScrollState_A6D4` in the engine — offset
26 = `tileWidth`, NOT a fresh struct; reuse the existing field name).
Signature: `sub_08015C24(u8 bank, u16 dstX, u16 dstY, u8 cols, u8 rows, const u16 *src)`
  bank=r0, dstX=r1, dstY=r2, cols=r3, rows=[sp+0]→r4, src=[sp+4]→r6.
Pure leaf function (no callees), no high registers, classify: ATTEMPT_MATCH.

## Drift

**Best byte_diff: 19 (diff_count 19)** — reproduced again Round 3. ALL 19 are a single
coupled register-coloring cascade (state r2↔r7, stride r2↔r7, dstX/dstY sign-ext
direction, product reg, loop col r1↔r2 / nextRow r2↔r1). No structural diffs.

### Root cause — CONFIRMED via agbcc source (NEW, Round 3)

The baserom keeps the state ptr (0x030060A0) in **r2** through the multiply block,
then SPLITS its live range with a copy `adds r7, r2, #0` at the loop preheader
(0x15c80, executed ONCE — the backedge is to 0x15c82, NOT 0x15c80). In the loop
state lives in **r7**, r2 is reused for `col`, stride is re-read each iter via r7.

  Baserom multiply block (0x15c66):
    lsls r0,r1,#16; asrs r1,r0,#16   ; (s16)dstX -> r1  (OUT-of-place, r0 scratch)
    lsls r0,r2,#16; asrs r0,r0,#16   ; (s16)dstY -> r0  (in place; r2/dstY now dead)
    ldr  r2,[pc..]                   ; state -> r2  (reuses just-freed dstY reg)
    ldrh r7,[r2,#26]                 ; stride -> r7  (state PRESERVED in r2)
    muls r0,r7 ; adds r0,r1,r0       ; product in r0, sum = dstX(r1)+product(r0)
  Loop preheader: adds r7,r2,#0      ; SPLIT copy state r2 -> r7 (then r2:=col)

**Why agbcc cannot reproduce this** (read tools/agbcc-src/gcc_arm/):
1. `config/arm/arm.h` REG_ALLOC_ORDER = `{3,2,1,0,12,14,4,5,6,7,...}` — agbcc tries
   r3 FIRST, then r2,r1,r0, then ip/lr, then r4..r7 LAST.
2. `global.c` allocno_compare priority = `(n_refs*10000/live_length)*10000*size`.
   The loop counters (col/row, high n_refs, short range) are HIGH priority → claim
   r3/r2 first. The state ptr (2-3 refs, long range spanning the loop) is LOW
   priority → allocated LAST → gets r7.
3. `global.c` find_reg assigns ONE hard reg per pseudo — it does NOT split a live
   range. So a SINGLE `state` variable → r7 everywhere (no copy), size 148 (4 bytes
   short — missing the `adds r7,r2,#0`). byte_diff ~66-68.
4. To get the baserom SPLIT you must write TWO C variables: `state` (multiply) and
   `loopState = state` (loop), so the copy is `adds r7,r2,#0`. BUT then `state`
   becomes a 2-use pseudo and global.c colors it **r3** (first in alloc order),
   bumping `cols` off r3 → r7, and the whole loop re-colors. byte_diff ~87-89.

The baserom wants: state=r2 (NOT r3, NOT r7) in the multiply, cols=r3, loopState=r7,
col=r2 in loop, with the r2→r7 split copy. This is a coloring where state has
priority *just below* cols (so cols takes r3, state takes r2) AND its loop use is a
separate short pseudo. agbcc's frequency model never ranks state that high.

#include "iwram.h"
#include "types.h"

struct SceneScrollState_15C24 {
    u8 _pad00[26];
    u16 tileWidth;
};

void sub_08015C24(u8 bank, u16 dstX, u16 dstY, u8 cols, u8 rows, const u16 *src)
{
    u16 *dst;

    switch (bank) {
    case 0:
        dst = (u16 *)0x02000000;
        break;
    case 1:
        dst = (u16 *)0x02010000;
        break;
    case 2:
        dst = (u16 *)0x02020000;
        break;
    default:
        goto outer;
    }

    dst += (s16)dstX + (s16)dstY * ((struct SceneScrollState_15C24 *)0x030060A0)->tileWidth;

outer: {
    u8 row = 0;

    if (row < rows) {
        struct SceneScrollState_15C24 *loopState = (struct SceneScrollState_15C24 *)0x030060A0;

        do {
            u16 nextRow;
            u8 col;

            col = 0;
            nextRow = row + 1;

            if (col < cols) {
                do {
                    *dst++ = *src++;
                    col++;
                } while (col < cols);
            }
            dst += loopState->tileWidth - cols;
            row = (u8)nextRow;
        } while (row < rows);
    }
}
}
