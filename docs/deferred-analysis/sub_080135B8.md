# sub_080135B8 deferred analysis

## Drift

`classify_unmatchable.py sub_080135B8` returns `ATTEMPT_MATCH`. The high-reg
advisory is a false positive for this function's practical class: the function
is a 220-byte leaf and has no `bl`. Do not ship NAKED for this target.

The readable C structure below is correct and re-confirmed in this worktree:
size 220, `byte_diff 52`, `diff_count 44`. The whole miss is the same
register-coloring cascade documented by the previous agent. The pivot is the
gate load of `gGameStuff._unk00`.

Target gate:

```asm

ldr  r1, [r0]      @ now; base survives in r0
ldr  r2, [r3, #4]  @ lastTick
subs r1, r1, r2
mov  r9, r0        @ deferred high-reg home-store
ldrb r0, [r3, #11]
cmp  r1, r0
```

old_agbcc gate from the best C:

```asm
ldr  r0, [pc]
mov  ip, r0        @ eager home-store

```

That eager-vs-deferred reload decision changes which hard registers conflict
with `kind`, then cascades through `stepX`, `stepY`, `maxX`, and the saved
`gGameStuff` base. The responsible compiler area is `gcc_arm/reload1.c`
(`emit_reload_insns` / reload inheritance and output reload ordering), not a
control-flow mismatch.
