## Root cause (instrumented — this is the real blocker)

The default/correct compiler is `old_agbcc` (the Thumb compiler in
`tools/agbcc-src/gcc/`, NOT `gcc_arm/`). That compiler has **no
`REG_ALLOC_ORDER`** (none in `gcc/thumb.h`), so global-alloc (`gcc/global.c`
`find_reg`) is plain **numeric first-fit**: it scans hard regs 0,1,2,3,4,5,…
and takes the lowest free one (call-used preferred for non-call-crossing
pseudos, but order is still numeric).

I built a PRIVATE instrumented `old_agbcc` (fprintf at the `reg_renumber[…]
= best_reg` site in `gcc/global.c find_reg`) and dumped the allocation for
the best-effort C:

```
ALLOC pseudo 45(kind)    -> r2     (target wants r5)
ALLOC pseudo 42(xAxis)   -> r3     (✓)
ALLOC pseudo 43(yAxis)   -> r4     (✓)
ALLOC pseudo 27(stepX)   -> r5     (target wants r6)
ALLOC pseudo 37(stepY)   -> r6     (target wants r7)
ALLOC pseudo 22(maxX)    -> r7→r9  (target wants ip)
ALLOC pseudo 44(gGameStuff) -> r12 (target wants r9)
ALLOC pseudo 32(maxY)    -> r8     (✓)
```

`kind` (pseudo 45) is allocated FIRST (highest priority,
`floor_log2(refs)*refs/live = log2(6)*6/22 ≈ 0.55`) and, being first-fit,
grabs the lowest free reg = **r2**. The whole one-slot cascade follows:
kind@r2 leaves r5 free → stepX@r5, stepY@r6, maxX@r9, gGameStuff@r12.

The baserom instead has kind@r5. For that, kind must CONFLICT with r2 at
allocation. In the baserom, r2 IS used by the gate:

```asm
ldr  r0, [pc] @ &gGameStuff
ldr  r1, [r0]        @ now      (base PRESERVED in r0)
ldr  r2, [r3, #4]    @ lastTick (uses r2!)
subs r1, r1, r2      @ elapsed
mov  r9, r0          @ DEFERRED save of base to its home r9
ldrb r0, [r3, #11]   @ interval (reuses r0 after base saved)
cmp  r1, r0
```

The gate uses r0,r1,r2 and DEFERS the base→r9 save. Because the base stays
live in r0 across the deref, `now`→r1 and `lastTick`→r2 — and r2's use here
overlaps `kind`'s live range (kind is checked at `cmp r5,#4` AFTER the gate),
so kind conflicts with r2 and is pushed to r5. THAT is the linchpin.

Our build instead emits the EAGER save and uses only r0,r1:

```asm
ldr  r0, [pc]
mov  r9, r0          @ EAGER save
ldr  r0, [r0]        @ now reuses r0 (base already saved)
ldr  r1, [r3, #4]    @ lastTick -> r1
subs r0, r0, r1
ldrb r1, [r3, #11]
```

Only r0,r1 used → kind never conflicts with r2 → kind keeps r2 → cascade.

**So the eager-vs-deferred base save and the kind@r2-vs-r5 coloring are the
SAME bug.** Fix the gate to (a) preserve the base in r0 through the deref and
(b) defer the home-save, and the entire cascade resolves.

This is a reload-time decision (`gcc/reload1.c`), not allocation-time and not
source-shape: the deref result `now` reuses the base register because reload
sees the base's home (a callee-saved reg) realized eagerly. No C reshaping I
tried moved it.

## Ruled out THIS run (all stayed 52 unless noted; verified via instrumented compiler)

- Re-derived clean C from scratch (escape the plateau): 52 / 44.

  the 52 form; the prior 51 used maxX-first — try BOTH, 1-byte delta only.

## Best-effort C

```c
#include "macros.h"
#include "types.h"
#include "game.h"

struct IwramAt6540 {
    u8 _pad00[4];
    u32 lastTick;
    u8 _pad08;
    u8 kind;
    u8 _pad0a;
    u8 interval;
    u8 _pad0c[0x20];
    s16 deltaX;
    u8 _pad2e[6];
    s16 posX;
};

struct IwramAt6480 {
    u8 _pad00[4];
    u32 lastTick;
    u8 _pad08;
    u8 kind;
    u8 _pad0a;
    u8 interval;
    u8 _pad0c[0x22];
    s16 deltaY;
    u8 _pad30[6];
    s16 posY;
};

extern struct IwramAt6540 gIwram_6540;
extern struct IwramAt6480 gIwram_6480;

void sub_080135B8(u16 maxX, u8 stepX, u16 maxY, u8 stepY)
{
    struct IwramAt6540 *xAxis;
    struct IwramAt6480 *yAxis;
    GameStuff *gs;
    u8 kind;

    gIwram_6540.deltaX = 0;
    gIwram_6480.deltaY = 0;

    xAxis = &gIwram_6540;
    yAxis = &gIwram_6480;

    kind = xAxis->kind;
    if (kind != 0) {
        gs = &gGameStuff;
        if (gs->_unk00 - xAxis->lastTick >= xAxis->interval) {
            if (kind == 4) {
                if ((s32)xAxis->posX <= (s32)(s16)maxX)
                    xAxis->posX += stepX;
                xAxis->deltaX = stepX;
            }
            if (xAxis->kind == 3) {
                if ((s32)xAxis->posX >= (s32)(s16)maxX)
                    xAxis->posX -= stepX;
                xAxis->deltaX = -stepX;
            }
            xAxis->lastTick = gs->_unk00;
        }
    }

    kind = yAxis->kind;
    if (kind != 0) {
        gs = &gGameStuff;
        if (gs->_unk00 - yAxis->lastTick >= yAxis->interval) {
            if (kind == 1) {
                if ((s32)yAxis->posY <= (s32)(s16)maxY)
                    yAxis->posY += stepY;
                yAxis->deltaY = stepY;
            }
            if (yAxis->kind == 2) {
                if ((s32)yAxis->posY >= (s32)(s16)maxY)
                    yAxis->posY -= stepY;
                yAxis->deltaY = -stepY;
            }
            yAxis->lastTick = gs->_unk00;
        }
    }
}
```
