# sub_0802A63C — deferred analysis

0x0802a63c..0x0802a8fc (704 bytes). Entity spawn/update dispatcher for the
section-spawn grid. Reads section index gEntities[30].field_1A (base+0x6aa),
looks up an 8-byte SpawnGridSubtable entry via sSpriteGridSubtable (ROM
0x083067d4) to get a 12-byte SpawnGridEntry slice pointer, and loops
i = 0..7 over gEntities[i+2], spawning/aging entities per two u16 bitmasks at
gEntities[30].field_08 (base+0x698 maskLo "spawned") and gEntities[30].field_0A
(base+0x69a maskHi "done").

## Confirmed-correct structural findings (all reduce the diff; apply next time)

1. **Slice/subtable types** (verified against data/sprite/grid_layout.bin and
   grid_subtable.bin):
   - `struct SpawnGridEntry { s16 x; s16 y; u8 col; u8 dy; u8 mode; s8 delay;
     u8 flags; u8 _pad09[3]; }` — 12-byte stride.
   - `struct SpawnGridSubtable { u32 count; const SpawnGridEntry *slice; }[8]`
     over sSpriteGridSubtable. `slice = sSpriteGridSubtable[(s8)*(s8*)(base+0x6aa)].slice`.
2. **e cached, NOT inlined.** `struct Entity *e = &gEntities[i+2];` once per
   iteration is correct — it makes SIZE match the baserom exactly (608).
   Inlining `gEntities[i+2]` at every use blows size up to 704 (WRONG); the
   prior note's instinct to inline was wrong.
3. **goto-to-end for the age block.** The maskLo-set ("age") block is physically
   LAST in baserom (jumped to via a forward branch from 0x2a750). Writing the
   loop as `if (maskLo bit) goto age; <spawn block>; continue; age: <age block>`
   reproduces that physical block order; a natural inline `if/else` puts the age
   block first (wrong order).
4. **signed mask reads:** both loop mask reads are `(s16)` (baserom uses ldrsh):
   `(*(s16*)(base+0x69a) >> i) & 1` and `(*(s16*)(base+0x698) >> i) & 1`.
5. **base pinned r7** (`register u8 *base asm("r7")`) for the loop.
6. **No spurious lastTick pre-write.** base+0x6b0 (lastTick) is written ONLY in
   the reset block (the maskHi==0xff path), twice (before and after the
   sub_08000764 section randomization). The main path leaves it stale.
7. cached `s8 *section = base+0x6aa` and `u16 *maskHi = base+0x69a` for setup.

## NEW root cause (allocno-level, via instrumented agbcc global.c)

Built a private debug old_agbcc with an fprintf at the find_reg() commit site
(global.c ~line 1196, `reg_renumber[allocno_reg[allocno]] = best_reg`) and
traced MY 504 build's high-reg assignments:

  pseudo(loop-counter i<<24)  -> r8   nrefs=6 live=154 calls=6
  pseudo(slice)               -> r9   nrefs=5 live=239 calls=9
  pseudo(tick)                -> r10  nrefs=3 live=179 calls=6   (NO SPILL)

The BASEROM instead does:
  constant 1                  -> r8   (persistent, reused at 5 sites)
  loop-counter i<<24          -> r9
  slice                       -> r10/sl
  tick                        -> SPILLED to [sp,#24]   (=> sub sp #28 vs my #24)

So the ENTIRE divergence is one allocation-chain shift: **baserom keeps the
constant `1` live in a callee-saved reg (r8) the whole loop**, which pushes the
counter to r9, slice to sl, and forces tick to spill. agbcc here re-materializes
`movs #1` cheaply and never creates a persistent `1` pseudo, so r8 is free for
the counter, slice fits in r9, tick fits in sl — a strictly MORE efficient,
no-spill coloring (my build is 4 bytes smaller, sub sp #24 vs #28).

baserom uses `r8 = 1` (mov r8,r0 at 0x2a6fc) at these 5 sites only:
  - maskHi bit test `(maskHi>>i) & 1`     (0x2a70a: mov r5,r8; ands)
  - maskLo bit test `(maskLo>>i) & 1`     (0x2a748: mov r3,r8; ands)
  - Entity_Init 7th arg = 1               (0x2a7a6: mov r0,r8; str [sp,#8])
  - maskLo |= (1<<i)                       (0x2a838: mov r0,r8; lsls r0,r4)
  - maskHi |= (1<<i) in the >178 branch    (0x2a88c: mov r0,r8; lsls r0,r4)
The other literals (slice[i].flags & 1, status & 8, y > 178, 0x8000, 0x7fff)
are NOT r8 — they materialize fresh.

## Levers tried that did NOT escape the minimum

- `u32 one = 1;` used at exactly the 5 r8 sites (not pinned): agbcc does NOT
  create a separate `one` pseudo — it folds it into the counter / re-materializes.
  504/256, high-reg assignment UNCHANGED (counter still r8, slice r9, tick sl).
- `register u32 one asm("r8")` used at the 5 sites: 555/287 — pinning `one` to

#include "game.h"
#include "iwram.h"
#include "types.h"

extern u8 sub_08000764(u8 range);
extern void sub_08020C78(u32 sound);
extern void sub_0800696C(void *unused, s32 bits);
extern void sub_080059C4(void *p);
extern void sub_08020F3C(u8 arg);
extern void Entity_Init(struct Entity *p, u8 a, s16 b, s16 c, u8 d, u16 e, u8 f, u8 g, u8 h, u16 i);

struct SpawnGridEntry {
    s16 x;
    s16 y;
    u8 col;
    u8 dy;
    u8 mode;
    s8 delay;
    u8 flags;
    u8 _pad09[3];
};

struct SpawnGridSubtable {
    u32 count;
    const struct SpawnGridEntry *slice;
};

extern const struct SpawnGridSubtable sSpriteGridSubtable[8];

void sub_0802A63C(void)
{
    register u8 *base asm("r7");
    s8 *section;
    u16 *maskHi;
    const struct SpawnGridEntry *slice;
    u32 tick;
    s8 i;
    struct Entity *e;

    base = (u8 *)0x03003720;
    section = (s8 *)(base + 0x6aa);
    maskHi = (u16 *)(base + 0x69a);
    slice = sSpriteGridSubtable[*section].slice;

    if (*maskHi == 0xff) {
        gIwram_6110.flags2--;
        *(u16 *)(base + 0x698) = 0;
        *maskHi = 0;
        *(u32 *)(base + 0x6b0) = gGameStuff._unk00;
        if (gIwram_6110.gateByte == 2)
            *section = sub_08000764(5) + 3;
        else if (gIwram_6110.gateByte == 1)
            *section = sub_08000764(5) + 3;
        else
            *section = sub_08000764(3);

        *(u32 *)(base + 0x6b0) = gGameStuff._unk00;
        *(u16 *)(base + 0x698) = 0;
        *(u16 *)(base + 0x69a) = 0;
        if (gIwram_6110.flags2 == 0)
            return;
    }

    tick = gGameStuff._unk00;

    for (i = 0; i <= 7; i++) {
        e = &gEntities[i + 2];

        if ((*(s16 *)(base + 0x69a) >> i) & 1) {
            e->status |= 8;
            continue;
        }

        if ((*(s16 *)(base + 0x698) >> i) & 1)
            goto age;

        if (tick - *(u32 *)(base + 0x6b0) <= (u32)slice[i].delay) {
            e->status |= 8;
            continue;
        }

        Entity_Init(e, 0x51, slice[i].x, slice[i].y, 3, (i % 8) * 16 + 0x41, 1, 3, 2, 16);

        if (slice[i].flags & 1)
            sub_08020C78(0x3d);

        if (gIwram_6110.gateByte == 0) {
            e->field_32 = slice[i].mode;
            e->field_31 = slice[i].dy;
        } else {
            e->field_31 = slice[i].dy - 1;
            e->field_32 = slice[i].mode;
        }
        e->field_30 = slice[i].col;

        *(u16 *)(base + 0x698) |= 1 << i;
        sub_0800696C(&gIwram_6110, i + 2);
        sub_080059C4(e);
        continue;

    age:
        if (e->status & 8)
            continue;
        if ((s16)e->y > 178) {
            *(u16 *)(base + 0x69a) |= 1 << i;
            e->status |= 8;
            continue;
        }
        if (e->status & 0x8000)
            e->status = (e->status & 0x7fff) | 2;
        sub_08020F3C((u8)(i + 2));
        sub_080059C4(e);
    }
}
