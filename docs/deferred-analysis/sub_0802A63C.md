# sub_0802A63C — deferred analysis

0x0802a63c..0x0802a8fc (704 bytes). Entity spawn/update dispatcher for the
section-spawn grid. Reads section index gEntities[30]+0x1a, looks up a 12-byte
SpawnGridEntry slice via sSpriteGridSubtable (ROM 0x083067d4), and loops
i = 0..7 over gEntities[i+2], spawning/aging entities per two u16 bitmasks at
gEntities[30]+0x698 (maskLo "spawned") and +0x69a (maskHi "done").

## Status

Structure fully understood and ATTEMPT_MATCH (classify: ATTEMPT_MATCH, advisory
about r8/r9/sl high regs across bl). Best **byte_diff 483, diff_count 243**
(down from 562/351 on the first clean attempt). NOT matched — a sharp global
register-coloring local minimum on a ~300-instruction function.

## Drift

The function is correct semantically; the gap is entirely register allocation
cascading into different instruction selection (pool-literal loads vs
movs+lsls offset materialization).

Confirmed-correct structural findings (apply these next time — they each
reduced the diff):

1. **slice type / subtable**: `struct SpawnGridSubtable { u32 count; const
   struct SpawnGridEntry *slice; }[8]` cast over sSpriteGridSubtable; slice =
   sSpriteGridSubtable[(s8)base[0x6aa]].slice (12-byte SpawnGridEntry stride).
2. **BUG fixed**: do NOT write `*(u32*)(base+0x6b0) = tick` before the loop.
   The lastTick slot at base+0x6b0 is written ONLY in the init/reset blocks
   (the field_0A==0xff path). The main path leaves it stale from a prior frame.
   Removing the spurious pre-loop write dropped byte_diff 541 -> 526.
3. **signed mask reads**: both loop mask reads are `(s16)` (baserom uses
   ldrsh): `(*(s16*)(base+0x69a) >> i) & 1` and `(*(s16*)(base+0x698) >> i)
   & 1`. Dropped diff_count 254 -> 243.
4. **base pin r7**: `register u8 *base asm("r7")` (loop base reg) dropped
   277 -> 254/259. Without it, 281.
5. cached `s8 *section = base+0x6aa` and `u16 *maskHi = base+0x69a` for the
   setup block (the reset block keeps section live across the rand() calls).

Remaining divergence (the wall):
- baserom keeps **base in r4** for the setup block (cheap `r4 + 0xd6<<3`
  movs+lsls offset adds) and **reloads base into r7** for the loop — two live
  ranges. agbcc instead keeps base in ONE high register the whole function,
  forcing pool-literal offset loads everywhere.
- baserom keeps **slice in sl** and **spills tick to [sp,#24]**. agbcc (with
  the r7 pin) keeps slice in r9 and tick in sl, with NO spill (sub sp #24 vs
  baserom's #28) — i.e. my build is *more* efficient but colored differently.
- The allocno priority (global.c: floor_log2(n_refs)*n_refs/live_length) gives
  base the longest live range and most refs, so it wins the persistent reg and
  the two-range split never happens.

Levers tried that did NOT help (all stayed 483 or worse): -fno-gcse,
-fno-strength-reduce, -fno-schedule-insns/2, -fno-expensive-optimizations,
-fno-cse-skip-blocks, -fno-caller-saves, -ffixed-r8/r9/sl (worse, loop needs
them), -fforce-addr, -O1, AGBCC (newer) compiler swap (305, worse). Pinning
slice to sl directly: 271-399 (worse — disrupts everything). Two-base-local
split (setup r4 + loop r7 reassign): 257 (CSE'd). Inlining base via macro: 340.
Permuter: UNAVAILABLE in this worktree (.venv missing in main).

Instrumented a private debug old_agbcc (global.c allocno trace) — confirmed the
spilled pseudo is the one with longest live_length; the two-range base split in
baserom is what frees a low reg for the setup offset adds. The C shape that
forces agbcc to split base into r4(setup)+r7(loop) live ranges was not found.

Next attempt: try to make base's setup live range END before the loop (so a
fresh base pseudo for the loop), perhaps by routing every setup access through
section/maskHi/a dedicated setup pointer and never touching a raw `base` in
the loop except a fresh local — combined with the permuter (once its venv is
restored) from this 243 base, OR escalate to codex.

#include "game.h"
#include "iwram.h"
#include "types.h"

extern u8 sub_08000764(u8 range);
extern void sub_08020C78(u32 sound);
extern void sub_0800696C(void *unused, s32 bits);
extern void sub_080059C4(void *p);
extern void sub_08020F3C(u8 arg);
extern void Entity_Init(struct Entity *p, u8 a, s16 b, s16 c, u8 d, u16 e, u8 f, u8 g, u8 h, u16 i);

struct SpawnGridEntry {
    s16 x;     /* +0 */
    s16 y;     /* +2 */
    u8 _pad04; /* +4: anim column seed */
    u8 dy;     /* +5 */
    u8 mode;   /* +6 */
    s8 delay;  /* +7: minimum elapsed-tick gate */
    u8 flags;  /* +8: bit 0 -> play spawn sound */
    u8 _pad09[3];
};

struct SpawnGridSubtable {
    u32 count;
    const struct SpawnGridEntry *slice;
};

extern const struct SpawnGridSubtable sSpriteGridSubtable[8];

void sub_0802A63C(void)
{
    register u8 *base asm("r7");
    s8 *section;
    u16 *maskHi;
    const struct SpawnGridEntry *slice;
    u32 tick;
    s8 i;

    base = (u8 *)0x03003720;
    section = (s8 *)(base + 0x6aa);
    slice = sSpriteGridSubtable[*section].slice;
    maskHi = (u16 *)(base + 0x69a);

    if (*maskHi == 0xff) {
        gIwram_6110.flags2--;
        *(u16 *)(base + 0x698) = 0;
        *maskHi = 0;
        *(u32 *)(base + 0x6b0) = gGameStuff._unk00;
        if (gIwram_6110.gateByte == 2)
            *section = sub_08000764(5) + 3;
        else if (gIwram_6110.gateByte == 1)
            *section = sub_08000764(5) + 3;
        else
            *section = sub_08000764(3);

        *(u32 *)(base + 0x6b0) = gGameStuff._unk00;
        *(u16 *)(base + 0x698) = 0;
        *(u16 *)(base + 0x69a) = 0;
        if (gIwram_6110.flags2 == 0)
            return;
    }

    tick = gGameStuff._unk00;

    for (i = 0; i <= 7; i++) {
        struct Entity *e = (struct Entity *)(base + (i + 2) * sizeof(struct Entity));

        if ((*(s16 *)(base + 0x69a) >> i) & 1) {
            e->status |= 8;
            continue;
        }

        if ((*(s16 *)(base + 0x698) >> i) & 1) {
            if (e->status & 8)
                continue;
            if ((s16)e->y > 178) {
                *(u16 *)(base + 0x69a) |= 1 << i;
                e->status |= 8;
                continue;
            }
            if (e->status & 0x8000)
                e->status = (e->status & 0x7fff) | 2;
            sub_08020F3C((u8)(i + 2));
            sub_080059C4(e);
            continue;
        }

        if (tick - *(u32 *)(base + 0x6b0) <= (u32)slice[i].delay) {
            e->status |= 8;
            continue;
        }

        Entity_Init(e, 0x51, slice[i].x, slice[i].y, 3, (i % 8) * 16 + 0x41, 1, 3, 2, 16);

        if (slice[i].flags & 1)
            sub_08020C78(0x3d);

        if (gIwram_6110.gateByte == 0) {
            e->field_32 = slice[i].mode;
            e->field_31 = slice[i].dy;
        } else {
            e->field_31 = slice[i].dy - 1;
            e->field_32 = slice[i].mode;
        }
        e->field_30 = slice[i]._pad04;

        *(u16 *)(base + 0x698) |= 1 << i;
        sub_0800696C(&gIwram_6110, i + 2);
        sub_080059C4(e);
    }
}
