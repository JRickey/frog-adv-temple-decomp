  continues; otherwise if `commit != 0` it returns early.
- `stream = *(u8**)((u8*)gFrameCellTable_08307EAC + 12 + (pendingMode-1)*20)`
  i.e. word 3 of the 5-word (20-byte) scene entry. `gFrameCellTable_08307EAC` is
  the existing ROM linker symbol (`= 0x08307EAC`), `extern const u32 *[]`.
- `rec = records + (stream[idx*2] + streamBytes[idx]) * 24` where
  `streamBytes = (u8*)0x030063F0`.
- Bank if/else on `(rec->flags >> 4) & 1`: blit->bank (off 8) = 1/0, ewram =
  0x02010000 / 0x02000000 (the else value is emitted inline as `0x80 << 18`);
  blit->srcOffset (off 0x18) = ewram after the merge. blit = 0x03006540.
- `gIwram_35E0._field_10 = 1` (writes 0x030035F0 = 1).
- blit->tile (0) = streamBytes[idx]+1; if commit, blit[2] += 1<<idx.
- blit->_unk0B(0xB)=rec->_unk0C(0xC); blit halfwords 0x30/0x32/0x2C/0x2E =

- switch (rec->flags & 15): stride = `((SceneStride*)0x030060A0)->stride`

## What WORKED (keep these — they each fixed a real divergence)

1. **Prologue control: `control asm("r2")` + a second `ctrlSaved asm("ip")`
   alias.** First guard read goes through `control` (r2): baserom
   `ldr r2,=ctrl; adds r0,r2,#0; adds r0,#42; ldrb`. Then `ctrlSaved = control;`
   caches it to ip (`mov ip,r2`), and the SECOND guard read + the tail read
   `control[0x2b]` go through `ctrlSaved` (ip) → `mov r0,ip; adds r0,#43`. This
   reproduced the baserom prologue BYTE-FOR-BYTE (offsets 0x00-0x2a). The single
   `asm("r2")` pin alone (prior round) chained the second read as `adds r0,#1`
   and never emitted `mov ip`. The r2+ip split is the key insight the prior
   round missed.
2. **`streamBytes asm("r6")`** → forces commit to r7 (the baserom coloring:
   commit=r7, streamBytes=r6). Without it, commit colors to r6 and the push +
   every branch offset shift by one byte.
3. **Scene-table +12 anti-fold.** `(u8*)gFrameCellTable + 12 + (pm-1)*20` folds
   `12 - 20 = -8` into the symbol relocation addend (`subs r1,#1` disappears,
   pool literal becomes `0xfffffff8`). Fix: opaque the base with
   `asm("" : "+r"(table))`, then `table += 12;` as a runtime add. Baserom emits
   `ldr =table; adds r2,#12`.
4. **Per-branch blit materialization.** Reference `((BlitWork*)0x03006540)->bank`
   inside EACH bank branch (not a pre-assigned variable). A single pre-assigned
   `blit` is CSE'd to one `ldr` and stays in r5; the baserom reloads blit per
   branch.
5. idx pinned r4; the const `1` left UNPINNED (a `one asm("r3")` pin hoisted
   `movs r3,#1` before the control load — wrong order; unpinned, it falls to r3
   naturally AFTER the control load, matching).

## The remaining wall (the ~117-instruction diff)

The baserom keeps blit in TWO registers: r5 (canonical, survives to case 4) and
r2 (working copy `adds r2,r5,#0`, used for blit->tile + the 5 fill stores +
cases 1/2/3). That r2 working copy is what evicts streamBytes from r2 to r6
(`adds r6,r2,#0` at 0x10e3c) and shapes the bank-block register layout
(addr→r0, value→r1). My structurally-correct C keeps blit in r5 only (records
dies → r5 reused for blit, the natural agbcc behavior), so:
  - no r2 working copy forms,
  - streamBytes never needs to vacate r2 (so the `streamBytes asm("r6")` pin
    is doing by hand what the eviction would do — but without the eviction
    instruction),
  - the bank block colors addr→r1, value→r0 (swapped from baserom).

Attempts to FORCE the working copy:
- explicit `blitWork = blit` (unpinned): agbcc CSE's it back to r5 — the copy
  instruction appears (`adds r2,r5,#0`) but the fill stores still use r5. 210.
- `blitWork asm("r2")` (with streamBytes r6 pin): fill DOES use r2, but the
  canonical blit colors to r3 (not r5). 253.
- `blit asm("r5")` + `blitWork asm("r2")`: blit=r5 collides with the
  records→r5 param save (records and blit naturally REUSE r5 at different
  times; pinning blit to r5 forces a reservation that conflicts with records,
  causing spills). 391.

The working copy is an agbcc local-alloc decision (`local-alloc.c` qty_compare
priority = `floor_log2(n_refs)*n_refs*size/(death-birth)` — the heavy fill
region makes a working copy "worth it"). It cannot be triggered from C without
introducing a pin that conflicts with the records/blit r5 reuse. The right next
move is to INSTRUMENT agbcc local-alloc.c at the `find_free_reg` / qty_order
site, compile ONLY this TU, and watch when/why the baserom would split blit into
r5+r2 — then find the C shape (or accept it needs a different param coloring) that
makes records NOT occupy r5 at the moment blit is born, so r5 is the canonical
and r2 the working copy can both be assigned without a pin conflict.

Other small residual diffs (each ~1-3 insns), likely to fall once the working
copy is solved: scene-table loads gGameStuff before gFrameCellTable (the asm
fence sequences the table load late); streamBytes load placement; bank-block
r0/r1 swap.

## Best-effort C (byte_diff 195, size 396)

Needs no Makefile flags (default OLD_AGBCC). The `register ... asm(...)` pins
and the one `asm("")` fence are each load-bearing and explained above.

#include "game.h"
#include "iwram.h"
#include "types.h"

extern const u32 *gFrameCellTable_08307EAC[];

struct DrawRecord {
    u16 x;      /* +0x00 */
    u16 _unk02; /* +0x02 */
    u16 w;      /* +0x04 */
    u16 h;      /* +0x06 */
    u8 flags;   /* +0x08 */
    u8 _pad09[3];
    u8 _unk0C; /* +0x0C */
    u8 _pad0D[3];
    u32 *src; /* +0x10 */
};

struct BlitWork {
    u8 tile; /* +0x00 */
    u8 _pad01;
    u8 _unk02; /* +0x02 */
    u8 _pad03[5];
    u8 bank; /* +0x08 */
    u8 _pad09[2];
    u8 _unk0B; /* +0x0B */
    u8 _pad0C[12];
    u32 srcOffset; /* +0x18 */
    u8 _pad1C[16];
    u16 _unk2C; /* +0x2C */
    u16 _unk2E; /* +0x2E */
    u16 _unk30; /* +0x30 */
    u16 _unk32; /* +0x32 */
};

struct SceneStride {
    u8 _pad00[26];
    u16 stride; /* +0x1A */
};

void sub_08010DD8(struct DrawRecord *records, u32 idxArg, u32 commit)
{

    register u8 *control asm("r2") = (u8 *)&gIwram_6110;
    register u8 *ctrlSaved asm("ip");
    u8 *stream;
    register u8 *streamBytes asm("r6");
    struct DrawRecord *rec;
    struct BlitWork *blit;
    u32 bitA;
    u32 ewram;

    bitA = control[0x2a] >> i & 1;
    ctrlSaved = control;
    if (bitA == 0 || bitA == (ctrlSaved[0x2b] >> i & 1)) {
        if (commit != 0) {
            return;
        }
    }

    {
        u8 *table = (u8 *)gFrameCellTable_08307EAC;
        u32 sceneIdx = gGameStuff.pendingMode - 1;

        /* Keep the +12 a runtime add (not folded into the symbol relocation
           addend): the baserom emits `ldr =table; adds r2,#12`. */

        table += 12;
        stream = *(u8 **)(table + sceneIdx * 20);
    }
    streamBytes = (u8 *)0x030063F0;
    rec = (struct DrawRecord *)((u8 *)records + (stream[i * 2] + streamBytes[i]) * 24);

    if ((rec->flags >> 4 & 1) != 0) {
        ((struct BlitWork *)0x03006540)->bank = 1;
        ewram = 0x02010000;
    } else {
        ((struct BlitWork *)0x03006540)->bank = 0;
        ewram = 0x02000000;
    }
    blit = (struct BlitWork *)0x03006540;
    blit->srcOffset = ewram;

    gIwram_35E0._field_10 = 1;

    blit->tile = streamBytes[i] + 1;
    if (commit != 0) {
        blit->_unk02 += 1 << i;
    }

    blit->_unk0B = rec->_unk0C;
    blit->_unk30 = rec->w;
    blit->_unk32 = rec->h;
    blit->_unk2C = rec->w;
    blit->_unk2E = rec->h;

    switch (rec->flags & 15) {

        blit->srcOffset += 2 * (rec->x + ((struct SceneStride *)0x030060A0)->stride * (rec->_unk02 + rec->h - 1));
        *(u32 *)((u8 *)blit + 16) = *rec->src + 2 * ((rec->h - 1) * rec->w);
        break;
    case 1:
    case 3:
        blit->srcOffset += 2 * (rec->x + ((struct SceneStride *)0x030060A0)->stride * rec->_unk02);
        *(u32 *)((u8 *)blit + 16) = *rec->src;
        break;
    case 4:

    }

    if (commit != 0) {

    }
}
