## The TWO remaining clusters (everything else matches)

### Cluster 1 — bank-block r0-threading (the dominant residual)
The target threads the blit pointer through **r0 across the bank if/else** and
into the merge, then spills it to r5 (canonical) + r2 (working):
```
.L_if:   ldr r0,=blit; movs r1,#1; strb r1,[r0,#8]; ldr r1,=ewram   # blit in r0
.L_else: ldr r0,=blit; strb r1,[r0,#8]; <ewram via r1>             # blit in r0
.merge:  str r1,[r0,#24]   (srcOffset, blit via r0)
         adds r5,r0,#0     (canonical r5)
         <gIwram_35E0._field_10=1 — CLOBBERS r0>
         adds r2,r5,#0     (working r2, copied from r5 since r0 dead)
```
Our `vO` instead RELOADS blit at the merge (`ldr r5,=blit; str r0,[r5,#24]`) and
never threads r0, so the `adds r5,r0,#0`/`adds r2,r5,#0` pair is replaced by a
single reload. ROOT CAUSE (confirmed by reading the asm): the target's bank
**if-branch** puts blit in **r0** and the store value `1` in **r1**; our
if-branch puts blit in **r1** and `1` in **r0**. The bank test
(`lsrs r1,#4; movs r0,#1; ands r1,r0`) leaves r0=1; agbcc REUSES that r0=1 as the
if-branch store value, pushing blit to r1. Because the if/else leave blit in
DIFFERENT registers (r1 vs r0), the merge cannot thread and must reload.

The target also has r0=1 after the test, yet it materializes a FRESH `movs r1,#1`
and keeps blit in r0 — because its GLOBAL allocation has already decided blit
lives in r0 across the bank block (so it threads to the merge). This is the
circular, global-liveness decision that no local source shape reproduces: a
`blit` variable assigned before the bank hoists to a callee-saved reg (r5) as a
SINGLE register (no working copy, the 195-base); a `blit` assigned after the bank
(inline-cast bank) makes the merge reload (vO). Neither threads r0.

## What semantics are (ground truth from the asm — unchanged, verified)

- params: `records` (r0, struct stride 24), `idx` (r1, used as `(u8)idx`),
  `commit` (r2).
- Guard: `bitA = control[0x2a] >> idx & 1` where `control = &gIwram_6110`
  (`u8*`). If `bitA != 0 && bitA != (control[0x2b] >> idx & 1)` continue;
  else if `commit != 0` return early.
- `stream = *(u8**)((u8*)gFrameCellTable_08307EAC + 12 + (pendingMode-1)*20)`
  (word 3 of the 5-word scene entry). `gFrameCellTable_08307EAC` is the existing
  linker symbol (`= 0x08307EAC`).
- `rec = records + (stream[idx*2] + streamBytes[idx]) * 24`,
  `streamBytes = (u8*)0x030063F0`.
- Bank if/else on `(rec->flags >> 4) & 1`: blit->bank (off 8) = 1/0,
  ewram = 0x02010000 / 0x02000000 (else value emitted inline as `0x80 << 18`);
  blit->srcOffset (off 0x18) = ewram. blit = 0x03006540.
- `gIwram_35E0._field_10 = 1`.
- blit->tile (0) = streamBytes[idx]+1; if commit, blit[2] += 1<<idx.
- blit->_unk0B(0xB)=rec->_unk0C(0xC); blit halfwords 0x30/0x32/0x2C/0x2E =
  rec->w(4)/rec->h(6)/w/h.
- switch (rec->flags & 15): stride = `*(u16*)0x030060BA`
  (`((SceneStride*)0x030060A0)->stride`, off 0x1A). Physical block order:
  case 2 → cases {1,3} → case 4 → tail. cases adjust blit->srcOffset(0x18) and
  blit[0x10] using rec->x(0), rec->_unk02(2), w, h, *rec->src(deref of off 0x10).
  Cases 1/2/3 use the blit WORKING copy (r2); case 4 uses the CANONICAL (r5)
  because case 4 clobbers r2 as scratch (`ldrh r2,[r3,#0]` for rec->x).
- tail: if commit, `control[0x2b] = control[0x2a]` (read through `ip`/ctrlSaved).
