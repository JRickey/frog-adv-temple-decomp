# sub_0800DC50 — deferred analysis

Entity-spawn driver at 0x0800DC50 (304 B, Thumb). It indexes the 8-byte
`sEntityInitTable` records by `gGameStuff.pendingMode`, runs an initial settle
loop while `gEntities[0].field_1A <= 3`, then iterates spawn-point coordinate
pairs and calls `sub_0800A458(x, y)` until each point reports done.

`classify_unmatchable.py sub_0800DC50` still reports `ATTEMPT_MATCH`, with only
high-register advisory. This is not a class3-libgcc strong-unmatchable case, so
the asm slice should remain the built path until a true C match is found.

## Drift

Best result remains **byte_diff 30 / diff_count 30**, all
`ARGUMENT_MISMATCH` register-coloring diffs and no structural replacements.
The active C shape at that point has the correct size (304 B), prologue/epilogue,
loop layout, branch targets, pool layout, high-register roles, and point-loop
back-edge. The residual sites are the same systematic coloring choices:

- `ldrb rN, [base, #10]; lsls r0, rN, #3` in the baserom vs
  `ldrb r0; lsls r0, r0, #3` from agbcc at the table-index sites.
- low-register scratch constants in the baserom (`r3`, `r4`, `r1`) vs agbcc
  choosing `r0`/`r1`/`r2` for the `ldrsh` offsets, flag ORs, inner-loop bit
  test, and `0x01000000` addend.
- phase-2 base/table handoff mismatches such as `ldr r4; mov sl, r4` vs
  `ldr r0; mov sl, r0`, and `mov r2, r9` vs `mov r0, r9`.

Compiler pass implicated: `tools/agbcc-src/gcc_arm/local-alloc.c` and
`reload1.c`. `agbcc_oracle.py --pass greg` on the 30-byte base shows the bad
sites are already structurally correct in RTL; the remaining issue is final
pseudo-to-hard-register allocation and reload scratch choice. The key source
constraints are still mutually opposed: the macro `gGameStuff` form preserves
the baserom's per-phase load/copy structure but colors dying field-read indexes
into `r0`; the linker-symbol held-base idiom can separate some indexes but
reshapes phase register allocation and pool placement.

## Best-effort C

```c
#include "game.h"
#include "iwram.h"
#include "macros.h"
#include "types.h"

#define SPAWN_DRIVER_FLAG_DONE 1
#define SPAWN_DRIVER_FLAG_WAITING 2

typedef struct EntityInitDesc {
    s8 spawnCount;
    u8 settleLimit;
    u8 waitLimit;
    u8 _pad3;
    const s16 *points;
} EntityInitDesc;

extern const EntityInitDesc sEntityInitTable[];
extern void sub_0800A520(void);
extern void sub_0800A2D8(void);
extern void sub_080008DC(void);
extern void sub_0800A328(void);
extern u32 sub_0800A458(s16 x, s16 y);

void sub_0800DC50(void)
{
    u8 flags;
    register u32 origin asm("r6");
    s8 i;
    u8 result;
    register GameStuff *gs asm("r9");
    register const EntityInitDesc *table asm("sl");
    register s32 pointOffset asm("r8");

    flags = 0;
    origin = gGameStuff._unk00;

    if ((u32)flags < sEntityInitTable[gGameStuff.pendingMode].settleLimit && gEntities[0].field_1A <= 3) {
        do {
            sub_0800A520();
            sub_0800A2D8();
            sub_080008DC();
            sub_0800A328();
        } while ((gGameStuff._unk00 - origin) < sEntityInitTable[gGameStuff.pendingMode].settleLimit &&
                 gEntities[0].field_1A <= 3);
    }

    if (sEntityInitTable[gGameStuff.pendingMode].spawnCount == 0) {
        return;
    }

    i = 0;
    if (i >= sEntityInitTable[gGameStuff.pendingMode].spawnCount) {
        return;
    }

    gs = &gGameStuff;
    do {
        flags &= 0xfe;
        if ((flags & SPAWN_DRIVER_FLAG_DONE) == 0) {
            table = sEntityInitTable;
            pointOffset = i * 4;
            do {
                if (flags & SPAWN_DRIVER_FLAG_WAITING) {
                    if ((gs->_unk00 - origin) > table[gs->pendingMode].waitLimit) {
                        flags &= 0xfd;
                    }
                } else {
                    const s16 *points = sEntityInitTable[gGameStuff.pendingMode].points;
                    points = (const s16 *)((const u8 *)points + pointOffset);
                    result = (u8)sub_0800A458(points[0], points[1]);
                    if (result == 0xff) {
                        origin = gGameStuff._unk00;
                        flags |= SPAWN_DRIVER_FLAG_WAITING;
                    }
                    if (result == 1) {
                        flags |= SPAWN_DRIVER_FLAG_DONE;
                    }
                }
                sub_0800A2D8();
                sub_080008DC();
                sub_0800A328();
            } while ((flags & SPAWN_DRIVER_FLAG_DONE) == 0);
        }
        i++;
    } while (i < sEntityInitTable[gs->pendingMode].spawnCount);
}
```
