# Deferred analysis: sub_0801A614

Script-step advance for the gIwram_34C0 (0x030034C0) cursor/delay state, a
sibling of sub_080179B8. Reads an opcode byte-stream selected by `useTableA`
from one of two ROM script-pointer tables, advances the cursor, and applies
hold/end opcodes (0xFE hold, 0xFD un-hold, 0xFF reset).

Range [0x0801a624, 0x0801a6d4) = 176 bytes. NOTE the asm slice
asm/disasm_0x0801a614.s is mis-peeled: its first 16 bytes (0x1a614-0x1a623)
are actually sub_0801A268's TRAILING LITERAL POOL (words 0x0000dfff,
0x0000bfff, 0x03003540, 0x03005330, referenced from 0x1a5d8/0x1a5e0/0x1a5ec/
0x1a5f0). The real function starts at 0x1a624 (`push {r4,r5,r6,lr}`). To
decompile, extend the sub_0801A268 INCBIN from 0x3ac to 0x3bc (absorb its
pool) and start the C function at 0x1a624. See linker.ld around line 537.

Callees: sub_08000900 (returns *(u32*)0x03003530, the frame tick), __udivsi3
(libgcc unsigned divide, peeled at 0x08033ee4). Both already peeled.

ROM tables (still inside the data blob; add as linker-assigned symbols):
  gScriptPtrTable_08308164 = 0x08308164;   (useTableA != 0)
  gScriptPtrTable_083081A0 = 0x083081A0;   (useTableA == 0)
Each entry is a `const u8 *` opcode stream.

## Drift

Best: **byte_diff 8, diff_count 5** — structurally a near-match; the whole
function matches EXCEPT the 0xFF-reset tail block. The remaining diff is one
agbcc reload-pass register-coloring artifact:

Target (0x1a6be):                 Built:
  movs r0, #0                       movs r0, #0
  strb r0, [r5, #0]                 adds r1, r0, #0      <- spurious copy
  strb r0, [r5, #1]                 strb r1, [r5, #0]
  str  r0, [r5, #12]                strb r1, [r5, #1]
  movs r0, #255                     str  r0, [r5, #12]
  b.n  0x1a6ce  (bare pop)          b.n  <ret_zero r4-epilogue>

Two coupled problems:
1. **QImode-truncation copy**: agbcc copies the SImode zero (r0) into r1 for
   the two byte stores (strb cursor/delay) while keeping r0 for the u32 store
   (str holdFlag). The baserom feeds all three stores from r0 directly.
2. **Return-path merge**: the 0xFF return value (op==0xFF, op pinned r4) is
   merged into the shared `adds r0,r4,#0` ret_zero epilogue, so the block
   ends `b.n ret_zero` instead of the baserom's fresh `movs r0,#255; b.n
   <bare pop>`. agbcc proves 0xFF==op and reuses op's epilogue.

The two are linked: because op (r4) must reach r0 via the merged epilogue,
agbcc keeps r0/r4 busy and reaches for r1 to hold the truncated byte-store
value.

## Levers already tried (all stay at byte_diff 8 or regress)

- `register int z asm("r0") = 0` reset pin — this is what GETS to byte_diff 8
  (defeats a `movs r2,#0` GCSE-style hoist seen with plain literal 0, which is
  byte_diff 77). REQUIRED in any base. z pinned to r1/r2/r3 -> byte_diff 9.
- `script[(u8)c1]` op==0 branch: cast to `(u32)script + idx` with idx pinned
  r0 keeps script in r6 and matches that branch (was a separate drift; fixed).
- `register const u8 *script asm("r6")`, `struct IwramAt34C0 *s asm("r5")`,
  `int op asm("r4")` pins — REQUIRED (match the 4-reg prologue + body regs).
- return variants: `return op` (=byte_diff 8, best) vs `return 0xFF` /
  `z=0xFF; return z` / `op=0xFF; return op` (all byte_diff 27 — copy persists
  AND return still merges).
- `asm volatile("" : "+r"(z))` / bare `asm("")` barrier before the return to
  break the op==0xFF merge -> byte_diff 27 (barrier adds overhead, no help).
- Flags (all byte_diff 8, no change): -fno-gcse, -fno-cse-follow-jumps,
  -fno-schedule-insns, -fno-schedule-insns2, -fno-peephole, -fno-defer-pop,
  -fcaller-saves, -fno-rerun-cse-after-loop, -fno-expensive-optimizations,
  -fforce-mem, -fomit-frame-pointer. OLD_AGBCC compiler -> byte_diff 8 too.
- z type u8 -> byte_diff 25 (holdFlag widening); u32 -> 8 (same as int).
- store order swaps (cursor/delay/holdFlag perms) -> byte_diff 8 (or worse).
- two separate zero pseudos for the strb-pair vs the str -> byte_diff 8.
- unpinning op -> byte_diff 40; volatile zero -> byte_diff 40.
- `op - 0xFF` / `op - op` derived zero -> real subtraction, worse.

## Best-effort C (byte_diff 8)

```c
#include "iwram.h"
#include "macros.h"
#include "types.h"

/* Sibling script-pointer tables of gScriptPtrTable_08307fec (sub_080179B8),
 * still inside the ROM data blob. useTableA selects which table; index picks
 * an entry. Each entry points at a byte-stream of opcodes. */
extern const u8 *const gScriptPtrTable_08308164[];
extern const u8 *const gScriptPtrTable_083081A0[];

u32 sub_08000900(void);
u32 __udivsi3(u32 num, u32 den);

int sub_0801A614(u8 index, int useTableA)
{
    register const u8 *script asm("r6");
    register struct IwramAt34C0 *s asm("r5");
    register int op asm("r4");

    if (useTableA != 0) {
        script = gScriptPtrTable_08308164[index];
    } else {
        script = gScriptPtrTable_083081A0[index];
    }

    s = &gIwram_34C0;
    if (s->delay != 0) {
        if (__udivsi3(sub_08000900() - s->stepTick, 60) < s->delay) {
            goto ret_zero;
        }
    }

    s->delay = 0;
    s->stepTick = 0;

    op = script[s->cursor];
    if (op == 0xFE) {
        s->holdFlag = 1;
    } else if (op == 0xFD) {
        s->holdFlag = 0;
    }

    s = &gIwram_34C0;
    {
        register u8 c asm("r0") = s->cursor;
        register u8 c1 asm("r1") = c + 1;
        s->cursor = c1;
        op = script[c];
        if (op == 0) {
            register u32 idx asm("r0");
            s->cursor = c1 + 1;
            idx = (u8)c1;
            idx = (u32)script + idx;
            s->delay = *(u8 *)idx;
            s->stepTick = sub_08000900();
            return op;
        }
    }

    if ((u8)(op + 3) <= 1) {
        goto ret_zero;
    }

    if (op != 0xFF) {
        return op;
    }

    {
        register int z asm("r0") = 0;
        s->cursor = z;
        s->delay = z;
        s->holdFlag = z;
    }
    return op;

ret_zero:
    op = 0;
    return op;
}
```
