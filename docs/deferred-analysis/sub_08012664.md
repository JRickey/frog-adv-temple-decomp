# sub_08012664 — deferred analysis

Spawn-tile picker. Reads cached tile coords from `gIwram_35E0` (offsets 8 and
10, read as `u8`), builds two exclusion bands `[base..base+4]` / `[base..base+2]`
where `base = (u8)(coord - 3)`, collects the values in `0..7` / `0..4` NOT in
each band into two stack candidate buffers, then random-picks (via
`sub_0801185C(count)`, a VCOUNT LCG RNG returning `[0,count)`) and writes
`gIwram_3720._field_692` (tile-X, clamped to `[1,8]`) and `_field_694` (tile-Y,
clamped to `[2,6]`). NOTE the genuine original quirk: the **Y** pick indexes the
**X** candidate buffer (`colCand`, held in r8) with a count drawn from the Y
exclusion set — the baserom's `add r0, r8` at 0x12740 reuses r8=colCand, not the
rowCand buffer. The best-effort C below faithfully reproduces that.

## Drift

Best reached: **byte_diff 8, diff_count 8** — pure register-coloring, identical
opcodes/operand-structure throughout. The ENTIRE residual is one constant's
register:

  target: `movs r6,#253; lsls r6,#24; adds r1,r1,r6; adds r0,r0,r6`  (0xfd<<24 in r6)
  built:  `movs r2,#253; lsls r2,#24; adds r1,r1,r2; adds r0,r0,r2`  (0xfd<<24 in r2)

This cascades to one coupled swap: the baserom puts the `colCand` base-temp in
**r0** and the `sp`/`colExcl` base in **r6** (`add r0,sp,#12; mov r8,r0; mov r6,sp`),
while agbcc puts colCand-base in r6 and sp-base in r0. It is a single
coalescing-order decision in agbcc's local allocator — it parks the short-lived
`0xfd<<24` constant in callee-saved **r6** because it is about to reuse r6 for the
sp-base, minimizing pressure; our build instead grabs the low caller-saved r2 for
the constant and leaves r6 for colCand-base.

### Cracking the byte-subtraction (already solved, keep this)

`base = (u8)(coord - 3)` naively compiles to `subs #3; lsls#24; lsrs#24` (narrow),
but the baserom uses the WIDE shift-domain form with a SHARED `0xfd<<24` constant.
The winning structure is the **two-intermediate** form (do NOT regress this):

    t8  = q[8]  << 24;            /* both byte reads + <<24 first ... */
    t10 = q[10] << 24;
    colBase = (t8  + 0xFD000000) >> 24;   /* ... then both adds share 0xfd<<24 */
    rowBase = (t10 + 0xFD000000) >> 24;

That, plus `extern int sub_0801185C(...)` (NOT `u8` — the `int` return removes the
two post-`bl` `lsls/lsrs#24` index truncations), plus pinning the struct pointer
`q asm("r0")`, plus the `hit`-reset-at-loop-bottom shape (init `hit=0` once before
loop3, reset at the bottom of each outer iteration), plus `u8 rowCand[4]` (a [5]
forces `sub sp,#28`; the baserom frame is exactly 24), takes it from diff 99 -> 8.

### Levers already tried (pick a DIFFERENT one next)

- `register asm("rN")` pins: `q=r0` (clean diff-8), `t8=r1/t10=r0` (also diff-8),
  base pins r3/r4 (neutral). Pinning the constant `k asm("r6"/"r5"/"r7")` FAILS to
  compile (agbcc spill error — those regs are needed for the sp/array bases).
  Pinning `t10=r2`/`t8=r2` or colCand/colExcl base ptrs all REGRESS (47..227).
- Flags (all REGRESS to 14 or no-op): `-fforce-addr`, `-fno-expensive-optimizations`,
  `-fno-gcse`, `-fno-strength-reduce`, `-fno-schedule-insns{,2}`, `-fcaller-saves`,
  `-ffixed-r2` (can't — loop counter needs r2), `-funsigned-char`, `-fsigned-char`.
- Compiler: default is `old_agbcc` (macOS) = diff-8 (best); `AGBCC_BIN` (newer) = 14.
- Constant hoisting to top / inlining base into the fill loop: REGRESS (46..78).
- decomp-permuter: ~2200 iters across TWO bases (q=r0 pin, and t8/t10 pins),
  base score 85, never beat 85, no score-0, no output dir. It cannot reach the
  r2->r6 constant recolor — randomization mutates statements/scope, not this
  coalescing choice.

### Next idea to try (NOT yet attempted)

Force the colCand base-temp into **r0** (reusing the now-dead `q`/struct-pointer

The straight `register u8 *cc asm("r0")` persistent pin regressed (r0 too hot);
needs a way to make agbcc reuse r0 ONLY for the transient `&colCand` setup — maybe

## Best-effort C

```c
#include "iwram.h"
#include "types.h"

extern int sub_0801185C(u8 range);

void sub_08012664(void)
{
    u8 colExcl[5];
    u8 rowExcl[3];
    u8 colCand[8];
    u8 rowCand[4];
    register u8 *q asm("r0");
    u32 t8;
    u32 t10;
    u8 colBase;
    u8 rowBase;
    u8 i;
    u8 j;
    u8 colCount;
    u8 rowCount;
    u8 hit;
    s16 value;

    q = (u8 *)&gIwram_35E0;
    t8 = q[8] << 24;
    t10 = q[10] << 24;
    colBase = (t8 + 0xFD000000) >> 24;
    rowBase = (t10 + 0xFD000000) >> 24;

    for (i = 0; i <= 4; i++)
        colExcl[i] = i + colBase;
    for (i = 0; i <= 2; i++)
        rowExcl[i] = i + rowBase;

    hit = 0;
    colCount = 0;
    for (i = 0; i <= 7; i++) {
        for (j = 0; j <= 4; j++) {
            if (i == colExcl[j])
                hit = 1;
        }
        if (hit == 0)
            colCand[colCount++] = i;
        hit = 0;
    }

    rowCount = 0;
    for (i = 0; i <= 4; i++) {
        for (j = 0; j <= 2; j++) {
            if (i == rowExcl[j])
                hit = 1;
        }
        if (hit == 0)
            rowCand[rowCount++] = i;
        hit = 0;
    }

    /* Y pick deliberately indexes colCand (baserom reuses r8=colCand at 0x12740). */
    gIwram_3720._field_692 = colCand[sub_0801185C(colCount)] + 1;
    gIwram_3720._field_694 = colCand[sub_0801185C(rowCount)] + 2;

    value = (s16)gIwram_3720._field_692;
    if (value <= 0)
        gIwram_3720._field_692 = 1;
    value = (s16)gIwram_3720._field_692;
    if (value > 8)
        gIwram_3720._field_692 = 8;

    value = (s16)gIwram_3720._field_694;
    if (value <= 1)
        gIwram_3720._field_694 = 2;
    value = (s16)gIwram_3720._field_694;
    if (value > 6)
        gIwram_3720._field_694 = 6;
}
```
