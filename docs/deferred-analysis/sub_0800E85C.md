# Deferred analysis: sub_0800E85C (0x0800e85c, 704 bytes)

Sprite/BG-layer asset loader. Verdict from classify_unmatchable.py:
ATTEMPT_MATCH (advisory: 2 high regs r8/r9 pinned across a `bl`).
NOT corpus-confirmed-unmatchable — do NOT ship NAKED. The C below is
structurally complete and correct (byte_diff 439 with huge matching runs
between the mismatch clusters); the blocker is a single register-coloring
local minimum, re-confirmed from scratch in round 17.

## What the function does (fully reverse-engineered)
- Param `u8 count` (r9) = number of sprite poses/layers to load (1..3).
- Three DMA3 fills (2 words of 0) clearing EWRAM 0x02000000, VRAM 0x06000000,
  palette 0x05000000.
- Loop `for (pose = 0; pose < count; pose++)` over `sCharacterSpriteFrames`
  (0x080e3190, 16-byte records `{const void* tilesA,tilesB,tilesC; u16 width,height}`,
  indexed `gGameStuff.pendingMode*3 + pose`). Each iter stores width/height into
  the per-layer control slot at `0x030060A0 + pose*0x20` (+0x18/+0x1a), then a
  `switch (pose)`:
    - case 0: LZ77UnCompWram(tilesA→0x02000000) [tilesA cached in sl across iters],
      DMA 0x02000000→VRAM 0x06000000 (0x80004000); if pendingMode==13 re-DMA
      tilesA→0x06000000; LZ77UnCompWram(tilesC→0x02000000); REG_BG0CNT=0x1C03.
    - case 1: if tilesA: DMA tilesA→0x02010000 (0x80002000);
      LZ77UnCompWram(tilesC→0x02010000); REG_BG1CNT=0x1D02.
    - case 2: if tilesA: DMA tilesA→0x0600C000 (0x80001000);
      if tilesC: DMA tilesC→0x02020000 (0x80008000) else fill 0→0x02020000
      (0x81008000); REG_BG2CNT=0x1E0D.
- Post-loop: DMA record0.tilesB→palette 0x05000000 (0x80000100); REG_DISPCNT=0x1040;
  `switch (count)` toggling BG layers via sub_0800EE94(enable)/sub_0800EE34(disable):
    count 1: EE94(0),EE34(1);  count 2: EE94(0),EE94(1),EE34(2),EE94(3);
    count 3: EE94(0..3).
- Epilogue: REG_IE &= ~IRQ_HBLANK; REG_DISPSTAT &= ~DISPSTAT_HBLANK_IRQ;
  gIwram_3608._pad4 = 1; gIwram_3608._field_5 = 0.

sub_0802D568 = BIOS SWI 17 (LZ77UnCompWram) wrapper, interior of the SWI-table
slice sub_0802D558. Exposed via top-of-file `asm(".global/.thumb_set
sub_0802D568, 0x0802D569")` (same idiom as sub_0802D56C in sub_08017abc.c) — this
relocates correctly; it is NOT the blocker.

## Drift — ROOT CAUSE pinpointed (round 17, fresh re-derivation)
- **Best byte_diff: 439, diff_count 189/312** (reproduced exactly from the
  best-effort C below; round 17 independently re-derived the same number from a
  blank ptr-var attempt and from the macro attempt, so 439 is the floor for
  every C shape tried).
- The ENTIRE 439 is ONE root divergence cascading. Side by side at the loop top:
    baserom pre-header + body (r3=&REG_DMA3 dies at the copy):
        adds r4, r3, #0     ; DMA copy   (THIRD/last pre-header insn; r3 now DEAD)
        ldr  r0, =0x030060a0 ; ctrl base → r0   (lowest free scratch)
        lsls r1, r7, #5      ; pose<<5   → r1
        adds r1, r1, r0      ; slot addr → r1
        ldrb r2, [r5, #10]   ; pendingMode → r2
    OUR build (r3=&REG_DMA3 STAYS LIVE into the loop body):
        adds r4, r3, #0      ; DMA copy   (FIRST pre-header insn; r3 still LIVE)
        ldr  r0,=frames; mov r8,r0
        ldr  r5,=gGameStuff
        lsls r2, r7, #5      ; pose<<5   → r2   (r0/r1 NOT chosen — see below)
        ldr  r1, =0x030060a0 ; ctrl base → r1
        adds r2, r2, r1      ; slot addr → r2
        ldrb r1, [r5, #10]   ; pendingMode → r1
- **The mechanism:** the prologue materializes `&REG_DMA3` (0x040000d4) into the
  FIRST scratch reg r3 (REG_ALLOC_ORDER = r3,r2,r1,r0,ip,lr,r4,r5,r6,r7,r8,sl,r9)
  and keeps it through the 3 fills. The loop needs it callee-saved across the BLs,
  so the allocator copies r3→r4. In the BASEROM the prologue r3-value DIES at that
  copy, so r3 is a 4th free scratch in the loop body → ctrl→r0, slot→r1, mode→r2,
  and the copy lands LAST in the pre-header. In OUR build the same prologue
  r3-pseudo's live range extends PAST the copy into the loop body (r3 is not reused
  as scratch until case-0's `movs r3,#192` at +0xca), so only r0/r1/r2 are free in
  the width/height block → slot→r2, mode→r1 (one register shifted), and the copy is
  emitted FIRST. Every subsequent insn differs by exactly one operand register while
  the STRUCTURE matches (matching runs of 29/30/48/22 insns between clusters).
- Responsible agbcc pass: the prologue-pseudo→callee-saved live-range extension is a
  global-alloc / update_equiv_regs reconciliation (gcc_arm/{global,local-alloc}.c),
  NOT loop.c invariant motion (frames/gGameStuff hoist correctly first). It is the
  *liveness* of the prologue r3-value across the loop boundary, not a CSE fold.

## Levers tried (round 17 — ALL fail to kill r3's loop-spanning live range)
- The 439 floor is shape-invariant: macro `REG_DMA3.` everywhere (439),
  ptr-var `dma=&REG_DMA3` (537, hoists DMA to r4 with no r3 copy — worse),
  hybrid prologue-macro + loop-var (505/619), two-var (616). Macro = best.
- Pins frames=r8, lastTilesA=sl, g=r5, cnt=r9 are REQUIRED for 439; dropping any
  regresses (g→557, cnt→473, both confirmed round 17).
- ctrl base/index order: `ctrl[pose]`, `ctrl+pose`, `(T*)0x030060A0+pose`,
  `(T*)(0x030060A0+(pose<<5))`, inline-cast — ALL 439 (agbcc canonicalizes; the
  index-first vs base-first order is decided by scratch availability, NOT source).
- Field-CSE: reading `gGameStuff.pendingMode` (global macro) instead of `g->pendingMode`
  loses the r5 base pin → 557. Cannot get base-in-r5 AND field-reloaded via source.
- CFLAGS (round 17, all 439): -fno-caller-saves, -fno-cse-follow-jumps,
  -fno-rerun-cse-after-loop, -fno-rerun-loop-opt, -fno-thread-jumps,
  -fno-omit-frame-pointer, -fno-defer-pop, -fno-function-cse, -fno-peephole,
  -ffixed-ip. **-ffixed-r6 = 439 AND the loop-top scratch swap PERSISTS** → r6 is
  irrelevant; the cascade is purely r3's live range. (deferred-round flags
  -fforce-addr/-fno-gcse/-fno-strength-reduce/-fno-expensive-optimizations also 439;
  -fno-schedule-insns rejected by old_agbcc.)
- Compiler swap OLD_AGBCC↔AGBCC: identical (per prior round).
- Prologue `zero=0` vs `src=&zero` reorder (to fix the minor `movs r2,#0` 2-byte
  shift): 516 (worse) — that shift is a red herring, not the cascade trigger.

## Next-attempt suggestions (DIFFERENT levers — the above are exhausted)
1. **Permuter is the right tool** (statement-order/scope mutation is exactly what
   breaks a scratch cascade rooted in a live-range/spill decision) — BUT
   make_permuter_target.py CANNOT build a usable target for this fn:
     (a) it emits `bl *ABS*0x802d569` for the thumb_set BL (GAS rejects `*ABS*`);
         workaround: post-patch target.s with `.thumb_set __abs_802d568,0x0802d569`
         + `bl __abs_802d568` (assembles clean).
     (b) FATAL: it uses the *candidate's* reloc OFFSETS with the *baserom's* BYTES.
         Since the candidate is non-matching, the BL offsets (be/100/148) don't line
         up with the baserom BL offsets (be/106/14a) → spurious mid-pool BLs →
         scorer misaligns. A correct target needs the BASEROM function's own reloc
         layout (its $t/$d + BL targets), which the tool does not derive. FIX THE
         TOOL to disassemble baserom bytes and detect BL/.word relocs from the bytes
         themselves (not the candidate .o), THEN permute from the 439 base.
2. Instrument a PRIVATE agbcc (codegen-notes "Instrumenting agbcc itself") — fprintf
   at the live-range-end / callee-save-copy emission in global.c/local-alloc.c to
   learn WHY the prologue r3-pseudo stays live past the `r4=r3` copy. The cure (if
   any) is then a source shape that makes the prologue DMA value provably dead at the
   loop boundary so r3 becomes the 4th loop scratch.
3. Source idea NOT yet tried: make the prologue's LAST DMA access clobber r3 with an
   UNRELATED value (so the prologue r3-pseudo genuinely ends before the loop), then
   re-establish &REG_DMA3 as a fresh pre-header load that the allocator can place
   last + leave r3 free in the body. (Risk: a fresh `ldr r4,=DMA` ≠ `adds r4,r3`
   encoding; needs CSE to still produce the copy.)

#include "game.h"
#include "iwram.h"
#include "gba/dma.h"
#include "gba/io.h"
#include "gba/intr.h"
#include "types.h"

/* sub_0802D568 = BIOS SWI 17 (LZ77UnCompWram) wrapper; .thumb_set so the BL
 * relocates (idiom of sub_0802D56C in sub_08017abc.c). */
asm(".global sub_0802D568\n"
    ".thumb_set sub_0802D568, 0x0802D569\n");

extern void sub_0802D568(const void *src, void *dst);
extern void sub_0800EE34(u8 layer);
extern void sub_0800EE94(u8 layer);

struct CharacterSpriteFrame {
    const void *tilesA;
    const void *tilesB;
    const void *tilesC;
    u16 width;
    u16 height;
};
extern const struct CharacterSpriteFrame sCharacterSpriteFrames[];

struct LayerCtrl_60A0 {
    u8 _pad00[0x18];
    u16 width;
    u16 height;
    u8 _pad1c[4];
};

void sub_0800E85C(u8 count)
{
    u16 zero;
    u8 pose;
    register GameStuff *g asm("r5");
    register const struct CharacterSpriteFrame *frames asm("r8");
    const struct CharacterSpriteFrame *rec;
    struct LayerCtrl_60A0 *ctrl;
    register const void *lastTilesA asm("sl");
    register u8 cnt asm("r9");

    cnt = count;
    zero = 0;
    REG_DMA3.src = &zero;
    REG_DMA3.dst = (void *)0x02000000;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 2;
    (void)REG_DMA3.cnt;

    zero = 0;
    REG_DMA3.src = &zero;
    REG_DMA3.dst = (void *)0x06000000;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 2;
    (void)REG_DMA3.cnt;

    zero = 0;
    REG_DMA3.src = &zero;
    REG_DMA3.dst = (void *)0x05000000;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 2;
    (void)REG_DMA3.cnt;

    for (pose = 0; pose < cnt; pose++) {
        frames = sCharacterSpriteFrames;
        g = &gGameStuff;
        ctrl = (struct LayerCtrl_60A0 *)0x030060A0;
        ctrl[pose].width = frames[g->pendingMode * 3 + pose].width;
        ctrl[pose].height = frames[g->pendingMode * 3 + pose].height;

        switch (pose) {
        case 0:
            rec = &frames[g->pendingMode * 3];
            if (rec->tilesA != NULL) {
                lastTilesA = rec->tilesA;
            }
            sub_0802D568(lastTilesA, (void *)0x02000000);
            REG_DMA3.src = (const void *)0x02000000;
            REG_DMA3.dst = (void *)0x06000000;
            REG_DMA3.cnt = DMA_ENABLE | 0x4000;
            (void)REG_DMA3.cnt;

            if (g->pendingMode == 13) {
                rec = &frames[g->pendingMode * 3];
                REG_DMA3.src = rec->tilesA;
                REG_DMA3.dst = (void *)0x06000000;
                REG_DMA3.cnt = DMA_ENABLE | 0x4000;
                (void)REG_DMA3.cnt;
            }

            rec = &frames[g->pendingMode * 3];
            sub_0802D568(rec->tilesC, (void *)0x02000000);
            REG_BG0CNT = 0x1C03;
            break;

        case 1:
            rec = &frames[g->pendingMode * 3 + 1];
            if (rec->tilesA != NULL) {
                REG_DMA3.src = rec->tilesA;
                REG_DMA3.dst = (void *)0x02010000;
                REG_DMA3.cnt = DMA_ENABLE | 0x2000;
                (void)REG_DMA3.cnt;
            }
            rec = &frames[g->pendingMode * 3 + 1];
            sub_0802D568(rec->tilesC, (void *)0x02010000);
            REG_BG1CNT = 0x1D02;
            break;

        case 2:
            rec = &frames[g->pendingMode * 3 + 2];
            if (rec->tilesA != NULL) {
                REG_DMA3.src = rec->tilesA;
                REG_DMA3.dst = (void *)0x0600C000;
                REG_DMA3.cnt = DMA_ENABLE | 0x1000;
                (void)REG_DMA3.cnt;
            }
            rec = &frames[g->pendingMode * 3 + 2];
            if (rec->tilesC != NULL) {
                REG_DMA3.src = rec->tilesC;
                REG_DMA3.dst = (void *)0x02020000;
                REG_DMA3.cnt = DMA_ENABLE | 0x8000;
                (void)REG_DMA3.cnt;
            } else {
                zero = 0;
                REG_DMA3.src = &zero;
                REG_DMA3.dst = (void *)0x02020000;
                REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x8000;
                (void)REG_DMA3.cnt;
            }
            REG_BG2CNT = 0x1E0D;
            break;
        }
    }

    frames = sCharacterSpriteFrames;
    g = &gGameStuff;
    REG_DMA3.src = frames[g->pendingMode * 3].tilesB;
    REG_DMA3.dst = (void *)0x05000000;
    REG_DMA3.cnt = DMA_ENABLE | 0x100;
    (void)REG_DMA3.cnt;

    REG_DISPCNT = 0x1040;

    switch (cnt) {
    case 1:
        sub_0800EE94(0);
        sub_0800EE34(1);
        break;
    case 2:
        sub_0800EE94(0);
        sub_0800EE94(1);
        sub_0800EE34(2);
        sub_0800EE94(3);
        break;
    case 3:
        sub_0800EE94(0);
        sub_0800EE94(1);
        sub_0800EE94(2);
        sub_0800EE94(3);
        break;
    }

    REG_IE &= ~IRQ_HBLANK;
    REG_DISPSTAT &= ~DISPSTAT_HBLANK_IRQ;
    gIwram_3608._pad4 = 1;
    gIwram_3608._field_5 = 0;
}
