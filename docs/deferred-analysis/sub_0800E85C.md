# Deferred analysis: sub_0800E85C (0x0800e85c, 704 bytes)

Verdict: `ATTEMPT_MATCH`, not `STRONG_UNMATCHABLE`. The only advisory is the
high-reg case (`frames`/`count`/`tilesA` live across the inner `bl
sub_0802D568`), which is matchable per project precedent. **Do not ship
NAKED.**

## What the function does (fully understood)

`sub_0800E85C(u8 count)` uploads `count` (1..3) character-sprite layers.
Prologue DMA-clears three VRAM/EWRAM regions (0x02000000, 0x06000000,
0x05000000) with a stack-local `u16 zero` as a fixed source. Then a
`for (pose = 0; pose < count; pose++)` loop indexes
`sCharacterSpriteFrames[gGameStuff.pendingMode * 3 + pose]` (16-byte records:
`{tilesA, tilesB, tilesC, u16 width, u16 height}`), writes width/height into
the per-pose layer-control slot at `0x030060A0 + pose * 0x20` (+0x18/+0x1A),
and a `switch (pose)` dispatches pose-specific DMA + LZ77 (`sub_0802D568` =
svc-17 LZ77UnCompVRAM) loads, ending each case with a BGxCNT write
(0x1C03 / 0x1D02 / 0x1E0D) through a shared store. The tail DMAs
`frames[pendingMode*3].tilesB` to palette RAM (0x05000000), sets
`REG_DISPCNT = OBJ_ON|OBJ_1D`, runs a `switch (count)` toggling BG layers via
`sub_0800EE94`/`sub_0800EE34` (count==1 and count==2 share a
`disable(2); enable(3)` tail via fallthrough), clears HBlank IRQ state, and
writes `gIwram_3608._pad4 = 1; gIwram_3608._field_5 = 0;`.

Callee prerequisite RESOLVED this session: `sub_0802D568` is an internal
entry (+0x10, the `svc 17` wrapper) of the NAKED libagbsyscall block
`sub_0802D558`. It is NOT separately peelable. Exposed it as a real Thumb
symbol via `.global sub_0802D568` + `.thumb_set sub_0802D568,
sub_0802D558 + 0x11` inside that block's NAKED asm (points into real `.text`,
so a C `bl` links with NO veneer — verified). This is the same pattern
`sub_08017abc.s` uses for `sub_0802D56C`. The next attempt should reuse this
(it's a one-line add to `src/game/sub_0802d558.c`).

## Drift — the remaining gap is a PURE register-coloring rotation

Best this session: **byte_diff 498, diff_count 171**, built with the default
`OLD_AGBCC_BIN`, with **ZERO pins, ZERO inline asm, ZERO flags** — a strictly
cleaner base than the prior round's `byte_diff 449` (which needed 4 register
pins). The instruction SHAPE is a perfect match: the dense pose `switch`
lowers to agbcc's exact comparison tree (`cmp #1; beq; cmp #1; bgt; cmp #0;
beq; b`), the prologue holds the DMA base in `r3` then copies it to `r4` at
the loop preheader (`add r4, r3, #0` — matches), `frames=r8`, `count=r9`,
`tilesA=sl`, the slot is CSE'd once and reused for both width+height stores,
and the libgcc/LZ77 BLs encode correctly. **Every single remaining mismatch
is a register-NAME difference, not a shape difference.**

The divergence is a 3-way coloring rotation in the low callee-saved file:

| value | baserom | built |
|-------|---------|-------|
| dma   | r4      | r4 ✓  |
| game  | r5      | r7    |
| pose  | r7      | r6    |
| slot  | r1      | r2    |
| (skipped low reg) | r6 | r5 |

baserom skips **r6** and uses r4/r5/r7 for dma/game/pose; the build skips
**r5** and uses r4/r6/r7 for dma/pose/game. `ARM REG_ALLOC_ORDER` is
`4,5,6,7,…` so the highest-priority allocno takes r4, next r5, etc. baserom
assigns `game→r5` (game is the 2nd-priority allocno after dma) and forces
`pose→r7` (skipping r6 — pose evidently carries an r7 register/copy
preference that the C-from-source path does not reproduce). The build instead
colors `pose→r6, game→r7`. Responsible pass: `gcc_arm/global.c`
`allocno_compare` (priority `floor_log2(n_refs)*n_refs/live_length*size`) +
the copy-preference machinery (`hard_reg_copy_preferences`) that biases
`pose` toward r7 in the baserom. `local-alloc.c`/`loop.c`/`cse.c` are NOT the
issue — the shape is already correct.

## Levers RULED OUT this session (so the next attempt picks differently)

- Single pins (`game asm("r5")`, `pose asm("r7")`, either alone, both, and
  r4/r6 variants): ALL strictly worse (657–622, lenA grows to 728–752 — the
  pin forces game to spill across the `bl` instead of staying callee-saved).
  This is the classic "pins fight a flow-based allocation" case.
- Per-TU flags via direct compile probe vs expected `.text`:
  `-fcaller-saves`, `-fno-regmove`, `-fno-optimize-register-move`,
  `-fno-strength-reduce`, `-fno-expensive-optimizations`, `-fno-peephole`,
  `-fno-force-mem`, `-fno-cse-follow-jumps`, `-fno-rerun-cse-after-loop`,
  `-fomit-frame-pointer`, `-fcall-saved-r6`, `-freduce-all-givs`,
  `-fno-move-all-movables`, `-fno-thread-jumps`, `-fno-function-cse`: all
  leave byte_diff at 539 (probe metric) — coloring unchanged.
  `-ffixed-r6` / `-fmove-all-movables` / `-fforce-addr` / `-fno-omit-frame-
  pointer`: worse. `-fcall-used-r6`: fixes `pose→r7` but moves `game→r6`
  WITH a spill (`str r6,[sp,#4]; bl; ldr r6,[sp,#4]`) → 520 (probe) / nets
  494/164 via Makefile with `-fno-gcse` — only 4 instr better than the clean
  498 AND costs 2 flags + a spill, so NOT worth taking.
- Structural variants: dropping the `frames` local (use array name directly)
  → 533/187 (worse diff_count); using `gGameStuff.pendingMode` directly with
  no `game` ptr → 501/172 (agbcc re-CSEs the pointer anyway); `s32`/`u32`
  pose → 557/569 (worse — `u8 pose` with the `lsls/lsrs #24` wrap is correct,
  baserom wraps); hoisting frames/game/dma before the loop → 527 (loads move
  before the zero-trip guard); local-decl reordering → inert (agbcc numbers
  allocnos by first-USE in RTL, not declaration order).
- Newer `AGBCC_BIN` for this TU: identical byte_diff to `old_agbcc` (539
  probe). Not a compiler-choice problem.
- Permuter: **UNAVAILABLE in this environment** — `vendor/decomp-permuter`
  submodule is empty (no `permuter.py`, no `.venv`), in both the worktree and
  `/Users/jackrickey/Dev/frog-adv-decomp` main. The asm-history corpus search
  confirms the `lsls #5` slot idiom + for/switch loop is reproducible in pure
  C across many repos (metroidret/mzm, etc.), i.e. this IS matchable — but no

## Best-effort C (clean, byte_diff 498, ZERO levers — resume from here)

```c
#include "gba/dma.h"
#include "gba/intr.h"
#include "gba/io.h"
#include "game.h"
#include "iwram.h"
#include "types.h"

#define CHARACTER_BG0CNT 0x1C03
#define CHARACTER_BG1CNT 0x1D02
#define CHARACTER_BG2CNT 0x1E0D

struct CharacterSpriteFrame {
    const void *tilesA;
    const void *tilesB;
    const void *tilesC;
    u16 width;
    u16 height;
};

struct CharacterLayerCtrl {
    u8 _pad00[0x18];
    u16 width;
    u16 height;
    u8 _pad1C[4];
};

extern const struct CharacterSpriteFrame sCharacterSpriteFrames[];

/* svc 17 (LZ77UnCompVRAM) wrapper inside the libagbsyscall block. Expose via
   `.global sub_0802D568` + `.thumb_set sub_0802D568, sub_0802D558 + 0x11`
   inside src/game/sub_0802d558.c's NAKED asm. */
extern void sub_0802D568(const void *src, void *dst);
extern void sub_0800EE34(u8 layer);
extern void sub_0800EE94(u8 layer);

void sub_0800E85C(u8 count)
{
    volatile DmaChannel *dma;
    struct CharacterLayerCtrl *layer;
    const struct CharacterSpriteFrame *frames;
    GameStuff *game;
    const void *tilesA;
    u16 zero;
    u8 pose;

    zero = 0;
    REG_DMA3.src = &zero;
    REG_DMA3.dst = (void *)0x02000000;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 2;
    (void)REG_DMA3.cnt;

    zero = 0;
    REG_DMA3.src = &zero;
    REG_DMA3.dst = (void *)0x06000000;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 2;
    (void)REG_DMA3.cnt;

    zero = 0;
    REG_DMA3.src = &zero;
    REG_DMA3.dst = (void *)0x05000000;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 2;
    (void)REG_DMA3.cnt;

    for (pose = 0; pose < count; pose++) {
        frames = sCharacterSpriteFrames;
        game = &gGameStuff;
        dma = &REG_DMA3;
        layer = (struct CharacterLayerCtrl *)0x030060A0;

        layer[pose].width = frames[game->pendingMode * 3 + pose].width;
        layer[pose].height = frames[game->pendingMode * 3 + pose].height;

        switch (pose) {
        case 0:
            if (frames[game->pendingMode * 3].tilesA != NULL) {
                tilesA = frames[game->pendingMode * 3].tilesA;
            }
            sub_0802D568(tilesA, (void *)0x02000000);

            dma->src = (const void *)0x02000000;
            dma->dst = (void *)0x06000000;
            dma->cnt = DMA_ENABLE | 0x4000;
            (void)dma->cnt;

            if (game->pendingMode == 13) {
                dma->src = frames[game->pendingMode * 3].tilesA;
                dma->dst = (void *)0x06000000;
                dma->cnt = DMA_ENABLE | 0x4000;
                (void)dma->cnt;
            }

            sub_0802D568(frames[game->pendingMode * 3].tilesC, (void *)0x02000000);
            REG_BG0CNT = CHARACTER_BG0CNT;
            break;
        case 1:
            if (frames[game->pendingMode * 3 + 1].tilesA != NULL) {
                dma->src = frames[game->pendingMode * 3 + 1].tilesA;
                dma->dst = (void *)0x02010000;
                dma->cnt = DMA_ENABLE | 0x2000;
                (void)dma->cnt;
            }
            sub_0802D568(frames[game->pendingMode * 3 + 1].tilesC, (void *)0x02010000);
            REG_BG1CNT = CHARACTER_BG1CNT;
            break;
        case 2:
            if (frames[game->pendingMode * 3 + 2].tilesA != NULL) {
                dma->src = frames[game->pendingMode * 3 + 2].tilesA;
                dma->dst = (void *)0x0600C000;
                dma->cnt = DMA_ENABLE | 0x1000;
                (void)dma->cnt;
            }
            if (frames[game->pendingMode * 3 + 2].tilesC != NULL) {
                dma->src = frames[game->pendingMode * 3 + 2].tilesC;
                dma->dst = (void *)0x02020000;
                dma->cnt = DMA_ENABLE | 0x8000;
                (void)dma->cnt;
            } else {
                zero = 0;
                dma->src = &zero;
                dma->dst = (void *)0x02020000;
                dma->cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x8000;
                (void)dma->cnt;
            }
            REG_BG2CNT = CHARACTER_BG2CNT;
            break;
        }
    }

    REG_DMA3.src = sCharacterSpriteFrames[gGameStuff.pendingMode * 3].tilesB;
    REG_DMA3.dst = (void *)0x05000000;
    REG_DMA3.cnt = DMA_ENABLE | 0x100;
    (void)REG_DMA3.cnt;

    REG_DISPCNT = DISPCNT_OBJ_ON | DISPCNT_OBJ_1D;

    switch (count) {
    case 1:
        sub_0800EE94(0);
        sub_0800EE34(1);
        sub_0800EE34(2);
        sub_0800EE94(3);
        break;
    case 2:
        sub_0800EE94(0);
        sub_0800EE94(1);
        sub_0800EE34(2);
        sub_0800EE94(3);
        break;
    case 3:
        sub_0800EE94(0);
        sub_0800EE94(1);
        sub_0800EE94(2);
        sub_0800EE94(3);
        break;
    }

    REG_IE &= ~IRQ_HBLANK;
    REG_DISPSTAT &= ~DISPSTAT_HBLANK_IRQ;
    gIwram_3608._pad4 = 1;
    gIwram_3608._field_5 = 0;
}
```
