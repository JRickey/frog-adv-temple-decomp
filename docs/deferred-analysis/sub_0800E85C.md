# Deferred analysis: sub_0800E85C (0x0800e85c, 704 bytes)

Sprite/BG-layer asset loader. Verdict from classify_unmatchable.py:
ATTEMPT_MATCH (advisory: 2 high regs r8/r9 pinned across a `bl`).
NOT corpus-confirmed-unmatchable — do NOT ship NAKED. The C below is
structurally complete and correct; the blocker is a register-coloring /
instruction-scheduling local minimum, not a missing idiom.

## What the function does (fully reverse-engineered)
- Param `u8 count` (r9) = number of sprite poses/layers to load (1..3).
- Three DMA3 fills (2 words of 0) clearing EWRAM 0x02000000, VRAM 0x06000000,
  palette 0x05000000.
- Loop `for (pose = 0; pose < count; pose++)` over `sCharacterSpriteFrames`
  (0x080e3190, 16-byte records `{const void* tilesA,tilesB,tilesC; u16 width,height}`,
  indexed `gGameStuff.pendingMode*3 + pose`). Each iter stores width/height into
  the per-layer control slot at `0x030060A0 + pose*0x20` (+0x18/+0x1a), then a
  `switch (pose)`:
    - case 0: LZ77UnCompWram(tilesA→0x02000000) [tilesA cached in sl across iters],
      DMA 0x02000000→VRAM 0x06000000 (0x80004000); if pendingMode==13 re-DMA
      tilesA→0x06000000; LZ77UnCompWram(tilesC→0x02000000); REG_BG0CNT=0x1C03.
    - case 1: if tilesA: DMA tilesA→0x02010000 (0x80002000);
      LZ77UnCompWram(tilesC→0x02010000); REG_BG1CNT=0x1D02.
    - case 2: if tilesA: DMA tilesA→0x0600C000 (0x80001000);
      if tilesC: DMA tilesC→0x02020000 (0x80008000) else fill 0→0x02020000
      (0x81008000); REG_BG2CNT=0x1E0D.
- Post-loop: DMA record0.tilesB→palette 0x05000000 (0x80000100); REG_DISPCNT=0x1040;
  `switch (count)` toggling BG layers via sub_0800EE94(enable)/sub_0800EE34(disable):
    count 1: EE94(0),EE34(1);  count 2: EE94(0),EE94(1),EE34(2),EE94(3);
    count 3: EE94(0..3).
- Epilogue: REG_IE &= ~IRQ_HBLANK; REG_DISPSTAT &= ~DISPSTAT_HBLANK_IRQ;
  gIwram_3608._pad4 = 1; gIwram_3608._field_5 = 0.

sub_0802D568 = BIOS SWI 17 (LZ77UnCompWram) wrapper, interior of the SWI-table
slice sub_0802D558. Exposed via top-of-file `asm(".global/.thumb_set
sub_0802D568, 0x0802D569")` (same idiom as sub_0802D56C in sub_08017abc.c) — this
relocates correctly; it is NOT the blocker.

## Drift
- **Best byte_diff: 439, diff_count 189/312** (down from 563 first pass).
- The diff is one root cause cascading: at loop entry agbcc emits the
  REG_DMA3-base→callee-saved spill `adds r4, r3` FIRST, then loads
  frames(r8)/gGameStuff(r5). The baserom orders it THIRD
  (frames; gGameStuff; `adds r4,r3`; gIwram_60A0). This flips which scratch reg
  (r0 vs r1) holds the gIwram_60A0 base and which (r1 vs r2) holds pose<<5 in the
  `ctrl[pose]` address calc, then `gGameStuff.pendingMode` (r2 target / r1 built) —
  a one-register scratch shift that makes ~every subsequent insn differ in operand
  register while the STRUCTURE matches (big matching runs of 29/30/48/22 insns
  between the mismatch clusters).
- Responsible agbcc pass: instruction scheduling of the loop-invariant
  base-address spill in local-alloc/reload (REG_ALLOC_ORDER = r3,r2,r1,r0,ip,lr,
  r4,r5,r6,r7,r8,sl,r9 — locals fill r4 first; old_agbcc has NO -fschedule-insns
  so the spill placement cannot be moved by a flag).
- Secondary: 0x02000000 in case 0 is materialized into r6 (callee-saved) vs r2
  (scratch) in the baserom — same scratch cascade, not a separate CSE-fold.

## Levers tried (all FAILED to break the cascade)
- Pins: frames=r8, lastTilesA=sl, g=r5, cnt(=count)=r9 — REQUIRED; reaching 439.
  Dropping ANY regresses (g unpinned→582, cnt unpinned→473, frames/sl unpinned→589).
- Compiler swap OLD_AGBCC↔AGBCC: identical (451/451, 572/572) — no help.
- CFLAGS sweep -fforce-addr / -fno-gcse / -fno-strength-reduce /
  -fno-expensive-optimizations (and combos): all 451/439 unchanged.
  -fno-schedule-insns is REJECTED by old_agbcc.
- REG_DMA3 macro used directly everywhere (vs a `dma`/`dma2` pointer var):
  439 (best) — this got case-0's post-BL DMA to reload `&REG_DMA3` fresh into r1
  like the baserom. Mixing macro+var regressed (505); single-var 518; two-var 475.
- Reorder `dma2 = dma` / ctrl base-first arithmetic / explicit slot ptr /
  `*(T*)(0x030060A0 + pose*0x20)` / write height-before-width / rec cached vs
  recomputed: all 439–550, none flip the loop-top spill order.
- asm("":"+r"(ctrl)) fence to anchor base-load-first: 462 (worse).
- Permuter: CANNOT set up — make_permuter_target.py fails to assemble target.s
  ("can't resolve value for symbol L0", the mov-pc switch + external thumb_set BL
  relocations). Permuter is the right tool for this exact coloring/scheduling drift
  but the harness can't build a target for this function as-is. Fixing that (or
  hand-building nonmatchings/sub_0800E85C/target.{s,o} with $t/$d + the
  sub_0802D568/EE34/EE94 relocations) is the most promising next step.

## Best-effort C
```c
#include "game.h"
#include "iwram.h"
#include "gba/dma.h"
#include "gba/io.h"
#include "gba/intr.h"
#include "types.h"

/* sub_0802D568 = BIOS SWI 17 (LZ77UnCompWram) wrapper; .thumb_set so the BL
 * relocates (idiom of sub_0802D56C in sub_08017abc.c). */
asm(".global sub_0802D568\n"
    ".thumb_set sub_0802D568, 0x0802D569\n");

extern void sub_0802D568(const void *src, void *dst);
extern void sub_0800EE34(u8 layer);
extern void sub_0800EE94(u8 layer);

struct CharacterSpriteFrame {
    const void *tilesA;
    const void *tilesB;
    const void *tilesC;
    u16 width;
    u16 height;
};
extern const struct CharacterSpriteFrame sCharacterSpriteFrames[];

struct LayerCtrl_60A0 {
    u8 _pad00[0x18];
    u16 width;
    u16 height;
    u8 _pad1c[4];
};

void sub_0800E85C(u8 count)
{
    u16 zero;
    u8 pose;
    register GameStuff *g asm("r5");
    register const struct CharacterSpriteFrame *frames asm("r8");
    const struct CharacterSpriteFrame *rec;
    struct LayerCtrl_60A0 *ctrl;
    register const void *lastTilesA asm("sl");
    register u8 cnt asm("r9");

    cnt = count;
    zero = 0;
    REG_DMA3.src = &zero;
    REG_DMA3.dst = (void *)0x02000000;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 2;
    (void)REG_DMA3.cnt;

    zero = 0;
    REG_DMA3.src = &zero;
    REG_DMA3.dst = (void *)0x06000000;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 2;
    (void)REG_DMA3.cnt;

    zero = 0;
    REG_DMA3.src = &zero;
    REG_DMA3.dst = (void *)0x05000000;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 2;
    (void)REG_DMA3.cnt;

    for (pose = 0; pose < cnt; pose++) {
        frames = sCharacterSpriteFrames;
        g = &gGameStuff;
        ctrl = (struct LayerCtrl_60A0 *)0x030060A0;
        ctrl[pose].width = frames[g->pendingMode * 3 + pose].width;
        ctrl[pose].height = frames[g->pendingMode * 3 + pose].height;

        switch (pose) {
        case 0:
            rec = &frames[g->pendingMode * 3];
            if (rec->tilesA != NULL) {
                lastTilesA = rec->tilesA;
            }
            sub_0802D568(lastTilesA, (void *)0x02000000);
            REG_DMA3.src = (const void *)0x02000000;
            REG_DMA3.dst = (void *)0x06000000;
            REG_DMA3.cnt = DMA_ENABLE | 0x4000;
            (void)REG_DMA3.cnt;

            if (g->pendingMode == 13) {
                rec = &frames[g->pendingMode * 3];
                REG_DMA3.src = rec->tilesA;
                REG_DMA3.dst = (void *)0x06000000;
                REG_DMA3.cnt = DMA_ENABLE | 0x4000;
                (void)REG_DMA3.cnt;
            }

            rec = &frames[g->pendingMode * 3];
            sub_0802D568(rec->tilesC, (void *)0x02000000);
            REG_BG0CNT = 0x1C03;
            break;

        case 1:
            rec = &frames[g->pendingMode * 3 + 1];
            if (rec->tilesA != NULL) {
                REG_DMA3.src = rec->tilesA;
                REG_DMA3.dst = (void *)0x02010000;
                REG_DMA3.cnt = DMA_ENABLE | 0x2000;
                (void)REG_DMA3.cnt;
            }
            rec = &frames[g->pendingMode * 3 + 1];
            sub_0802D568(rec->tilesC, (void *)0x02010000);
            REG_BG1CNT = 0x1D02;
            break;

        case 2:
            rec = &frames[g->pendingMode * 3 + 2];
            if (rec->tilesA != NULL) {
                REG_DMA3.src = rec->tilesA;
                REG_DMA3.dst = (void *)0x0600C000;
                REG_DMA3.cnt = DMA_ENABLE | 0x1000;
                (void)REG_DMA3.cnt;
            }
            rec = &frames[g->pendingMode * 3 + 2];
            if (rec->tilesC != NULL) {
                REG_DMA3.src = rec->tilesC;
                REG_DMA3.dst = (void *)0x02020000;
                REG_DMA3.cnt = DMA_ENABLE | 0x8000;
                (void)REG_DMA3.cnt;
            } else {
                zero = 0;
                REG_DMA3.src = &zero;
                REG_DMA3.dst = (void *)0x02020000;
                REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x8000;
                (void)REG_DMA3.cnt;
            }
            REG_BG2CNT = 0x1E0D;
            break;
        }
    }

    frames = sCharacterSpriteFrames;
    g = &gGameStuff;
    REG_DMA3.src = frames[g->pendingMode * 3].tilesB;
    REG_DMA3.dst = (void *)0x05000000;
    REG_DMA3.cnt = DMA_ENABLE | 0x100;
    (void)REG_DMA3.cnt;

    REG_DISPCNT = 0x1040;

    switch (cnt) {
    case 1:
        sub_0800EE94(0);
        sub_0800EE34(1);
        break;
    case 2:
        sub_0800EE94(0);
        sub_0800EE94(1);
        sub_0800EE34(2);
        sub_0800EE94(3);
        break;
    case 3:
        sub_0800EE94(0);
        sub_0800EE94(1);
        sub_0800EE94(2);
        sub_0800EE94(3);
        break;
    }

    REG_IE &= ~IRQ_HBLANK;
    REG_DISPSTAT &= ~DISPSTAT_HBLANK_IRQ;
    gIwram_3608._pad4 = 1;
    gIwram_3608._field_5 = 0;
}
```
