# sub_0801C078 — deferred analysis (round 13, Opus escalation #2)

## What the function is

A pipe(`|`)-terminated ASCII **text -> BG-tilemap renderer** (credits / menu /
save-dialog text). For each character it writes one or two 16-bit tilemap
entries into a BG screenblock chosen by param `sb` (0..3 ->
0x0600E000 / 0x0600E800 / 0x0600F000 / 0x0600F800, screenblocks 28..31).

Font layout (added to base tile id `sp8`, OR'd with palette field `palBits`):
  - `A`-`Z` -> sp8 + (c-'A')               (0..25)
  - `a`-`z` -> sp8 + (c-'a') + 26          (26..51)
  - `1`-`9` -> sp8 + (c-'1') + 0x3A        ; `0` -> sp8 + 9 + 0x3A
  - `' '`   -> 0 (blank tile)
  - `*`     -> two tiles: palBits+0x24 at row+1, palBits+0x09 at row+2
  - `?`     -> 0xE0D6
  - `~`     -> 0xE0EA + palBits
  - `\n`    -> newline (col=0, row++)
  - `|`     -> terminate
  - `[ddd]` -> 3-digit decimal escape (parsed by sub_0801CEC0). n = ddd - 0xC0;
              if n<=63, copy two halfwords from sCreditsTilemapEng (u16 stride 3:
              table[n*3+1] at addr, table[n*3+2] at addr+0x40). i += 4.

Address = base + colBase*2 + col*2 + ((row*2 + rowBase) << 6) [+ 0x40].
`palBits = (pal4 << 28) >> 16` = `(pal4 & 0xF) << 12`.

## SOLVED this round (the prior agent's two big walls — both broken)

### Residual 1 SOLVED — `base += colBase*2` preheader placement
The prior plateau had `base += colBase*2` emitted BEFORE the entry guard, never
in the gcc preheader. **Fix: write an EXPLICIT redundant guard.**
```c
i = 0;
if (i < count) {
    base = (u16 *)(colBase * 2 + (u32)base);
}
for (; i < count; i++) { ... }
```
gcc merges the explicit `if (i < count)` with the for-loop's own entry test and
sinks the `base += colBase*2` into the preheader, with base allocated to r6.
This is byte-identical to the baserom through the ENTIRE prologue/guard/preheader/
body-start: `movs r3,#0; str r3,[sp,12]; ldr r0,[sp,4]; cmp r3,r0; bcc .pre;
b exit; .pre: lsls r0,r2,#1; adds r6,r0,r6; ldr r1,[sp,0]; ldr r3,[sp,12]; ...`.
KEY: base must be PINNED to r6 (the comma-init/explicit-guard keeps it there);
i naturally spills to [sp,12] (memory-resident, matches baserom). `-fno-caller-saves`
is the per-TU flag (keeps i memory-resident across the inner BL).

### Residual 2 SOLVED — digit/a-z value reassociation + digit cross-jump merge
The prior plateau had the digit value `sp8 + (t+0x3A)` reassociated by agbcc to
`(sp8+0x3A)+t` (CSE/canonicalization of loop-invariant + constant), forcing the
value into r0, addr into r1, and the WRONG cross-jump merge (with A-Z instead of `~`).
**Fix: a `(u16)` cast on the const-adjacent subexpression** defeats the reassoc:
```c
dval = (u16)(t + 0x3A) + sp8 + palBits;   /* digit; was sp8 + (t + 0x3A) + palBits */
... = (u16)(t + 26) + sp8 + palBits;       /* a-z;  was sp8 + (t + 26)  + palBits */
```
The `(u16)` forces `t + 0x3A` to be materialized as a unit BEFORE sp8 is loaded,
so agbcc emits `r1=t; r1+=0x3a; r2=sp8; r1=r2+r1` (value in r1, t-first) exactly
like the baserom. For the DIGIT case ALSO pin the value to r1 and address to r0
(`register u16 dval asm("r1"); register u16 *daddr asm("r0");`) AND flip the
col-part operand order to col-first (`(u32)(col * 2 + (u32)(u8 *)base)`): this
makes the digit store-tail byte-identical to `~` (`add r1,sl; strh r1,[r0]`), so
gcc cross-jumps and MERGES them (digit `b 0x1c264`). Confirmed: the digit case is
now byte-identical to the baserom.

### Table `[ddd]` lowering — use `<< 1` not `* 2`
`*(u16 *)(sCreditsTilemapEng + ((n*3 + 1) << 1))` (shift) instead of `* 2`
(multiply) lowers to the baserom's `adds r0,r1,#1; lsls r0,#1; adds r0,r0,table`
(index-first) instead of folding +1 into the table base pointer. Combined with a
shared `s32 m = n*3;`, this dropped diff_count from 68 to 49. This was the single
biggest late win.

## THE ONE REMAINING RESIDUAL — `[` decimal-escape case register ROTATION

The `[` case (the only case with the inner `bl sub_0801CEC0` + the 2-halfword
table copy) is byte-identical to the baserom in STRUCTURE but its registers are
cyclically ROTATED by one:
  - baserom: n*3 in r1, address in r2, table-base in r3, str[i+4] in r3.
  - ours:    n*3 in r2, address in r3, table-base in r1, str[i+4] in r0.
The rotation cascades from the `ldrb` register for `str[i+4]` in the
`c == '[' && str[i + 4] == ']'` guard: baserom `ldrb r3,[r2,#4]`, ours
`ldrb r0,[r2,#4]`. This is a pure local-allocator scratch-register tie in the
highest-pressure case (n pinned r4, base r6, col/row/palBits in r8/r9/sl, plus
the table base and address all live across the region). ~12 instructions of the
49-instruction diff are this rotation; the rest are branch-target address shifts
caused by it.

## Levers TRIED for the `[` rotation (do NOT repeat — pick something else)

- `(u16)(t+26)` cast on a-z (fixes a-z value AND incidentally str[i+4]->r3) but
  REGRESSES the `[` case to 205/60 (worse than 149/49). The a-z reassoc residual
  is only ~2 cheap instructions; keeping a-z as `sp8 + (t + 26) + palBits` (149/49)
  beats casting it (205/60). The a-z->str[i+4] coupling rotates `[` differently.
- col-first operand flip in the `[` dst: no change (150/50) — rotation is not
  operand-order driven.
- pinning the `[`-case dst to r2 (`register u16 *edst asm("r2")`): 190/51, worse
  (disrupts the table/n*3 allocation).
- per-TU flags ON TOP of -fno-caller-saves: -fno-cse-follow-jumps, -fschedule-insns,
  -fno-peephole, -fno-gcse, -fno-strength-reduce, -O1 — all stay 149/49 (the
  rotation is fixed regardless).
- n*3 inline (no `m` var): 264/67 — the `m` share is required.
- u16* table pointer var: 290/163 (clobbers n=r4 with col).
- PERMUTER (set up with main-repo venv + -fno-caller-saves in permuter_compile.sh):

```c
#include "types.h"

extern s32 sub_0801CEC0(const char *str, u8 len);

extern const u8 sCreditsTilemapEng[];

void sub_0801C078(const u8 *str, u8 count, u8 colBase, u8 rowBase, u16 sp8, s32 pal4, u8 sb)
{
    register s32 col asm("r8");
    register s32 row asm("r9");
    register u16 palBits asm("sl");
    register u16 *base asm("r6");
    u8 i;
    register int c asm("r5");
    u16 t;
    u16 *dst;
    register s32 n asm("r4");
    int d;
    register u16 dval asm("r1");
    register u16 *daddr asm("r0");

    palBits = (pal4 << 28) >> 16;
    col = 0;
    row = 0;

    switch (sb) {
    case 0:
        base = (u16 *)0x0600E000;
        break;
    case 1:
        base = (u16 *)0x0600E800;
        break;
    case 2:
        base = (u16 *)0x0600F000;
        break;
    case 3:
        base = (u16 *)0x0600F800;
        break;
    }

    /* explicit redundant guard -> gcc merges with the loop entry test and sinks
       `base += colBase*2` into the PREHEADER (after the guard), base in r6 */
    i = 0;
    if (i < count) {
        base = (u16 *)(colBase * 2 + (u32)base);
    }
    for (; i < count; i++) {
        c = str[i];
        if ((u8)(c - '0') <= 9) {
            if (c == '0') {
                t = 9;
            } else {
                t = c - '1';
            }
            /* (u16) cast defeats the sp8+0x3A reassoc; dval=r1/daddr=r0 +
               col-first make the store-tail merge (cross-jump) with the `~` case */
            daddr = (u16 *)(((row * 2 + rowBase) << 6) + (u32)(col * 2 + (u32)(u8 *)base) + 0x40);
            dval = (u16)(t + 0x3A) + sp8 + palBits;
            *daddr = dval;
        } else if ((d = c - 'A'), (u8)d <= 25) {
            t = d;
            *(u16 *)(((row * 2 + rowBase) << 6) + (u32)((u8 *)base + col * 2) + 0x40) = sp8 + t + palBits;
        } else if ((d = c - 'a'), (u8)d <= 25) {
            t = d;
            *(u16 *)(((row * 2 + rowBase) << 6) + (u32)((u8 *)base + col * 2) + 0x40) = sp8 + (t + 26) + palBits;
        } else if (c == '[' && str[i + 4] == ']') {
            n = sub_0801CEC0((const char *)(str + i + 1), 3) - 0xC0;
            if ((u32)n <= 63) {
                s32 m = n * 3;
                dst = (u16 *)(((row * 2 + rowBase) << 6) + (u32)((u8 *)base + col * 2));
                *dst = *(u16 *)(sCreditsTilemapEng + ((m + 1) << 1));
                dst = (u16 *)((u8 *)dst + 0x40);
                *dst = *(u16 *)(sCreditsTilemapEng + ((m + 2) << 1));
            }
            i += 4;
        } else if (c == ' ') {
            *(u16 *)(((row * 2 + rowBase) << 6) + (u32)((u8 *)base + col * 2) + 0x40) = 0;
        } else if (c == '*') {
            dst = (u16 *)(((row * 2 + rowBase) << 6) + (u32)((u8 *)base + col * 2) + 0x40);
            *dst = palBits + 0x24;
            dst = (u16 *)((u8 *)dst + 0x40);
            *dst = palBits + 0x24 - 0x1B;
        } else if (c == '?') {
            *(u16 *)(((row * 2 + rowBase) << 6) + (u32)((u8 *)base + col * 2) + 0x40) = 0xE0D6;
        } else if (c == '~') {
            *(u16 *)(((row * 2 + rowBase) << 6) + (u32)((u8 *)base + col * 2) + 0x40) = 0xE0EA + palBits;
        } else if (c == '|') {
            break;
        }

        col = (u8)(col + 1);
        if (c == '\n') {
            col = 0;
            row = (u8)(row + 1);
        }
    }
}
```
