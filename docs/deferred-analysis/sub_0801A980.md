# Deferred: sub_0801A980 (opus, round 21)

Window-wipe transition. Slides the two GBA hardware windows shut over
`count` vblank-synced frames (per-frame step = 56/count), then snaps both
windows fully open and clears the requested window-enable bits in
REG_DISPCNT (`flags` bit0 -> clear WIN0 enable, bit1 -> clear WIN1).

Range [0x0801a980, 0x0801aa60), 224 bytes. Callees: __divsi3 (0x08033d14,
SIGNED div), sub_080008DC (vblank wait). asm slice
asm/disasm_0x0801a980.s; dest src/engine/sub_0801a980.c.

2. `left + step` in the loop (offset +0x58):
   - target: `mov r1, r8 ; adds r0, r1, r5`  (rn=left, rm=step)

   Same registers, swapped rn/rm in the commutative 3-reg thumb add.
   combine.c's commutative canonicalization (line ~3354) does NOT fire
   here (both operands are REG class 'o'), so the order comes out of
   reload — and reload picks step (r5) first while baserom picks left.

## Levers already tried (do NOT repeat — pick a DIFFERENT one)

What got us from 47 -> 6 (KEEP these — they are the matching base):
- `register s32 count asm("r4") = count_;` — pinning the truncated arg1 to
  r4 FUSES the param narrow into `lsrs r4,r1,#24` (eliminates the spurious
  `adds r4,r1,#0` copy agbcc emits when count is an ordinary u8 local).
  SIGNED s32 is required so `56/count` uses __divsi3 (0x33d14), not
  __udivsi3 — u32 count gives __udivsi3 (wrong, +2 byte_diff).
- `u8 step = 56 / count;` — u8 step gives the `lsls;lsrs r5` step-trunc the
  baserom has. (u32 step loses it -> blows up to 158.)
- win0v store INLINED as raw `*(vu16*)0x04000044 = ...` (NOT a `register
  vu16* asm("sl")` pinned pointer). The sl-pin made the loop read the base
  back through r2 instead of reusing r1 (+ pool reorder). Inlining the
  store dropped 30 -> 12.
- Declaration order `u8 top = 56;` BEFORE `register u32 stepc asm("r9");`
  (top-before-stepc) — this is what dropped 10 -> 6 (fixed the `movs r6,#56`
  / `mov r9,r5` ordering around the n computation). stepc-before-top => 10.
- `left = (u8)(left + step);` and `top = (u8)(top - stepc);` — the (u8)
  casts give the `lsls;lsrs` accumulator narrows (NOT `& 0xff`, which emits
  `ands` -> +6).

DID NOT help the two residual diffs (tried, all stayed 6 or worse):
- swap add operands `step + left` (commutative, no asm change).
- `(u32)step` cast in the add; `left += step; left=(u8)left;` split (+3).
- `n` as: separate int temp `m`; `count=count+1; n=count;`; `(count+1)&0xff`
  (-> ands, +6); `int n`; declaring n early (disrupts divsi3, +26).
- `register u8 step asm("r5")` pin (disrupts, +168).
- per-TU CFLAGS: -fno-peephole, -fno-thread-jumps, -fcaller-saves,

## Best-effort C (byte_diff 6)

```c
#include "types.h"

void sub_080008DC(void);

/* Window-wipe transition. Slides the two hardware windows shut over
 * `count` vblank-synced frames (per-frame step 56/count), then snaps
 * both windows fully open and clears the requested window-enable bits
 * in REG_DISPCNT (flags bit0 -> clear WIN0, bit1 -> clear WIN1). */
void sub_0801A980(u8 flags, u8 count_)
{
    register s32 count asm("r4") = count_;
    register u32 left asm("r8") = 104;
    u8 step = 56 / count;
    u8 top = 56;
    register u32 stepc asm("r9") = step;
    u8 n = count + 1;
    if (n != 0) {
        do {
            *(vu16 *)0x04000040 = 0xf0;
            *(vu16 *)0x04000044 = (left << 8) | 0xa0;
            *(vu16 *)0x04000042 = 0xf0;
            *(vu16 *)0x04000046 = top;
            sub_080008DC();
            left = (u8)(left + step);
            top = (u8)(top - stepc);
            n = n - 1;
        } while (n != 0);
    }
    *(vu16 *)0x04000040 = 0xf0;
    *(vu16 *)0x04000044 = 0xa0;
    *(vu16 *)0x04000042 = 0xf0;
    *(vu16 *)0x04000046 = 0;
    *(vu16 *)0x04000000 &= 0xf7ff;
    if (flags & 1) *(vu16 *)0x04000000 &= 0xdfff;
    if (flags & 2) *(vu16 *)0x04000000 &= 0xbfff;
}
```
