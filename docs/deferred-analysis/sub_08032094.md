# sub_08032094 — deferred (byte_diff 10, reload-coloring local minimum)

Sound-request teardown at 0x08032094 (180 bytes), dest `src/system/sub_08032094.c`,
neighbour cluster around `sub_0803299c.c` / `sound_mixer_tail.c`. Callees
`sub_0802F9F0` and `sub_0802E724` are both peeled. `make check` passes on the
pristine tree; the asm slice is left in place (this is a deferral, not a ship).

## What the function does (fully understood)

```
ss   = gpSoundSystem;                  // *(SoundSystem**)0x030065e0
slot = ss->slot;                       // +0x118
flags = slot->flags;                   // +0x151, one byte
if ((flags & 7) != 3) return 0;        // state nibble must be 3
slot->flags = (flags & ~SOUND_REQUEST_FLAG_ACTIVE) | 4;   // 0xfd & flags, | 4
if (mode == 0) return 1;
for (i = 0; i < (s32)gpSoundSystem->count + 4; i++) {      // count re-read each iter
    SoundDrainEntry *e = &((SoundDrainEntry*)slot->nextRegion)[i];   // stride 12, +0x110
    if (e->live == 0) continue;        // +4 byte
    if (mode == 1) sub_0802F9F0(i);
    else { gpSoundSystem->channelSeqs[i].opPtr = NULL;     // +0x114, stride 16, store 0
           sub_0802E724(i); }
    e->live = 0;
}
return 1;
```

This is a SINGLE-loop function (NOT the two-loop `*gpGlobal` class) and is
structurally fully matchable — classify is ATTEMPT_MATCH, not STRONG.

## Drift — byte_diff 10, diff_count ~8 insns, ALL pure reload-pass scratch coloring

Best base (see "Best-effort C") reaches byte_diff 10. Every remaining diff is
agbcc's reload pass choosing a DIFFERENT scratch register for an anonymous
materialization temp — mine grabs r0 where the baserom uses r1/r2. The baserom
consistently keeps r0 free (for the BL arg `i` / return value) and uses r1/r2
for loop scratch; agbcc here greedily takes r0. The remaining sites:

| site (loop body)                          | baserom | mine |
|-------------------------------------------|---------|------|
| `0x110` const → `r6 = &slot->nextRegion`  | r2      | r0   |
| `mov rX, r8` for the `mode == 1` compare  | r0      | r1   |
| `0x114` const → `&gpSoundSystem->channelSeqs` | r1   | r2   |
| ip-reload `ldr rX,[pc]; mov ip,rX`        | r2      | r0   |

The count-check temp `mov rX, ip; ldr [rX]` IS fixable: pin a
`register SoundSystem **p asm("r1") = gpsp;` and read the count through `(*p)`
(that brought 14 → 10). The other four are NOT C-steerable: they are reload-pass
temps for inline constant materialization (`0x88<<1`, `0x8a<<1`), the `mov ip`
reload source, and the `r8→rN` mode copy — none are exposed as a C pseudo I can
`register asm()`-pin (tried; the hint is coalesced away at the rematerialization
site).

## Levers tried (none reach < 10)

- ~18 source shapes: inverted `if ((flags&7)==3){...}` (return-0 at tail — the
  big win, 169→74; the `bne`-to-tail polarity is REQUIRED), `gpsp = &gpSoundSystem`
  placed AFTER the `flags & 7` precompute (deferred `mov ip` to the right spot,
  74→16/26), the in-loop `gpsp = &gpSoundSystem` reload after the calls (THE
  structural key for the ip-reload-after-call, 76→19), removing the `mode asm("r8")`
  pin (16→14, mode flows to r8 naturally), count-temp pin `p asm("r1")` (14→10).
- CFLAGS sweep: `-fforce-addr -fno-expensive-optimizations -fno-gcse`,
  `-fno-schedule-insns[2]`, `-fno-cse-*`, `-fno-regmove` (12, worse),
  `-fcaller-saves` (12, worse), `-fno-caller-saves`, plus DEFAULT (no flags) —
  all land at 10. So no CFLAGS line is needed; default CFLAGS give the same 10.
- Compiler swap: newer `agbcc` (AGBCC_BIN) — identical 10.
- Pins on the four reload temps (`asm("r2")` / `asm("r0")` on intermediates) —
  coalesced away, no effect.
- decomp-permuter: ~16000 iterations across 3 runs (j4, --stop-on-zero,
  --better-only) on the 14- and 10-diff bases. NEVER beat base score 60
  (= 10 diffs). The randomizer mutates statement order/scope/temps; it does not
  reach reload-pass scratch coloring, which is the only thing left.

## Best-effort C (byte_diff 10, one load-bearing pin + the ip idiom)

```c
#include "sound.h"

extern void sub_0802F9F0(s32 idx);
extern void sub_0802E724(s32 ch);

u32 sub_08032094(u32 mode)
{
    register SoundSystem **gpsp asm("ip");
    SoundRequestSlot *slot;
    u8 flags;
    u32 state;
    u32 newFlags;
    s32 i;

    slot = gpSoundSystem->slot;
    flags = slot->flags;
    state = flags & 7;
    gpsp = &gpSoundSystem;

    if (state == 3) {
        newFlags = (u8)~SOUND_REQUEST_FLAG_ACTIVE;
        newFlags &= flags;
        newFlags |= 4;
        slot->flags = newFlags;

        if (mode != 0) {
            for (i = 0;; i++) {
                register SoundSystem **p asm("r1") = gpsp;  /* count-temp -> r1 (14->10) */
                if (i >= (s32)(*p)->count + SOUND_REQUEST_DRAIN_EXTRA_COUNT)
                    break;
                if (((SoundDrainEntry *)slot->nextRegion)[i].live == 0)
                    continue;
                if (mode == 1) {
                    sub_0802F9F0(i);
                } else {
                    gpSoundSystem->channelSeqs[i].opPtr = NULL;
                    sub_0802E724(i);
                }
                ((SoundDrainEntry *)slot->nextRegion)[i].live = 0;
                gpsp = &gpSoundSystem;   /* reload ip after the BLs clobber r12 */
            }
        }
        return 1;
    }
    return 0;
}
```
