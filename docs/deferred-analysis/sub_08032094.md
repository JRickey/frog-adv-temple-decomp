# sub_08032094 — deferred (byte_diff 10, sharp local-alloc scratch-coloring minimum)

neighbour cluster around `sub_0803299c.c` / `sound_mixer_tail.c`. Callees
`sub_0802F9F0` and `sub_0802E724` are both peeled. `make check` passes on the
pristine tree; the asm slice is left in place (this is a deferral, not a ship).

## What the function does (fully understood — structurally MATCHABLE, ATTEMPT_MATCH)

```
ss   = gpSoundSystem;                  // *(SoundSystem**)0x030065e0
slot = ss->slot;                       // +0x118
flags = slot->flags;                   // +0x151, one byte
if ((flags & 7) != 3) return 0;        // state nibble must be 3 (bne-to-tail polarity REQUIRED)
slot->flags = (flags & ~SOUND_REQUEST_FLAG_ACTIVE) | 4;   // (flags & 0xfd) | 4
if (mode == 0) return 1;
for (i = 0; i < (s32)gpSoundSystem->count + 4; i++) {      // count RE-READ each iter via ip
    SoundDrainEntry *e = &((SoundDrainEntry*)slot->nextRegion)[i];   // stride 12, field +0x110
    if (e->live == 0) continue;        // +4 byte
    if (mode == 1) sub_0802F9F0(i);
    else { gpSoundSystem->channelSeqs[i].opPtr = NULL;     // +0x114, stride 16, store 0, FRESH literal
           sub_0802E724(i); }
    e->live = 0;
}
return 1;
```

Single-loop function (NOT the two-loop `*gpGlobal` class). classify = ATTEMPT_MATCH.

## Drift — byte_diff 10 / diff_count 10, ALL scratch register-rotation

|------|---------|------|---------------------------------------|
| 0x42 | r2      | r0   | const 0x110 -> `r6 = slot + 0x110` (=&nextRegion) |

## ROOT CAUSE — re-confirmed THIS round by INSTRUMENTING old_agbcc gcc/ passes

The default CC for this TU is **old_agbcc** (built from `tools/agbcc-src/gcc/`, NOT
`gcc_arm/`). This round I built a PRIVATE debug old_agbcc and instrumented BOTH
`global.c:find_reg` (FINDREG trace) and `local-alloc.c:find_free_reg` (FREEREG trace,
dumping the `first_used` hard-reg mask for every block-local qty).

KEY FINDINGS (new, decisive):
- The 4 diverging scratches are **block-local pseudos** handled by **local-alloc**
  (which runs BEFORE global-alloc). The loop-spanning values (i=r4, slot=r5, base=r6,
  zero=r7, mode=r8, gpsp=ip) are global qtys assigned by global.c AFTER.
- `find_free_reg` builds `used = fixed_reg_set | (OR of regs_live_at[ins] for ins in
  [birth,death))` and returns the LOWEST hard reg not in `used`. At local-alloc time
  pseudos are NOT yet hard regs, so `regs_live_at` only carries already-assigned HARD
  regs.
- For the 0x110 scratch in MINE, the trace prints `firstused_lo8=0x80` — ONLY r7 is
  excluded (r7 is the pre-claimed zero constant). So local-alloc picks r0.
- To match the baserom (r2), the scratch's `firstused` must be `0x83` (r0+r1+r7) — i.e.
  hard regs r0 AND r1 must be LIVE across the scratch's 3-insn window. NO source shape
  tried makes a hard-reg value's live range *extend through* the scratch window: a
  `register x asm("r0")`/`asm("r1")` pin on the count/ip-alias temp ends its live range
  at the consuming insn (the `bge`/the `ldr`), so r0/r1 are dead by the scratch and the
  mask stays 0x80. (Verified: `register s32 n asm("r0")` on the count value → still 10,
  same 4 sites.)
- Newer agbcc (`tools/agbcc/bin/agbcc`) produces the SAME r0 at 0x42 — the
  `{3,2,1,0,...}` REG_ALLOC_ORDER in `gcc_arm/config/arm/arm.h` does NOT govern these
  local scratches; compiler swap is NOT a lever here.

The inversion (r0 busy in loop-setup at 0x42/0x8a but free at the mode-dispatch 0x56 in
the baserom; exactly opposite in mine) is a per-instruction local-alloc liveness
difference of ~1 insn that no source expression, pin, or CFLAG reproduces.

## Levers tried this round (re-derived from scratch — NONE beats 10)

- Plain C, NO pins → byte_diff 149 (agbcc uses TWO callee-saved high regs r8+r9; the
  baserom uses ONLY r8 for mode and keeps &gpSoundSystem in CALL-CLOBBERED ip,
  reloaded after each BL). CONFIRMS the `register SoundSystem **gpsp asm("ip")` shape is
  STRUCTURALLY REQUIRED (and is a corpus-validated pure-C idiom: katam
  `dark_meta_knight.c:2526` uses `register u32 ip asm("ip")`).
- ip-pin + `register p asm("r1") = gpsp` for the count-check (`mov r1,ip; ldr r0,[r1]`)
  → byte_diff 10 (the canonical/best shape). This r1 pin is LOAD-BEARING (without it the
  count check fuses to `mov r0,ip; ldr r0,[r0]`, never touching r1 → worse).
- if-nest body vs `continue` → identical 10, same 4 sites.
- `n asm("r0")` count pin → 10, same 4 sites (pin coalesces, doesn't extend liveness).
- count hoisted into local `n` (while-loop) → 51 (count check de-loops badly).
- else-branch-first (`if (mode != 1)`) → 83 (polarity flip, wrong physical order).
- ip-init at declaration (`gpsp = &gpSoundSystem` at top) → 167 (prologue reorders).
- compiler swap to newer agbcc → same r0 at 0x42 (no help).
- decomp-permuter: correctly-scored target (`make_permuter_target.py`, base score 60 =
  10 diffs × 6), fresh `-j4 --stop-on-zero --better-only` run ~520 iters in 4 min, best
  stayed 60 (every mutation ≥60; 70/80 seen but those are WORSE). Combined with the
  prior note's 16k + this lineage's 10k iters, permuter is exhausted.

## Next-attempt suggestions (do something DIFFERENT from everything above)

1. The crux is making local-alloc's `first_used` mask = 0x83 (exclude r0+r1) at the
   0x110-scratch window WITHOUT a pin. local-alloc only excludes HARD regs live across
   [birth,death). So you need a value that is BOTH (a) forced to a hard reg r0 (or r1)
   AND (b) whose live range demonstrably SPANS the scratch's 3 insns (movs/lsls/adds).
   A pin alone fails (range ends at the consuming insn). Idea NOT yet tried: a value
   USED on BOTH sides of the scratch (read before 0x42, read again after 0x46) and
   pinned to r0 — e.g. a redundant re-load of `slot` or `i` placed so its two reads
   straddle the base computation. The straddle is what extends the range across the
   scratch; the pin makes it r0.

   (Done partially: global only assigns the 8 loop-spanning qtys to r4/r5/r6/r7/r8 +

## Best-effort C (byte_diff 10 — ip pin + one load-bearing r1 pin)

```c
#include "sound.h"

extern void sub_0802F9F0(s32 idx);
extern void sub_0802E724(s32 ch);

u32 sub_08032094(u32 mode)
{
    register SoundSystem **gpsp asm("ip");
    SoundRequestSlot *slot;
    u8 flags;
    u32 state;
    u32 newFlags;
    s32 i;

    slot = gpSoundSystem->slot;
    flags = slot->flags;
    state = flags & 7;
    gpsp = &gpSoundSystem;

    if (state == 3) {
        newFlags = (u8)~SOUND_REQUEST_FLAG_ACTIVE;
        newFlags &= flags;
        newFlags |= 4;
        slot->flags = newFlags;

        if (mode != 0) {
            for (i = 0;; i++) {
                register SoundSystem **p asm("r1") = gpsp;  /* count-check -> mov r1,ip; ldr r0,[r1] */
                if (i >= (s32)(*p)->count + SOUND_REQUEST_DRAIN_EXTRA_COUNT)
                    break;
                if (((SoundDrainEntry *)slot->nextRegion)[i].live == 0)
                    continue;
                if (mode == 1) {
                    sub_0802F9F0(i);
                } else {
                    gpSoundSystem->channelSeqs[i].opPtr = NULL;
                    sub_0802E724(i);
                }
                ((SoundDrainEntry *)slot->nextRegion)[i].live = 0;
                gpsp = &gpSoundSystem;   /* reload ip after the BLs clobber r12 */
            }
        }
        return 1;
    }
    return 0;
}
```
