## ROOT CAUSE — confirmed by INSTRUMENTING old_agbcc (NEW this round)

Built a private debug old_agbcc (`gcc/local-alloc.c`, probe at the `find_free_reg`
return). KEY FINDING: **old_agbcc's Thumb backend (gcc/, telf.h/thumb.md) defines NO
`REG_ALLOC_ORDER`** — so `find_free_reg` iterates `regno = 0,1,2,3,…` and returns the
**lowest-numbered free hard reg**. (The `{3,2,1,0,12,…}` REG_ALLOC_ORDER in
`gcc_arm/config/arm/arm.h` is the NEWER agbcc only — irrelevant to old_agbcc, which is
the default CC for this TU. Don't be misled by reading gcc_arm.)

Consequence: agbcc greedily takes r0 for a free temp; the baserom's r1/r2 choices mean
**r0 (and sometimes r1) were BUSY at those exact points in the original**. The match
therefore requires reproducing the original's precise per-instruction liveness so that
r0 is live across 0x42/0x70/0x8a but FREE at 0x56 — and mine is exactly INVERTED there
(r0 free at 0x42/0x8a, excluded at 0x56). That inversion is a global-allocation
phase difference of a pseudo whose live range differs by ~1 insn; it is NOT steerable
by any source expression tried.

## Why slot lands in r5 (solved — so the canonical shape is REQUIRED)

local-alloc allocates qtys by DECREASING life length. `i` (long life, crosses calls)
gets r4 first; `slot`'s last use (`r6 = slot+0x110`) happens AFTER `i=0` is live, so
`i` excludes r4 from slot's range and slot coalesces to r5 (then r5 is REUSED as the
byte-offset IV). Only the infinite-for+break+continue+staged-flags shape produces this;
a plain `for (i=0; cond; i++)` puts slot in r3 (149→96→… 28). Keep the canonical shape.

```c
#include "sound.h"

extern void sub_0802F9F0(s32 idx);
extern void sub_0802E724(s32 ch);

u32 sub_08032094(u32 mode)
{
    register SoundSystem **gpsp asm("ip");
    SoundRequestSlot *slot;
    u8 flags;
    u32 state;
    u32 newFlags;
    s32 i;

    slot = gpSoundSystem->slot;
    flags = slot->flags;
    state = flags & 7;
    gpsp = &gpSoundSystem;

    if (state == 3) {
        newFlags = (u8)~SOUND_REQUEST_FLAG_ACTIVE;
        newFlags &= flags;
        newFlags |= 4;
        slot->flags = newFlags;

        if (mode != 0) {
            for (i = 0;; i++) {
                register SoundSystem **p asm("r1") = gpsp;  /* count-temp -> r1 (14->10) */
                if (i >= (s32)(*p)->count + SOUND_REQUEST_DRAIN_EXTRA_COUNT)
                    break;
                if (((SoundDrainEntry *)slot->nextRegion)[i].live == 0)
                    continue;
                if (mode == 1) {
                    sub_0802F9F0(i);
                } else {
                    gpSoundSystem->channelSeqs[i].opPtr = NULL;
                    sub_0802E724(i);
                }
                ((SoundDrainEntry *)slot->nextRegion)[i].live = 0;
                gpsp = &gpSoundSystem;   /* reload ip after the BLs clobber r12 */
            }
        }
        return 1;
    }
    return 0;
}
```
