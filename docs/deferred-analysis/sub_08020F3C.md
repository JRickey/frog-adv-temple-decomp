# Deferred analysis: sub_08020F3C

Per-tick mover for the entity at index `arg` in the 0x38-stride entity array
at 0x03003720 (entity[0] doubles as the player header `gIwram_3720`).

## Semantics (confidently reconstructed)

```c
void sub_08020F3C(u8 arg)
{
    /* gate: sub_08006830 returns a u64; the caller ORs the halves and bails on 0 */
    if (sub_08006830(&gIwram_6110, arg, arg) == 0)
        return;

    e = &gEntities_03003720[arg];          /* base 0x03003720, stride 0x38 */

    /* rate-limit: skip until enough ticks have elapsed since field_2c was stamped */
    if ((u32)(gGameStuff._unk00 - e->_field_2c) < e->_field_32)
        return;

    dx = (s8)e->_field_30;                 /* signed per-tick X delta (ldrsb) */
    dy = (s8)e->_field_31;                 /* signed per-tick Y delta (ldrb + sxtb) */
    e->_field_2 += dx;                     /* advance entity sub-coords */
    e->_field_4 += dy;

    /* if this is the "controlled" entity (35E0.field_10 bit 1 set and
       35E0.field_D == arg), advance the player header (entity[0]) too */
    if ((gIwram_35E0._field_10 & 2) && gIwram_35E0._field_D == arg) {
        gIwram_3720._field_2 += dx;
        gIwram_3720._field_4 += dy;
    }

    e->_field_2c = gGameStuff._unk00;      /* restamp the rate-limit timestamp */
}
```

Field types nailed from the asm: field_2/field_4 = s16 (ldrh/strh), field_2c =
u32 (ldr/str), field_30 = s8 (read via `ldrsb`), field_31 = u8 read then
sign-extended (`lsl#24;asr#24`), field_32 = u8 (unsigned compare).
`gGameStuff._unk00` is the u32 at 0x03005330+0 (a tick/timestamp).
`sub_08006830(base6110, arg, arg)` returns a `long long`; gate is `== 0`.

## Drift (opus attempt — round 6)

Best base this session: **byte_diff 97, diff_count 54** (size 168). This is an
improvement over the prior plateau (105/54). The improvement came from a NEW
lever the prior attempt's list (1–10) did NOT include:

### The keystone NEW lever: split gGameStuff into gsLo(r4) + gsHi(r8)

The prior attempt tried `gs asm("r4")` (regressed — no r4->r8 spill) and never
tried `gs asm("r8")` alone, and never tried the SPLIT. The split is what
unlocks baserom's register map:

```c
register GameStuff *gsLo asm("r4");   /* holds gGameStuff across the gate read */
register GameStuff *gsHi asm("r8");   /* spilled copy reloaded at the final store */
...
gsLo = &gGameStuff;
...
gsHi = gsLo;                          /* compiles to baserom's `mov r8, r4` spill */
... gsLo->_unk00 ...                  /* gate read from r4 */
... gsHi->_unk00 ...                  /* final store reload from r8 */
```

Combined with the rest of the matching pin/structure set:

```c
register EntityMover *base asm("r3");
register EntityMover *e    asm("ip");
register u32 argReg asm("r6");        /* arg -> r6 (MATCHES baserom) */
register u32 arg8   asm("r5");        /* arg<<3 CSE -> r5 (MATCHES baserom) */
u32 off;
...
argReg = arg;
... sub_08006830(&gIwram_6110, argReg, argReg) ...
gsLo = &gGameStuff;
base = (EntityMover *)&gIwram_3720;
arg8 = argReg << 3;
off  = (arg8 - argReg) << 3;          /* explicit ((arg<<3)-arg)<<3 == arg*0x38 */
delta = gsLo->_unk00 - *(u32 *)((u8 *)base + off + 0x2c);
e = (EntityMover *)((u8 *)base + off);
gsHi = gsLo;
if (delta < e->interval) return;
... e->dx / e->dy / e->x += dx / e->y += dy ...
*(u32 *)((u8 *)base + ((arg8 - argReg) << 3) + 0x2c) = gsHi->_unk00;
```

**This now reproduces baserom's WHOLE front half byte-for-byte**: the
`b5f0; mov r7,r8; push{r7}` prologue (r8 saved), `lsrs r6` (arg=r6),
`ldr r4,=gGameStuff; ldr r3,=base; lsls r5,r6,#3` (arg8=r5),
`subs r0,r5,r6; lsls #3; mov ip; mov r8,r4` (spill) — ALL match. The
register-coloring wall the prior attempt hit (arg in r5 vs r6, no r5 CSE)
is SOLVED. The prologue is now `b5f0` (r4-r7 saved) matching baserom.

### THE remaining wall: the `[rN, #0x2c]` displacement fold (instruction selection)

The ONLY structural residual is how the `field_2c` (stamp) address is formed,
at BOTH the gate read and the final store:

- baserom: `adds r0,r3,#0; adds r0,#0x2c; adds r0,r1,r0; ldr r0,[r0,#0]`
  — it materializes `base + 0x2c` into a register, then adds the variable
  offset (register+register), then loads with displacement **0**.
- every C structure tried (round 6): `adds r0,r3,r1(off); ldr r0,[r0,#0x2c]`
  — agbcc folds the constant `0x2c` into the load displacement (2 insns
  shorter). This 2-insn shift is what inflates byte_diff from ~1-2 to 97 by
  cascading the alignment of everything after the gate.

**The fold is an agbcc instruction-selection INVARIANT, not a schedule/flag
issue.** Confirmed exhaustively this session:
- Both `agbcc` and `old_agbcc` fold it identically.
- `-fno-gcse`, `-fno-expensive-optimizations`, `-fno-strength-reduce`,
  `-fno-force-mem`, `-fno-omit-frame-pointer`: NONE prevent the fold (the
  `combine` pass reassociates `(p+0x2c)+reg -> (p+reg)+0x2c` and folds 0x2c
  into the mem displacement; 0x2c=44 is a valid 5-bit-scaled word offset).
- Every C address form folds: `e->stamp`; `*(u32*)((u8*)base+off+0x2c)`;
  `((u8*)((u8*)base+0x2c))+off`; `(u32)base+0x2c+off` (integer arith);
  `&base->stamp + off`; nested casts; `StampSlot` array based at base+0x2c.
- A SHARED `stampBase = (u8*)base+0x2c` local (reused at both sites) DOES
  force the register-materialized form — but keeping it LIVE across the body
  displaces the register coloring and regresses to byte_diff 162. baserom
  RECOMPUTES `base+0x2c` at each site (does NOT keep it live), so a shared
  live value is the wrong model.

### What that implies for the next attempt

baserom emits the non-folded `adds #0x2c` form WITHOUT keeping `base+0x2c`
live. The next agent should hunt for the SOURCE EXPRESSION that makes agbcc
recompute `base+0x2c` into a register at each use without a live CSE — likely
a different struct/access shape than a flat `EntityMover` with `u32 stamp` at
+0x2c. Untried angles:
- Model the stamp via a nested sub-struct/union whose member sits at element
  offset 0 of a sub-array based at +0x2c, indexed by `arg` with stride 0x38,
  such that the multiply is SHARED with `e`'s multiply (so arg8=r5 CSE
  survives) but the base `+0x2c` materializes per-use. The `StampSlot[arg]`
  attempt failed only because it used an INDEPENDENT `arg*0x38` multiply (lost
  the arg8 CSE) — feed it the SAME `off` value instead of `[argReg]`.
- Try reading `gGameStuff._unk00` and the stamp in the OTHER order, or storing
  the gate result through a different temp, to nudge `combine` away from the
  fold (low-probability — combine is deterministic here).
- The dx/dy register choice (baserom dx=r4 reuses the reg gGameStuff vacated;
  dy=r1) is DOWNSTREAM of the spill placement and will likely fall out once
  the field_2c form matches and the alignment stops cascading. Do NOT chase
  dx/dy independently until the fold is solved.

Permuter is the WRONG tool here: it mutates statement order / scope / temps
(scheduling), but the residual is INSTRUCTION SELECTION (`ldr [r,#0x2c]` vs
`adds #0x2c; ldr [r,#0]`) which the permuter cannot rewrite. Not attempted for
that reason.

## Best-effort C (byte_diff 97 — the gsLo/gsHi split base)

```c
#include "game.h"
#include "iwram.h"
#include "types.h"

typedef struct EntityMover {
    u8 _pad00[2];
    s16 x;        /* +0x02 */
    s16 y;        /* +0x04 */
    u8 _pad06[0x26];
    u32 stamp;    /* +0x2c: rate-limit timestamp */
    s8 dx;        /* +0x30 */
    u8 dy;        /* +0x31 */
    u8 interval;  /* +0x32 */
    u8 _pad33[5];
} EntityMover;

extern long long sub_08006830(struct IwramAt6110 *p, u8 a, u8 b);

void sub_08020F3C(u8 arg)
{
    register EntityMover *base asm("r3");
    register EntityMover *e asm("ip");
    register GameStuff *gsLo asm("r4");
    register GameStuff *gsHi asm("r8");
    register u32 argReg asm("r6");
    register u32 arg8 asm("r5");
    u32 off;
    s8 dx;
    s8 dy;

    argReg = arg;
    if (sub_08006830(&gIwram_6110, argReg, argReg) == 0)
        return;

    gsLo = &gGameStuff;
    base = (EntityMover *)&gIwram_3720;
    arg8 = argReg << 3;
    off = (arg8 - argReg) << 3;

    e = (EntityMover *)((u8 *)base + off);
    gsHi = gsLo;

    if ((u32)(gsLo->_unk00 - *(u32 *)((u8 *)base + off + 0x2c)) < e->interval)
        return;

    dx = e->dx;
    dy = (s8)e->dy;
    e->x += dx;
    e->y += dy;

    if ((gIwram_35E0._field_10 & 2) && gIwram_35E0._field_D == argReg) {
        base->x += dx;
        base->y += dy;
    }

    *(u32 *)((u8 *)base + ((arg8 - argReg) << 3) + 0x2c) = gsHi->_unk00;
}
```
