# sub_08015B6C — deferred analysis (round 8, Opus escalation)

2D rectangular tilemap copy (a `sub_08012BC4` cousin). Copies a `width x height`
rectangle of u16 tiles from `src->tiles` (struct field 12, row stride at field 48
= 0x30) into one of three EWRAM buffers selected by `mode` (0 -> `0x80<<18` =
0x02000000, 1 -> 0x02010000, 2 -> 0x02020000), at sub-rect origin (dstX, dstY)
which are SIGNED s16 (`asr`), using the scene stride at `*(u16*)(0x030060A0 + 26)`.

Signature: `void sub_08015B6C(u8 mode, s16 dstX, s16 dstY, u8 widthArg,
u8 heightArg, struct BlitSource *src)`. Range 0x08015B6C..0x08015C24 (184 bytes).
Leaf (no calls). Classifier: ATTEMPT_MATCH. Default compiler OLD_AGBCC. Dest:
`src/engine/sub_08015a00.c`. Do NOT NAKED (not STRONG_UNMATCHABLE).

## THE KEY NEW IDIOM (round 8): shared-variable-pinned-r1 → base in r1

The target colors ONE physical register r1 across THREE disjoint roles:
dstX-arg (entry) -> base-pointer (offset block, `ldr r1; ldrh r3,[r1,#26]`) ->
nextRow (loop, `adds r1,r0,#1`). The base and nextRow SHARE r1 at disjoint times.

Round 7 proved a `register base asm("r1")` PIN cannot do this (the pin makes r1
fixed whole-function, so base conflicts with nextRow -> spill, 166/47). The escape:
**declare ONE variable used as base-pointer early and as nextRow late, pinned r1.**
Because they are the SAME pseudo, the r1 pin creates NO base/nextRow conflict:

```c
register u32 r1slot asm("r1");
...
r1slot = 0x030060A0;                                   /* ldr r1, [pc]  (base)  */
dst += (s16)dyh * ((struct BlitState *)r1slot)->stride + dx;  /* ldrh r3,[r1,#26] */
...
loopState = (struct BlitState *)r1slot;                /* mov r9, r1  (DEFERRED) */
if (row < height) {
    do {
        r1slot = row + 1;                              /* adds r1, r0, #1 (nextRow) */
        ...
        row = (u8)r1slot;
    } while (...);
}
```

This single change: base -> r1 (was r2/r3), the `mov r9,r1` cache DEFERS past the
stride+srcData reads (matches target 0x66), and nextRow reuses r1. Prologue stays
clean once `srcp = src` is the FIRST init (loads src early like target 0x0a) and
`dyh = (u16)dstY` precedes `dx` (so dstX vacates r1 before r1slot needs it).
ALSO needed: `dx asm("r2")` pin (gives dx r2) + offset written product-first
(`(s16)dyh*stride + dx`) so the sum accumulates in r0 (product) not r2 (dx).

## The 3 residual clusters (all coupled coloring/scheduling — 20 diffs)

1. **Offset base-early (~5):** `r1slot = 0x030060A0` is a STATEMENT, so agbcc
   loads the const at the statement (0x4a) — target loads it inline in the
   multiply (0x54, AFTER dx+dyh). Tried: inline const in expr (breaks the
   pin-coupling, base->r2 eager, 49/25); comma-operator `(r1slot=const, ...)`
   (no defer, 44/21); precompute dyTmp (sum reg regresses to r2, 45/22). The
   const load placement is the dominant remaining structural diff.
2. **Prologue src-load timing (~6):** target loads src `[sp,#32]` at 0x0a
   immediately after height `[sp,#28]` at 0x08 (both raw, casts all deferred to
   the end). With `srcp=src` first, ours loads src at ~0x18 (after the dstX
   pre-shift). Not closed by init reorder. (Round-7 also flagged this as not
   reachable by statement reorder / -fno-schedule-insns — and old_agbcc REJECTS
   -fno-schedule-insns/insns2: it has NO separate scheduler, order is from RTL
   gen + combine + reload.)
3. **srcp lower-temp r0-vs-r7 (~4):** target lowers srcp(r8) into r7 (=scratch2)
   for both `->tiles` (`mov r7,r8; ldr r3,[r7,#12]`) and `->srcStride`
   (`mov r7,r8; ldrh r7,[r7,#48]`); ours lowers into r0. The two-step idiom
   that works for loopState does NOT work here (srcp two-step spills srcData to
   stack, 69-72/22-23 — round 7 warned this).

## Best-effort C (AH: byte_diff 46 / diff_count 20, size EXACT 184)

```c
struct BlitState {
    u8 _pad00[26];
    u16 stride;
};

struct BlitSource {
    u8 _pad00[12];
    const u16 *tiles;
    u8 _pad10[32];
    u16 srcStride;
};

void sub_08015B6C(u8 mode, s16 dstX, s16 dstY, u8 widthArg, u8 heightArg, struct BlitSource *src)
{
    register struct BlitSource *srcp asm("r8");
    register u16 *dst asm("r6");
    register const u16 *srcData asm("r3");
    register u32 row asm("r0");
    register u32 r1slot asm("r1");   /* base-ptr early, nextRow late: shares r1 (the idiom) */
    register u32 width asm("r5");
    register u32 height asm("r4");
    register u32 dyh asm("ip");
    register struct BlitState *loopState asm("r9");
    u8 col;
    register u32 scratch2 asm("r7");
    register s16 dx asm("r2");

    srcp = src;
    dyh = (u16)dstY;
    dx = (s16)dstX;
    width = (u8)widthArg;
    height = (u8)heightArg;

    switch (mode) {
    case 0:
        dst = (u16 *)(0x80 << 18);
        break;
    case 1:
        dst = (u16 *)0x02010000;
        break;
    case 2:
        dst = (u16 *)0x02020000;
        break;
    }

    r1slot = 0x030060A0;
    dst += (s16)dyh * ((struct BlitState *)r1slot)->stride + dx;

    srcData = srcp->tiles;
    row = 0;
    loopState = (struct BlitState *)r1slot;
    if (row < height) {
        register u32 scratch asm("r2");

        do {
            col = 0;
            r1slot = row + 1;
            if (col < width) {
                do {
                    *dst++ = *srcData++;
                    col = (u8)(col + 1);
                } while (col < width);
            }

            scratch = (u32)loopState;
            scratch = ((struct BlitState *)scratch)->stride;
            dst += scratch - width;
            scratch2 = srcp->srcStride;
            srcData += scratch2 - width;
            row = (u8)r1slot;
        } while (row < height);
    }
}
```
