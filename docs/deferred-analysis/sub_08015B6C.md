# sub_08015B6C — deferred analysis (round 5, Opus)

2D rectangular tilemap copy (a `sub_08012BC4` cousin). Copies a
`width x height` rectangle of u16 tiles from `src->tiles` (struct field 12,
row stride at field 48) into one of three EWRAM buffers selected by `mode`
(0 -> 0x02000000, 1 -> 0x02010000, 2 -> 0x02020000), at sub-rect origin
(dstX, dstY) which are **SIGNED s16** (`asr`, not `lsr`), using the global
scene stride at `*(u16*)(0x030060A0+26)`.

Range 0x08015B6C..0x08015C24 (184 bytes). Leaf (no calls).
Classifier: ATTEMPT_MATCH (no computed jump; the switch is a comparison
cascade, not casesi). Default compiler OLD_AGBCC. Dest: `src/engine/sub_08015a00.c`.
NEW agbcc gives the identical diff (44/26) — not a compiler-swap case.

Two round-4 sub-issues stayed solved (u32 width/height; struct-cast in-loop stride
read). Round 5 ADDED two improvements over round 4:
- **Deferred r9 cache via `base asm("r2")` pin.** Pinning the offset/cache base to

  and the copy can defer. (43->fixes the cache-placement cluster.)
- **`scratch2 asm("r7")` for the in-loop srcStride read** + **`dx = (s16)dstX` hoisted
  to its own early statement** (this last hint came FROM the permuter — see below).
  Together: 45 -> 40 byte_diff.

## The ONE remaining blocker — copy-suggestion register coloring (r0-collapse)

Post-switch, the TARGET colours the offset block + loop tail to keep **r0 reserved**
and spread temps across **r2 and r7**:
```
asrs r2,r0,#16            ; (s16)dstX HELD in r2
mov r7,ip; lsls; asrs r0  ; (s16)dstY in r0
ldr r1,=base; ldrh r3,[r1,#26] ; base in r1 (the dead dstX-param reg!), stride r3
muls r0,r3; adds r0,r2,r0 ; dstX(r2) + dstY*stride(r0)
... mov r9,r1             ; base cached LAST (r1 survived: nothing clobbers it)
in-loop:  mov r2,r9; ldrh r2,[r2,#26]; subs r0,r2,r5   ; stride via r2
          mov r7,r8; ldrh r7,[r7,#48]; subs r0,r7,r5   ; srcStride via r7
```
agbcc-from-our-C instead **collapses everything into r0**:
```
ldr r2,=base (EARLY, base pinned r2); asrs r0,r0,#16 (dstX->r0)
mov r3,ip; ...; asrs r1 (dstY->r1); ldrh r3,[r2,#26]; muls r1,r3; adds r0,r0,r1
in-loop:  mov r0,r9; ldrh r0,[r0,#26]; subs r0,r0,r5   ; stride via r0 (collapse)
```
Root cause: the target keeps the dstX cast in **r2** (held across the multiply) and
base in **r1** (the just-freed dstX-param reg, loaded AFTER the casts). This is driven
by agbcc's **copy-suggested register allocation** (`local-alloc.c` `find_free_reg` +
`qty_phys_copy_sugg`): in the baserom, dstX's quantity gets a copy-suggestion to r2 and
base's to r1, so r0 stays free and temps spread to r2/r7. Our C cannot reproduce that
suggestion chain — the base load lands in r2 (because we MUST pin it there for the
deferred cache) which forces dstX to r0, and the whole loop then collapses into r0.

The three remaining clusters (all the same root cause + 1 prologue):
1. **prologue (~4 diffs):** target loads src `[sp,#32]->r5->r8` EARLY (right after the
   height stack-arg load); ours loads it late. Statement reorder does NOT move it.
2. **offset block (~12 diffs):** base r1-vs-r2, dstX r2-vs-r0 cast, base-load order.
3. **in-loop tail (~10 diffs):** stride/srcStride read via r2/r7 (target) vs r0 (ours).

## Best-effort C (byte_diff 40 / diff_count 26, size EXACT 184)

```c
struct BlitState {
    u8 _pad00[26];
    u16 stride;
};

struct BlitSource {
    u8 _pad00[12];
    const u16 *tiles;
    u8 _pad10[32];
    u16 srcStride;
};

void sub_08015B6C(u8 mode, s16 dstX, s16 dstY, u8 widthArg, u8 heightArg, struct BlitSource *src)
{
    register struct BlitSource *srcp asm("r8");
    register u16 *dst asm("r6");
    register const u16 *srcData asm("r3");
    register u32 row asm("r0");
    register u32 nextRow asm("r1");
    register u32 width asm("r5");
    register u32 height asm("r4");
    register u32 dyh asm("ip");
    register struct BlitState *loopState asm("r9");
    register struct BlitState *base asm("r2");
    u8 col;
    register u32 scratch2 asm("r7");
    s16 dx;

    dx = (s16)dstX;
    dyh = (u16)dstY;
    width = (u8)widthArg;
    height = (u8)heightArg;
    srcp = src;

    switch (mode) {
    case 0:
        dst = (u16 *)(0x80 << 18);
        break;
    case 1:
        dst = (u16 *)0x02010000;
        break;
    case 2:
        dst = (u16 *)0x02020000;
        break;
    }

    base = (struct BlitState *)0x030060A0;
    dst += dx + (s16)dyh * base->stride;

    srcData = srcp->tiles;
    row = 0;
    loopState = base;
    if (row < height) {
        register u32 scratch asm("r2");

        do {
            col = 0;
            nextRow = row + 1;
            if (col < width) {
                do {
                    *dst++ = *srcData++;
                    col = (u8)(col + 1);
                } while (col < width);
            }

            scratch = loopState->stride;
            dst += scratch - width;
            scratch2 = srcp->srcStride;
            srcData += scratch2 - width;
            row = (u8)nextRow;
        } while (row < height);
    }
}
```
