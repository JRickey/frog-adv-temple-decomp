# sub_08015B6C — deferred analysis (round 4, Opus)

2D rectangular tilemap copy (a `sub_08012BC4` cousin). Copies a
`width x height` rectangle of u16 tiles from `src->tiles` (struct field 12,
row stride at field 48) into one of three EWRAM buffers selected by `mode`
(0 -> 0x02000000, 1 -> 0x02010000, 2 -> 0x02020000), at sub-rect origin
(dstX, dstY) which are **SIGNED s16** (`asr`, not `lsr`), using the global
scene stride at `*(u16*)(0x030060A0+26)`.

Range 0x08015B6C..0x08015C24 (184 bytes). Leaf (no calls).
Classifier: ATTEMPT_MATCH. Default compiler OLD_AGBCC (correct model;
the matched cousin sub_08012BC4 uses it too). Dest: `src/engine/sub_08015a00.c`.

## Status — IMPROVED FLOOR (round 4)

Prior round bottomed at **diff_count 72 / byte_diff 104** then **diff_count 44**
(height-pin). Round 4 reached **diff_count 29 / byte_diff 57, size EXACT 184**
with a clean pure-C structure (pins only; no asm/NAKED/volatile). Every Thumb
instruction is present and in the right order EXCEPT one scheduling cluster.

The two round-3 "clusters" were KILLED:
- **sl-spill of width/height** — fixed by typing `width`/`height` as **u32**
  (not u8). u8 made agbcc re-truncate + cache them in `sl`/`ip` inside the loop
  preheader (size 200/208). u32 masks once in the prologue and uses them
  directly → size collapses to 184, sl gone.
- **`&state[13]` address-hoist into `ip`** (in-loop) — fixed by the cousin's
  struct-cast idiom: read the in-loop stride via
  `scratch = base; scratch = ((struct BlitState_inner*)scratch)->stride;`
  instead of `loopState[13]`. The integer→pointer reconstruction stops loop.c
  from treating `&state[13]` as a hoistable invariant address.

## The ONE remaining blocker — base-load vs sign-extend ordering

Post-switch, the target emits (in this order):
```
(s16)dstX -> r2 ; (s16)dstY -> r0 [restored from ip] ; ldr base -> r1 ;
ldrh stride -> r3 ; muls dstY*stride ; adds dstX ; ... ; mov r9,r1 (cache base)
```
agbcc instead emits the base-load + stride-read FIRST, then the casts:
```
ldr base -> r7 ; ldrh stride -> r2 ; (s16)dstX ; (s16)dstY ; muls ; ... ;
mov r9,r7 (cache, later)
```
Root cause: the separate statement `stride = state[13];` (needed — inlining it
CSEs with the in-loop `base` constant and makes things WORSE, diff 39) is
emitted before the cast-laden `dst +=` expression, so its base-load lands first.
The target's baserom run scheduled the casts first and kept the single base
register (r1) live across srcData/row=0 down to `mov r9,r1`. This is a
register-liveness / basic-block-emission-order artifact, NOT controllable by
the source shapes tried. A SECONDARY diff: dstY is held in `ip` in the target
but `r9` in our build (r9 is free in the preheader before loopState is live);
an explicit `register u32 dyh asm("ip")` pin fixes the prologue+dstY (~6 diffs)
but does NOT touch the base-load order and nets WORSE (34) due to extra moves.

## Best-effort C (diff_count 29 / byte_diff 57, size 184)

```c
struct BlitState_inner {
    u8 _pad00[26];
    u16 stride;
};

struct BlitSource {
    u8 _pad00[12];
    const u16 *tiles;
    u8 _pad10[32];
    u16 srcStride;
};

void sub_08015B6C(u8 mode, s16 dstX, s16 dstY, u8 widthArg, u8 heightArg, struct BlitSource *src)
{
    register struct BlitSource *srcp asm("r8");
    register u16 *dst asm("r6");
    register const u16 *srcData asm("r3");
    register u32 row asm("r0");
    register u32 nextRow asm("r1");
    register u32 width asm("r5");
    register u32 height asm("r4");
    u16 stride;
    u16 *state;
    u8 col;
    u32 scratch;

    width = (u8)widthArg;
    height = (u8)heightArg;
    srcp = src;

    switch (mode) {
    case 0:
        dst = (u16 *)(0x80 << 18);
        break;
    case 1:
        dst = (u16 *)0x02010000;
        break;
    case 2:
        dst = (u16 *)0x02020000;
        break;
    }

    state = (u16 *)0x030060A0;
    stride = state[13];
    dst += (s16)dstX + (s16)dstY * stride;

    srcData = srcp->tiles;
    row = 0;
    if (row < height) {
        register u32 base asm("r9") = 0x030060A0;

        do {
            col = 0;
            nextRow = row + 1;
            if (col < width) {
                do {
                    *dst++ = *srcData++;
                    col = (u8)(col + 1);
                } while (col < width);
            }
            {
                scratch = base;
                scratch = ((struct BlitState_inner *)scratch)->stride;
                dst += scratch - width;
            }
            srcData += srcp->srcStride - width;
            row = (u8)nextRow;
        } while (row < height);
    }
}
```
