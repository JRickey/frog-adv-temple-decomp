# sub_08015B6C — deferred analysis (round 6, Opus escalation)

2D rectangular tilemap copy (a `sub_08012BC4` cousin). Copies a
`width x height` rectangle of u16 tiles from `src->tiles` (struct field 12,
row stride at field 48 = 0x30) into one of three EWRAM buffers selected by
`mode` (0 -> 0x02000000 i.e. `0x80<<18`, 1 -> 0x02010000, 2 -> 0x02020000), at

the global scene stride at `*(u16*)(0x030060A0 + 26)`.

u8 heightArg, struct BlitSource *src)`. (widthArg = arg3/r3, heightArg =
arg4/[sp,#28], src = arg5/[sp,#32].)

Range 0x08015B6C..0x08015C24 (184 bytes). Leaf (no calls).

## Root cause — confirmed against agbcc source (REG_ALLOC_ORDER)

`tools/agbcc-src/gcc_arm/config/arm/arm.h` REG_ALLOC_ORDER = `{3,2,1,0,12,14,4,5,6,7,8,...}`
— so r1 is the 3rd-most-preferred GP register. The target's allocator puts the
scene-state base pointer in **r1** (it reuses the dstX param register, which dies
once dstX is cast into r2), then defers the cache `mov r9,r1` to the loop
pre-header (between `movs r0,#0` and `cmp r0,r4`, i.e. BEFORE the height guard).
Because that cache is in the pre-header, base's live range ends before nextRow
(also r1) is born inside the loop body — so base and nextRow legally SHARE r1 at
disjoint times. This is pure natural (UNPINNED) copy-suggested allocation.

We cannot reproduce it from C:
- Pinning base->r1 makes r1 a FIXED reg for the whole function, so nextRow can't
  also use r1 -> the loop spills, size 188, byte_diff ~170. (confirmed, matches
  round-5 "base pinned r1 = 166".)
- Leaving base UNPINNED, the base->r9 cache lands AFTER the height guard (because
  any `loopState = base` placement we tried either fuses base->r9 immediately
  (cache right at the constant load -> base never in a low reg, reads stride via
  r9) OR defers it past the guard (base's range reaches into the loop block where
  r1/nextRow is live -> find_free_reg skips r1, base falls to r7). Either way
  base != r1.
- Pinning base->r2 (round-5 / note C) gives the deferred cache and is the BEST
  (40/26), but forces dstX into r0 (the "r0-collapse") and base into r2 not r1.

The THREE clusters in the 40/26 diff (vs target):
1. **Prologue src load (~8 diffs):** target does `ldr r5,[sp,#32]; mov r8,r5`
   as the 2nd/3rd instruction (BEFORE the mode cast), reusing r5 for width after
   src vacates it. agbcc-from-our-C schedules the src-arg load LATE (after the
   mode + width/height pre-shifts), into r2 then r8. `srcp = src` first in source
   gets src into r5 (right reg) but STILL after the mode cast (47/30 total). Not
   reachable by statement reorder or `-fno-schedule-insns(2)` (both no-op). This
   is RTL emission order within the entry block, driven by liveness priority of
   the switch selector.
2. **Offset block (~12 diffs):** base r1-vs-r2, dstX r2-vs-r0 cast, base-load
   order — the root cause above.
3. **Loop tail (~2 diffs):** target `mov r7,r8; ldrh r7,[r7,#48]` (src via r7);
   ours `mov r0,r8; ldrh r7,[r0,#48]` (src via r0).

```c
struct BlitState {
    u8 _pad00[26];
    u16 stride;
};

struct BlitSource {
    u8 _pad00[12];
    const u16 *tiles;
    u8 _pad10[32];
    u16 srcStride;
};

void sub_08015B6C(u8 mode, s16 dstX, s16 dstY, u8 widthArg, u8 heightArg, struct BlitSource *src)
{
    register struct BlitSource *srcp asm("r8");
    register u16 *dst asm("r6");
    register const u16 *srcData asm("r3");
    register u32 row asm("r0");
    register u32 nextRow asm("r1");
    register u32 width asm("r5");
    register u32 height asm("r4");
    register u32 dyh asm("ip");
    register struct BlitState *loopState asm("r9");
    register struct BlitState *base asm("r2");
    u8 col;
    register u32 scratch2 asm("r7");
    s16 dx;

    dx = (s16)dstX;
    dyh = (u16)dstY;
    width = (u8)widthArg;
    height = (u8)heightArg;
    srcp = src;

    switch (mode) {
    case 0:
        dst = (u16 *)(0x80 << 18);
        break;
    case 1:
        dst = (u16 *)0x02010000;
        break;
    case 2:
        dst = (u16 *)0x02020000;
        break;
    }

    base = (struct BlitState *)0x030060A0;
    dst += dx + (s16)dyh * base->stride;

    srcData = srcp->tiles;
    row = 0;
    loopState = base;
    if (row < height) {
        register u32 scratch asm("r2");

        do {
            col = 0;
            nextRow = row + 1;
            if (col < width) {
                do {
                    *dst++ = *srcData++;
                    col = (u8)(col + 1);
                } while (col < width);
            }

            scratch = loopState->stride;
            dst += scratch - width;
            scratch2 = srcp->srcStride;
            srcData += scratch2 - width;
            row = (u8)nextRow;
        } while (row < height);
    }
}
```
