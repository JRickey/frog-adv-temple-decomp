# sub_08015B6C — deferred analysis (round 7, Opus escalation)

2D rectangular tilemap copy (a `sub_08012BC4` cousin). Copies a
`width x height` rectangle of u16 tiles from `src->tiles` (struct field 12,
row stride at field 48 = 0x30) into one of three EWRAM buffers selected by
`mode` (0 -> 0x02000000 i.e. `0x80<<18`, 1 -> 0x02010000, 2 -> 0x02020000), at
sub-rect origin (dstX, dstY) which are **SIGNED s16** (`asr`, not `lsr`), using
the global scene stride at `*(u16*)(0x030060A0 + 26)`.

Signature: `void sub_08015B6C(u8 mode, s16 dstX, s16 dstY, u8 widthArg,
u8 heightArg, struct BlitSource *src)`. (widthArg = arg3/r3, heightArg =
arg4/[sp,#28], src = arg5/[sp,#32].)

Range 0x08015B6C..0x08015C24 (184 bytes). Leaf (no calls).

## New finding (round 7): two-step pointer-lower fixes the loopState read

The target reads `loopState->stride` as
`mov r2,r9; ldrh r2,[r2,#26]` — lowering the high reg (r9) into a LOW reg and
loading INTO THE SAME low reg (r2). A one-statement `scratch = loopState->stride`
makes agbcc pick a *separate* lower-temp (r0) → `mov r0,r9; ldrh r0,[r0,#26]`
which mismatches the target's r2. The cousin sub_08012BC4 idiom fixes it:

```c
scratch = (u32)loopState;                          /* mov r2,r9 */
scratch = ((struct BlitState *)scratch)->stride;   /* ldrh r2,[r2,#26] */
```

This collapses the loopState-read cluster (3 diffs) → 40/26 becomes 37/23.

NOTE: the SAME two-step applied to the `srcp->srcStride` read does NOT help —
it emits an EXTRA `adds r0,r7,#0` copy (63/25, worse). For r7 (scratch2) the
two-step does not coalesce the way it does for r2. Leave srcStride as a
one-statement `scratch2 = srcp->srcStride;`. So: two-step for loopState ONLY.

## Root cause (confirmed, unchanged from round 6) — base wants r1, no C gets it

REG_ALLOC_ORDER (`tools/agbcc-src/gcc_arm/config/arm/arm.h`) =
`{3,2,1,0,12,14,4,5,6,7,8,...}`. The target naturally colors the scene-state
base pointer into **r1** (the dstX arg reg, which dies once dstX is cast out),
reads stride via that r1, then DEFERS the cache `mov r9,r1` to the loop
pre-header (after `ldr r3,[src,#12]` and `movs r0,#0`). Because the cache is in
the pre-header, base's live range ends before `nextRow` (also r1) is born, so
base and nextRow legally SHARE r1 at disjoint times. This is pure natural
(UNPINNED, copy-suggested) allocation.

No C shape reproduces it:
- `base asm("r1")` → r1 becomes FIXED for the whole function → dstX (which
  arrives in r1) is spilled to r9 (`mov r9,r1` at the dstX mask), size 188,
  byte_diff ~170. Confirmed identical whether `dx` is a precomputed local or
  the cast is inlined. (round 6 "base pinned r1".)
- base UNPINNED (separate `state`/`loopState` + `loopState=state`, or a single
  inlined cast, or via the linker symbol `&gIwram_60A0`) → agbcc loads base into
  the most-preferred free reg (r3, occasionally r2/r0) and EAGER-caches `mov
  r9,base` right at the load, reading stride via r9. 120-156 byte_diff.
- `base asm("r2")` (round-6 / current best) → gives the DEFERRED cache (good)
  but forces base into r2 (not r1) and dstX into r0 (not r2) — the "r0/r2
  swap". This is the 37/23 floor. The 3 residual clusters all stem from this:
  1. **Offset block (~12):** base r2-vs-r1, dstX r0-vs-r2, dy r1-vs-r0, the
     base load early-vs-late, cache `mov r9,r2`-vs-`mov r9,r1`.
  2. **Prologue src load (~8):** target loads `[sp,#32]` (src) immediately
     after `[sp,#28]` (height) before any cast; agbcc-from-our-C schedules the
     src load AFTER the width/height pre-shifts (`lsls r3;lsls r4`). srcp-first
     gets src into r5→r8 (right regs) but STILL late. NOT reachable by
     statement reorder or `-fno-schedule-insns(2)` (both confirmed no-op).
  3. **srcp reads (~2):** target lowers srcp(r8) into r7 for both `->tiles` and
     `->srcStride` (`mov r7,r8; ldr/ldrh r... [r7,...]`); ours lowers into r0
     (`mov r0,r8; ...[r0,...]`). The lower-temp reg choice is allocator-driven.

## Best-effort C (byte_diff 37 / diff_count 23, size EXACT 184)

```c
struct BlitState {
    u8 _pad00[26];
    u16 stride;
};

struct BlitSource {
    u8 _pad00[12];
    const u16 *tiles;
    u8 _pad10[32];
    u16 srcStride;
};

void sub_08015B6C(u8 mode, s16 dstX, s16 dstY, u8 widthArg, u8 heightArg, struct BlitSource *src)
{
    register struct BlitSource *srcp asm("r8");
    register u16 *dst asm("r6");
    register const u16 *srcData asm("r3");
    register u32 row asm("r0");
    register u32 nextRow asm("r1");
    register u32 width asm("r5");
    register u32 height asm("r4");
    register u32 dyh asm("ip");
    register struct BlitState *loopState asm("r9");
    register struct BlitState *base asm("r2");
    u8 col;
    register u32 scratch2 asm("r7");
    s16 dx;

    dx = (s16)dstX;
    dyh = (u16)dstY;
    width = (u8)widthArg;
    height = (u8)heightArg;
    srcp = src;

    switch (mode) {
    case 0:
        dst = (u16 *)(0x80 << 18);
        break;
    case 1:
        dst = (u16 *)0x02010000;
        break;
    case 2:
        dst = (u16 *)0x02020000;
        break;
    }

    base = (struct BlitState *)0x030060A0;
    dst += dx + (s16)dyh * base->stride;

    srcData = srcp->tiles;
    row = 0;
    loopState = base;
    if (row < height) {
        register u32 scratch asm("r2");

        do {
            col = 0;
            nextRow = row + 1;
            if (col < width) {
                do {
                    *dst++ = *srcData++;
                    col = (u8)(col + 1);
                } while (col < width);
            }

            /* two-step pointer-lower: mov r2,r9; ldrh r2,[r2,#26] (matches target) */
            scratch = (u32)loopState;
            scratch = ((struct BlitState *)scratch)->stride;
            dst += scratch - width;
            scratch2 = srcp->srcStride;
            srcData += scratch2 - width;
            row = (u8)nextRow;
        } while (row < height);
    }
}
```
