# sub_08015B6C — deferred analysis (round 9, Opus escalation)

2D rectangular tilemap copy (`sub_08012BC4` cousin). Copies a `width x height`
rect of u16 tiles from `src->tiles` (struct field 12) into one of three EWRAM
banks selected by `mode` (0 -> `0x80<<18` = 0x02000000, 1 -> 0x02010000,
2 -> 0x02020000), at sub-rect origin (dstX, dstY). dstX/dstY are SIGNED s16
(`asr`). The dest row stride is the scene `tileWidth` at
`*(u16*)(0x030060A0 + 26)`; the source row stride is `src->srcStride` (u16 at
field 48 = 0x30). Per dest row: `dst += tileWidth - width`; per source row:
`src += srcStride - width`.

Signature: `void sub_08015B6C(u8 mode, s16 dstX, s16 dstY, u8 widthArg,
u8 heightArg, struct BlitSource *src)`. Range 0x08015B6C..0x08015C24 (184 bytes).
Leaf. Classifier: ATTEMPT_MATCH. Default compiler OLD_AGBCC (AGBCC gives
IDENTICAL output — verified; the newer scheduler does NOT help here). Dest:
`src/engine/sub_08015a00.c`. Do NOT NAKED (not STRONG_UNMATCHABLE).

## THE WINNING STRUCTURE (round 9 — keep this, it is the cleanest base yet)

Pins that ARE load-bearing (each reproduces the target loop body exactly):
  srcp=r8, dst=r6, srcData=r3, row=r0, r1slot=r1 (base early / nextRow late =
  the shared-r1 idiom), width=r5, height=r4, dyh=ip, loopState=r9, r2slot=r2
  (dx early / col-stride-scratch late = the shared-r2 idiom), scratch7=r7
  (srcStride scratch). col is a PLAIN u8 (NOT pinned — unpinning it made agbcc
  emit the target's `adds r0,r2,#1; lsls; lsrs r2,r0` scratch-form increment;
  pinning it forced the in-place `adds r2,#1` 2-byte form, a regression).

Key levers found in round 9 (vs round 8):
  - The dst-stride read MUST be a TWO-STEP through r2slot to get `mov r2,r9;
    ldrh r2,[r2,#26]`. Writing `r2slot = loopState->tileWidth` lowers r9 via r0.
  - The srcStride read MUST be DIRECT (`scratch7 = srcp->srcStride`). The
    analogous two-step there ADDS a spurious `adds r0,r7,#0` copy (regression
    to 67/21). So the two idioms are ASYMMETRIC — only the r2/loopState side
    benefits from the two-step.
  - Offset written product-first (`(s16)dyh*tileWidth + r2slot`) lands the sum
    in r0 (target shape) and defers nothing else. dx-first regresses to 24.

## The 3 residual clusters (all coupled coloring/scheduling — 19 diffs)

1. **Prologue stack-arg ordering (8 diffs, 0x0a-0x22).** Target loads BOTH
   stack args first (`ldr r4,[sp,#28]` height, then `ldr r5,[sp,#32]` src ->
   `mov r8,r5`) BEFORE any param-mask, then casts in reg order incl.
   `mov ip,r2` (dyh) BEFORE width/height. Ours: agbcc emits the src high-reg
   move (`mov r8,r5`) and the dyh high-reg move (`mov ip,r2`) LATE, after the
   width/height `lsls #24` pre-shifts. Both deferred moves are HIGH-reg copies.
   INVARIANT to statement order and every flag. This is agbcc's RTL emission
   order for param normalization + high-reg copies; old_agbcc has NO scheduler
   so it is NOT reachable by -fno-schedule-insns (rejected) — it lives in the
   RTL-gen / local-alloc / reload emission sequence (gcc_arm/{stmt,function,
   local-alloc,reload}.c). The round-8 global.c probe addressed register
   CHOICE, not INSTRUCTION ORDER — a future round should trace WHERE the
   `mov r8,Rn` / `mov ip,Rn` insns are emitted (likely `emit_move_insn` during
   parm setup in function.c::assign_parms, or the high-reg copy split in
   reload), to learn why they sink past the low-reg masks.

2. **Offset-block scratch selection (6 diffs, 0x4a-0x5a).** Three sub-diffs:
   (a) dx-cast: target `lsls r0,r1,#16; asrs r2,r0,#16` (r0 intermediate);
       ours `lsls r2,r1,#16; asrs r2,r2,#16` (in-place). The r0-intermediate
       appears only when the cast is INLINE inside the offset expr, but inlining
       `(s16)dstX` there conflicts with the r1slot pin (dstX gets stashed). With
       r2slot pre-assigned, agbcc casts in-place.
   (b) dyh copy: target `mov r7,ip`; ours `mov r3,ip`. Pure scratch choice.
   (c) base load: target `ldr r1,[pc]` LATE at 0x54 (after the dyh cast, right
       before the stride read); ours EARLY at 0x4e because `r1slot = 0x030060A0`
       is a standalone statement (a pinned-reg assignment materializes the const
       AT the statement). Inlining the assignment (`(Scene*)(r1slot=const)` or a
       comma operator) defers the load but stashes dstX -> regression. Product-
       staging through `row` (r0) DID defer the base to 0x1be but cost +1 diff
       elsewhere (42/23). The base-late wants the const materialized at the MEM
       operand of the multiply, not at the pinned assignment — an expand_expr /
       const-pool placement issue, NOT register choice.

3. **srcp high-reg lowering (4 diffs, 0x60/0x62 tiles, 0x90/0x92 srcStride).**
   Target lowers srcp(r8) into r7 for both `->tiles` (`mov r7,r8; ldr r3,[r7,
   #12]`) and `->srcStride` (`mov r7,r8; ldrh r7,[r7,#48]`). Ours lowers into r0
   (`mov r0,r8`) because r0 (row) is DEAD at those points and r0 is reload's
   lowest-cost free scratch. Forcing r7: the two-step spills srcData (tiles) or
   adds a copy (srcStride) — see asymmetry above. Corpus confirms `mov r7,r8`
   lowering appears in MATCHED C (pret librfu), so it IS reachable; the choice is
   reload's scratch-preference given r0 free. Candidate: make r0 unavailable at
   the lower points (without breaking row), or find the reload knob that biases
   the scratch toward a callee-saved low reg.

## Best-effort C (round 9: byte_diff 41 / diff_count 19, size EXACT 184)

```c
struct SceneScrollState_F2F8 {
    u8 _pad00[26];
    u16 tileWidth;
};

struct BlitSource {
    u8 _pad00[12];
    const u16 *tiles;
    u8 _pad10[32];
    u16 srcStride;
};

void sub_08015B6C(u8 mode, s16 dstX, s16 dstY, u8 widthArg, u8 heightArg, struct BlitSource *src)
{
    register struct BlitSource *srcp asm("r8");
    register u16 *dst asm("r6");
    register const u16 *srcData asm("r3");
    register u32 row asm("r0");
    register u32 r1slot asm("r1");   /* base-ptr early, nextRow late: shares r1 */
    register u32 width asm("r5");
    register u32 height asm("r4");
    register u32 dyh asm("ip");
    register struct SceneScrollState_F2F8 *loopState asm("r9");
    register u32 r2slot asm("r2");   /* dx early, dst-stride scratch late: shares r2 */
    register u32 scratch7 asm("r7");
    u8 col;

    srcp = src;
    dyh = (u16)dstY;
    width = (u8)widthArg;
    height = (u8)heightArg;

    switch (mode) {
    case 0:
        dst = (u16 *)(0x80 << 18);
        break;
    case 1:
        dst = (u16 *)0x02010000;
        break;
    case 2:
        dst = (u16 *)0x02020000;
        break;
    }

    r2slot = (s16)dstX;
    r1slot = 0x030060A0;
    dst += (s16)dyh * ((struct SceneScrollState_F2F8 *)r1slot)->tileWidth + r2slot;
    srcData = srcp->tiles;
    row = 0;
    loopState = (struct SceneScrollState_F2F8 *)r1slot;
    if (row < height) {
        do {
            col = 0;
            r1slot = row + 1;
            if (col < width) {
                do {
                    *dst++ = *srcData++;
                    col = (u8)(col + 1);
                } while (col < width);
            }
            r2slot = (u32)loopState;
            r2slot = ((struct SceneScrollState_F2F8 *)r2slot)->tileWidth;
            dst += r2slot - width;
            scratch7 = srcp->srcStride;
            srcData += scratch7 - width;
            row = (u8)r1slot;
        } while (row < height);
    }
}
```
