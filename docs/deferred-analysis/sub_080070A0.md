## What the function does

Advances 0x24-byte scroll-step entries over the inclusive range [first, last].
The whole sweep is gated on the first entry being "ripe"
(`gGameStuff._unk00 - entry->stamp >= entry->ageMax`, unsigned). For each entry
the signed `(deltaX@0x10, deltaY@0x11)` is added to its `(subX@0, subY@2)`
sub-coordinates; when the gIwram_35E0 +0x10 flags have bit 0x02 set AND the
entry's own +0x1A flags have bit 0x02 set, the same raw delta is mirrored onto
`gEntities[0].(x@2, y@4)`. Each touched entry's `stamp@0xC` is refreshed to the
current tick. `gEntities` base is the pool literal 0x03003720; `gGameStuff` is
0x03005330; the flags base is `gIwram_35E0` (0x030035e0).

## Drift (down to 34/15 — the THREE structural keys that cracked the old plateau)

The prior round was stuck at `60/33` because of THREE coupled coloring problems.
This round SOLVED two of them with pure source shape (no pins):

1. **mask/active swap (SOLVED).** Target wants `mask=2` in r9 and `active` in ip;
   the old clean C put mask in ip, active in r9. FIX: declare `s32 mask;`
   UNINITIALIZED and assign `mask = 2;` lazily AFTER the guards (not at the
   declaration). An initialized `s32 mask = 2;` materializes the constant into a
   high reg too early (claims ip via a copy-preference). The lazy assign makes
   `movs rN,#2; mov r9,rN` happen at the loop-setup point like the baserom, and
   active then naturally lands in ip.

2. **first/i + i>last ordering (SOLVED).** Target computes `i = first` as a
   SEPARATE r4 copy BEFORE the `first > last` guard, and the guard COMPARES `i`
   (r4), not `first`. FIX: write `i = first; if (i > last) return;` (with `i`
   used in the guard), not `if (first > last) return; ... i = first;`. This puts
   `first` in r3 (scratch) and `i` in r4 exactly like the baserom and removes the
   whole `first`-in-r4 cascade.

3. **base/entry register swap (UNSOLVED — the remaining 15 diffs).** Target:
   base `&gGameStuff` → r2 (scratch), `mov r8, r2` interleaved into the age
   guard right after the first read; entry (offset result) → r5, then moved to
   r3 for the loop; the mask const reuses the freed r2 (`movs r2,#2`). MINE:
   base → r4, `mov r8, r4` after both guards; entry → r2 (stays r3 for loop);
   mask const must use r7 (`movs r7,#2`) because r2 is taken by entry. The
   downstream effect: with entry in r2 the loop is one register tighter, so
   `entry->deltaY` (s8 @0x11) compiles to `ldrb [r3,#17]; lsls#24; asrs#24`
   instead of the baserom's register-indexed `movs r0,#17; ldrsb r0,[r3,r0]`
   (deltaX@0x10 IS the indexed `ldrsb` in both). Fix base/entry and the deltaY
   form should follow.

   ROOT (confirmed by instrumenting a private debug old_agbcc — fprintf in
   `gcc/local-alloc.c:find_free_reg`): the base pseudo (`const 0x03005330`) is
   copy-suggested toward its r8 destination (`game`), and that suggestion biases
   it onto the callee-saved r4 instead of the scratch r2; the offset-result
   (entry) then claims r2. It is a `find_free_reg` copy-suggestion tie, not a
   `global.c allocno_compare` tie. The age-guard read must use a base in a low
   reg (Thumb can't `ldr [r8]`), so base and game cannot coalesce, and the
   suggestion can't be honored — yet it still skews the fallback register.

## Best-effort C (34/15 — clean, no pins/asm/flags)

```c
struct ScrollStepEntry {
    u16 subX;  /* +0x00 */
    u16 subY;  /* +0x02 */
    u8 _pad04[8];
    u32 stamp; /* +0x0C */
    s8 deltaX; /* +0x10 */
    s8 deltaY; /* +0x11 */
    u8 ageMax; /* +0x12 */
    u8 _pad13[7];
    u8 flags;  /* +0x1A */
    u8 _pad1B[9];
};

void sub_080070A0(struct ScrollStepEntry *entries, s32 first, s32 last)
{
    GameStuff *game;
    struct ScrollStepEntry *entry;
    s32 mask;
    u16 active;
    s32 i;

    if (gGameStuff._unk00 - entries[first].stamp < entries[first].ageMax)
        return;

    game = &gGameStuff;

    i = first;
    if (i > last)
        return;

    mask = 2;
    active = (u16)(gIwram_35E0._field_10 & mask);

    entry = &entries[first];
    do {
        s8 dy = entry->deltaY;
        s8 dx = entry->deltaX;

        entry->subX += dx;
        entry->subY += dy;

        if (active != 0 && (entry->flags & mask) != 0) {
            gEntities[0].x += dx;
            gEntities[0].y += dy;
        }

        entry->stamp = game->_unk00;
        entry++;
        i++;
    } while (i <= last);
}
```
