## What the function does (settled — semantics are NOT the blocker)

Advances a row of 36-byte (0x24) sub-pixel scroll entries over the inclusive index
range `[first, last]`, stepping each entry's sub-coords by its per-axis delta and (when
both the gIwram_35E0 dirty bit 0x02 AND the entry's own bit 0x02 are set) mirroring the
same step onto gEntities[0]. Tick from gGameStuff._unk00 gates ripeness
(`tick - stamp >= ageMax`, unsigned) and is refreshed into each entry's stamp at the
end of every step.

Struct (verified against every load/store offset in the slice):
- +0  u16 subX  (`+= deltaX`)
- +2  u16 subY  (`+= deltaY`)
- +12 u32 stamp
- +16 s8  deltaX  (applied to subX and gEntities[0].x)
- +17 s8  deltaY  (applied to subY and gEntities[0].y)
- +18 u8  ageMax
- +26 u8  flags  (bit 0x02 = mirror-to-gEntities)
- stride 0x24
gIwram_3720 == gEntities[0] (0x03003720); the +2/+4 accesses are gEntities[0].x/.y.

## Drift — a 3-way register-coloring local minimum (NOT control-flow, NOT struct)

The control flow, instruction count, struct layout, and the `ldrsb` register-offset
delta loads all line up. The residual 33-insn diff is purely register coloring, and it
is a coupled 3-way problem where fixing one piece displaces another:

1. **first/i coalescing.** Target keeps `first` in r3 (entry-base calc + copied to the
   loop counter) and `i` in r4 as a SEPARATE pseudo. old_agbcc COALESCES `i = first`
   into one pseudo and colors it r4, so `first` never lands in r3 (REG_ALLOC_ORDER head).
   This cascades: `entry` then takes r3 directly instead of target's r5->r3 move, and
   gIwram_3720 lands in r4 instead of r5. This is `combine_regs`/register-tying in
   `tools/agbcc-src/gcc_arm/local-alloc.c` (copy of a dying source -> tie). The original
   Konami compiler did NOT tie here; old_agbcc always does.
   - Unaffected by: -fno-strength-reduce, -fno-gcse, -fforce-addr,
     -fno-expensive-optimizations, -fno-function-cse, -fno-cse-follow-jumps,
     -fno-rerun-cse-after-loop, -fno-thread-jumps, -fno-peephole, -fno-caller-saves.
   - Unaffected by: for-loop vs do-while; `i = first` as its own statement; gating on
     `i > last` vs `first > last`; reordering entry-calc before/after the game load.

2. **mask vs active swap (ip <-> r9).** Target: active->ip, mask(const 2)->r9. old_agbcc:
   mask->ip, active->r9. Per `allocno_compare` in `global.c` the priority is
   `floor_log2(refs)*refs/live_length`; the shared constant `2` has 3 refs (active-calc
   AND the loop flags-check both `& mask`, plus its def) vs active's 2 refs, so mask wins
   the higher-priority ip slot. CSE merges any two literal `2`s back into the one mask
   pseudo, so you cannot drop mask to 2 refs while still holding it in a callee-saved reg
   across the loop (which the 152-byte size REQUIRES — a pure-literal mask drops to 144B
   with no r9 save). `flag_live_range` is OFF by default so the `REG_N_RANGE_COPY_P`
   tiebreak is inert; it is pure refs/live_length.

3. **gGameStuff `mov r8` timing.** Target loads &gGameStuff into scratch r2, does the
   first tick read `ldr r0,[r2]`, THEN `mov r8,r2`. old_agbcc (when gGameStuff naturally
   takes r8) emits `mov r8,r1` right at the load and reads it BACK via `mov r7,r8; ldr`,
   inserting 2 extra insns. Reload-pass artifact; not reachable from source ordering.

## Best-effort C (byte_diff 60, ZERO pins — the readable reference)

```c
struct ScrollEntry {
    u16 subX;  /* +0 */
    u16 subY;  /* +2 */
    u8 _pad04[8];
    u32 stamp; /* +12 */
    s8 deltaX; /* +16 */
    s8 deltaY; /* +17 */
    u8 ageMax; /* +18 */
    u8 _pad13[7];
    u8 flags; /* +26 */
    u8 _pad1B[9];
};

void sub_080070A0(struct ScrollEntry *entries, s32 first, s32 last)
{
    GameStuff *game = &gGameStuff;
    struct ScrollEntry *entry = &entries[first];
    s32 mask = 2;
    s32 i;
    u16 active;

    if (game->_unk00 - entry->stamp < entry->ageMax)
        return;
    if (first > last)
        return;

    active = (u16)(gIwram_35E0._field_10 & mask);

    i = first;
    do {
        s8 deltaY = entry->deltaY;
        s8 deltaX = entry->deltaX;

        entry->subX += deltaX;
        entry->subY += deltaY;

        if (active != 0 && (entry->flags & mask) != 0) {
            gEntities[0].x += deltaX;
            gEntities[0].y += deltaY;
        }

        entry->stamp = game->_unk00;
        entry++;
        i++;
    } while (i <= last);
}
```
