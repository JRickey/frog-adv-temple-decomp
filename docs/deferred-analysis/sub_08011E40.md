## Drift

### sub_08011E40 — best **byte_diff 27, diff_count 10** (round 17 Opus)
Round 17 improved the prior diff_count-42 (clean) base to **byte_diff 27 /
diff_count 10** with three load-bearing levers (all PURE C, status stays
"matched"-eligible): `s32` return type, `register s32 one asm("r8")`, and
`register s32 result asm("sl")`. This is a MUCH better base than the prior
clean-42 and is the right base for the permuter to finish.

Three changes that moved the needle (each verified by direct byte-diff probe):
1. **Pre-loop compare via ABSOLUTE `gIwram_6110.byteFlags8/.gateByte`, loop
   body via a `ctrl = &gIwram_6110` local.** Defeats the cross-block CSE that
   folded `&base[0x2a]` into a pool literal (the prior round's root cause). The
   loop now re-derives `ctrl+0x2a`/`+0x2b` each iter, matching baserom. Drops
   the folded `0x0300613a` pool entry. (Prior round's "compare via absolute"
   note said 44; combined with the levers below it is the key.)
2. **`s32` return type (NOT `u8`).** Caller truncates with `lsls r0,#24`, so
   baserom's function does a bare `mov r0,sl` with NO `(u8)` zero-extend. A
   `u8` return makes agbcc append `lsls/lsrs #24` (3 extra tail diffs). `s32`
   removes them. (Variable `result` is also `s32` pinned to `sl`.)
3. **`register s32 one asm("r8") = 1`.** baserom holds the mask constant `1`
   in r8 and copies it to a low reg per `& 1`. Pinning `one` to r8 took
   byte_diff 146→95 (then →27 with s32). Use `one` in the `& one` masks; use
   the *literal* `1 << i` in the `gateByte |=` store (using `one << i` there
   regresses by forcing an `adds r0,r1,#0`).

ROOT CAUSE of the residual 10 (two atomic coloring decisions, both robust):

(A) **Zero constant: `mov r9,r4` vs baserom `movs r2,#0; mov r9,r2`.**
The loop-invariant `0` written by the DMA `strh` (the `zero` u16 slot value)
is kept in r9. baserom materialises it FRESH (`movs r2,#0; mov r9,r2`); agbcc
notices `i` (r4) already holds 0 at loop entry and COPIES it (`mov r9,r4`) —
one instruction shorter, which shifts the whole pool and cascades. This is
`combine_movables`/copy-coalescing in loop.c+cse.c finding the const 0 in r4.
Tried & FAILED to break it: every -fno-{gcse,cse-follow-jumps,
rerun-cse-after-loop,move-all-movables,regmove,schedule-insns,strength-reduce,
expensive-optimizations} (no change or worse); -O1 (no change); `register …
zfill/zerov asm("r9")=0` pin (makes the strh re-materialise `movs r1,#0`
INSTEAD of reusing r9 — defeats itself, byte_diff↑); hoisting `zero=0` before
the loop (drops one of the two strh — the two `zero=0` writes are
load-bearing, one per DMA block). i pinned r4 — no change.

(B) **First mask const reg + materialisation count.** baserom:
`mov r0,r8; ands r1,r0; cmp r1,#0` (mask the byteFlags8 bit IN PLACE into r1,
const in r0 which then DIES on the gateByte `ldrb r0,[r6]`), then for the
gateByte bit `mov r2,r8; ands r0,r2` (const re-materialised fresh in r2).
i.e. **bit value CSE'd (single r1) BUT const materialised TWICE (r0 then r2).**
agbcc refuses this split:
  - If you CSE the bit (cache `bit = (bf>>i)&one` in a temp, or pin `bit`=r1):
    agbcc gets the in-place `mov r2,r8; ands r1,r2` shape (RIGHT) but puts the
    const in **r2, not r0**, and the gateByte mask REUSES r2 (no 2nd
    materialise — WRONG). The gateByte `ldrb r0` does not clobber r2, so the
    const survives. byte_diff ~186 (const-in-r2 cascades the pool).
  - If you DON'T cache the bit (write `((bf>>i)&one)` twice — the byte_diff-27
    base): agbcc materialises the const TWICE (matching the count) but does
    NOT CSE the bit, so it adds `adds r0,r1,#0` (keeps the unmasked shift in
    r1 to re-mask) — 6 small diffs but BEST total alignment (27).
The needed state — bit-in-r1 AND const-in-r0-first-so-it-dies — needs the
const pseudo to land in r0 (the freed address reg). agbcc locks it to r2
regardless of `-ffixed-r2/-r3` (ignored on this pseudo) and IGNORES a
per-iteration `register s32 m asm("r0")=one` helper (folds it away). This is
the pure register-coloring minimum the permuter exists for.

Levers that did NOT help (round 17): `-ffixed-r2`(↑), `-ffixed-r3`(=), all
CSE/gcse/loop/sched/regmove flags(=/↑), `-O1`(↑), full pins r4/r7/r8/r9/sl
(spills, byte_diff 246), `bit`/`sh`/`a,b` temps, nested-if vs `&&`, `&(1<<i)`
mask form(↑223), `1<<i` mask form. AGBCC(newer) swap: regresses (OLD_AGBCC
correct).

## Best-effort C (byte_diff 27, diff_count 10 — permuter-ready base)

```c
#include "game.h"
#include "gba/dma.h"
#include "gba/io.h"
#include "iwram.h"
#include "types.h"

extern void sub_08011984(const u8 *records, u8 idx);
extern void sub_0800EE94(u8 layer);
extern s8 sub_08011AA4(const u8 *records);
extern u8 gIwram_6480[];
extern const u8 gBlitRecord_08306d40[];

s32 sub_08011E40(void)
{
    struct IwramAt6110 *ctrl;
    volatile DmaChannel *dma;
    u16 zero;
    u16 i;
    register s32 one asm("r8");   /* baserom holds mask const 1 in r8 */
    register s32 result asm("sl");

    result = 0;

    if (gIwram_6110.byteFlags8 != gIwram_6110.gateByte) {  /* absolute → no CSE-fold of &base+0x2a */
        i = 0;
        ctrl = &gIwram_6110;
        one = 1;
        dma = &REG_DMA3;
        do {
            if (((ctrl->byteFlags8 >> i) & one) != 0 &&
                ((ctrl->byteFlags8 >> i) & one) != ((ctrl->gateByte >> i) & one)) {
                zero = 0;
                dma->src = &zero;
                dma->dst = (void *)0x0600f000;
                dma->cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x400;
                (void)dma->cnt;

                zero = 0;
                dma->src = &zero;
                dma->dst = (void *)0x02020000;
                dma->cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x8000;
                (void)dma->cnt;

                sub_08011984(gBlitRecord_08306d40, (u8)(i * 3));
                sub_0800EE94(2);

                *(vu16 *)0x04000050 = 0x1744;
                *(vu16 *)0x04000052 = 0x020e;

                ctrl->gateByte |= (u8)(1 << i);   /* literal 1<<i; `one<<i` regresses */
                gIwram_6480[2] = (u8)i;
            }
            i++;
        } while (i <= 1);
    }

    if ((s8)sub_08011AA4(gBlitRecord_08306d40) != 0)
        result = 1;

    return result;
}
```
