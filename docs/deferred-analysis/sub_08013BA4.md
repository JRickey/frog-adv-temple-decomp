# sub_08013BA4 — deferred (register-coloring local minimum)

Range `[0x08013ba4, 0x08013c60)`, 188 bytes, dest `src/engine/sub_08013aac.c`.
Classifier verdict: ATTEMPT_MATCH (no structural impossibility). This is a
genuine near-match deferred ONLY on a sharp register-coloring tie.

## What it does (fully understood)
1. If `gIwram_60A0[0x40] & 1`: writes BG-offset MMIO `*(u16*)0x04000050 = 0x1744`,
   `*(u16*)0x04000052 = 0x030D`, clears the flag bit, calls `sub_0800EE94(2)`.
2. Always calls `sub_08012CAC()`.
3. Reads a 16-byte `DmaJob` descriptor from ROM `0x08307220` (count at +0, table
   ptr at +4, DMA dest at +8, xfer-count at +0xC; byte at +2 = `mode`), copies it
   to a stack local (matches the `ldmia/stmia {r3,r5,r6}` + `ldr/str` copy).
4. Ring-buffer gate on `gGameStuff._unk00` (timestamp) vs `queue->_seed` (+4) and
   `mode`: runs the DMA only when `(u32)(seed - queue->_seed) >= mode || seed == queue->_seed`.
5. Inside: post-increments `queue->_cursor` (+0xA), loads `table[oldCursor]` into
   `REG_DMA3.src`, sets dst/cnt (`DMA_ENABLE | (xferCount>>1)`), reads back cnt,
   wraps the cursor (`if (cursor >= count) cursor = 0`), stores the seed.
6. Calls `sub_08017000()`.

`queue` is the IWRAM struct at `0x030064C0`; `Queue_64C0` = {u8 +0; u32 _seed +4;
u8 _cursor +10}. `DmaJob` is a halfword-view of the 16-byte transfer descriptor so
`count`/`xferCount` read as `ldrh` (NOT `(u16)word` which agbcc lowers to ldr+lsl+lsr).

## Drift
- **byte_diff 4, diff_count 4** (best). The function is byte-identical EXCEPT one
  comparison's register coloring, at the cursor-wrap check:
    target: `mov r0,sp; ldrb r6,[r4,#10]; ldrh r0,[r0,#0]; cmp r6,r0; bcc`
    built:  `mov r1,sp; ldrb r0,[r4,#10]; ldrh r1,[r1,#0]; cmp r0,r1; bcc`
  Same instructions, same order, same `bcc`. Only the register NUMBERS differ —
  target puts the wrap-check cursor in r6 and count/count-addr in r0; agbcc puts
  cursor in r0 and count in r1.
- ROOT CAUSE (agbcc local-alloc/regclass coalescing): the cursor is read twice from
  `queue->_cursor` — once for the post-increment+index (needs r0, because the index
  scaling is `(oldCursor<<24)>>22` and reuses the ldrb result in r0) and once for the
  wrap-check. The TARGET gives these two reads DIFFERENT physical registers (r0 then
  r6); agbcc COALESCES them. Any attempt to pin the wrap-check read to r6 (via
  `register u8 x asm("r6")`) makes agbcc allocate r6 for the post-increment too
  (regresses to byte_diff 31-33: `adds r6,r0,#1; strb r6` instead of r1). The two
  reads share one quantity in agbcc but two in the baserom — the split the original
  compiler made is not reproducible from any source shape tried.

## Levers tried (all fail to reach 0)
- `++` post-increment IS required (gives the `<<24>>22` index scaling; explicit
  `cursor = q->_cursor; q->_cursor = cursor+1` regresses to `lsls #2`, byte_diff 92).
- `job.count` MUST be read via a halfword-view struct field (`ldrh`), and reading it
  into a LOCAL read *after* the DMA block is what gets the `mov sp`-first ordering
  (byte_diff 5 → 4). This is the current best-effort C.
- Comparison operand swap `count <= cursor`: gets order right but flips to `bhi` +
  swapped regs (byte_diff 5, worse).
- `register asm("r6")` pin on the wrap-check cursor: coalesces into the post-increment
  (byte_diff 31). `register asm("r0")` pin on count: breaks the `mov sp` order.
- CFLAGS sweep (`-fforce-addr`, `-fno-expensive-optimizations`, `-fno-gcse`,
  `-fcaller-saves`, `-fno-cse-follow-jumps`, `-ffixed-r0/r1/r3`): ALL leave byte_diff
  at 4 (agbcc ignores `-ffixed` for the low arg regs here; the coalescing is upstream).
- Compiler swap to `AGBCC_BIN` (newer agbcc): byte_diff still 4.
- Reordering the seed-write before the wrap-check: byte_diff 61 (must stay last).
- **decomp-permuter**: 50s, `-j4 --better-only`, base score 535, never beat it
  (no zero). Statement-level mutation cannot split the coalesced cursor quantity.

## Best-effort C
```c
struct DmaJob {
    u16 count;       /* +0x0: low half of word0 = ring length */
    u16 _hw02;
    void *table;     /* +0x4: base of the source-pointer table */
    void *dest;      /* +0x8: DMA destination */
    u16 xferCount;   /* +0xC: low half of wordC = transfer count (halfword units) */
    u16 _hw0E;
};

struct Queue_64C0 {
    u8 _field_00;
    u8 _pad01[3];
    u32 _seed;     /* +4: last gGameStuff._unk00 the queue advanced on */
    u8 _pad08[2];
    u8 _cursor;    /* +10: ring index into the pointer table */
};

void sub_08013BA4(void)
{
    const struct DmaJob *src;
    struct DmaJob job;
    struct Queue_64C0 *queue;
    u8 mode;
    u32 seed;
    u8 cursor;

    if ((gIwram_60A0[0x40] & 1) != 0) {
        *(u16 *)0x04000050 = 0x1744;
        *(u16 *)0x04000052 = 0x030D;
        gIwram_60A0[0x40] &= 0xFE;
        sub_0800EE94(2);
    }

    sub_08012CAC();

    src = (const struct DmaJob *)0x08307220;
    mode = ((const u8 *)src)[2];
    queue = (struct Queue_64C0 *)0x030064C0;
    job = *src;

    seed = gGameStuff._unk00;
    if ((u32)(seed - queue->_seed) >= mode || seed == queue->_seed) {
        const void *source;

        cursor = queue->_cursor++;
        source = ((const void *const *)job.table)[cursor];

        REG_DMA3.src = source;
        REG_DMA3.dst = job.dest;
        REG_DMA3.cnt = DMA_ENABLE | (job.xferCount >> 1);
        (void)REG_DMA3.cnt;

        {
            u16 count = job.count;
            if (queue->_cursor >= count) {
                queue->_cursor = 0;
            }
        }

        queue->_seed = gGameStuff._unk00;
    }

    sub_08017000();
}
```
