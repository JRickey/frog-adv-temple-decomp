# sub_08016404 — deferred analysis

588-byte Thumb leaf at 0x08016404 (the per-column view-clip span builder).
Classifier verdict is `ATTEMPT_MATCH` (no `bl` calls — the high-reg advisory is
a false positive; r8/r9/sl are pure register-pressure spills, not call-live).
The function is **structurally correct in pure C** (the instruction *sequence*
is reproducible byte-for-byte — see "Round 23" below); the blocker is a sharp
**global register-coloring fixed point** that no single source shape or `-fXXX`
flag reaches, and the permuter (the designated tool for exactly this) is
**unavailable in this environment** (the submodule was never checked out and an
isolated clone is sandbox-denied).

## Round 23 — instrumented root cause (definitive, supersedes prior diagnosis)

Built a PRIVATE instrumented `old_agbcc` (copied `tools/agbcc-src/gcc` to /tmp,
added an `fprintf` in `global.c:find_reg` at the `reg_renumber[...] = best_reg`
site + a `used`-set trace + a per-pseudo register-exclusion hook). This pins the
divergence to a single allocator decision and proves the cascade.

### The reproducible base (NEW — better than every prior shape)

Declaring the wide value **explicitly** makes the instruction *sequence* match
the target exactly (only registers differ):

```c
loWide = (gViewState->viewX - 0x30) << 16;   /* s32 loWide, s32 hiWide */
lo  = (u16)((u32)loWide >> 16);
hiWide = loWide + (0x100 << 16);
hi  = (u16)((u32)hiWide >> 16);
...
spanLo = (u16)((u32)loWide >> 19);
spanHi = (u16)((u32)hiWide >> 19);
```

- inline-loWide (no `camera` var) + reused `viewX` for the column loop:
  **byte_diff 366, size 568** (BEST clean base — beats prior 374/375).
- inline-loWide + separate transient (camera never a named var):
  **byte_diff 411, size 568** — prologue arithmetic byte-identical to target
  through 0x30 (`subs r0,#48; lsls r3,r0,#16; ...`), ONLY register coloring
  differs (r3↔r4, r7↔r8, r8↔r9 permutation).

### The one allocator decision

`AGBCC_DUMP_ALLOC` trace, separate-transient base:
- pseudo 31 = `loWide`  → **hardreg 3 (r3)**  (refs=4, live_len=40)   [target: r4]
- pseudo 34 = `lo`      → r7                  [target: r8]
- pseudo 32 = `hiWide`  → r8                  [target: r9]
- pseudo 29 = column-loop `viewX` → r4 (refs=16) — does NOT conflict with 31.

`AGBCC_TRACE_PSEUDO=31`:
```
pseudo 31: used_nopref={0 1 2 8..15}  used1={0 1 2 8..15}  regs_used_so_far={0..7 11..15}
```
So the FREE set for loWide is **{3,4,5,6,7}** and `find_reg`'s pass-0 first-fit
loop (`for i=0..; if !used: best_reg=i; break`) picks the **lowest = r3**. The
target wants **r4**. r3 is genuinely free (the col-loop viewX in r4 doesn't
conflict — disjoint liveness — so r4 is also free; first-fit just takes r3).

### Why every lever fails (each fixes ONE notch, breaks another)

- **`-ffixed-r3`** (remove r3 from pool): prologue becomes byte-IDENTICAL to
  target (`subs r0,#48; lsls r4,...; lsrs r0,...; mov r8,r0; ... mov r9,r1`),
  loWide→r4, lo→r8, hiWide→r9 ALL correct. BUT r3 is then unavailable for the
  parts that NEED it (DMA `dst` const 0x030053A0, the `31` const), forcing an
  extra stack slot → **`sub sp,#20`** vs target **`#16`** → byte_diff 437.
- **instrumented `AGBCC_EXCLUDE_REG_FOR=31:3`** (exclude r3 for loWide ONLY,
  keep r3 in the pool): loWide→r4 cleanly, `sub sp,#12` (no extra spill) — but
  lo→r7, hiWide→r8 (target r8/r9). Forcing lo→r8 too (`34:3:4:5:6:7`) pushes lo
  to **ip**, not r8, and the zero-const order + stack layout still diverge.
- **separate `camera` local**: 411/420 (fixes the `adds r4,r0,#0` copy but
  loWide still first-fits r3).
- flags on the wide base: `-ffixed-r{5,6,7}` 443-445; `-fforce-addr` 506;
  `-fno-gcse`/`-fno-strength-reduce` 506; `-fno-cse-*` 449; `-fno-defer-pop`/
  `-fno-peephole` 449; `-fno-schedule-insns2` build-fail. None reach <411.

### The real wall

The target's allocation isn't a single-register permutation of the built one:
it requires **lo, hiWide, spanLo all promoted to high regs (r8/r9/sl) AND the
`i*8` bounds index spilled to `[sp,#12]`** (hence `sub sp,#16`, a 4th slot).
That whole layout only emerges from a higher-register-pressure intermediate
state. Even forcing the individual hard-reg assignments via the instrumented
exclusion hook does NOT reproduce it — the stack layout and the zero-constant
materialization order (`movs r1,#0` before `movs r5,#0`) come from a different
live-range structure, not a coloring tweak. This is the textbook
"sharp register-coloring local minimum no single source shape escapes" case the
workflow reserves for `vendor/decomp-permuter` (statement-reorder / scope
mutation to explore the allocation space).

## Best-effort C  (wide-derivation base — instruction sequence matches target; 366/411)

```c
#include "macros.h"
#include "types.h"
#include "game.h"
#include "gba/dma.h"

typedef struct {
    u16 lo;
    u16 hi;
    u8 unk4;
    u8 unk5;
    u8 _pad6[2];
    u32 lastTick;
    u8 tickDelta;
    u8 _pad13[3];
} ClipSpan;

typedef struct {
    u16 start;
    u16 end;
    u16 _pad4;
    u16 _pad6;
} ColumnRange;

typedef struct {
    u16 left;
    u16 top;
    u16 _pad4;
    u16 _pad6;
} ViewBounds;

typedef struct {
    u8 _pad0[8];
    s32 viewX;
} ViewState;

#define gViewState ((ViewState *)0x030060A0)
#define gViewBounds ((ViewBounds *)0x0830696C)
#define gFixedClipSpans ((ClipSpan *)0x030063C0)
#define gColumnClipSpans ((ClipSpan *)0x03006360)

void sub_08016404(ColumnRange *columns, u8 count)
{
    vu16 fill;
    u8 *active;
    s32 viewX;
    s32 loWide;
    s32 hiWide;
    ViewState *viewState;
    u16 lo;
    u16 hi;
    u16 spanLo;
    u16 spanHi;
    ViewBounds *bounds;
    ClipSpan *fixed;
    u8 i;

    {
        u16 *clear = (u16 *)0x030065D0;
        u8 zero = 0;
        clear[1] = 0;
        clear[0] = 0;
        active = (u8 *)0x03003608;
        active[5] = zero;
    }

    /* Wide form: keep loWide held so lo, spanLo, hiWide, spanHi all CSE off the
       single `viewX<<16`. Using viewX (not a separate camera) for the shared
       value gives the 366 base. */
    viewX = gViewState->viewX - 0x30;
    loWide = viewX << 16;
    lo = (u16)((u32)loWide >> 16);
    hiWide = loWide + (0x100 << 16);
    hi = (u16)((u32)hiWide >> 16);

    {
        ViewBounds *viewBounds = gViewBounds;
        if (lo >= viewBounds[0].top)
            goto reset_columns;
        if (hi <= viewBounds[1].left)
            goto reset_columns;
    }

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x030053A0;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x50;
    (void)REG_DMA3.cnt;

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x03003610;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x50;
    (void)REG_DMA3.cnt;

    active[5] = 1;
    active[4] = 1;

    spanLo = (u16)((u32)loWide >> 19);
    spanHi = (u16)((u32)hiWide >> 19);
    bounds = gViewBounds;
    fixed = gFixedClipSpans;

    for (i = 0; i <= 1; i++) {
        if (spanLo < (u16)(bounds[i].left >> 3))
            fixed[i].lo = (((s32)(u16)bounds[i].left - lo) >> 3) + 1;
        else
            fixed[i].lo = 0;

        if (spanHi < (u16)(bounds[i].top >> 3)) {
            fixed[i].hi = 31;
        } else {
            fixed[i].hi = ((s32)(u16)bounds[i].top - lo) >> 3;
            if ((s16)fixed[i].hi > 31)
                fixed[i].hi = 31;
        }
    }

    viewState = gViewState;
    for (i = 0; i < count; i++) {
        u8 *buffer;
        s32 elapsed;
        u16 j;

        viewX = viewState->viewX;
        if (viewX >= (u16)columns[i].end)
            continue;
        if (viewX + 0x100 <= (u16)columns[i].start)
            continue;

        if (viewX > (u16)columns[i].start)
            gColumnClipSpans[i].lo = 0;
        else
            gColumnClipSpans[i].lo = columns[i].start - viewX;

        viewX = viewState->viewX;
        if (viewX + 0x100 < (u16)columns[i].end)
            gColumnClipSpans[i].hi = 255;
        else
            gColumnClipSpans[i].hi = columns[i].end - viewX;

        elapsed = gGameStuff._unk00 - gColumnClipSpans[i].lastTick;
        if (elapsed >= gColumnClipSpans[i].tickDelta) {
            gColumnClipSpans[i].lastTick = gGameStuff._unk00;
            if (gColumnClipSpans[i].unk5 == 0)
                gColumnClipSpans[i].unk4++;
            else
                gColumnClipSpans[i].unk4--;
        }

        for (j = gColumnClipSpans[i].lo; j < (s16)gColumnClipSpans[i].hi; j++) {
            if (gColumnClipSpans[i].unk5 & 0x10)
                buffer = (u8 *)0x03003610;
            else
                buffer = (u8 *)0x030053A0;
            buffer[j] = gColumnClipSpans[i].unk4;
        }
    }

reset_columns:
    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x03005440;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x30;
    (void)REG_DMA3.cnt;

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x030036B0;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x30;
    (void)REG_DMA3.cnt;
}
```
