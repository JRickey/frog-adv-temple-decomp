# sub_08016404 — deferred analysis

588-byte Thumb leaf at 0x08016404 (the per-column view-clip span builder).
Classifier verdict is `ATTEMPT_MATCH` (no `bl` calls — the high-reg advisory is
a false positive; r8/r9/sl are pure register-pressure spills, not call-live).
The function is **already structurally correct in pure C**; the blocker is a
single sharp register-coloring local minimum that originates in the prologue and
cascades through the whole body.

## Root cause (this round — more precise than prior diagnosis)

Plateau with the clean readable C (below) on default `old_agbcc`: **size 572,
byte_diff 375, diff_count 178**. Newer `agbcc`: **size 572, byte_diff 374/390**.
Both compilers stall at the same wall.

The diff is NOT spread across the function in a structural way — it is a single
register *permutation* born in the prologue and propagated by name. Of 248
instructions, ~124 differ, but every one is a register-rename of an otherwise
byte-identical instruction. The instruction **sequence** matches the target
almost exactly. The divergence chain, traced end to end:

1. **Prologue copy.** Target computes the camera in place:
   `subs r0, #48` (camera stays in r0, coalesced with the `ldr [r0,#8]` load).
   Built emits an extra `adds r4, r0, #0; subs r4, #48` — agbcc colored the
   `viewX` pseudo to a callee-saved reg (r4) instead of coalescing into r0.
2. Because target keeps camera "hot" in r0, it must reuse r0 for `hi`, so it
   moves `lo` out to **r8** (`lsrs r0,r4,#16; mov r8,r0`). Built has a free low
   reg, so `lo` lands in **r7** (low) with no move.
3. In the fixed-span loop, target's `lo` (r8, HIGH) and bounds-base (ip, HIGH)
   each need a `mov r5, r8` / `mov r5, ip` scratch-down before the Thumb
   `adds`/`subs`. Those scratch moves **consume r5**, so `i*8` (the bounds
   index) must **spill to `[sp,#12]`** (hence target's `sub sp, #16` — four
   slots: fill/columns/count/`i*8`-spill). Built keeps `lo` in low r7 (used
   directly, no scratch), leaving r5 free to hold `i*8` → **no spill** →
   `sub sp, #12`.
4. With r5 occupied by `i*8`, the `31` constant (pseudo 148) cannot get a free
   low reg and is moved to `ip` (`movs r3,#31; mov ip,r3`), costing an extra
   `mov r1,ip`/`mov r2,ip` before each `strh`. Target keeps `31` directly in r3.

`-dg` confirms the global allocator actually assigns `31` (pseudo 148) to **r3**
(`(set (reg:SI 3 r3) (const_int 31))`); it is **reload** that moves it to ip
because r3 is clobbered by `&bounds[i] = i*8 + base` inside the loop. So the fix
must keep `&bounds[i]` and `lo`/bounds-base off r3, which only happens once the
prologue puts `lo` in a high reg and forces the `i*8` spill — i.e. the whole
chain hinges on step 1 (eliminating the `adds r4,r0,#0` copy so `lo` is forced
to r8).

The single anchor to flip everything: **make agbcc color `viewX`→r0 (coalesce
with the load) instead of r4.** Every lever tried perturbs *other* pseudos
instead.

## Levers tried this round (all FAIL — what does NOT work)

Source shape:
- `hi = viewX + 0x100` (un-truncated) instead of `lo + 0x100`: **417** (worse;
  the `lo+0x100`-from-truncated-lo shape is required for the wide CSE).
- separate `s32 camera` for the prologue (isolate from column-loop `viewX`):
  **420**.
- inline `lo = gViewState->viewX - 0x30` (drop the `viewX =` intermediate):
  **436** — the `viewX =` intermediate is load-bearing for the `<<16` CSE.
- `hi` before `lo`: **437**. swap cmp operands: **393**.
- cache `bounds[i].left` into a local: **402**. byte-pointer
  `(ViewBounds*)((u8*)bounds + i*sizeof)` recompute per clip: **391** (folded
  back to indexed). `ViewBounds *bound = &bounds[i]` per clip: **492** (agbcc
  keeps the pointer, shrinks to 552 — wrong direction).
- explicit `loWide` (`camera<<16`) pinned r4 + `lo` pinned r8 +
  `spanLo=(u32)loWide>>19`: **415**, still `sub sp,#12` (no spill); the explicit
  wide form loses the natural CSE.
- `u16`/`s32` retyping of lo/hi/spanLo/spanHi: neutral or **521** (`s32 lo/hi`
  loses the u16 truncation entirely).

Register pins (all disrupt the prologue CSE chain → worse):
- `register u16 lo asm("r8")`: **530** (forces eager materialization of lo,
  destroys `lsls/lsrs` wide CSE).
- `register ViewBounds *bounds asm("ip")`: **442** (pushes `columns` param to
  sl, cascades).

Flags (`-fXXX`, default old_agbcc unless noted):
- `-ffixed-r{3,4,5,6,7}`: all **530–533** (free a reg → forces *more* spills).
- `-ffixed-r5` (free the reg that holds `i*8`, hoping to force the spill):
  **533**; `-fno-cse-skip-blocks -ffixed-r5`: **545**.
- `-fno-cse-skip-blocks` alone: **383, size 580** — best flag, but the extra
  bytes are a column-loop change, NOT the prologue spill (prologue still has the
  `adds r4,r0,#0` copy). Not the fix.
- `-fno-force-mem`: **414**. `-fno-gcse`: **498**. `-fno-omit-frame-pointer`:
  **544**.
- neutral (391): `-fno-strength-reduce`, `-fforce-mem`, `-frerun-loop-opt`,
  `-fno-thread-jumps`, `-fno-defer-pop`, `-fno-peephole`, `-fno-function-cse`,
  `-fno-inline`, `-fno-schedule-insns{,2}`, `-fcaller-saves`.
- newer `agbcc`: **390**, same prologue, no spill.

Permuter: **unavailable in this environment** — `vendor/decomp-permuter` is a
symlink into main's submodule mountpoint, but main never checked the submodule
out (no `.venv`, no `permuter.py`). This is exactly the "sharp coloring local
minimum no single source shape escapes" case the workflow designates the
permuter for, so a future attempt should (a) populate the permuter
(`git submodule update` + `scripts/setup-decomp-permuter.sh`) and run it from
the byte_diff-375 base, OR (b) build a PRIVATE instrumented `old_agbcc`
(SAFETY: never touch the shared `tools/agbcc-src`; copy to a private prefix) and
trace `local-alloc.c` coalescing of the `viewX` pseudo + `global.c:find_reg` to
find the one source/flag perturbation that colors `viewX`→r0.

#include "macros.h"
#include "types.h"
#include "game.h"
#include "gba/dma.h"

typedef struct {
    u16 lo;
    u16 hi;
    u8 unk4;
    u8 unk5;
    u8 _pad6[2];
    u32 lastTick;
    u8 tickDelta;
    u8 _pad13[3];
} ClipSpan;

typedef struct {
    u16 start;
    u16 end;
    u16 _pad4;
    u16 _pad6;
} ColumnRange;

typedef struct {
    u16 left;
    u16 top;
    u16 _pad4;
    u16 _pad6;
} ViewBounds;

typedef struct {
    u8 _pad0[8];
    s32 viewX;
} ViewState;

#define gViewState ((ViewState *)0x030060A0)
#define gViewBounds ((ViewBounds *)0x0830696C)
#define gFixedClipSpans ((ClipSpan *)0x030063C0)
#define gColumnClipSpans ((ClipSpan *)0x03006360)

void sub_08016404(ColumnRange *columns, u8 count)
{
    vu16 fill;
    u8 *active;
    s32 viewX;
    ViewState *viewState;
    u16 lo;
    u16 hi;
    u16 spanLo;
    u16 spanHi;
    ViewBounds *bounds;
    ClipSpan *fixed;
    u8 i;

    {
        u16 *clear = (u16 *)0x030065D0;
        u8 zero = 0;
        clear[1] = 0;
        clear[0] = 0;
        active = (u8 *)0x03003608;
        active[5] = zero;
    }

    viewX = gViewState->viewX - 0x30;
    lo = viewX;
    hi = lo + 0x100;

    {
        ViewBounds *viewBounds = gViewBounds;
        if (lo >= viewBounds[0].top)
            goto reset_columns;
        if (hi <= viewBounds[1].left)
            goto reset_columns;
    }

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x030053A0;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x50;
    (void)REG_DMA3.cnt;

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x03003610;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x50;
    (void)REG_DMA3.cnt;

    active[5] = 1;
    active[4] = 1;

    spanLo = lo >> 3;
    spanHi = hi >> 3;
    bounds = gViewBounds;
    fixed = gFixedClipSpans;

        if (spanLo < (u16)(bounds[i].left >> 3))
            fixed[i].lo = (((s32)(u16)bounds[i].left - lo) >> 3) + 1;
        else
            fixed[i].lo = 0;

        if (spanHi < (u16)(bounds[i].top >> 3)) {
            fixed[i].hi = 31;
        } else {
            fixed[i].hi = ((s32)(u16)bounds[i].top - lo) >> 3;
            if ((s16)fixed[i].hi > 31)
                fixed[i].hi = 31;
        }
    }

    viewState = gViewState;
    for (i = 0; i < count; i++) {
        u8 *buffer;
        s32 elapsed;
        u16 j;

        viewX = viewState->viewX;
        if (viewX >= (u16)columns[i].end)
            continue;
        if (viewX + 0x100 <= (u16)columns[i].start)
            continue;

        if (viewX > (u16)columns[i].start)
            gColumnClipSpans[i].lo = 0;
        else
            gColumnClipSpans[i].lo = columns[i].start - viewX;

        viewX = viewState->viewX;
        if (viewX + 0x100 < (u16)columns[i].end)
            gColumnClipSpans[i].hi = 255;
        else

            if (gColumnClipSpans[i].unk5 == 0)
                gColumnClipSpans[i].unk4++;
            else
                gColumnClipSpans[i].unk4--;
        }

        for (j = gColumnClipSpans[i].lo; j < (s16)gColumnClipSpans[i].hi; j++) {

                buffer = (u8 *)0x03003610;
            else
                buffer = (u8 *)0x030053A0;
            buffer[j] = gColumnClipSpans[i].unk4;
        }
    }

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x03005440;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x30;
    (void)REG_DMA3.cnt;

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x030036B0;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x30;
    (void)REG_DMA3.cnt;
}
