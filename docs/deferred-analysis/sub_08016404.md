- target keeps `(viewX - 0x30) << 16` through `r4`, truncated `lo` in `r8`,

  that coloring choice.

doubles live length for equivalent constants. The `-dg` dump for the clean
plateau confirms pseudo `148` is `31`: `refs = 5`, `live_length = 102`,
`pref LO_REGS`, allocated through `ip` (`r3=31; ip=r3`). This matches the
previous root-cause diagnosis.
