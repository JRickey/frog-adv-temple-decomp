# sub_08016404 — deferred analysis

588-byte (~147-instruction) Thumb leaf at 0x08016404. Pure leaf (no callees).
Camera/scroll-edge clip-range setup. The ARITHMETIC and CONTROL FLOW are
fully decoded and the best-effort C below compiles to a structurally-correct
program; the blocker is a sharp register-coloring local minimum (the
"no single source shape escapes" case in CLAUDE.md / docs/codegen-notes).

## What it does (decoded, high confidence)

Caller: `sub_08000CEC` -> `sub_08016404(columns=0x08306944, count=5)`.

- `columns` (arg0) points at 5 ROM 8-byte records `{u16 start, u16 end, u16, u16}`
  at 0x08306944 (start=424..584, end=472..648).
- ROM table `gViewBounds` at 0x0830696C: 8-byte records `{u16 _unk0, u16 top, ...}`.
  t[0]={lo=440,hi=648}, t[1]={lo=432,hi=560}.
- IWRAM bases: 0x030060A0 +8 = `viewX` (s32 pixel camera-x, read 3x);
  0x030063C0 = `gFixedSpans` (2 fixed vertical ClipSpans, 16B stride);
  0x03006360 = `gColumnSpans` (per-column ClipSpans, 16B stride — same
  `Dst08016360` 16-byte layout as src/engine/sub_08016360.c, with a u32 at +8);
  0x03003608 +4/+5 = active flags; 0x030065D0 = two halfwords cleared.
- DMA3 zero-fills (src-fixed): 0x030053A0 & 0x03003610 with count 0x50 (taken
  path), then 0x03005440 & 0x030036B0 with count 0x30 (always, shared epilogue).

Top: clear 0x030065D0[0/2], active[5]=0. `viewX = *(s32*)(0x030060A0+8) - 0x30`,
`lo=(u16)viewX`, `hi=(u16)(lo+0x100)`. Early-return (-> final 0x30-fills) if
`lo >= gViewBounds[0].top` OR `hi <= gViewBounds[1]._unk0`.

Loop1 (i=0,1) fills gFixedSpans[i]: `.lo = (lo>>3 >= t[i].lo>>3) ? 0 :
((t[i].lo - lo)>>3)+1`; `.hi = (hi>>3 >= t[i].hi>>3) ? 31 : min(((t[i].hi-lo)>>3), 31)`
where the 31-clamp re-reads the stored s16.

Loop2 (i=0..count): per gColumnSpans[i], gate on `viewX < columns[i].end` and
`viewX+0x100 > columns[i].start`; set `.lo = (viewX<=start)?(start-viewX):0`,
`.hi = (viewX+0x100>=end)?(255-viewX):255`; a `gGameStuff._unk00`-timed
`.unk4 += (.unk5? -1 : +1)` step; then inner `for(j=.lo; j<(s16).hi; j++)`
writes `.unk4` into `((.unk5 & 0x10)?0x03003610:0x030053A0)[j]`.

## Drift

Best result (v3 below): byte_diff 505, diff_count 242, size 572 (target 588).
(A no-base-local variant "v2" reached byte_diff 475 / diff_count 276 / size 552,
but worse instruction-alignment.)

The decoded idioms ALL reproduce correctly:
- shared `(viewX-0x30)<<16` intermediate feeding both `lo=(>>16)` and
  `hi=((0x100<<16)+x)>>16` — reproduced by writing `lo=viewX; hi=lo+0x100;`.
- `slo=lo>>3`, `shi=hi>>3` emitted as `>>19` of the `<<16` form — reproduced
  once `bounds`/`fixed` were lifted to base-pointer locals.
- function-parameter home-slot spill (`str r0,[sp,#4]; str r1,[sp,#8]`) for
  columns+count — reproduced (the base-pointer locals tied up enough registers).
- both DMA blocks share one `cnt` constant register — reproduced.

Remaining divergence is PURELY physical-register coloring, robust to every
lever tried:
- target colors `lo=r8`, `slo=sl`, `shi=r9`, `bounds(t-base)=ip`, `fixed=r7`,
  `i=r6`, `31=r3`, and spills the `i<<3` t-index to `[sp,#12]` (4th stack slot,
  `sub sp,#16`). My best build colors `bounds=r8` and keeps `i<<3` in a reg
  (`sub sp,#12`, 3 slots) — one fewer live value in loop1.
- LEVERS TRIED (all neutral or worse, do NOT repeat):
  - register pins: `lo asm("r8")` (483), `lo+slo+shi` high pins (514),
    `lo+hi+slo+bounds asm("ip")` coordinated (523/251, size hit 584 but body
    register conflicts) — every pin DISRUPTS the natural shared-`<<16` shift
    (forces re-`<<16>>16` masking) and raises diff.
  - per-TU CFLAGS: `-fno-gcse`, `-fforce-addr`, `-fno-expensive-optimizations`,
    `-fno-strength-reduce`, `-fno-schedule-insns`, and the combo — ALL produce
    byte-identical 505/242/572. Coloring is set by source shape, not these passes.
  - compiler swap OLD_AGBCC <-> AGBCC_BIN: identical (548 baseline pre-base-locals).
- corpus: classify=ATTEMPT_MATCH (high-reg advisory is a false positive — pure
  leaf, no `bl`). History search `mov (r8|r9|sl), r[0-7]` --require-c hits
  pret pokeemerald librfu (high-reg loop state IS reachable in pure C), so this
  is NOT corpus-confirmed-unmatchable. It is the documented sharp-coloring
  local minimum (CLAUDE.md sub_08017364 caveat) — but diff_count 242 is far
  above permuter's ~40 effective range, so permuter was not run.

## Best-effort C

```c
#include "macros.h"
#include "types.h"
#include "game.h"
#include "gba/dma.h"

/* One screen-edge clip span: a tile range [lo, hi] derived from a pixel
 * range. The two fixed entries at 0x030063C0 hold the vertical clip; the
 * count entries at 0x03006360 hold the per-column horizontal clip. */
typedef struct {
    u16 lo;
    u16 hi;
    u8 unk4;
    u8 unk5;
    u8 _unk6[2];
    u32 unk8;
    u8 unk12;
    u8 _unk13[3];
} ClipSpan;

/* Source record (ROM): a pixel range [start, end] per column. */
typedef struct {
    u16 start;
    u16 end;
    u16 _unk4;
    u16 _unk6;
} ColumnRange;

/* Bounds for the two fixed vertical spans, in pixels. */
typedef struct {
    u16 _unk0;
    u16 top;
    u16 _unk4;
    u16 _unk6;
} ViewBounds;

/* Camera/scroll state; +8 is the current view X (in pixels). */
typedef struct {
    u8 _pad0[8];
    s32 viewX;
} ViewState;

#define gViewState ((ViewState *)0x030060A0)
#define gViewBounds ((const ViewBounds *)0x0830696C)
#define gFixedSpans ((ClipSpan *)0x030063C0)
#define gColumnSpans ((ClipSpan *)0x03006360)

void sub_08016404(ColumnRange *columns, u8 count)
{
    vu16 fill;
    u8 *active;
    s32 viewX;
    u16 lo, hi;
    u16 slo, shi;
    const ViewBounds *bounds;
    ClipSpan *fixed;
    u8 i;

    *(u16 *)0x030065D0 = 0;
    *(u16 *)0x030065D2 = 0;

    active = (u8 *)0x03003608;
    active[5] = 0;

    viewX = gViewState->viewX - 0x30;
    lo = viewX;
    hi = lo + 0x100;

    if (lo >= gViewBounds[0].top)
        goto reset_columns;
    if (hi <= gViewBounds[1]._unk0)
        goto reset_columns;

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x030053A0;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x50;
    (void)REG_DMA3.cnt;

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x03003610;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x50;
    (void)REG_DMA3.cnt;

    active[5] = 1;
    active[4] = 1;

    slo = lo >> 3;
    shi = hi >> 3;

    bounds = gViewBounds;
    fixed = gFixedSpans;

    for (i = 0; i <= 1; i++) {
        if (slo >= (u16)(bounds[i]._unk0 >> 3))
            fixed[i].lo = 0;
        else
            fixed[i].lo = (((s32)(u16)bounds[i]._unk0 - lo) >> 3) + 1;

        if (shi >= (u16)(bounds[i].top >> 3)) {
            fixed[i].hi = 31;
        } else {
            fixed[i].hi = ((s32)(u16)bounds[i].top - lo) >> 3;
            if ((s16)fixed[i].hi > 31)
                fixed[i].hi = 31;
        }
    }

    for (i = 0; i < count; i++) {
        ClipSpan *span = &gColumnSpans[i];
        u8 *base;
        s32 x;
        s16 j;

        viewX = gViewState->viewX;
        if (viewX >= (s16)columns[i].end)
            continue;
        if (viewX + 0x100 <= (s16)columns[i].start)
            continue;

        if (viewX <= (s16)columns[i].start)
            span->lo = columns[i].start - viewX;
        else
            span->lo = 0;

        viewX = gViewState->viewX;
        if (viewX + 0x100 >= (s16)columns[i].end)
            span->hi = 255 - viewX;
        else
            span->hi = 255;

        x = gGameStuff._unk00 - span->unk8;
        if (x >= span->unk12) {
            span->unk8 = gGameStuff._unk00;
            if (span->unk5 != 0)
                span->unk4--;
            else
                span->unk4++;
        }

        if ((s16)span->lo >= (s16)span->hi)
            continue;

        for (j = span->lo; j < (s16)span->hi; j++) {
            base = (span->unk5 & 0x10) ? (u8 *)0x03003610 : (u8 *)0x030053A0;
            base[j] = span->unk4;
        }
    }

reset_columns:
    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x03005440;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x30;
    (void)REG_DMA3.cnt;

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x030036B0;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x30;
    (void)REG_DMA3.cnt;
}
```
