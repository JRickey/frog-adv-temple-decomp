# sub_08016404 — deferred analysis (round 22, Opus escalation)

588-byte (~147-instruction) Thumb leaf at 0x08016404. Pure leaf, no callees.
Camera/scroll-edge clip-range setup. Arithmetic + control flow are now FULLY
decoded and VERIFIED against the baserom bytes. Round-22 re-derivation FIXED
several structural bugs the round-21 note had wrong; remaining blocker is a
sharp global register-coloring local minimum (the CLAUDE.md sub_08017364
caveat: "a near-match can still be a sharp register-coloring local minimum no
single source shape escapes").

## Corrections vs the round-21 note (these were real bugs, now fixed)

1. **Loop1 hi-clamp branch was INVERTED.** Correct: `if (shi >= (top>>3))`
   compute `min((top-lo)>>3, 31)`, else `hi = 31`. (r21 had it the other way.)
2. **Loop2 hi value was WRONG.** Correct: `(viewX+0x100 >= end) ? (end - viewX)
   : 255`. (r21 said `255 - viewX`; the asm at 0x1657c is `subs r0,r0,r4` =
   `end - viewX`, not `255 - viewX`.)
3. **Block ORDER** for every if/else in loop1+loop2 had to be inverted at the
   C level so agbcc emits the compute/store-0/store-31 blocks in baserom
   physical order (target keeps the "compute" body as the second block; write
   the condition so the trivial body is the fall-through). This alone took
   diff_count 226 -> 205.
4. **gViewState must be cached** in a loop-invariant local (`ViewState *vs =
   gViewState;`) before loop2 — the baserom keeps it in `sl` and re-reads
   `[sl,#8]`; the `gViewState->viewX` macro reloads the pool each time. This
   took diff_count 205 -> 165 (biggest single win).
5. **gColumnSpans[i] must be accessed inline** (no cached `ClipSpan *span`
   pointer) so agbcc recomputes `i<<4 + base` per access like the baserom.
6. **Inner-loop counter `j` must be `u16`** (not `s16`) so the guard
   `j < (s16)hi` emits `ldrsh [base, #2-reg]` (register-offset signed load)
   matching the baserom, instead of `ldrh + lsls#16; asrs#16`.
7. **The early bounds check must read `bounds[0].top` (+2) and `bounds[1]._unk0`
   (+8) through ONE base** (a local `ViewBounds *vb`), not via two folded
   absolute literals (`gViewBounds` and `gViewBounds+8`).

## What it does (decoded, high confidence — see Best-effort C below)

Caller: `sub_08000CEC` -> `sub_08016404(columns=0x08306944, count=5)`.

- `columns` (arg0): 5 ROM 8-byte `{u16 start, u16 end, u16, u16}` at 0x08306944
  (start=424..584, end=472..648).
- `gViewBounds` at 0x0830696C: 8-byte `{u16 _unk0, u16 top, ...}`;
  [0]={_unk0=440, top=648}, [1]={_unk0=432, top=560}.
- IWRAM: 0x030060A0+8 = `viewX` (s32, raw; the top uses viewX-0x30, loop2 uses
  raw); 0x030063C0 = gFixedSpans (ClipSpan[2], 16B stride); 0x03006360 =
  gColumnSpans (ClipSpan[count], 16B stride, u32 at +8); 0x03003608+4/+5 =
  active flags; 0x030065D0 two halfwords cleared (clear[1] then clear[0]).
- DMA3 src-fixed zero-fills: 0x030053A0 & 0x03003610 count 0x50 (only on the
  taken path), then 0x03005440 & 0x030036B0 count 0x30 (always, the
  `reset_columns:` shared epilogue).

## Drift (round 22)

Best clean result (Best-effort C below, NO pins/asm/CFLAGS): byte_diff **431**,
diff_count **182**, size **572** (target 588). Reg-agnostic structural
similarity ~67% — every diff is a register-NAME mismatch, not a missing/extra
instruction (the opcode+immediate sequence is essentially correct). This is a
big improvement over r21's 505/242.

The single remaining structural delta is the **loop1 `i<<3` spill**: the
baserom does `sub sp,#16` + `str r0,[sp,#12]` (spills the ViewBounds index to a
4th stack slot) and reloads it for the hi-half to recompute `&bounds[i]`. My
build does `sub sp,#12` and keeps `i<<3` in a register (one fewer live value).

ROOT CAUSE (newly identified): the spill is downstream of the **`31` constant's
register class**. Baserom keeps `31` in a LOW reg (r3) and stores it directly
(`strh r3`); mine keeps `31` in `ip` (so each store needs an extra `mov r2,ip;
strh r2`). With `31` in a low reg the baserom runs out of low regs and spills
`i<<3`; with `31` in `ip` mine has a spare low reg and doesn't spill. The whole
413/431 diff is this one coloring choice cascading: baserom keeps `lo` in r8,
`hi<<16` in r9, `bounds` in `ip`, `31` in r3, `fixed` in r7; mine puts `lo` in
r7, `hi<<16` in r8, `bounds` in r8/r4, `31` in ip.

## LEVERS TRIED (round 22) — all NEUTRAL or WORSE, do NOT repeat

- register pins: `lo asm("r8")` (465, breaks the shared `<<16`),
  `bounds asm("ip")` (491). Every pin disrupts the shared
  `(viewX-0x30)<<16` intermediate feeding lo/hi/slo/shi and raises diff.
- per-TU CFLAGS: `-fno-strength-reduce`, `-fno-gcse`, `-fno-schedule-insns`,
  `-fforce-addr`, and combos: ALL bump to 431+ (none below the no-flag build).
  `-ffixed-ip` gives 411 but is WRONG (baserom USES ip for bounds).
- compiler swap OLD_AGBCC <-> AGBCC: AGBCC gives 485 (worse, size 548).
  OLD_AGBCC (the Makefile default) is correct.
- forcing `31` low via a `s16 hiClamp` local: makes the body TIGHTER (568 bytes,
  fewer instrs) — the OPPOSITE of the needed spill. byte_diff 476.
- forcing `&bounds[i]` recompute via `((ViewBounds*)((u8*)bounds+i*8))->top`:
  agbcc folds it back; no spill, 431.
- unifying the early-check `bounds` load with loop1's (so `mov ip, r7` reuses
  it like the baserom): 483 (worse — keeps bounds live across the DMA blocks).

## Best-effort C (round 22 — byte_diff 431, structurally correct, NO levers)

```c
#include "macros.h"
#include "types.h"
#include "game.h"
#include "gba/dma.h"

/* One screen-edge clip span: a tile range [lo, hi] derived from a pixel
 * range. The two fixed entries at 0x030063C0 hold the vertical clip; the
 * count entries at 0x03006360 hold the per-column horizontal clip. */
typedef struct {
    u16 lo;
    u16 hi;
    u8 unk4;
    u8 unk5;
    u8 _unk6[2];
    u32 unk8;
    u8 unk12;
    u8 _unk13[3];
} ClipSpan;

/* Source record (ROM): a pixel range [start, end] per column. */
typedef struct {
    u16 start;
    u16 end;
    u16 _unk4;
    u16 _unk6;
} ColumnRange;

/* Bounds for the two fixed vertical spans, in pixels. */
typedef struct {
    u16 _unk0;
    u16 top;
    u16 _unk4;
    u16 _unk6;
} ViewBounds;

/* Camera/scroll state; +8 is the current view X (in pixels). */
typedef struct {
    u8 _pad0[8];
    s32 viewX;
} ViewState;

#define gViewState ((ViewState *)0x030060A0)
#define gViewBounds ((ViewBounds *)0x0830696C)
#define gFixedSpans ((ClipSpan *)0x030063C0)
#define gColumnSpans ((ClipSpan *)0x03006360)

void sub_08016404(ColumnRange *columns, u8 count)
{
    vu16 fill;
    u8 *active;
    s32 viewX;
    ViewState *vs;
    u16 lo, hi;
    u16 slo, shi;
    ViewBounds *bounds;
    ClipSpan *fixed;
    u8 i;

    {
        u16 *clear = (u16 *)0x030065D0;
        clear[1] = 0;
        clear[0] = 0;
    }

    active = (u8 *)0x03003608;
    active[5] = 0;

    viewX = gViewState->viewX - 0x30;
    lo = viewX;
    hi = lo + 0x100;

    {
        ViewBounds *vb = gViewBounds;
        if (lo >= vb[0].top)
            goto reset_columns;
        if (hi <= vb[1]._unk0)
            goto reset_columns;
    }

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x030053A0;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x50;
    (void)REG_DMA3.cnt;

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x03003610;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x50;
    (void)REG_DMA3.cnt;

    active[5] = 1;
    active[4] = 1;

    slo = lo >> 3;
    shi = hi >> 3;

    bounds = gViewBounds;
    fixed = gFixedSpans;

    for (i = 0; i <= 1; i++) {
        if (slo < (u16)(bounds[i]._unk0 >> 3))
            fixed[i].lo = (((s32)(u16)bounds[i]._unk0 - lo) >> 3) + 1;
        else
            fixed[i].lo = 0;

        if (shi < (u16)(bounds[i].top >> 3)) {
            fixed[i].hi = 31;
        } else {
            fixed[i].hi = ((s32)(u16)bounds[i].top - lo) >> 3;
            if ((s16)fixed[i].hi > 31)
                fixed[i].hi = 31;
        }
    }

    vs = gViewState;
    for (i = 0; i < count; i++) {
        u8 *base;
        s32 x;
        u16 j;

        viewX = vs->viewX;
        if (viewX >= (u16)columns[i].end)
            continue;
        if (viewX + 0x100 <= (u16)columns[i].start)
            continue;

        if (viewX > (u16)columns[i].start)
            gColumnSpans[i].lo = 0;
        else
            gColumnSpans[i].lo = columns[i].start - viewX;

        viewX = vs->viewX;
        if (viewX + 0x100 < (u16)columns[i].end)
            gColumnSpans[i].hi = 255;
        else
            gColumnSpans[i].hi = columns[i].end - viewX;

        x = gGameStuff._unk00 - gColumnSpans[i].unk8;
        if (x >= gColumnSpans[i].unk12) {
            gColumnSpans[i].unk8 = gGameStuff._unk00;
            if (gColumnSpans[i].unk5 == 0)
                gColumnSpans[i].unk4++;
            else
                gColumnSpans[i].unk4--;
        }

        for (j = gColumnSpans[i].lo; j < (s16)gColumnSpans[i].hi; j++) {
            base = (gColumnSpans[i].unk5 & 0x10) ? (u8 *)0x03003610 : (u8 *)0x030053A0;
            base[j] = gColumnSpans[i].unk4;
        }
    }

reset_columns:
    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x03005440;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x30;
    (void)REG_DMA3.cnt;

    fill = 0;
    REG_DMA3.src = (void *)&fill;
    REG_DMA3.dst = (void *)0x030036B0;
    REG_DMA3.cnt = DMA_ENABLE | DMA_SRC_FIXED | 0x30;
    (void)REG_DMA3.cnt;
}
```
