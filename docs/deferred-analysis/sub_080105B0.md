# Deferred analysis: sub_080105B0

VERDICT (classify_unmatchable.py): ATTEMPT_MATCH — `push {r4,r5,r6,r7,lr}`
prologue, no structural-impossibility signature. NOT a NAKED candidate.

## What it does (fully understood)

`sub_080105B0(struct BlitEntry *base, u8 index, u8 srcIndex)` — a tilemap-blit
driver, a near-twin of the already-matched `sub_08012BC4` / `sub_080112C0`. It
copies a `cols x rows` block of u16 tiles from a per-entry source-pointer table
into one of two EWRAM staging banks, advancing the dst by the scene stride at
`0x030060A0+26` between rows. Unlike its twins, the src/dst pointers live in the
IWRAM blit-state block at `0x03006500` (+12 = src, +20 = dst) and are stored
back on every inner-loop step.

Struct layout (confirmed via objdump trace):
- `struct BlitEntry` (24-byte stride): +0 dstX (u16), +2 dstY (u16), +4 cols
  (u16), +6 rows (u16), +8 flags (u8, bit4 selects EWRAM bank
  0x02010000 vs 0x02000000), +0x10 srcTable (const u16 *const *).
- `struct BlitState` @ 0x03006500: +0x0c src, +0x14 dst.
- `struct SceneScroll` @ 0x030060A0: +0x1a stride (u16).

The full inner blit loop AND the entire outer-loop body + epilogue already match
byte-for-byte in the best-effort C below. All residual diff is concentrated in
the prologue + pre-loop setup.

## Drift

Best: **byte_diff 121, diff_count 60** (OLD_AGBCC, the project default).
Progression across ~12 fundamentally-different attempts:
- clean unpinned C: 190
- pin args (gBase=r9, index=ip, srcIndex=r6): 168
- + state=r4, index2=r5: 164
- + e=r3, stride=r7, loop st8=r8/idx2=sl pins: 146

This is a **sharp 7-callee-saved-register coloring local minimum** (baserom uses
r4-r7 + r8/r9/sl). The residual diffs are ALL register-coloring / commutativity,
no structural error:

1. **Prologue insn order** (~4 bytes): baserom emits `mov r9, r0` (gBase=arg0)
   BEFORE the `lsls r1,#24`/`lsls r2,#24` byte-extends; agbcc schedules the two
   `lsls` first. agbcc 2.x exposes NO `-fno-schedule-insns` (rejected by both
   old_agbcc and the newer agbcc) — could not steer via source ordering.
2. **index2 reuse vs recompute**: baserom computes a throwaway `index*2` (r0)
   for the flags check, then RECOMPUTES `index2` into r5 at the e-computation.
   Hoisting index2 early (the 121 win) makes the flags check reuse r5 (2-byte
   diff) but fixes more downstream; computing it at e-comp (146 variant) fixes
   the flags check but costs elsewhere. Neither placement wins both.
3. **`e` pointer chain**: pinning `e` to r3 lands the field accesses on `[r3,#N]`
   (matches baserom) but forces the address arithmetic in-place
   (`lsls r3; add r3,r9`) vs baserom's r0-temp chain (`lsls r0; adds r3,r0,r1`).
   Unpinned `e` lands in r2 → every field access is a 1-bit reg diff (worse).
4. **`stride * e->dstY`** muls operand order: baserom `r1=stride; muls r1,dstY`;
   agbcc emits `r1=dstY; muls r1,stride`. Source operand swap had no effect
   (allocator-determined).
5. **`e->srcTable[srcIndex]`**: baserom `ldr r1,[r3,#16]; lsls r0,r6,#2` (table
   in r1, preserves srcIndex r6); agbcc `ldr r0,[r3,#16]; lsls r6,r6,#2`
   (destroys r6). Separate temp for the table load had no effect.
6. **`index2`/r5 backup discipline**: baserom keeps index2 in r5 across the
   outer loop, backs it up to sl, lets the inner loop CLOBBER r5 with the saved
   `ce` pointer (`adds r5, r0, #0`), then RESTORES r5 from sl (`mov r5, sl`) at
   the outer-bottom. Could not reproduce the r5↔sl backup/restore without
   either spilling to stack (too many simultaneous pins) or letting agbcc keep
   the ce-recompute in sl directly (a different coloring).

  (sub_08012BC4, sub_080112C0) matched with FULL explicit pins; the blocker here
  is the r4→col and r5↔sl register REUSE across non-overlapping lifetimes, which

## Best-effort C (byte_diff 121, structure correct; whole loop + tail match)

```c
#include "types.h"

struct BlitEntry {
    u16 dstX;
    u16 dstY;
    u16 cols;
    u16 rows;
    u8 flags;
    u8 _pad09[7];
    const u16 *const *srcTable;
    u8 _pad14[4];
};

struct BlitState {
    u8 _pad00[12];
    const u16 *src;
    u8 _pad10[4];
    u16 *dst;
};

struct SceneScroll {
    u8 _pad00[26];
    u16 stride;
};

void sub_080105B0(struct BlitEntry *base, u8 indexArg, u8 srcIndexArg)
{
    register struct BlitEntry *gBase asm("r9") = base;
    register u32 index asm("ip");
    register u32 srcIndex asm("r6");
    register struct BlitState *state asm("r4");
    register u32 index2 asm("r5");
    register struct BlitEntry *e asm("r3");
    register u32 stride asm("r7");
    struct SceneScroll *scene;
    u32 row;
    u32 col;

    index = (u8)indexArg;
    srcIndex = (u8)srcIndexArg;
    index2 = index * 2;

    if ((gBase[index].flags >> 4) & 1) {
        ((struct BlitState *)0x03006500)->dst = (u16 *)0x02010000;
    } else {
        ((struct BlitState *)0x03006500)->dst = (u16 *)0x02000000;
    }

    state = (struct BlitState *)0x03006500;
    e = (struct BlitEntry *)((u8 *)gBase + (index2 + index) * 8);
    scene = (struct SceneScroll *)0x030060A0;
    stride = scene->stride;
    state->dst += stride * e->dstY + e->dstX;
    state->src = e->srcTable[srcIndex];

    row = 0;
    if (row < e->rows) {
        register struct BlitState *st8 asm("r8") = state;
        register u32 idx2 asm("sl") = index2;
        struct BlitEntry *ent = e;

        do {
            struct BlitEntry *ce;

            col = 0;
            ce = (struct BlitEntry *)((u8 *)gBase + (idx2 + index) * 8);
            if (col < ce->cols) {
                struct BlitState *bs = (struct BlitState *)0x03006500;
                do {
                    *bs->dst++ = *bs->src++;
                    col = (u8)(col + 1);
                } while (col < ce->cols);
            }
            scene = (struct SceneScroll *)0x030060A0;
            st8->dst += scene->stride - ent->cols;
            row = (u8)(row + 1);
        } while (row < ent->rows);
    }
}
```
