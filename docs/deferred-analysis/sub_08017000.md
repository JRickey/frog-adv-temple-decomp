   (-fno-cse-follow-jumps/-skip-blocks/-gcse/-rerun-cse-after-loop) are ALL

   cached-pointer phase 2 (`cur5320->byte0`) agbcc puts cursor -> r8 (r8 freed
   after phase-1 ctrl), idx -> r9. ROOT: r8 is double-booked — ctrl (phase 1)
   AND idx-stash (phase 2) want it; the function-scope `ctrl asm("r8")` pin
