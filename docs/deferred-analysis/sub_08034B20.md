# sub_08034B20 — deferred analysis

`sub_08034B20` is the **double-precision soft-float unpack** (libgcc fp-bit.c
`unpack_d` analog), sister of the single-precision `sub_080340D4` in the same
cluster (`src/game/sub_080340d4.c`). It decomposes a raw 64-bit IEEE-754 value
into a `FloatComponents`-style struct extended for doubles.

## Semantics (fully understood — the algorithm is correct)

- Input: `u32 *input` where **input[0] is the HIGH word** (sign/exp/frac-high20)
  and **input[1] is the LOW word** (frac-low32). The function copies them into an
  8-byte stack local with the words SWAPPED (local.lo = input[1], local.hi = input[0]),
  then reads the high word's exponent/sign via a halfword/byte load (`ldrh [+6]`,
  `ldrb [+7]`).
- Output struct: `{ u32 type; u32 sign; s32 exp; u32 fraclow; u32 frachigh; }`
  (type at +0, sign +4, exp +8, fraclow +12, frachigh +16).
  type: 0 = SNAN, 1 = QNAN, 2 = ZERO, 3 = FINITE, 4 = INFINITY.
- exponent = (input[0] >> 20) & 0x7FF ; sign = input[0] >> 31.
- 52-bit mantissa = {frachigh20 : fraclow32}, shifted left by 8 into a 60-bit
  value held across {frachigh:fraclow}.
- exp==0: zero (type 2) if mantissa==0, else subnormal — exp=-1022, normalize loop
  `while (frachigh <= 0x0FFFFFFF) { {frachigh:fraclow}<<=1; out->exp--; }`.
- exp==0x7FF: mantissa==0 → INF (type 4); else QNAN (type 1) if
  (frachigh & 0x80000) else SNAN (type 0).
- finite (exp 1..0x7FE): out->exp = exp - 1023, frachigh gets implicit bit | 0x10000000.

The best-effort C below is BYTE-CORRECT in behavior — it is purely a
register-coloring / scheduling mismatch, NOT a semantic error.

## Drift

Best result: **byte_diff 162, diff_count 78** with the readable C + a single
`register struct DoubleComponents *o asm("r6")` pin and per-TU
`-mno-thumb-interwork` (matching the rest of the float cluster). diff_count drops
to **74** if `fraclow` is additionally pinned to r4, but byte_diff rises to 172.

Root cause (sharp local minimum):

1. **frachigh register class.** The target keeps `frachigh` in a CALLEE-SAVED reg
   (r5) and lowers `frachigh = (frachigh<<8)|(fraclow>>24)` as a **copy-back**:
   computes the result into a scratch reg then `adds r5, rTMP, #0`. agbcc here puts
   `frachigh` in CALLER-SAVED r2 and does the shift **in-place** (`lsls r2,r2,#8`),
   which is shorter but wrong. Pinning frachigh=r5 forces the register but STILL
   does the in-place shift — agbcc's coalescer eliminates the copy regardless of
   register class or whether the C uses an explicit `u32 t = ...; frachigh = t;`
   temp (it coalesces the temp away). So the copy-back is an artifact of the
   target's *unpinned* allocation that no pin/source-shape reproduced.

2. **r7 / loop constant.** Target holds `0x0FFFFFFF` in callee-saved r7 across the
   normalize loop (→ `push {r4,r5,r6,r7,lr}`). agbcc here has a free caller-saved
   reg (r1) for it, so r7 is never pushed.

3. **input-register reuse.** Target keeps `input` in r2 and reuses r2 as `&local`
   (`mov r2, sp`); agbcc reads input straight from r0 and uses a fresh r1 for the
   local pointer.

The `out->exp -= 1` in-loop memory decrement (ldr/sub/str each iter — a register
pressure spill, NOT a register cache) IS reproduced once `out` is pinned to r6.
The exponent extraction (`ldrh [+6]` → `(u16)<<17>>21` logical) matches exactly
after casting the halfword to u32.

## Best-effort C

```c
#include "types.h"

struct DoubleComponents {
    u32 type;
    u32 sign;
    s32 exp;
    u32 fraclow;
    u32 frachigh;
};

union DoubleWords {
    struct {
        u32 lo;
        u32 hi;
    } w;
    u16 h[4];
    u8 b[8];
};

void sub_08034B20(u32 *input, struct DoubleComponents *out)
{
    union DoubleWords local;
    union DoubleWords *u;
    register struct DoubleComponents *o asm("r6") = out; /* keeps out in r6 + forces out->exp in-memory loop dec */
    u32 fraclow;
    u32 frachigh;
    u32 exponent;
    u32 nanbit;

    local.w.lo = input[1];
    local.w.hi = input[0];
    u = &local; /* escaped pointer forces the 8-byte stack copy + partial-width ldrh/ldrb reads */

    fraclow = u->w.lo;
    frachigh = (u->w.hi << 12) >> 12;
    exponent = ((u32)u->h[3] << 17) >> 21; /* (u32) cast -> logical lsrs, not asrs */
    o->sign = u->b[7] >> 7;

    if (exponent == 0) {
        if ((fraclow | frachigh) == 0) {
            o->type = 2;
            return;
        }

        o->exp = -1022;
        frachigh = (frachigh << 8) | (fraclow >> 24);
        fraclow = fraclow << 8;
        o->type = 3;

        if (frachigh <= 0x0FFFFFFF) {
            do {
                frachigh = (frachigh << 1) | (fraclow >> 31);
                fraclow = fraclow << 1;
                o->exp -= 1;
            } while (frachigh <= 0x0FFFFFFF);
        }

        o->fraclow = fraclow;
        o->frachigh = frachigh;
        return;
    }

    if (exponent == 0x7FF) {
        if ((fraclow | frachigh) == 0) {
            o->type = 4;
            o->fraclow = fraclow;
            o->frachigh = frachigh;
            return;
        }

        nanbit = ((u32)0x80 << 12) & frachigh;
        if (nanbit != 0) {
            o->type = 1;
        } else {
            o->type = nanbit;
        }
        o->fraclow = fraclow;
        o->frachigh = frachigh;
        return;
    }

    o->exp = (s32)exponent - 1023;
    o->type = 3;
    o->fraclow = fraclow << 8;
    o->frachigh = ((frachigh << 8) | (fraclow >> 24)) | 0x10000000;
}
```
