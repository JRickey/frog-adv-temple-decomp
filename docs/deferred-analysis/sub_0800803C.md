# Deferred analysis: sub_0800803C

Range [0x0800803c, 0x08008174) (312 bytes), thumb. Dest:
`src/game/sub_08007dd0.c` (append at tail, after sub_08007F88). Pure leaf,
no callees. Operates on `gIwram_3720` (pool literal 0x03003720, loaded

## What the function does (semantics fully reversed — this part is solid)

`u8 sub_0800803C(s16 x, s16 y, s16 targetX, s16 targetY)` — steps
`gIwram_3720._field_2` (X sub-coord) and `._field_4` (Y sub-coord) toward
(targetX, targetY), at most 4 units per axis per call (clamped to the
remaining distance: 1, 2, 3, else 4). Returns 1 iff BOTH axes equal the
target after this call (compared as 16-bit), else 0.

Four independent `if` blocks in order:
  block1  if (x > targetX): switch((s16)(x-targetX)) { 1: f2-=1; 2: f2-=2;
          3: f2-=3; default: reload &gIwram_3720; f2-=4; }
  block2  if (x < targetX): switch((s16)(targetX-x)) { ... f2+=1..4 }
  block3  if (y > targetY): switch((s16)(y-targetY)) { ... f4-=1..4 }
  block4  if (y < targetY): switch((s16)(targetY-y)) { ... f4+=1..4 }
  tail    dy=f4; dx=f2; if (dx != targetX) return 0; if (dy == targetY) return 1; return 0;

The structure (block-by-block) MATCHES the baserom exactly. This is NOT a
structural problem.

## Drift (best byte_diff 249, diff_count 73 — all cascade from 2 root causes)

ROOT CAUSE 1 — 3-way callee-saved register ROTATION of the precomputed
zero-extended args. agbcc precomputes zext(arg1=y), zext(arg3=targetY),
zext(arg0=x) into callee-saved regs at the prologue (kept alive because the
arg regs r0-r3 get reused as scratch). The coloring differs:
    TARGET:  zext(y)->r4,  zext(targetY)->r7, zext(x)->r6
    BUILT:   zext(y)->r7,  zext(targetY)->r6, zext(x)->r4   (cyclic r7->r4->r6->r7)
This single rotation shifts every subsequent compare/branch, producing the
73-instruction cascade. The pointer pin (r5) is correct in both.

ROOT CAUSE 2 — final-compare representation. TARGET keeps `ip=targetX<<16`,
`r6=targetY<<16` and compares `field<<16` against them (`lsls r0,dx,#16; cmp r0,ip`).
BUILT instead extracts u16 (`lsrs r0,ip,#16; cmp dx,r0`). Both correct, 1 insn
each, but agbcc picks the lsr direction. Plain `dx != targetX` (s16) got
byte_diff from 253->249 vs the `(u16)` cast; neither flips the lsls form.

```c
/* Steps gIwram_3720's (X,Y) sub-coords (_field_2, _field_4) toward the
 * target (targetX, targetY), at most 4 units per axis per call (clamped to
 * the remaining distance: 1, 2, 3, else 4). Returns 1 once both axes have
 * reached the target this call, else 0. */
u8 sub_0800803C(s16 x, s16 y, s16 targetX, s16 targetY)
{
    register struct IwramAt3720 *p asm("r5") = &gIwram_3720;
    s16 dx;
    s16 dy;

    if (x > targetX) {
        switch ((s16)(x - targetX)) {
        case 1: p->_field_2 -= 1; break;
        case 2: p->_field_2 -= 2; break;
        case 3: p->_field_2 -= 3; break;
        default: p = &gIwram_3720; p->_field_2 -= 4; break;
        }
    }
    if (x < targetX) {
        switch ((s16)(targetX - x)) {
        case 1: p->_field_2 += 1; break;
        case 2: p->_field_2 += 2; break;
        case 3: p->_field_2 += 3; break;
        default: p->_field_2 += 4; break;
        }
    }
    if (y > targetY) {
        switch ((s16)(y - targetY)) {
        case 1: p->_field_4 -= 1; break;
        case 2: p->_field_4 -= 2; break;
        case 3: p->_field_4 -= 3; break;
        default: p->_field_4 -= 4; break;
        }
    }
    if (y < targetY) {
        switch ((s16)(targetY - y)) {
        case 1: p->_field_4 += 1; break;
        case 2: p->_field_4 += 2; break;
        case 3: p->_field_4 += 3; break;
        default: p->_field_4 += 4; break;
        }
    }

    dy = p->_field_4;
    dx = p->_field_2;
    if (dx != targetX) {
        return 0;
    }
    if (dy == targetY) {
        return 1;
    }
    return 0;
}
```
