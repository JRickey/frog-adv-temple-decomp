# sub_08030644 — deferred (round 66, opus)

Sound-script "wait N frames" opcode handler. One of the
`sSoundOpcodeHandlers` entries dispatched by `sub_080315D8`.
Signature: `u32 sub_08030644(s32 ch, SoundChannelSeq *seq)` (returns 1).

ATTEMPT_MATCH per classify_unmatchable (no structural-impossibility
signature). NOT a NAKED candidate. Genuinely stuck at a sharp
block-layout local minimum after ~25 distinct structural approaches.

## Semantics (fully understood, verified against baserom)

The 6-byte opcode record at `seq->opPtr` (call it `op`):
- `op[0]`   opcode (consumed by the dispatcher)
- `op[1]`   flags: bit0 abort-while-stopping, bit1 randomize, bit2 abort-while-stream
- `*(u16*)(op+2)` duration (0 = unconditional skip, 0xffff = count forever w/o re-latch)
- `*(s16*)(op+4)` step (byte delta to next opcode record)

`seq` is `SoundChannelSeq` with a NEW field `u16 countdown` at offset +8
(was `_pad08[2]`) — this header change is required and is safe (no other
code used `_pad08`; `cursor` stays at +0xa).

Channel flags: `ch<=3` → `gpSoundSystem->chFlags[ch]`; `ch>3` →
`SOUND_SYSTEM_SW_SLOT_FOR_CHANNEL(ss, ch)->flags` (+0x38).
STOP-pending bit = 0x100. RETIRE_PENDING = 0x200 (SOUND_SLOT_FLAG_RETIRE_PENDING).
Stream table = `SOUND_SYSTEM_STREAM_TABLE(ss)` (= ss->auxTable at +0xc4),
indexed `[ch-4]`.

KEY LOGIC FIX (was wrong in early drafts): skip/cancel happens when the
stream-table entry IS NULL, i.e. `streamTable[ch-4] == NULL` (verified:
target `cmp r0,#0; bne randomize` → fall-through-to-skip when stream==NULL).
Likewise the abort triggers when `(slot.flags & 0x200) == 0`.

Latch-path stream check CACHES ss in a local (baserom holds it in r3 across
the swSlot + stream-table reads). Tick-path stream check reads
`gpSoundSystem` INLINE for each access (baserom re-loads the pool literal —
do NOT cache ss in the tick path).

## Drift (best byte_diff 159, no pins)

Reached byte_diff 159 with a clean pin-free body (ch=r2, seq=r4, op=r5 all
match the baserom prologue). Remaining diff is ~entirely BASIC-BLOCK
PLACEMENT: agbcc lays out the `skip` (op+6 abort exit) and the
`randomize/latch` block in the opposite physical order from the baserom.

- Baserom: stream check ends `bne randomize` (stream!=NULL → latch), then
  the SKIP block (`ldr r0,[r4]; adds#6; b store`) is the fall-through, then
  the randomize block. i.e. skip = fall-through, randomize = jump target.
- agbcc (every source variant tried): `if (... stream==NULL) goto skip`
  with skip placed at the FUNCTION END and the randomize block as
  fall-through. The blocks are swapped, cascading branch-offset diffs
  through the rest.

### Levers tried (all reverted, none closed it)
- Register pins (ch=r2, seq=r4, op=r5, flags=r6, duration=r7) individually
  and in combination: pinning the prologue regs helps the head but the pins
  prevent agbcc from reusing r5/r6 as scratch in the body → WORSE (207–335).
  Pins are the wrong lever here.
- Splitting `flags`/`ss` into per-path locals (`tflags`/`tss`) to lower
  their `QTY_CMP_PRI` so `ch` is allocated before them → got ch to r2
  (lreg/greg dumps confirm the priority reorder). Then INLINING `op[1]`
  everywhere (dropping the flags cache entirely) gave op=r5 and dropped to
  163. Caching duration at top + reading it directly dropped to 159/158.
  But the baserom DOES cache flags in r6 (`adds r6,r1,#0`) — the inlined
  form deviates and the block layout still doesn't flip.
- CFLAGS sweep: -fno-gcse, -fno-cse-follow-jumps, -fno-expensive-optimizations,
  -fcaller-saves, -fno-strength-reduce, -fno-schedule-insns, -frename-registers,
  -fforce-addr — NONE changed byte_diff. AGBCC (new) vs OLD_AGBCC: no change.
- Explicit `goto latch` to make skip the fall-through (matching baserom
  layout): agbcc generated extra branches → WORSE (221).
- Reordering source blocks (cancel before advance, skip before randomize,
  shared `store` epilogue): agbcc re-lays-out regardless → 161–167.
- Two-step duration read (temp → duration): WORSE (337). Using cached
  duration for the random arg: WORSE (196) — baserom re-reads `[r5,#2]`
  fresh for the randomize call (the two `*(u16*)(op+2)` reads are NOT CSE'd
  in the baserom; agbcc CSE-folds them and spills the value to `ip`).

### Instrumentation findings (agbcc -dlreg/-dgreg dumps)
- `ch` crosses 0 calls (lreg: no "crosses N call"); it SHOULD get a
  caller-saved reg (r2/r3). The GLOBAL allocator gives it r4 by default
  because `flags`/`ss` have higher `QTY_CMP_PRI` (log2(refs)*refs*size/life)
  and grab r2/r3 first. Lowering their priority (split vars) is what frees
  r2 for ch — this is the lever that worked, but it can't fix block layout.
- `seq`/`op` cross 1 call (they're written after the randomize bl) → both
  correctly callee-saved.

### Next attempt
The block-layout flip (skip = fall-through, randomize = jump target) is the
ONE remaining structural difference. Try: (a) decomp-permuter is NOT viable
(byte_diff 159 >> 40); (b) a private instrumented agbcc on
`final.c`/`stmt.c` basic-block reorder pass to learn WHY agbcc puts the
goto-target (skip) at the end vs inline; (c) a source shape where the
randomize/latch is unambiguously the cold/secondary block (e.g. the abort
checks as the primary `if` whose taken-branch is the latch). When the
layout flips, the remaining diff should collapse to near-0 since registers
already match.

## Best-effort C (byte_diff 159, builds, NON-matching)

```c
#include "sound.h"

extern u32 sub_0802E3C8(u32 limit);

#define SOUND_CHANNEL_STOP_PENDING 0x100
#define SOUND_SEQ_OP_FLAG_ABORT_STOPPED 0x1
#define SOUND_SEQ_OP_FLAG_RANDOMIZE     0x2
#define SOUND_SEQ_OP_FLAG_ABORT_STREAM  0x4

/* SoundChannelSeq needs `u16 countdown` at +8 (replacing _pad08[2]). */

u32 sub_08030644(s32 ch, SoundChannelSeq *seq)
{
    u8 *op = (u8 *)seq->opPtr;
    u32 countdown = seq->countdown;
    SoundSystem *ss;

    if (countdown != 0)
        goto decrement;

    if (*(u16 *)(op + 2) == 0)
        goto skip;

    if (op[1] & SOUND_SEQ_OP_FLAG_ABORT_STOPPED) {
        if (ch <= 3) {
            if (gpSoundSystem->chFlags[ch] & SOUND_CHANNEL_STOP_PENDING)
                goto skip;
        } else if (SOUND_SYSTEM_SW_SLOT_FOR_CHANNEL(gpSoundSystem, ch)->flags & SOUND_CHANNEL_STOP_PENDING) {
            goto skip;
        }
    }

    if ((op[1] & SOUND_SEQ_OP_FLAG_ABORT_STREAM) && ch > 3) {
        ss = gpSoundSystem;
        if ((SOUND_SYSTEM_SW_SLOT_FOR_CHANNEL(ss, ch)->flags & SOUND_SLOT_FLAG_RETIRE_PENDING) == 0 &&
            SOUND_SYSTEM_STREAM_TABLE(ss)[ch - 4] == NULL)
            goto skip;
    }

    if (op[1] & SOUND_SEQ_OP_FLAG_RANDOMIZE)
        seq->countdown = sub_0802E3C8(*(u16 *)(op + 2));
    else
        seq->countdown = *(u16 *)(op + 2);

    goto advance;

skip:
    seq->opPtr = (u32 *)(op + 6);
    return 1;

decrement:
    if (*(u16 *)(op + 2) == 0xffff)
        goto tick;

    countdown -= 1;
    seq->countdown = countdown;
    if ((countdown & 0xffff) != 0)
        goto tick;

    seq->opPtr = (u32 *)(op + 6);
    return 1;

tick:
    if (op[1] & SOUND_SEQ_OP_FLAG_ABORT_STOPPED) {
        if (ch <= 3) {
            if (gpSoundSystem->chFlags[ch] & SOUND_CHANNEL_STOP_PENDING)
                goto cancel;
        } else if (SOUND_SYSTEM_SW_SLOT_FOR_CHANNEL(gpSoundSystem, ch)->flags & SOUND_CHANNEL_STOP_PENDING) {
            goto cancel;
        }
    }

    if ((op[1] & SOUND_SEQ_OP_FLAG_ABORT_STREAM) && ch > 3) {
        if ((SOUND_SYSTEM_SW_SLOT_FOR_CHANNEL(gpSoundSystem, ch)->flags & SOUND_SLOT_FLAG_RETIRE_PENDING) == 0 &&
            SOUND_SYSTEM_STREAM_TABLE(gpSoundSystem)[ch - 4] == NULL)
            goto cancel;
    }

advance:
    seq->opPtr = (u32 *)((u8 *)seq->opPtr + *(s16 *)(op + 4));
    return 1;

cancel:
    seq->countdown = 0;
    seq->opPtr = (u32 *)((u8 *)seq->opPtr + 6);
    return 1;
}
```
