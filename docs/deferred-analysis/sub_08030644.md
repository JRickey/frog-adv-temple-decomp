# sub_08030644 — deferred

Sound-script "wait N frames" opcode handler. One of the `sSoundOpcodeHandlers`
entries dispatched by `sub_080315D8`.

Signature: `u32 sub_08030644(s32 ch, SoundChannelSeq *seq)` (returns 1).

`classify_unmatchable.py sub_08030644` returns `ATTEMPT_MATCH`, not
`STRONG_UNMATCHABLE`. Do not ship NAKED for this target.

## Drift

Best new lane: `byte_diff 40`, `diff_count 14`, size 340. This improves the
previous best (`byte_diff 159`) by flipping the source polarity of the stream
checks:

- Latch path now matches the baserom block order when exits are written as
  direct store+return blocks: skip is the local fall-through block before
  randomize/latch, not a late tail block.
- Tick stream path also matches the baserom polarity when non-null stream
  branches to `advance` and null stream falls through to `cancel`.
- Remaining miss in the best lane is cancel tail merging: gcc replaces the
  target's local cancel block
  `movs r0,#0; strh r0,[r4,#8]; ldr r0,[r4]; adds #6; b store`
  with `movs r0,#0; strh r0,[r4,#8]; b latchSkip`, deleting the second
  `ldr [r4]; add #6` block. That shifts the final pool/branch offsets.

Other levers tried in this round:

- Clean no-pin/no-volatile body: `byte_diff 298`, size 332. Registers mostly
  good, but latch skip was tail-placed.
- Nonzero-duration `if` block with source-local skip before latch: unchanged
  (`byte_diff 298`); gcc canonicalized it back to a tail skip.
- Sibling-style pins (`ch=r2`, `seq=r4`, `op=r5`, `countdown=r0`, flags `r6`)
  plus split exits: size 344, `byte_diff 198`; introduced duration carry in
  `ip`.
- Volatile duration read fixed the `ip` spill and restored
  `ldrh r0,[r5,#2]` before `bl sub_0802E3C8`: `byte_diff 194`.
- Rewriting stream checks as pass-branches-to-latch/advance improved to
  `byte_diff 178`; tick order correct, latch skip still tail-merged.
- `-fno-thread-jumps`: no change. `-O1`: slightly worse (`byte_diff 179`).
  Newer `agbcc`: no help (`byte_diff 179`). Undocumented
  `-fno-crossjumping` is rejected by old_agbcc.
- Volatile `s->opPtr` read in latch skip did not prevent tail merging.
- Direct store+return exits gave the best block order but made the countdown
  expired path mutate/store `r5` directly. Reintroducing a shared store just
  for countdown fixed that path but exposed the cancel tail merge above.

Pass attribution: the blocker is `jump.c` cross-jump/tail merging after RTL
generation, not local register allocation. `stmt.c:expand_start_cond()` explains
why source polarity matters: false labels are emitted in source order, then
`jump.c` can delete/invert/merge tails. The unavailable flag is the final
cross-jump pass, not `-fthread-jumps`.

Corpus/permuter status:

- `tools/agent/corpus_asm_search.py` could not run because this worktree has no
  `tools/agent/corpus-mirrors`.
- `vendor/decomp-permuter` is empty in this worktree, so a bounded permuter run
  could not be performed. This lane is at the nominal permuter threshold and is
  a good seed once the local permuter is available.

## Best-effort C

Best lane below assumes `SoundChannelSeq` has `u16 countdown` at offset `+8`
(`u16 cursor` remains at `+0xa`). It is not committed because the asm slice must
remain the matching implementation while this is deferred.

```c
#include "sound.h"
#include "macros.h"

extern u32 sub_0802E3C8(u32 limit);

u32 sub_08030644(s32 channel, SoundChannelSeq *seq)
{
    /* Target keeps channel in r2 across both stop/stream gate blocks. */
    register s32 ch asm("r2");
    /* Target keeps the sequencer in r4 for all countdown/opPtr accesses. */
    register SoundChannelSeq *s asm("r4");
    /* Target keeps the opcode pointer in r5 across the handler. */
    register u8 *op asm("r5");
    /* Target keeps the countdown in r0 through entry and decrement tests. */
    register u32 countdown asm("r0");
    u8 *nextOp;

    ch = channel;
    s = seq;
    op = (u8 *)s->opPtr;
    countdown = s->countdown;
    if (countdown == 0) {
        u32 opHalf;
        u32 duration;
        register u32 flagsRaw asm("r1");
        u32 flagBit;
        /* Target keeps the wait flags in r6 for later bit tests after the first gate. */
        register u32 flags asm("r6");

        /* Volatile prevents cse.c from carrying the first duration read in ip; target re-reads [r5,#2] before BL. */
        duration = *(volatile u16 *)(op + 2);
        opHalf = duration;
        if (opHalf != 0) {
            flagsRaw = op[1];
            flagBit = flagsRaw & SOUND_SEQ_WAIT_SKIP_IF_STOPPING;
            flags = flagsRaw;
            if (flagBit != 0) {
                if (ch <= 3) {
                    SoundSystem *ss;

                    ss = gpSoundSystem;
                    if (ss->chFlags[ch] & SOUND_FLAG_STOP_PENDING)
                        goto latchSkip;
                } else {
                    SoundSystem *ss;

                    ss = gpSoundSystem;
                    if (SOUND_SYSTEM_SW_SLOT_FOR_CHANNEL(ss, ch)->flags & SOUND_FLAG_STOP_PENDING)
                        goto latchSkip;
                }
            }

            flagBit = flags & SOUND_SEQ_WAIT_SKIP_IF_NO_STREAM;
            if (flagBit == 0)
                goto latch;
            if (ch <= 3)
                goto latch;

            {
                SoundSystem *ss;

                ss = gpSoundSystem;
                if (SOUND_SYSTEM_SW_SLOT_FOR_CHANNEL(ss, ch)->flags & SOUND_SLOT_FLAG_RETIRE_PENDING)
                    goto latch;

                {
                    register void **streamTable asm("r1");
                    register u32 streamOff asm("r0");

                    streamTable = (void **)SOUND_SYSTEM_STREAM_TABLE(ss);
                    streamOff = (u32)ch << 2;
                    streamOff += (u32)streamTable;
                    streamOff -= 0x10;
                    if (*(void **)streamOff != NULL)
                        goto latch;
                }
            }
        }

latchSkip:
        s->opPtr = (u32 *)((u8 *)s->opPtr + 6);
        return 1;

latch:
        if (flags & SOUND_SEQ_WAIT_RANDOMIZE)
            s->countdown = sub_0802E3C8(*(u16 *)(op + 2));
        else
            s->countdown = opHalf;
        goto advance;
    }

    if (*(u16 *)(op + 2) != SOUND_STREAM_SENTINEL) {
        countdown -= 1;
        s->countdown = countdown;
        countdown &= SOUND_STREAM_SENTINEL;
        if (countdown == 0) {
            nextOp = op + 6;
            goto storeAdvance;
        }
    }

    {
        register u32 flagsRaw asm("r1");
        u32 flagBit;
        /* Target keeps the wait flags in r6 for the second gate block. */
        register u32 flags asm("r6");

        flagsRaw = op[1];
        flagBit = flagsRaw & SOUND_SEQ_WAIT_SKIP_IF_STOPPING;
        flags = flagsRaw;
        if (flagBit != 0) {
            if (ch <= 3) {
                SoundSystem *ss;

                ss = gpSoundSystem;
                if (ss->chFlags[ch] & SOUND_FLAG_STOP_PENDING)
                    goto cancel;
            } else {
                SoundSystem *ss;

                ss = gpSoundSystem;
                if (SOUND_SYSTEM_SW_SLOT_FOR_CHANNEL(ss, ch)->flags & SOUND_FLAG_STOP_PENDING)
                    goto cancel;
            }
        }

        flagBit = flags & SOUND_SEQ_WAIT_SKIP_IF_NO_STREAM;
        if (flagBit == 0)
            goto advance;
        if (ch <= 3)
            goto advance;

        {
            SoundSystem *ss;
            register void **streamTable asm("r1");
            register u32 streamOff asm("r0");

            ss = gpSoundSystem;
            streamTable = (void **)SOUND_SYSTEM_STREAM_TABLE(ss);
            streamOff = (u32)ch << 2;
            streamOff += (u32)streamTable;
            streamOff -= 0x10;
            if (*(void **)streamOff != NULL)
                goto advance;
        }
    }

cancel:
    s->countdown = 0;
    s->opPtr = (u32 *)((u8 *)s->opPtr + 6);
    return 1;

advance:
    nextOp = (u8 *)s->opPtr + *(s16 *)(op + 4);

storeAdvance:
    s->opPtr = (u32 *)nextOp;
    return 1;
}
```
