# Deferred: sub_080308B0

Sound-system "arm a sampled-wave mixer channel" helper at 0x080308b0 (240 B).
Range [0x080308b0, 0x080309a0). Two callees, both peeled+decompiled:
sub_0802F398 (pan commit, sound_pan.c), sub_0802FA60 (period commit,

## Drift (best byte_diff = 37, diff_count = 13)

The whole prologue and first ~2/3 of the body are BYTE-EXACT (verified). To get
there the following pure-C register pins were required and are correct/stable:
  index->r6, startOffset->r9, mode->sl (high callee-saved args; baserom saves
  r8/r9/sl), gpsp(&gpSoundSystem)->r3 held to the tail, ss(*gpsp)->ip (forces
  the `mov ip,r0` + `mov r2,ip`/`mov r0,ip`/`add r0,ip` base re-reads the
  baserom uses). Without ss->ip and gpsp->r3 the base lands in a low reg and the
  whole body's register refs diverge (58 diffs). zero MUST be a literal `0`
  (NOT a `register u32 zero asm("r8")` local) — an eager-init zero local hoists
  `mov r0,#0; mov r8,r0` above the gpSoundSystem load, clobbering r0 and forcing
  an extra `mov r0,ip` (+4 bytes). agbcc spills the literal-0 to r8 by itself.

All 13 remaining diffs are in the TAIL and are register-coloring / CSE ties:

1. Advance (0x8e-0x90): baserom `ldr r0,[r4,#4]; adds r2,r0,r1` (3-operand add,
   fresh dest r2, startOffset pre-moved to r1). agbcc reuses an input:
   `add r1,r0,r1` (natural) or, with `register u8* advanced asm("r2")`,
   `ldr r2,[r4,#4]; add r2,r9` (2-operand, r9 direct). The dest-register tie
   is decided in reload.c/local-alloc.c; NO C reshape or -fXXX flag reproduced
   the 3-operand `adds r2,r0,r1`.
2. Trailing zeros (0x9e-0xa0): baserom materializes 0 into BOTH r0 and r1
   (`movs r0,#0; movs r1,#0; strh r1,[22]; strb r0,[26]`). agbcc merges to one
   reg unless a distinct local/pin forces the split; when split it picks the
   r0<->r1 assignment opposite to baserom.
3. else-remat (0xb6-0xbc): baserom RE-materializes `movs r0,#0` in the
   byte_3d==0 else branch for entry[27]; agbcc reuses a still-live 0 reg
   (`strb r1,[27]`). CSE flags (-fno-gcse/-fno-cse-follow-jumps/...) do not
   defeat this.
4. mode-store (0xce-0xd4): 0x1000 (SOUND_STREAM_PRIORITY) lands in r1 then is
   copied (`adds r0,r1,#0`) for `strh r0,[20]`; baserom builds it directly in
   r0 (`movs r0,#0x80; lsls r0,#5`).

All four are the SAME failure mode: which scratch reg (r0 vs r1 vs r2) a
short-lived value occupies in the tail. This is exactly decomp-permuter's
domain (statement/var-scope mutation), but the permuter is UNAVAILABLE in this
environment — vendor/decomp-permuter in MAIN is an unpopulated self-referential
symlink (no permuter.py exists anywhere; bootstrap WARNed "permuter .venv
missing"). Next attempt: run the permuter from a near-matching base (the
best-effort C below is byte_diff 37) once a real permuter checkout exists, or
instrument a PRIVATE agbcc (reload.c register-tie) to find the exact lever.
Levers already tried and rejected: -fno-schedule-insns/-insns2, -fno-gcse,
-fno-strength-reduce, -fno-cse-follow-jumps, -fno-expensive-optimizations,
-fforce-addr, -fcaller-saves, -frerun-cse-after-loop, -O1; ~25 C restructurings
of the advance/zero/else/mode tail; pinning advanced->r2 (helps advance, costs
elsewhere), pinning a per-store zero->r0 (fixes one cluster, displaces `slot`
to r8 when used twice).

## Header note

This attempt added to include/sound.h (append-only, no layout change):
  #define SOUND_SYSTEM_SAMPLE_BANK_OFFSET 0x110
  #define SOUND_SYSTEM_SAMPLE_BANK(ss) (*(u8 **)((u8 *)(ss) + 0x110))
The field at SoundSystem+0x110 is the sample/sequence bank base pointer
(bank[+0x1c] = rel offset to a u32 offset-table indexed by sampleId; each entry
is a bank-relative offset to a {length, loopStart} sample descriptor with PCM
body at +0x10). sub_080309A0 (next slice) reads the same +0x110 bank with a
16-bit id and a [desc+0xb] byte — re-add the macro when either lands.

#include "sound.h"
#include "macros.h"
extern void sub_0802F398(s32 index);
extern void sub_0802FA60(s32 index);
void sub_080308B0(s32 indexArg, u32 sampleId, u32 startOffsetArg, u32 modeArg)
{
    register s32 index asm("r6") = indexArg;
    register u32 startOffset asm("r9") = startOffsetArg;
    register u32 mode asm("sl") = modeArg;
    register SoundSystem **gpsp asm("r3") = &gpSoundSystem;
    register SoundSystem *ss asm("ip") = *gpsp;
    u8 *slot = (u8 *)ss->swSlots + index * SOUND_SW_SLOT_STRIDE;
    u8 *entry = (u8 *)ss->mixTable + index * SOUND_STREAM_MIX_ENTRY_STRIDE;
    u8 *bank;
    u8 *desc;
    u8 *cur;
    u32 length;
    s32 loopStart;
    u8 zeroByte;

    ((u32 *)ss->auxTable)[index] = 0;
    *(u32 *)(slot + SOUND_SLOT_FLAGS_OFFSET) =
        (*(u32 *)(slot + SOUND_SLOT_FLAGS_OFFSET) & 0xffffb3ff) | SOUND_STREAM_PRIORITY;
    bank = SOUND_SYSTEM_SAMPLE_BANK(ss);
    desc = bank + ((u32 *)(bank + *(u32 *)(bank + 0x1c)))[sampleId];
    *(u8 **)(entry + 0) = desc;
    cur = desc + 0x10;
    *(u8 **)(entry + 4) = cur;
    length = *(u32 *)desc;
    *(u8 **)(entry + 8) = cur + length;
    loopStart = *(s32 *)(desc + 4);
    if (loopStart < 0) {
        *(u32 *)(entry + 12) = 0;
        *(u32 *)(entry + 16) = 0;
    } else {
        *(u8 **)(entry + 12) = cur + loopStart;
        *(u32 *)(entry + 16) = length - loopStart;
    }
    if (startOffset != 0) {
        register u8 *advanced asm("r2");
        u8 *base = *(u8 **)(entry + 4);
        advanced = base + startOffset;
        if (advanced < *(u8 **)(entry + 8))
            *(u8 **)(entry + 4) = advanced;
    }
    zeroByte = 0;
    *(u16 *)(entry + 22) = 0;
    *(u8 *)(entry + 26) = zeroByte;
    if (*(u8 *)(slot + 0x3d) != 0)
        *(u8 *)(entry + 27) = *(u8 *)((u8 *)*gpsp + SOUND_SYSTEM_STREAM_PAN_BYTE_OFFSET);
    else
        *(u8 *)(entry + 27) = 0;
    sub_0802F398(index);
    if (mode == 0) {
        sub_0802FA60(index);
    } else {
        *(u16 *)(entry + 20) = SOUND_STREAM_PRIORITY;
        *(u32 *)(slot + SOUND_SLOT_FLAGS_OFFSET) &= ~SOUND_FLAG_ENV_DIRTY;
    }
}
