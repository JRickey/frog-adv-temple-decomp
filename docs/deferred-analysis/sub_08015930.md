# Deferred Analysis: sub_08015930

## Function
- Address: 0x08015930, size 128 bytes
- Asm: asm/disasm_0x08015930.s
- Destination: src/engine/sub_08015930.c

## What It Does
Iterates i=0..3, tests bit i of `gIwram_6110.selector5Flags`. If set:
1. Computes stride = i*24
2. Loads a TilemapTableEntry descriptor from ROM table at 0x08307e18 (4 entries, 24 bytes each)
3. Calls `sub_08012BC4(desc->unk08, desc->unk00, desc->unk02, desc->unk04, desc->unk06, *(void**)(ROM+16+i*24), bit_i)`
4. Sets bit i in `gIwram_6110.selector6Flags`

Uses r8=1 (constant), r9=ROM_base (0x08307e18), sl=ROM_base+16 as pinned high regs across BL.
Uses r6=i (loop counter), r7=IWRAM base.

## Drift
**Best byte_diff: 1** (diff_count: 1)

The ONLY remaining mismatch:
- `+0x0066 ARGUMENT_MISMATCH: target: bls.n 0x1594e  built: bls.n 0x15940`

Our loop-back: to 0x10 (= register pin re-init area for r8, r9, sl).

## Root Cause
The target was compiled with an agbcc that performs LOOP-INVARIANT CODE MOTION for
for-body register pins. Our agbcc doesn't perform this optimization:

- With for-body pins (`for(i=0;...){register r8=1; register r9=ROM; register sl=ROM+16; ...}`),
  agbcc DOES hoist the pin inits BEFORE the loop (good: pool order [IWRAM, ROM] is correct,
  and sl = ROM+16 is computed in the prologue init block at 0x18).
  BUT: the loop-back still includes the pin re-init area (branch goes to 0x10 not 0x1e).

- With function-scope pins (the "normal" approach), the loop-back is correct (to condition 0x1e)
  BUT: pool order is [ROM, IWRAM] (wrong), causing 24 bytes of diff.

The two requirements are mutually exclusive with our agbcc version:
1. Pool [IWRAM, ROM] requires for-body pins (IWRAM loaded first in loop condition)
2. Loop-back to condition (not pin area) requires function-scope pins

#include "macros.h"
#include "types.h"
#include "iwram.h"

struct TilemapTableEntry {
    u16 unk00;
    u16 unk02;
    u16 unk04;
    u16 unk06;
    u8 unk08;
    u8 pad09[7];
    void *tiles;
    u8 pad14[4];
};

extern void sub_08012BC4(u8 mode, u16 a, u16 b, u16 c, u16 d, void *tiles, u8 e);

void sub_08015930(void)
{
    u8 i;
    u32 stride;
    const struct TilemapTableEntry *desc;

    for (i = 0; i <= 3; i++) {
        register u32 one asm("r8") = 1;
        register const struct TilemapTableEntry *table asm("r9") =
            (const struct TilemapTableEntry *)0x08307e18;
        register const struct TilemapTableEntry *table16 asm("sl") =
            (const struct TilemapTableEntry *)((const u8 *)table + 16);

        if ((gIwram_6110.selector5Flags >> i) & one) {
            stride = (u32)i * 3;
            stride <<= 3;
            desc = (const struct TilemapTableEntry *)(stride + (u32)table);

            sub_08012BC4(desc->unk08, desc->unk00, desc->unk02, desc->unk04, desc->unk06,
                         *(void **)((stride += (u32)table16, (void *)stride)),
                         (gIwram_6110.selector5Flags >> i) & one);
            gIwram_6110.selector6Flags |= one << i;
        }
    }
}
