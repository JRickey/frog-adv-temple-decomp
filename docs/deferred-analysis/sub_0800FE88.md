# sub_0800FE88 — deferred (credits-roll renderer / typewriter step)

Scene state @ 0x03006440. Walks the tilemap-encoded credits stream at
`state->cursor` (+0x0C), emitting one BG-tilemap glyph pair per column into
the double-buffered row buffer (+0x14 front / +0x24 back), advancing the
column counter (+0x30). Stream markers: 0xFFFE = blink/wait-for-input header
gate; 0xFFFD = formatting command (next halfword `cmd`, glyph block index
`idx = (cmd + 0xFFFF1F19) * 3`, reads `sCreditsTilemapEng` entries idx+1 and
idx+2); 0xFFFF = end-of-line. Calls `sub_080004C4` (input poll) inside the
gates. The slice [0x0800fe88, 0x080100e4) also contains an unreferenced static
teardown `sub_080100A4` (zero-fill OBJ-VRAM, set REG_BG3CNT/REG_DISPCNT) that
compiles byte-exact.

### KEY NEW FINDINGS (these escape the prior plateau — DO NOT re-derive)

1. **The ENTRY interleave (prior "issue 2", the 2-session wall) is SOLVED.**
   Two coupled moves:
   - **Do NOT pin `state` to r7.** `register u8 *state asm("r7")` makes agbcc
     treat r7 as a non-callee-saved scratch (thumb.c prologue: r7 only enters
     `live_regs_mask` and the r8/r9-save trampoline picks `mov r7,r9; mov
     r6,r8` when r7 is a *naturally-coloured* callee-saved pseudo, NOT a hard
     pin). Leave `state` a plain `u8 *state;` — agbcc colours it to r7 AND
     pushes it, giving the exact `push {r4,r5,r6,r7,lr}; mov r7,r9; mov r6,r8;
     push {r6,r7}` prologue + the `adds r7,r0,#0` state-save. (Pinning state
     was the prior note's mistake; unpinning is the unlock.)
   - **Pin the END constant to r1 loaded EARLY:** a local
     `register u32 end asm("r1"); end = CREDITS_END;` set BEFORE
     `flag = &gIwram_5398;` forces the pool order `state, END, flag` and the
     `ldr r1,=END` to be emitted before `mov r9,flag` — matching fe96 exactly.
   Result: offsets +0x00..+0x62 are byte-identical (prologue + entry +
   first/second gate setup + gate loop).

2. **The gate back-edge (prior "explicit b fec6 vs bne fec6") is SOLVED** by
   writing the first gate as an explicit `gate_top:` label with
   `if (*gateFlag != INPUT_A) goto gate_top; goto clear_and_wait;` (instead of
   a `for(;;)` with two `goto clear_and_wait`). agbcc then emits the A-check's
   false edge AS the loop back-edge (`bne fec6`) with no extra `b`.

3. **The gate const-0 hoist (prior "issue 1") is SOLVED** by writing the gate
   zero stores as the live zero-valued gate locals: `gIwram_5398 = lastTick;`
   (not `= 0`) and blink-else `*(vram+0x76) = toggle;` (not `= 0`). The target
   genuinely reuses r4=lastTick / r6=toggle as the zero source (feba `strh
   r4`, ff00 `strh r6`). No hoist, gate byte-exact.

4. **The `*cursor` double-load is SOLVED** by caching `u16 ch = *cursor;` at
   the loop top and testing `ch` for both GATE and FORMAT (target loads
   `*cursor` once into r1 at feac and reuses it at the FORMAT compare ff26).

5. **The format intermediate store (prior "issue 3") is removed in the
   COMBINE pass, NOT flow.c.** Confirmed via `-da` RTL pass dumps: the store
   to `mem[r6+12]` count goes 3→2 between `gcse` and `combine`. combine.c
   deletes it because between the two `p->cursor=` stores nothing READS the
   `p+12` field; the glyph stores (through the loaded `vram` pointer) are
   disambiguated by `base_alias_check` (r6 has a known REG_BASE_VALUE, the
   glyph-store base register has base 0 but `flag_expensive_optimizations`
   resolves it via `canon_rtx`). The TARGET keeps the store because its
   `ldrh r5,[r5,#2]` cmd-read (an unknown-base load of `*(cursor+1)`)
   may-alias `p->cursor`, so combine's `mem_set_list` entry is spliced out by
   `anti_dependence` before the intermediate store is examined. In our C the
   `next[0]`/`cursor[1]` cmd-read gets a *known* relationship to the stored
   pointer (or reorders ahead of the store), so the anti-dependence doesn't
   fire. The ONLY shape that kept the store this round was `volatile` (size
   608, diff 367) or reading cmd via `(*(u16**)(p+12))[0]` (a p->cursor
   field reload — keeps store but adds `adds r0,r3,#0`, 596/361). The
   conservative-alias-WITHOUT-overhead shape is still unfound. **This is the
   single highest-value remaining lever: solving it removes the 12-byte
   deficit and collapses the whole pool/branch cascade.**

6. **Operand-order residual (`adds r0,r2,r0` vs target `adds r0,r0,r2`).**
   agbcc's expand puts the pre-loaded `vram` (lower pseudo-reg number, loaded
   first by the `vram = *(p+20)` statement) as op0. Source operand order
   (`vram + (col<<1)` vs `(col<<1) + vram`) does NOT flip it; nor does a
   `col` temp. Writing `vram` leading in the source DID help the SECOND store
   match (`adds r0,r0,r2` + `adds r0,#64`) — only the FIRST store (the `=0`
   one) still emits `adds r0,r2,r0`. ~3-4 insns. Likely needs permuter
   statement-reordering or a register pin on the add result.

7. **Normal-branch cursor store register (target `adds r0,r5,#2; str r0` vs
   built `adds r5,#2; str r5`).** Pure coloring — target uses a scratch r0,
   built reuses the dead cursor reg r5. ~2 insns.

## Levers ruled out THIS round (in addition to prior note)

- Pinning `state` to r7: WRONG — makes r7 a non-saved scratch (root cause of
  the prior prologue mismatch). Unpin it.
- `-fno-expensive-optimizations`, `-fno-schedule-insns(/2)`, `-fno-rerun-cse-
  after-loop`: no help / net worse on this (entry-fixed) base.
- `volatile` on the intermediate store: keeps it but 608/367.
- `cursor[1]` (vs `next[0]`) cmd-read: reorders vram ahead, removes store, 374.
- caching `dst` pointer or `col<<1` in a local: breaks the target's
  re-read-column-per-store pattern, much worse (392-522).
- in-place `(*(u16**)(p+12))++` increments: extra code, worse.
- unpinning glyphs(r8)/flag(r9)/cursor(r5): all needed, worse without.

## Best-effort C (byte_diff 326 / diff_count 99 — PERFECT entry+gate+eol+DMA)

```c
#include "game.h"
#include "gba/dma.h"
#include "gba/io.h"
#include "types.h"

extern u16 sub_080004C4(void);
extern const u8 sCreditsTilemapEng[];
extern u16 gIwram_5398;

enum {
    CREDITS_END = 0xFFFF,
    CREDITS_GATE = 0xFFFE,
    CREDITS_FORMAT = 0xFFFD,
    CREDITS_BLINK_TILE = 0xE0E4,
    CREDITS_FORMAT_BIAS = 0xFFFF1F19,
    INPUT_B = 0x10,
    INPUT_A = 0x20,
};

#define DMA_BLIT_ROW 0x8100001C

u8 sub_0800FE88(void)
{
    u8 *state;
    register u16 *flag asm("r9");
    register u16 *cursor asm("r5");

    {
        u8 *base;
        u16 *c;
        register u32 end asm("r1");

        base = (u8 *)0x03006440;
        c = *(u16 **)(base + 12);
        end = CREDITS_END;
        state = base;
        flag = &gIwram_5398;
        if (*c == end)
            goto eol;
    }

    {
        register u8 *p asm("r6");
        register const u8 *glyphs asm("r8");

        p = state;
        glyphs = sCreditsTilemapEng;
        do {
            u16 ch;

            cursor = *(u16 **)(p + 12);
            ch = *cursor;
            if (ch == CREDITS_GATE) {
                register u32 lastTick asm("r4");
                register u32 toggle asm("r6");
                register u32 *clock asm("r8");
                register u8 *gp asm("r7");
                register u16 *gateFlag asm("r5");

                lastTick = 0;
                toggle = 0;
                gIwram_5398 = lastTick;
                clock = (u32 *)0x03005330;
                gp = (u8 *)0x03006440;
                flag = &gIwram_5398;
                gateFlag = flag;
            gate_top:
                if (*(u32 *)0x03005330 - lastTick > 3) {
                    if (toggle)
                        *(u16 *)(*(u8 **)(gp + 20) + 0x76) = CREDITS_BLINK_TILE;
                    else
                        *(u16 *)(*(u8 **)(gp + 20) + 0x76) = toggle;
                    toggle = toggle ? 0 : 1;
                    lastTick = *clock;
                    *gateFlag = sub_080004C4();
                }
                if (*gateFlag == INPUT_B)
                    goto clear_and_wait;
                if (*gateFlag != INPUT_A)
                    goto gate_top;
                goto clear_and_wait;
            }

            if (ch != CREDITS_FORMAT) {
                u8 *vram;
                u16 *next;

                vram = *(u8 **)(p + 20);
                *(u16 *)(vram + (*(u16 *)(p + 48) << 1)) = 0;
                *(u16 *)(vram + 0x40 + (*(u16 *)(p + 48) << 1)) = *cursor;
                next = cursor + 1;
                *(u16 **)(p + 12) = next;
            } else {
                register u16 *next asm("r3");
                u8 *vram;
                u32 idx;

                next = cursor + 1;
                *(u16 **)(p + 12) = next;
                vram = *(u8 **)(p + 20);
                idx = (next[0] + CREDITS_FORMAT_BIAS) * 3;
                *(u16 *)((*(u16 *)(p + 48) << 1) + vram) =
                    *(u16 *)(glyphs + ((idx + 1) << 1));
                *(u16 *)((*(u16 *)(p + 48) << 1) + vram + 0x40) =
                    *(u16 *)(glyphs + ((idx + 2) << 1));
                next++;
                *(u16 **)(p + 12) = next;
            }

            *(u16 *)(p + 48) += 1;
            cursor = *(u16 **)(p + 12);
        } while (*cursor != CREDITS_END);
    }

eol:
    cursor = *(u16 **)(state + 12);
    if (*cursor != CREDITS_END)
        goto done_zero;

    *(u16 *)(state + 48) = 0;
    if (*(u16 *)(state + 50) == 0) {
        u32 front;

        *(u16 *)(state + 50) = 1;
        front = *(u32 *)(state + 36);
        *(u32 *)(state + 36) = *(u32 *)(state + 20);
        *(u32 *)(state + 20) = front;
        goto advance;
    }

    {
        u32 lastTick;
        u32 toggle;
        u32 *clock;

        lastTick = 0;
        toggle = 0;
        gIwram_5398 = lastTick;
        clock = (u32 *)0x03005330;
        for (;;) {
            if (*(u32 *)0x03005330 - lastTick > 3) {
                if (toggle)
                    *(u16 *)(*(u8 **)(state + 20) + 0x76) = CREDITS_BLINK_TILE;
                else
                    *(u16 *)(*(u8 **)(state + 20) + 0x76) = toggle;
                toggle = toggle ? 0 : 1;
                lastTick = *clock;
                gIwram_5398 = sub_080004C4();
            }
            flag = &gIwram_5398;
            if (*flag == INPUT_A)
                goto done_fe;
            if (*flag == INPUT_B)
                break;
        }
    }

    {
        u32 front;
        u32 back;
        vu16 fill;
        vu32 *dma;

        state = (u8 *)0x03006440;
        *(u16 *)(state + 50) = 0;
        back = *(u32 *)(state + 36);
        front = *(u32 *)(state + 20);
        *(u32 *)(state + 36) = front;
        *(u32 *)(state + 20) = back;

        fill = 0;
        dma = (vu32 *)0x040000D4;
        dma[0] = (u32)&fill;
        dma[1] = front;
        dma[2] = DMA_BLIT_ROW;
        (void)dma[2];

        fill = 0;
        dma[0] = (u32)&fill;
        front += 0x40;
        dma[1] = front;
        dma[2] = DMA_BLIT_ROW;
        (void)dma[2];

        fill = 0;
        dma[0] = (u32)&fill;
        dma[1] = back;
        dma[2] = DMA_BLIT_ROW;
        (void)dma[2];

        fill = 0;
        dma[0] = (u32)&fill;
        dma[1] = back + 0x40;
        dma[2] = DMA_BLIT_ROW;
        (void)dma[2];
    }

advance:
    *(u32 *)(state + 12) += 2;

done_zero:
    *flag = 0;
    return 0;

clear_and_wait:
    *flag = 0;

done_fe:
    return 0xFE;
}

static void sub_080100A4(void)
{
    vu16 fill;
    vu32 *dma;

    fill = 0;
    dma = (vu32 *)0x040000D4;
    dma[0] = (u32)&fill;
    dma[1] = 0x0600F800;
    dma[2] = DMA_ENABLE | DMA_SRC_FIXED | 0x400;
    (void)dma[2];

    REG_BG3CNT = 0x1F08;
    REG_DISPCNT = 0x840;
}
```
