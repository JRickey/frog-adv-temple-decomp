# sub_0800FE88 — deferred (credits-roll renderer / typewriter step)

Scene state @ 0x03006440. Walks the tilemap-encoded credits stream at
`state->cursor` (+0x0C), emitting one BG-tilemap glyph pair per column into
the double-buffered row buffer (+0x14 front / +0x24 back), advancing the
column counter (+0x30). Stream markers: 0xFFFE = blink/wait-for-input header
gate (flashes vram+0x76 between 0xE0E4 and 0; polls `sub_080004C4` until A
0x20 or B 0x10); 0xFFFD = formatting command (next halfword `cmd`, glyph
block index `idx = (cmd + 0xFFFF1F19) * 3`, reads `sCreditsTilemapEng`
entries idx+1 and idx+2); 0xFFFF = end-of-line (reset column; first pass
flips front/back row pointers; second pass runs the same input gate then
DMA-blits both rows to OBJ-VRAM via REG_DMA3, cnt 0x8100001C).

The slice [0x0800fe88, 0x080100e4) also contains an unreferenced static
teardown function at 0x080100a4 (`sub_080100A4`): zero-fill OBJ-VRAM
0x0600F800 (0x400 halfwords), REG_BG3CNT=0x1F08, REG_DISPCNT=0x840. This dead
function compiles byte-exact already.

## Drift

Best result this round: **byte_diff 325, diff_count 128, size 604** with
pure C, branch-local cursor advance pins, and per-TU
`-fno-expensive-optimizations -fno-gcse`. This improves the prior best
`diff_count` (133 -> 128) but not the byte drift. No inline asm, NAKED, or
NON_MATCHING path was used.

Classifier verdict remains `ATTEMPT_MATCH`; only advisory is high registers
`r8/r9` across `sub_080004C4`, not a strong unmatchable class.

Residuals:

- Entry pool/order and register color: target does
  `ldr r0,=0x03006440; ldr r2,[r0,#12]; ldr r1,=0xffff; add r7,r0,#0;
  ldr r0,=&gIwram_5398; mov r9,r0; ldrh r2,[r2]; cmp r2,r1`.
  Best C keeps the cursor in `r5`, loads `&gIwram_5398` before the `0xffff`
  literal, and compares through `r1`/`r0`.
- Format-branch cursor store: target has a visible intermediate
  `adds r3,r5,#2; str r3,[r6,#12]` before reading `cursor[1]`, then later
  `adds r3,#2; str r3,[r6,#12]`. Best C can pin the regular branch's
  `cursor+1` store into `r0` and the final format store into `r3`, but agbcc
  still deletes or reorders the intermediate store unless a volatile is used.
- `jump.c` cross-jumping and `local-alloc` coloring are still the likely
  responsible passes. `jump.c::find_cross_jump` compares post-reload RTL via
  `rtx_renumbered_equal_p`; once both stores are colored identically, the
  shared tail is legal to merge.

New levers ruled out:

- Clean no-pin monolithic C: builds at the correct address but drifts badly
  (`byte_diff 542`, `diff_count 258`).
- Helper functions before `sub_0800FE88`: invalid, shifts target by +0xB0.
- Separate scoped opening cursor pinned to `r2` plus `0xffff` pinned to `r1`:
  worsens to `byte_diff 557`, `diff_count 156`; allocator changes the whole
  entry/pool shape.
- Branch-local cursor advance pins only: improves instruction count to
  `diff_count 130` but leaves `byte_diff 327`.
- Volatile intermediate format cursor store: preserves the idea but grows the
  function to 608 bytes and worsens to `byte_diff 450`, `diff_count 137`.
- `-fno-cse-follow-jumps`: no effect versus branch pins alone.
- `-fno-gcse`: improves to `byte_diff 326`, `diff_count 128`.
- `-fforce-addr -fno-gcse`: much worse (`byte_diff 550`, `diff_count 152`).
- `-fforce-addr -fno-expensive-optimizations -fno-gcse`: lower instruction
  count (`diff_count 123`) but higher byte drift (`byte_diff 349`) and wrong
  format-store shape.
- `-O1`: worse (`byte_diff 451`, `diff_count 139`).
- Current-tree corpus grep for cursor/next-pointer/volatile patterns found no
  directly useful matched C. `corpus_asm_search.py` could not run because
  `tools/agent/corpus-mirrors/` is not populated in this worktree.

Suggested next move: instrument a private copy of old_agbcc at
`jump.c::find_cross_jump` and `local-alloc.c::find_free_reg` to see why the
format-branch intermediate cursor store is either deleted or colored into the
same store register. The direct goal is a source shape where the two format
stores survive with `r3` without volatile and without shifting the branch pool.

## Best-effort C

```c
#include "game.h"
#include "gba/dma.h"
#include "gba/io.h"
#include "types.h"

enum {
    CREDITS_MARK_END = 0xFFFF,
    CREDITS_MARK_GATE = 0xFFFE,
    CREDITS_MARK_FORMAT = 0xFFFD,
    CREDITS_BLINK_TILE = 0xE0E4,
    CREDITS_FORMAT_BIAS = 0xFFFF1F19,
    CREDITS_INPUT_B = 0x10,
    CREDITS_INPUT_A = 0x20,
    CREDITS_RETURN_WAIT = 0xFE,
    DMA_CLEAR_ROW = 0x8100001C,
    DMA_CLEAR_OBJ_VRAM = 0x81000400,
};

extern u16 sub_080004C4(void);
extern const u8 sCreditsTilemapEng[];
extern u16 gIwram_5398;

u8 sub_0800FE88(void)
{
    register u8 *state asm("r7");
    register u16 *gFlag asm("r9");
    register u16 *cursor asm("r5");

    {
        register u8 *p0 asm("r0");
        p0 = (u8 *)0x03006440;
        cursor = *(u16 **)(p0 + 12);
        state = p0;
    }
    gFlag = &gIwram_5398;
    if (*cursor == CREDITS_MARK_END)
        goto eol;

    {
        register u8 *outer asm("r6");
        register const u8 *glyphs asm("r8");
        u16 cmd;
        u32 idx;

        outer = state;
        glyphs = sCreditsTilemapEng;

        do {
            register u16 marker asm("r1");

            cursor = *(u16 **)(outer + 12);
            marker = *cursor;

            if (marker == CREDITS_MARK_GATE) {
                register u32 last asm("r4");
                register u32 toggle asm("r6");
                register GameStuff *clock asm("r8");
                register u16 *flag asm("r5");

                last = 0;
                toggle = 0;
                gIwram_5398 = last;
                clock = &gGameStuff;
                state = (u8 *)0x03006440;
                gFlag = &gIwram_5398;
                flag = gFlag;
                for (;;) {
                    if (gGameStuff._unk00 - last > 3) {
                        if (toggle)
                            *(u16 *)(*(u8 **)(state + 20) + 0x76) = CREDITS_BLINK_TILE;
                        else
                            *(u16 *)(*(u8 **)(state + 20) + 0x76) = toggle;
                        toggle = toggle ? 0 : 1;
                        last = clock->_unk00;
                        *flag = sub_080004C4();
                    }
                    if (*flag == CREDITS_INPUT_B)
                        goto done_gate1;
                    if (*flag == CREDITS_INPUT_A)
                        goto done_gate1;
                }
            }

            if (marker != CREDITS_MARK_FORMAT) {
                u8 *vram;
                register u16 *nextCursor asm("r0");
                vram = *(u8 **)(outer + 20);
                *(u16 *)((*(u16 *)(outer + 48) << 1) + (u32)vram) = 0;
                *(u16 *)((*(u16 *)(outer + 48) << 1) + (u32)vram + 0x40) = *cursor;
                nextCursor = cursor + 1;
                *(u16 **)(outer + 12) = nextCursor;
            } else {
                u8 *vram;
                register u16 *nextCursor asm("r3");
                nextCursor = cursor + 1;
                *(u16 **)(outer + 12) = nextCursor;
                vram = *(u8 **)(outer + 20);
                cmd = cursor[1];
                idx = (cmd + CREDITS_FORMAT_BIAS) * 3;
                *(u16 *)((*(u16 *)(outer + 48) << 1) + (u32)vram) = *(u16 *)(glyphs + ((idx + 1) << 1));
                *(u16 *)((*(u16 *)(outer + 48) << 1) + (u32)vram + 0x40) =
                    *(u16 *)(glyphs + ((idx + 2) << 1));
                nextCursor += 1;
                *(u16 **)(outer + 12) = nextCursor;
            }

            *(u16 *)(outer + 48) += 1;
            cursor = *(u16 **)(outer + 12);
        } while (*cursor != CREDITS_MARK_END);
    }

eol:
    cursor = *(u16 **)(state + 12);
    if (*cursor != CREDITS_MARK_END)
        goto done_zero;

    *(u16 *)(state + 48) = 0;
    if (*(u16 *)(state + 50) == 0) {
        u32 front;
        *(u16 *)(state + 50) = 1;
        front = *(u32 *)(state + 36);
        *(u32 *)(state + 36) = *(u32 *)(state + 20);
        *(u32 *)(state + 20) = front;
        goto advance;
    }

    {
        register u32 last asm("r4");
        register u32 toggle asm("r6");
        register GameStuff *clock asm("r8");
        register u8 *st asm("r5");
        u16 *flag;

        last = 0;
        toggle = 0;
        gIwram_5398 = 0;
        clock = &gGameStuff;
        st = state;
        flag = &gIwram_5398;
        for (;;) {
            if (gGameStuff._unk00 - last > 3) {
                if (toggle)
                    *(u16 *)(*(u8 **)(st + 20) + 0x76) = CREDITS_BLINK_TILE;
                else
                    *(u16 *)(*(u8 **)(st + 20) + 0x76) = toggle;
                toggle = toggle ? 0 : 1;
                last = clock->_unk00;
                *flag = sub_080004C4();
            }
            gFlag = &gIwram_5398;
            if (*flag == CREDITS_INPUT_A)
                goto done_fe;
            if (*flag == CREDITS_INPUT_B)
                break;
        }
    }

    {
        u32 front;
        u32 back;
        vu16 fill;
        vu32 *dma;

        state = (u8 *)0x03006440;
        *(u16 *)(state + 50) = 0;
        back = *(u32 *)(state + 36);
        front = *(u32 *)(state + 20);
        *(u32 *)(state + 36) = front;
        *(u32 *)(state + 20) = back;

        fill = 0;
        dma = (vu32 *)0x040000D4;
        dma[0] = (u32)&fill;
        dma[1] = front;
        dma[2] = DMA_CLEAR_ROW;
        (void)dma[2];

        dma[0] = (u32)&fill;
        front += 0x40;
        dma[1] = front;
        dma[2] = DMA_CLEAR_ROW;
        (void)dma[2];

        dma[0] = (u32)&fill;
        dma[1] = back;
        dma[2] = DMA_CLEAR_ROW;
        (void)dma[2];

        dma[0] = (u32)&fill;
        dma[1] = back + 0x40;
        dma[2] = DMA_CLEAR_ROW;
        (void)dma[2];
    }

advance:
    *(u32 *)(state + 12) += 2;

done_zero:
    *gFlag = 0;
    return 0;

done_gate1:
    *gFlag = 0;

done_fe:
    return CREDITS_RETURN_WAIT;
}

static void sub_080100A4(void)
{
    vu16 fill;
    vu32 *dma;

    fill = 0;
    dma = (vu32 *)0x040000D4;
    dma[0] = (u32)&fill;
    dma[1] = 0x0600F800;
    dma[2] = DMA_CLEAR_OBJ_VRAM;
    (void)dma[2];

    REG_BG3CNT = 0x1F08;
    REG_DISPCNT = 0x840;
}
```
