# sub_0800FE88 — deferred (credits-roll renderer / typewriter step)

Scene state @ 0x03006440. Walks the tilemap-encoded credits stream at
`state->cursor` (+0x0C), emitting one BG-tilemap glyph pair per column into
the double-buffered row buffer (+0x14 front / +0x24 back), advancing the
column counter (+0x30). Stream markers: 0xFFFE = blink/wait-for-input header
gate (flashes vram+0x76 between 0xE0E4 and 0; polls `sub_080004C4` until A
0x20 or B 0x10); 0xFFFD = formatting command (next halfword `cmd`, glyph
block index `idx = (cmd + 0xFFFF1F19) * 3`, reads `sCreditsTilemapEng`
entries idx+1 and idx+2); 0xFFFF = end-of-line (reset column; first pass
flips front/back row pointers; second pass runs the same input gate then
DMA-blits both rows to OBJ-VRAM via REG_DMA3, cnt 0x8100001C).

The slice [0x0800fe88, 0x080100e4) also contains an unreferenced static
teardown function at 0x080100a4 (`sub_080100A4`): zero-fill OBJ-VRAM
0x0600F800 (0x400 halfwords), REG_BG3CNT=0x1F08, REG_DISPCNT=0x840. This dead
function compiles byte-exact already.

## Drift

**Best result this round: byte_diff 322, diff_count 125, size 604** (improves
prior best 325/128). Pure C with register pins for the high-reg layout
(state r7, flag r9, cursor r5, glyphs r8) + the gate-loop pins
(lastTick r4, toggle r6, gGameStuff r8, gateFlag r5). No inline asm / NAKED /
NON_MATCHING. Classifier verdict: ATTEMPT_MATCH (advisory: r8/r9 across the bl,
not a strong class).

**Key new finding (root cause, via `-da` RTL dump of old_agbcc):** the entire
residual mismatch is confined to the first 0x100 bytes; **everything from
+0x100 onward (eol, second gate, DMA flush, epilogue, sub_080100A4) is
byte-perfect.** The front-half plateau is THREE independent, pool-coupled
agbcc divergences:

1. **const-0 CSE-merge + loop hoist into r7.** The first `cse` pass merges the
   three `u16`-store-of-0 sites (gate `gIwram_5398 = 0`, gate blink-else
   `*(vram+0x76) = 0`, normal-branch `*(vram...) = 0`) into ONE pseudo
   (`reg 46`, set once, used 3x). `loop.c` then move-movables it out of the
   do-while ("Insn 70 ... move-insn savings 3 moved to 654"), and the greg
   allocator gives it **r7** (free inside the loop because `state` is also r7
   but only read at eol). Result: a hoisted `mov r7, #0` at the do-while top,
   then `strh r7` for all three zero stores (target uses `strh r4`=lastTick,
   `strh r6`=toggle, and a fresh `movs r1,#0`), plus a redundant
   `ldr r7,=state` reload in the gate. Costs ~4 instruction mismatches
   (+0x22, +0x32, +0x78, +0xaa).

   **NO flag disables it:** verified on the dump that `-fno-gcse`,
   `-fno-loop-optimize`, `-fno-move-all-movables`, `-fno-strength-reduce`,
   `-fno-rerun-cse-after-loop`, `-fno-cse-follow-jumps`, `-fno-cse-skip-blocks`,
   `-fno-expensive-optimizations`, `-fforce-addr`, and the AGBCC (newer)
   compiler all leave `mov r7,#0` in place. (The `gcse` PRE pass DOES hoist a
   different expression — `*gateFlag` — into reg 204, but disabling it is a
   no-op on the bytes.)

   **The hoist IS killable via source** (`gIwram_5398 = lastTick` +
   blink-else `= toggle`, so the gate zeros reference live gate-local vars
   instead of const-0 — this makes the gate setup byte-EXACT:
   `mov r4,#0; mov r6,#0; strh r4,[&flag]` matching ff?? exactly, and removes
   the hoist entirely). BUT it then costs MORE elsewhere (see issue 2+3) and
   nets byte_diff 467 / size 608. The hoist-free variant is saved below as
   "## Hoist-free C" — it is the better STARTING POINT for the next attempt,
   because the gate is solved and only the entry + format issues remain.

2. **Entry pool/scheduling.** Target loads `0xFFFF` (END constant) FIRST, then
   `&gIwram_5398` into r9, then derefs `*cursor`, then `cmp; beq eol` — so r9
   is set unconditionally before the branch AND the pool order is
   `state, 0xFFFF, &flag, glyphs`. Achieving this exact interleave from C is
   the wall: `flag = &gIwram_5398` BEFORE the `if` → &flag's literal is
   referenced before 0xFFFF → wrong pool order (`state, &flag, 0xFFFF`);
   AFTER the `if` → r9 not set on the eol-taken path → extra
   `ldr r0,=&flag; mov r9,r0` reload (+2 bytes, the +0x14/+0x16 INSERTIONs in
   the hoist-free variant). Splitting the cursor load with `flag=` between
   (`cursor = state[12]; flag = &gIwram_5398; if (*cursor==END)`) still flips
   the pool. Also target does `ldr r0,=state; ldr r2,[r0,#12]; ...;
   adds r7,r0,#0` (state via scratch r0 then move); the `state asm("r7")` pin
   forces a direct `ldr r7,=state`. Unpinning state to recover `adds r7,r0,#0`
   adds a pool entry and cascades worse (531/523).

3. **Format-branch intermediate cursor store deleted (dead-store elim).**
   Target stores `state[12] = cursor+1` early, does the glyph work, then
   `state[12] = cursor+2` at the end — TWO stores. The first is a genuinely
   dead store (memory overwritten with no intervening read of state[12]) that
   the ORIGINAL agbcc keeps but OUR old_agbcc eliminates. Neither an
   incremented `next` pointer (`next=cursor+1; *p12=next; ...; next++;
   *p12=next;`) nor the AGBCC compiler preserves it. Only `volatile` on the
   intermediate store preserves it — and that grows the fn to 608 /
   byte_diff 450 (note's earlier finding, re-confirmed). This is likely the
   real reason the target keeps the dead store: it treats the glyph writes
   through `state[20]` (vram) as POSSIBLY ALIASING `state[12]`, so the store
   isn't provably dead. A source shape that makes agbcc's alias analysis
   conservative here (without `volatile`) is the unexplored lever.

Other small residuals: normal-branch vram lands in r1 not r2 (operand-order /
which-reg-is-base); gate-exit loop back-edge is an explicit `b fec6` vs the
target's `bne fec6` (jump.c cross-jump merge of the back-edge into the last
`cmp #32`).

## New levers ruled out this round (in addition to prior note's list)

- All ~18 individual `-fXXX` flags above + AGBCC compiler swap: no help on the
  hoist; AGBCC worse overall (425-429).
- `gIwram_5398 = lastTick` alone: kills hoist but flips pool (423).
- blink-else `= toggle` alone: kills hoist but cascades (435).
- both gate zeros distinct (lastTick + toggle): kills hoist, gate byte-exact,
  but entry +2 and format growth net 467/608. **<- best hoist-free base.**
- fresh barriered/local zero in normal branch: kills hoist, 471.
- cursor probe via scratch local for `adds r7,r0,#0`: 523.
- `next`-pointer format store / volatile format store: store still deleted
  (322) or fn grows (450).

## Suggested next move

The three issues are coupled only through the literal pool. Two attack plans:
(a) START FROM the hoist-free C below (gate already byte-exact), then solve
    ONLY the entry interleave (issue 2) — try a linker-assigned symbol for
    `gIwram_5398` (cvaos house-style, defeats CSE re-materialization of the
    address and may fix the r9 scheduling) and a conservative-alias shape for
    the format store (issue 3) WITHOUT volatile.
(b) Run `vendor/decomp-permuter` from EITHER the 322 or the 467 base — it was
    UNAVAILABLE this round (submodule not checked out, no `.venv` even in
    MAIN). Permuter mutates statement order / var scope, which is exactly what
    these three pool-coupled coloring issues need. This is the most likely
    one-shot crack and should be tried first once the venv exists.

## Best-effort C (byte_diff 322 — register-pin form, hoist present)

```c
#include "game.h"
#include "gba/dma.h"
#include "gba/io.h"
#include "types.h"

extern u16 sub_080004C4(void);
extern const u8 sCreditsTilemapEng[];
extern u16 gIwram_5398;

enum {
    CREDITS_END = 0xFFFF,
    CREDITS_GATE = 0xFFFE,
    CREDITS_FORMAT = 0xFFFD,
    CREDITS_BLINK_TILE = 0xE0E4,
    CREDITS_FORMAT_BIAS = 0xFFFF1F19,
    INPUT_B = 0x10,
    INPUT_A = 0x20,
};

#define DMA_BLIT_ROW (DMA_ENABLE | DMA_SRC_FIXED | 0x1C)

u8 sub_0800FE88(void)
{
    register u8 *state asm("r7");
    register u16 *flag asm("r9");
    register u16 *cursor asm("r5");

    state = (u8 *)0x03006440;
    if (*(*(u16 **)(state + 12)) == CREDITS_END)
        goto eol;
    flag = &gIwram_5398;

    {
        register u8 *p asm("r6");
        register const u8 *glyphs asm("r8");

        p = state;
        glyphs = sCreditsTilemapEng;
        do {
            cursor = *(u16 **)(p + 12);
            if (*cursor == CREDITS_GATE) {
                register u32 lastTick asm("r4");
                register u32 toggle asm("r6");
                register GameStuff *clock asm("r8");
                register u8 *gate asm("r7");
                register u16 *gateFlag asm("r5");

                lastTick = 0;
                toggle = 0;
                gIwram_5398 = 0;
                clock = &gGameStuff;
                gate = (u8 *)0x03006440;
                flag = &gIwram_5398;
                gateFlag = flag;
                for (;;) {
                    if (gGameStuff._unk00 - lastTick > 3) {
                        if (toggle)
                            *(u16 *)(*(u8 **)(gate + 20) + 0x76) = CREDITS_BLINK_TILE;
                        else
                            *(u16 *)(*(u8 **)(gate + 20) + 0x76) = 0;
                        toggle = toggle ? 0 : 1;
                        lastTick = clock->_unk00;
                        *gateFlag = sub_080004C4();
                    }
                    if (*gateFlag == INPUT_B)
                        goto clear_and_wait;
                    if (*gateFlag == INPUT_A)
                        goto clear_and_wait;
                }
            }

            if (*cursor != CREDITS_FORMAT) {
                u8 *vram;

                vram = *(u8 **)(p + 20);
                *(u16 *)((*(u16 *)(p + 48) << 1) + vram) = 0;
                *(u16 *)((*(u16 *)(p + 48) << 1) + vram + 0x40) = *cursor;
                *(u16 **)(p + 12) = cursor + 1;
            } else {
                u8 *vram;
                u32 idx;

                *(u16 **)(p + 12) = cursor + 1;
                vram = *(u8 **)(p + 20);
                idx = (cursor[1] + CREDITS_FORMAT_BIAS) * 3;
                *(u16 *)((*(u16 *)(p + 48) << 1) + vram) =
                    *(u16 *)(glyphs + ((idx + 1) << 1));
                *(u16 *)((*(u16 *)(p + 48) << 1) + vram + 0x40) =
                    *(u16 *)(glyphs + ((idx + 2) << 1));
                *(u16 **)(p + 12) = cursor + 2;
            }

            *(u16 *)(p + 48) += 1;
            cursor = *(u16 **)(p + 12);
        } while (*cursor != CREDITS_END);
    }

eol:
    cursor = *(u16 **)(state + 12);
    if (*cursor != CREDITS_END)
        goto done_zero;

    *(u16 *)(state + 48) = 0;
    if (*(u16 *)(state + 50) == 0) {
        u32 front;

        *(u16 *)(state + 50) = 1;
        front = *(u32 *)(state + 36);
        *(u32 *)(state + 36) = *(u32 *)(state + 20);
        *(u32 *)(state + 20) = front;
        goto advance;
    }

    {
        u32 lastTick;
        u32 toggle;
        GameStuff *clock;

        lastTick = 0;
        toggle = 0;
        gIwram_5398 = 0;
        clock = &gGameStuff;
        for (;;) {
            if (clock->_unk00 - lastTick > 3) {
                if (toggle)
                    *(u16 *)(*(u8 **)(state + 20) + 0x76) = CREDITS_BLINK_TILE;
                else
                    *(u16 *)(*(u8 **)(state + 20) + 0x76) = 0;
                toggle = toggle ? 0 : 1;
                lastTick = clock->_unk00;
                gIwram_5398 = sub_080004C4();
            }
            flag = &gIwram_5398;
            if (*flag == INPUT_A)
                goto done_fe;
            if (*flag == INPUT_B)
                break;
        }
    }

    {
        u32 front;
        u32 back;
        vu16 fill;
        vu32 *dma;

        state = (u8 *)0x03006440;
        *(u16 *)(state + 50) = 0;
        back = *(u32 *)(state + 36);
        front = *(u32 *)(state + 20);
        *(u32 *)(state + 36) = front;
        *(u32 *)(state + 20) = back;

        fill = 0;
        dma = (vu32 *)0x040000D4;
        dma[0] = (u32)&fill;
        dma[1] = front;
        dma[2] = DMA_BLIT_ROW;
        (void)dma[2];

        fill = 0;
        dma[0] = (u32)&fill;
        front += 0x40;
        dma[1] = front;
        dma[2] = DMA_BLIT_ROW;
        (void)dma[2];

        fill = 0;
        dma[0] = (u32)&fill;
        dma[1] = back;
        dma[2] = DMA_BLIT_ROW;
        (void)dma[2];

        fill = 0;
        dma[0] = (u32)&fill;
        dma[1] = back + 0x40;
        dma[2] = DMA_BLIT_ROW;
        (void)dma[2];
    }

advance:
    *(u32 *)(state + 12) += 2;

done_zero:
    *flag = 0;
    return 0;

clear_and_wait:
    *flag = 0;

done_fe:
    return 0xFE;
}

static void sub_080100A4(void)
{
    vu16 fill;
    vu32 *dma;

    fill = 0;
    dma = (vu32 *)0x040000D4;
    dma[0] = (u32)&fill;
    dma[1] = 0x0600F800;
    dma[2] = DMA_ENABLE | DMA_SRC_FIXED | 0x400;
    (void)dma[2];

    REG_BG3CNT = 0x1F08;
    REG_DISPCNT = 0x840;
}
```

## Hoist-free C (byte_diff 467 — gate byte-exact, hoist gone; better base)

Same as above, but in the FIRST gate replace `gIwram_5398 = 0;` with
`gIwram_5398 = lastTick;` and the blink-else `... = 0;` with `... = toggle;`.
This makes the gate setup compile byte-exact (`mov r4,#0; mov r6,#0;
strh r4,[&flag]`) and removes the `mov r7,#0` hoist entirely. The remaining
467 drift is purely issues 2 (entry interleave, +2 bytes from the eol-path
&flag reload) and 3 (format intermediate-store deletion) plus the resulting
pool-offset cascade and one `.align` NOP. Start the permuter or the
linker-symbol/alias experiments from THIS variant.
