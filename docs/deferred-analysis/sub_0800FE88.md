# sub_0800FE88 — deferred (credits-roll renderer / typewriter step)

Scene state @ 0x03006440. Walks the tilemap-encoded credits stream at
`state->cursor` (+0x0C), emitting one BG-tilemap glyph pair per column into
the double-buffered row buffer (+0x14 front / +0x24 back), advancing the
column counter (+0x30). Stream markers: 0xFFFE = blink/wait-for-input header
gate (flashes vram+0x76 between 0xE0E4 and 0; polls `sub_080004C4` until A
0x20 or B 0x10); 0xFFFD = formatting command (next halfword `cmd`, glyph
block index `idx = cmd - 0xE0E7`, reads `sCreditsTilemapEng` entries
idx*3+1 and idx*3+2); 0xFFFF = end-of-line (reset column; first pass flips
front/back row pointers; second pass runs the same input gate then DMA-blits
both rows to OBJ-VRAM via REG_DMA3, cnt 0x8100001C). Returns 0xFE on the
A-button completion path, else 0.

The slice [0x0800fe88, 0x080100e4) also contains an **unreferenced static
teardown function at 0x080100a4** (`sub_080100A4` in the best-effort below):
zero-fill OBJ-VRAM 0x0600F800 (0x400 halfwords), REG_BG3CNT=0x1F08,
REG_DISPCNT=0x840. **This dead function compiles BYTE-EXACT already** (verified
0x204..0x244 of the .o == target 0x100a4..0x100e4). Only the main function
remains nonmatching.

## Drift

- Best **diff_count: 154** (Thumb instruction-level), byte_diff ~395, on the
  584-byte version below. The dead helper is a perfect match; the entire 154
  is in the main function (compiled main = 0x204 = 516 B vs target main ≈ 540 B,
  so the build is ~12 instructions short — agbcc emits a tighter body).
- **Root cause: register-coloring divergence on a 6-live-pointer function.**
  Target keeps state in r7, a loop copy in r6 (`adds r6,r7,#0`), glyphs
  (sCreditsTilemapEng) in r8, gIwram_5398 ptr in r9, cursor in r5, scratch/zero
  in r4 — i.e. r4..r9 all callee-saved-live, prologue
  `push {r4-r7,lr}; mov r7,r9; mov r6,r8; push {r6,r7}`. Every attempted C
  shape made agbcc save the incoming r8/r9 into r5/r6 and **never allocate r7**
  (`push {r4,r5,r6,lr}`), so the dual state-pointer (r7 outer + r6 loop) never
  forms. Responsible passes: gcc_arm/local-alloc.c + regclass.c (the
  `register T x asm("rN")` hints are advisory and get spilled under the 6-value
  pressure; pinning state to r7 did NOT force r7 into the frame).
- **Two inlined wait-gates** (0xfffe header gate + the 0xffff second-pass gate)
  are textually identical source but compiled with *different* high-reg colorings
  (gate1: st=r7,flag=r5 from r9; gate2: st=r5,flag=r7), so a single shared shape
  can't satisfy both — they were almost certainly two source copies / a macro.
- **Pool-literal ordering** cascades: target order fee0(state) fee4(0xffff)
  fee8(0x03005398) feec(sCreditsTilemap) fef0(0xfffe) fef4(gGameStuff)
  fef8(0xe0e4); built order differs by first-use, shifting every PC-relative
  ldr (ARGUMENT_MISMATCH spam). Fixing the structure fixes the pool for free.

## Levers tried (none converged below 154)
- plain locals (no pins): 188
- all-pinned (state r7, outer r6, glyphs r8, gFlag r9 + gate pins): 166
- **unpin state only (best): 154**
- also unpin outer: 154 ; unpin gate st: 154
- pin state r7 + load literal through an r0 scratch (`adds r7,r0,#0` shape): 154
  (byte_diff worse; still no r7 in frame — agbcc spills the pin)
- gate `gIwram_5398 = last` (reuse the r4 zero like target `strh r4`): 165 (worse)
- toggle u8 -> u32 (kills the spurious `lsls #24` zero-extend on the toggle
  compare): helped (179->166); KEEP this in any retry.
- NOT tried: per-TU CFLAGS (-ffixed-r?, -fno-gcse, -fno-schedule-insns) to force
  the allocator; instrumenting local-alloc.c to see why the r7-pin spills. These
  are the next moves — the win is making agbcc keep state in r7 so the dual
  state-pointer (r6 loop copy) materializes. permuter is NOT applicable (154 >> 40).

## Best-effort C
```c
#include "game.h"
#include "gba/dma.h"
#include "gba/io.h"
#include "iwram.h"
#include "types.h"

extern u16 sub_080004C4(void);
extern const u8 sCreditsTilemapEng[];

extern u16 gIwram_5398;

u8 sub_0800FE88(void)
{
    u8 *state;
    register u16 *gFlag asm("r9");
    register u8 *outer asm("r6");
    u16 *cursor;
    register const u8 *glyphs asm("r8");
    u16 cmd;
    u32 idx;

    state = (u8 *)0x03006440;
    cursor = *(u16 **)(state + 12);
    gFlag = &gIwram_5398;
    if (*cursor == 0xFFFF)
        goto eol;

    outer = state;
    glyphs = sCreditsTilemapEng;

    do {
        cursor = *(u16 **)(outer + 12);

        if (*cursor == 0xFFFE) {
            register u32 last asm("r4");
            register u32 toggle asm("r6");
            register GameStuff *clock asm("r8");
            register u8 *st asm("r7");
            register u16 *flag asm("r5");

            last = 0;
            toggle = 0;
            gIwram_5398 = 0;
            clock = &gGameStuff;
            st = state;
            flag = gFlag;
            for (;;) {
                if (clock->_unk00 - last <= 3)
                    goto gate1_check;
                if (toggle)
                    *(u16 *)(*(u8 **)(st + 20) + 0x76) = 0xE0E4;
                else
                    *(u16 *)(*(u8 **)(st + 20) + 0x76) = toggle;
                toggle = !toggle;
                last = clock->_unk00;
                *flag = sub_080004C4();
            gate1_check:
                if (*flag == 16)
                    goto done_zero;
                if (*flag == 32)
                    goto done_zero;
            }
        }

        if (*cursor != 0xFFFD) {
            u8 *vram;
            vram = *(u8 **)(outer + 20);
            *(u16 *)(vram + (*(u16 *)(outer + 48) << 1)) = 0;
            *(u16 *)(vram + (*(u16 *)(outer + 48) << 1) + 0x40) = *cursor;
            *(u16 **)(outer + 12) = cursor + 1;
        } else {
            u8 *vram;
            u16 *dst;
            *(u16 **)(outer + 12) = cursor + 1;
            vram = *(u8 **)(outer + 20);
            dst = (u16 *)(vram + (*(u16 *)(outer + 48) << 1));
            cmd = cursor[1];
            idx = (cmd + 0xFFFF1F19) * 3;
            *dst = *(u16 *)(glyphs + ((idx + 1) << 1));
            *(u16 *)(vram + (*(u16 *)(outer + 48) << 1) + 0x40) = *(u16 *)(glyphs + ((idx + 2) << 1));
            *(u16 **)(outer + 12) = cursor + 2;
        }

        *(u16 *)(outer + 48) += 1;
        cursor = *(u16 **)(outer + 12);
    } while (*cursor != 0xFFFF);

eol:
    cursor = *(u16 **)(state + 12);
    if (*cursor != 0xFFFF)
        goto done_zero_noadv;

    *(u16 *)(state + 48) = 0;
    if (*(u16 *)(state + 50) == 0) {
        u32 front;
        *(u16 *)(state + 50) = 1;
        front = *(u32 *)(state + 36);
        *(u32 *)(state + 36) = *(u32 *)(state + 20);
        *(u32 *)(state + 20) = front;
        goto advance;
    }

    {
        register u32 last asm("r4");
        register u32 toggle asm("r6");
        register GameStuff *clock asm("r8");
        register u8 *st asm("r5");
        register u16 *flag asm("r7");

        last = 0;
        toggle = 0;
        gIwram_5398 = 0;
        clock = &gGameStuff;
        st = state;
        flag = &gIwram_5398;
        for (;;) {
            if (clock->_unk00 - last <= 3)
                goto gate2_check;
            if (toggle)
                *(u16 *)(*(u8 **)(st + 20) + 0x76) = 0xE0E4;
            else
                *(u16 *)(*(u8 **)(st + 20) + 0x76) = toggle;
            toggle = !toggle;
            last = clock->_unk00;
            *flag = sub_080004C4();
        gate2_check:
            gFlag = &gIwram_5398;
            if (*flag == 32)
                goto done_fe;
            if (*flag == 16)
                break;
        }
    }

    {
        register u32 front asm("r2");
        register u32 back asm("r6");
        vu16 fill;
        vu32 *dma;

        state = (u8 *)0x03006440;
        *(u16 *)(state + 50) = 0;
        back = *(u32 *)(state + 36);
        front = *(u32 *)(state + 20);
        *(u32 *)(state + 36) = front;
        *(u32 *)(state + 20) = back;

        fill = 0;
        dma = (vu32 *)0x040000D4;
        dma[0] = (u32)&fill;
        dma[1] = front;
        dma[2] = 0x8100001C;
        (void)dma[2];

        dma[0] = (u32)&fill;
        front += 0x40;
        dma[1] = front;
        dma[2] = 0x8100001C;
        (void)dma[2];

        dma[0] = (u32)&fill;
        dma[1] = back;
        dma[2] = 0x8100001C;
        (void)dma[2];

        dma[0] = (u32)&fill;
        dma[1] = back + 0x40;
        dma[2] = 0x8100001C;
        (void)dma[2];
    }

advance:
    *(u32 *)(state + 12) += 2;

done_zero_noadv:
    *gFlag = 0;
    return 0;

done_zero:
    *gFlag = 0;
    return 0;

done_fe:
    return 0xFE;
}

static void sub_080100A4(void)
{
    vu16 fill;
    vu32 *dma;

    fill = 0;
    dma = (vu32 *)0x040000D4;
    dma[0] = (u32)&fill;
    dma[1] = 0x0600F800;
    dma[2] = 0x81000400;
    (void)dma[2];

    REG_BG3CNT = 0x1F08;
    REG_DISPCNT = 0x840;
}
```
