# sub_0800FE88 — deferred (credits-roll renderer / typewriter step)

Scene state @ 0x03006440. Walks the tilemap-encoded credits stream at
`state->cursor` (+0x0C), emitting one BG-tilemap glyph pair per column into
the double-buffered row buffer (+0x14 front / +0x24 back), advancing the
column counter (+0x30). Stream markers: 0xFFFE = blink/wait-for-input header
gate (flashes vram+0x76 between 0xE0E4 and 0; polls `sub_080004C4` until A
0x20 or B 0x10); 0xFFFD = formatting command (next halfword `cmd`, glyph
block index `idx = cmd - 0xE0E7`, reads `sCreditsTilemapEng` entries
idx*3+1 and idx*3+2); 0xFFFF = end-of-line (reset column; first pass flips
front/back row pointers; second pass runs the same input gate then DMA-blits
both rows to OBJ-VRAM via REG_DMA3, cnt 0x8100001C).

The slice [0x0800fe88, 0x080100e4) also contains an **unreferenced static
teardown function at 0x080100a4** (`sub_080100A4`): zero-fill OBJ-VRAM
0x0600F800 (0x400 halfwords), REG_BG3CNT=0x1F08, REG_DISPCNT=0x840. This dead
function compiles BYTE-EXACT already.

## CORRECTED SEMANTICS (round 16) — prior note had this WRONG

**The 0xFFFE gate (gate1) returns 0xFE, NOT 0.** Target 0x801008c does
`*gFlag = 0` then FALLS THROUGH to 0x8010092 (`r0 = 0xFE`) → return 0xFE. The
prior best-effort C had `done_zero: *gFlag=0; return 0` for gate1 — that is a
behavioural bug. The correct label structure is THREE done blocks:
  - done_noadv (0x8010072): `gIwram_5398 = 0; return 0`   (eol/advance path)
  - done_gate1 (0x801008c): `gIwram_5398 = 0;` FALL THROUGH to done_fe
  - done_fe   (0x8010092): `return 0xFE`                  (gate1 + gate2 A-button)
Fixing this dropped diff_count 154 → 148 and is the correct model — KEEP IT.

## BREAKTHROUGH: how to make agbcc SAVE r7 (prologue match) — round 16

The prior note's wall ("pinning state to r7 did NOT force r7 into the frame")
is SOLVED. Root cause: `register u8 *state asm("r7")` is treated by agbcc as a
USER GLOBAL reg it may clobber WITHOUT a prologue save (ABI rule
`regs_ever_live && !call_used` is NOT set for an asm-pinned hard reg used only
as a reload-from-constant). And if the GATES also pin a var to r7
(`st asm("r7")` / `flag asm("r7")`), that re-confirms r7 as a user reg → no save.

The fix that PRODUCES `push {r4,r5,r6,r7,lr}; mov r7,r9; mov r6,r8; push {r6,r7}`
(byte-identical prologue):
  1. Pin `state asm("r7")` in the OUTER scope, used genuinely across the loop
     and re-read in eol → agbcc keeps it callee-saved AND saves r7.
  2. In gate1, do NOT pin its `st` to r7 — use the outer `state` var directly
     (it already IS r7). Pin the gate's OTHER vars (last r4, toggle r6, clock
     r8, flag r5).
  3. In gate2, do NOT pin `flag` to r7 — leave it UNPINNED; agbcc naturally
     colours it r7 (free in gate2 since state is copied to st=r5). Pinning
     flag=r7 here re-breaks the save.
Net of the prologue-match + gate single-pointer reuse + corrected done labels +
operand-order flips + marker cache: diff_count 154 → **133** (byte_diff 325).

## Other landed wins (all in the Best-effort C below)
- Gate `gIwram_5398 = 0` store: write `gIwram_5398 = last;` (last==0) so agbcc
  reuses the zero reg (`strh r4,[r0]`) instead of a fresh `movs r0,#0`. AND in
  gate1 order the assigns so the gIwram pointer (r0) loaded for the store is
  reused for gFlag(r9) and flag — single pool slot (kills the duplicate gIwram
  pool word). Order: last=0; toggle=0; gIwram_5398=last; clock=&gGameStuff;
  state=0x03006440; gFlag=&gIwram_5398; flag=gFlag.
- gate count-check uses `gGameStuff._unk00` (macro, reloads from pool each
  iter, matches target `ldr r0,=gGameStuff; ldr r0,[r0]`); the `last =` uses
  `clock->_unk00` (the r8 var).
- Entry: load 0x03006440 into a scratch (`register u8 *p0 asm("r0")`), deref
  cursor via p0, then `state = p0` — produces target's `ldr r0; ldr r2,[r0,#12];
  adds r7,r0,#0` (state copied, not loaded direct). Dropped 141 → 137.
- Glyph store operand order: write `(col<<1) + (u32)vram` NOT `vram + (col<<1)`
  so the `adds r0,r0,r2` operand order matches. Dropped ~2.
- marker = *cursor pinned r1 + cursor pinned r5: lets the 0xFFFD compare reuse
  the loaded *cursor in r1 (target `cmp r1,r0`) instead of re-deref. 137 → 133.

## Drift — the IRREDUCIBLE residual (diff_count 133, byte_diff 325)

After all the above, the floor is **133** and is TWO classes of agbcc-vs-original
codegen gap that NO source shape, pin, or old_agbcc flag escapes:

1. **Entry pool-word order**: target loads the 0xFFFF compare constant (fee4)
   BEFORE the gIwram/gFlag pointer (fee8); built loads gIwram first because the
   `gFlag = &gIwram_5398` statement precedes the `if (*cursor==0xFFFF)`. old_agbcc
   has NO instruction scheduler (`-fno-schedule-insns*` are rejected), so the
   load order = source order, and gFlag MUST be set before the eol-branch (the
   skip-loop→eol→done path reads r9). Splitting/duplicating gFlag (set in both
   if-taken and fallthrough) made it WORSE (220) — agbcc did not CSE the two
   gIwram address loads into one pool slot/r9. This single swapped pool word
   cascades through every PC-relative ldr offset = most of the 133.

2. **Cursor-store CROSS-JUMP (tail merge)**: in the regular and 0xFFFD branches
   the final `*(outer+12) = cursor+N` both compile to `str r5,[r6,#12]` with the
   SAME source reg, so agbcc (jump.c cross-jumping) MERGES them into one
   `str r5,[r6,#12]` at the shared col-advance, with each branch doing
   `adds r5,#2` / `adds r5,#4` in place first. The target keeps the stores
   per-branch from DIFFERENT regs (regular `adds r0,r5,#2; str r0`; fffd
   `str r3; ...; adds r3,#2; str r3`), so it does not cross-jump. Tried: a
   separate `adv` var, `cursor += N; store cursor`, duplicating the col-advance
   into each branch (166), keeping cursor live — none change the coloring;
   agbcc colours both stores to r5 and merges. This is an allocator-aggression
   gap: agbcc reuses the dead cursor reg where the original compiler used a
   fresh temp.

## Best-effort C (diff_count 133, byte_diff 325 — corrected semantics)
```c
#include "game.h"
#include "gba/dma.h"
#include "gba/io.h"
#include "types.h"

extern u16 sub_080004C4(void);
extern const u8 sCreditsTilemapEng[];

extern u16 gIwram_5398;

u8 sub_0800FE88(void)
{
    register u8 *state asm("r7");
    register u16 *gFlag asm("r9");
    register u16 *cursor asm("r5");

    {
        register u8 *p0 asm("r0");
        p0 = (u8 *)0x03006440;
        cursor = *(u16 **)(p0 + 12);
        state = p0;
    }
    gFlag = &gIwram_5398;
    if (*cursor == 0xFFFF)
        goto eol;

    {
        register u8 *outer asm("r6");
        register const u8 *glyphs asm("r8");
        u16 cmd;
        u32 idx;

        outer = state;
        glyphs = sCreditsTilemapEng;

        do {
            register u16 marker asm("r1");

            cursor = *(u16 **)(outer + 12);
            marker = *cursor;

            if (marker == 0xFFFE) {
                register u32 last asm("r4");
                register u32 toggle asm("r6");
                register GameStuff *clock asm("r8");
                register u16 *flag asm("r5");

                last = 0;
                toggle = 0;
                gIwram_5398 = last;
                clock = &gGameStuff;
                state = (u8 *)0x03006440;
                gFlag = &gIwram_5398;
                flag = gFlag;
                for (;;) {
                    if (gGameStuff._unk00 - last > 3) {
                        if (toggle)
                            *(u16 *)(*(u8 **)(state + 20) + 0x76) = 0xE0E4;
                        else
                            *(u16 *)(*(u8 **)(state + 20) + 0x76) = toggle;
                        toggle = toggle ? 0 : 1;
                        last = clock->_unk00;
                        *flag = sub_080004C4();
                    }
                    if (*flag == 16)
                        goto done_gate1;
                    if (*flag == 32)
                        goto done_gate1;
                }
            }

            if (marker != 0xFFFD) {
                u8 *vram;
                vram = *(u8 **)(outer + 20);
                *(u16 *)((*(u16 *)(outer + 48) << 1) + (u32)vram) = 0;
                *(u16 *)((*(u16 *)(outer + 48) << 1) + (u32)vram + 0x40) = *cursor;
                *(u16 **)(outer + 12) = cursor + 1;
            } else {
                u8 *vram;
                *(u16 **)(outer + 12) = cursor + 1;
                vram = *(u8 **)(outer + 20);
                cmd = cursor[1];
                idx = (cmd - 0xE0E7) * 3;
                *(u16 *)((*(u16 *)(outer + 48) << 1) + (u32)vram) = *(u16 *)(glyphs + ((idx + 1) << 1));
                *(u16 *)((*(u16 *)(outer + 48) << 1) + (u32)vram + 0x40) = *(u16 *)(glyphs + ((idx + 2) << 1));
                *(u16 **)(outer + 12) = cursor + 2;
            }

            *(u16 *)(outer + 48) += 1;
            cursor = *(u16 **)(outer + 12);
        } while (*cursor != 0xFFFF);
    }

eol:
    cursor = *(u16 **)(state + 12);
    if (*cursor != 0xFFFF)
        goto done_zero;

    *(u16 *)(state + 48) = 0;
    if (*(u16 *)(state + 50) == 0) {
        u32 front;
        *(u16 *)(state + 50) = 1;
        front = *(u32 *)(state + 36);
        *(u32 *)(state + 36) = *(u32 *)(state + 20);
        *(u32 *)(state + 20) = front;
        goto advance;
    }

    {
        register u32 last asm("r4");
        register u32 toggle asm("r6");
        register GameStuff *clock asm("r8");
        register u8 *st asm("r5");
        u16 *flag;

        last = 0;
        toggle = 0;
        gIwram_5398 = 0;
        clock = &gGameStuff;
        st = state;
        flag = &gIwram_5398;
        for (;;) {
            if (gGameStuff._unk00 - last > 3) {
                if (toggle)
                    *(u16 *)(*(u8 **)(st + 20) + 0x76) = 0xE0E4;
                else
                    *(u16 *)(*(u8 **)(st + 20) + 0x76) = toggle;
                toggle = toggle ? 0 : 1;
                last = clock->_unk00;
                *flag = sub_080004C4();
            }
            gFlag = &gIwram_5398;
            if (*flag == 32)
                goto done_fe;
            if (*flag == 16)
                break;
        }
    }

    {
        u32 front;
        u32 back;
        vu16 fill;
        vu32 *dma;

        state = (u8 *)0x03006440;
        *(u16 *)(state + 50) = 0;
        back = *(u32 *)(state + 36);
        front = *(u32 *)(state + 20);
        *(u32 *)(state + 36) = front;
        *(u32 *)(state + 20) = back;

        fill = 0;
        dma = (vu32 *)0x040000D4;
        dma[0] = (u32)&fill;
        dma[1] = front;
        dma[2] = 0x8100001C;
        (void)dma[2];

        dma[0] = (u32)&fill;
        front += 0x40;
        dma[1] = front;
        dma[2] = 0x8100001C;
        (void)dma[2];

        dma[0] = (u32)&fill;
        dma[1] = back;
        dma[2] = 0x8100001C;
        (void)dma[2];

        dma[0] = (u32)&fill;
        dma[1] = back + 0x40;
        dma[2] = 0x8100001C;
        (void)dma[2];
    }

advance:
    *(u32 *)(state + 12) += 2;

done_zero:
    *gFlag = 0;
    return 0;

done_gate1:
    *gFlag = 0;

done_fe:
    return 0xFE;
}

static void sub_080100A4(void)
{
    vu16 fill;
    vu32 *dma;

    fill = 0;
    dma = (vu32 *)0x040000D4;
    dma[0] = (u32)&fill;
    dma[1] = 0x0600F800;
    dma[2] = 0x81000400;
    (void)dma[2];

    REG_BG3CNT = 0x1F08;
    REG_DISPCNT = 0x840;
}
```
