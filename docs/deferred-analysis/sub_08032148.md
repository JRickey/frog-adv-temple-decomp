# sub_08032148 — deferred (reload copy-scheduling minimum, byte_diff 13)

Sound-engine "is anything still busy?" predicate at 0x08032148 (184 bytes,
src/system/sub_08032148.c). Reached entirely through `*gpSoundSystem`
(0x030065e0). Returns 1 while pending work remains, 0 once drained.

**Round-7 (Opus) result: byte_diff 13**, down from the prior attempt's 156.
The global register allocation now matches the baserom register-for-register
(gpsp=r5 then r7, drain=r5, limit=r6, slot=r4, i=r3) and the structure is
complete: live-range splits, drain hoist+walk, two separate signed compares.
The ONLY remaining diff is a reload-pass copy-scheduling artifact in the
prologue (offsets 0xe-0x1b) that no pure-C shape, flag, or the permuter
(21k+ iters, stuck at score 110) could move. Compile with `-fno-gcse`.

## Semantics (verified against agbcc offsets)

- `gpSoundSystem->slot`            -> [sys+0x118]  (SoundRequestSlot*)
- `slot->flags & 2`               -> (u8)[slot+0x151] & 2 (pool-load 0x151, NOT 0x118+0x39 fold)
- `slot->timers[i].cursor`        -> [slot + i*8]      (i 0..15, ble count-up)
- `slot->streams[i].cursor`       -> [slot+0x88 + i*8] (i 0..15)
- `gpSoundSystem->count`          -> (u8)[sys+0]; limit = count + 4
- `slot->nextRegion`              -> [slot+0x110] (SoundDrainEntry*, HOISTED out of loop,
                                     walked drain += 12 each iter)
- `drain->live`                   -> (u8)[drain+4]
- `gpSoundSystem->channelSeqs[i].opPtr` -> [ [sys+0x114] + i*16 ]
- i<=3: `gpSoundSystem->chanAcc[i]` (u16)[sys+0xac + i*2]; busy if `<= 0xff` (SIGNED ble)
- i>3 : `SOUND_SYSTEM_SW_SLOT(sys,i-4)->accA` (u16)[ [sys+0xc8] + i*64 - 0x100 + 0x34 ];
        busy if `<= 0xff` (path written as `> 0xff -> continue`, SIGNED bgt; uses the
        0xffffff00 = -256 pool constant for the `i*64 - 4*64` form)

## What CRACKED the prior 156 -> 13 (use these; they are load-bearing)

1. **`-fno-gcse`** REQUIRED — without it agbcc caches/folds `*gpsp` and uses
   `add #57` (0x118+0x39) instead of the `0x151` pool load. (newer agbcc is wrong here.)
2. **Read `slot` via the MACRO** `gpSoundSystem->slot`, then declare `gpsp =
   &gpSoundSystem` SECOND. This forces the `0x030065e0` constant into r0 (scratch)
   for the first deref and makes gpsp a copy — the baserom's `ldr r0,[pc]; ...;
   adds r5,r0` shape. Reading slot via `(*gpsp)->slot` instead loads the constant
   straight into r5 (no copy) -> byte_diff jumps to 166. (slot-via-gpsp is WRONG.)
3. **Two-pointer alias `gpsp2 = gpsp`** in the loop preheader, loop body uses
   `(*gpsp2)->...`. This splits the &gp live range (r5 early, r7 in loop) — the
   baserom's `adds r7,r5` copy. Using one pointer everywhere coalesces to r7 (no split).
4. **`gpsp` (NOT macro) for the count/loop derefs** so `*gpsp` RELOADS from `[r5]`/`[r7]`
   each use (baserom reloads; agbcc must not cache sys). Macro-for-count re-materializes
   the address (worse, 81).
5. **Hoist `drain` out of the loop** (compute `slot->nextRegion` once before the loop,
   index `drain[i]`) so agbcc walks it `drain += 12` — baserom behaviour. drain-inside-loop
   caches sys instead.
6. **limit split via `limit2 = limit`** + an explicit `if (i < limit) { ... do { } while
   (i < limit2); }` entry-guard/do-while. This makes the entry check use limit in r1
   (scratch) and copies r1->r6 for the loop — the baserom's `cmp r3,r1; ... adds r6,r1`
   split. A plain `for (i<limit)` keeps limit in r6 for both checks (no split). THIS
   single change took byte_diff 33 -> 13.
7. **Asymmetric signed compares via goto** so the two `cmp #255` blocks don't tail-merge
   into one unsigned `bhi`: chanAcc `if (acc <= 0xff) goto found;` (ble->return) and
   swSlot `if (acc > 0xff) goto cont;` (bgt->continue), sharing `found: return 1;`.
   `acc` MUST be read into an `s32` local first (defeats agbcc's u16 range-tracking so the
   compare is SIGNED ble/bgt, not unsigned bhi; an `(s16)` cast over-corrects to ldrsh).
   A symmetric `if (acc <= 0xff) return 1` in both branches re-merges (one cmp, bhi).

## Drift — the irreducible 13 bytes (offsets 0xe-0x1b only)

Region 1, the prologue gpsp-copy scheduling:
- Baserom: `ldr r1,[pc](0x151); adds r2,r4,r1; movs r1,#2; ldrb r2; ands r1,r2;
  adds r5,r0` — keeps &gp in r0 THROUGH the flag check (0x151 in r1), copies r0->r5 LAST.
- Ours:    `adds r5,r0; ldr r0,[pc](0x151); adds r1,r4,r0; ...` — copies &gp to r5 FIRST,
  then reuses r0 for the 0x151 constant.

Both are valid; the copy `adds r5,r0` may live anywhere between the const def (0x02) and
gpsp's first use (count at L_184). agbcc's local-alloc gives the 0x151 const r0 (forcing
the early evacuation); the baserom gives it r1 (keeping &gp in r0, copy late). This is a
LOCAL-ALLOC quantity-ordering / reload register-selection decision (gcc_arm/local-alloc.c
`find_free_reg`/`qty_compare`), NOT global-alloc (global is already identical — instrumented
global.c confirms gpsp->r5, gpsp2->r7, drain->r5, limit->r6). The 13-byte diff is the
register-rename cascade of this one r0-vs-r1 choice + the copy position.

## Best-effort C (byte_diff 13, -fno-gcse)

```c
#include "sound.h"

u8 sub_08032148(void)
{
    SoundRequestSlot *slot = gpSoundSystem->slot;
    SoundSystem **gpsp = &gpSoundSystem;
    SoundSystem **gpsp2;
    SoundDrainEntry *drain;
    s32 i;
    s32 limit;
    s32 limit2;
    s32 acc;

    if (slot->flags & 2) {
        for (i = 0; i <= 15; i++) {
            if (slot->timers[i].cursor != NULL)
                return 1;
            if (slot->streams[i].cursor != NULL)
                return 1;
        }
    }

    i = 0;
    limit = (s32)(*gpsp)->count + 4;
    if (i < limit) {
        drain = (SoundDrainEntry *)slot->nextRegion;
        gpsp2 = gpsp;
        limit2 = limit;
        do {
            if (drain[i].live != 0)
                return 1;
            if ((*gpsp2)->channelSeqs[i].opPtr != NULL) {
                if (i <= 3) {
                    acc = (*gpsp2)->chanAcc[i];
                    if (acc <= 0xff)
                        goto found;
                } else {
                    acc = SOUND_SYSTEM_SW_SLOT(*gpsp2, i - 4)->accA;
                    if (acc > 0xff)
                        goto cont;
                found:
                    return 1;
                }
            }
        cont:
            i++;
        } while (i < limit2);
    }

    return 0;
}
```
