# sub_08032148 — deferred (reload copy-scheduling minimum, byte_diff 13)

Sound-engine "is anything still busy?" predicate at 0x08032148 (184 bytes,
src/system/sub_08032148.c). Reached entirely through `*gpSoundSystem`
(0x030065e0). Returns 1 while pending work remains, 0 once drained.

**Best result so far: byte_diff 13** (Round-6 Opus re-derivation reproduced the
Round-7 number exactly, from scratch, and confirmed it independently with a
correctly-configured permuter). The global register allocation matches the
baserom register-for-register (gpsp=r5→r7, drain=r5, limit=r6, slot=r4, i=r3)
and the structure is complete. The ONLY remaining diff is a single copy-insn
SCHEDULING artifact in the prologue (offsets 0xe-0x1b). Compile with `-fno-gcse`.

## Semantics (verified against agbcc offsets)

- `gpSoundSystem->slot`            -> [sys+0x118]  (SoundRequestSlot*)
- `slot->flags & 2`               -> (u8)[slot+0x151] & 2 (pool-load 0x151, NOT 0x118+0x39 fold)
- `slot->timers[i].cursor`        -> [slot + i*8]      (i 0..15, ble count-up)
- `slot->streams[i].cursor`       -> [slot+0x88 + i*8] (i 0..15)
- `gpSoundSystem->count`          -> (u8)[sys+0]; limit = count + 4
- `slot->nextRegion`              -> [slot+0x110] (SoundDrainEntry*, HOISTED out of loop,
                                     walked drain += 12 each iter)
- `drain->live`                   -> (u8)[drain+4]
- `gpSoundSystem->channelSeqs[i].opPtr` -> [ [sys+0x114] + i*16 ]
- i<=3: `gpSoundSystem->chanAcc[i]` (u16)[sys+0xac + i*2]; busy if `<= 0xff` (SIGNED ble)
- i>3 : `SOUND_SYSTEM_SW_SLOT(sys,i-4)->accA` (u16)[ [sys+0xc8] + i*64 - 0x100 + 0x34 ];
        busy if `<= 0xff` (path written as `> 0xff -> continue`, SIGNED bgt; uses the
        0xffffff00 = -256 pool constant for the `i*64 - 4*64` form)

## What CRACKED 156 -> 13 (load-bearing; the Best-effort C below already has all of these)

1. **`-fno-gcse`** REQUIRED — without it agbcc caches/folds `*gpsp` and uses
   `add #57` (0x118+0x39) instead of the `0x151` pool load.
2. **Read `slot` via the MACRO** `gpSoundSystem->slot`, then declare `gpsp =
   &gpSoundSystem` SECOND. This forces `0x030065e0` into a SCRATCH reg (r0) for the
   slot deref and makes gpsp a COPY of it (`adds r5,r0`) — the baserom shape.
   Declaring gpsp FIRST or reading `slot` via `(*gpsp)->slot` loads the const straight
   into r5 (NO copy) -> byte_diff 162. (Re-confirmed both this round.)
3. **Two-pointer alias `gpsp2 = gpsp`** in the loop preheader; loop body uses
   `(*gpsp2)->...`. Splits the &gp live range (r5 early, r7 in loop) = baserom's `adds r7,r5`.
4. **`gpsp` (NOT macro) for count/loop derefs** so `*gpsp` RELOADS from `[r5]`/`[r7]`.
5. **Hoist `drain` out of the loop** (compute once, index `drain[i]`) -> `drain += 12` walk.
6. **limit split via `limit2 = limit`** + entry-guard `if (i < limit) { do {} while (i < limit2); }`.
   This single change took byte_diff 33 -> 13.
7. **Asymmetric signed compares via goto** so the two `cmp #255` blocks don't tail-merge
   into one unsigned `bhi`. `acc` MUST be read into an `s32` local first.

## Drift — the irreducible 13 bytes (offsets 0xe-0x1b only): copy-insn schedule

Baserom prologue keeps `&gp` (the 0x030065e0 pool const) in **r0** THROUGH the flag
check, and copies it to its callee-saved home **r5 LAST**, immediately before the
cmp/beq:
```
0x0e ldr  r1,[pc] @0x151 ; 0x10 adds r2,r4,r1 ; 0x12 movs r1,#2
0x14 ldrb r2,[r2]        ; 0x16 ands r1,r2     ; 0x18 adds r5,r0   <-- COPY LAST
0x1a cmp  r1,#0
```
Ours emits the copy FIRST (so r0 frees up and the 0x151 const reuses r0):
```
0x0e adds r5,r0          ; 0x10 ldr r0,[pc] @0x151 ; 0x12 adds r1,r4,r0
0x14 movs r0,#2          ; 0x16 ldrb r1,[r1]       ; 0x18 ands r0,r1
0x1a cmp  r0,#0
```
Both are valid. The whole 13-byte diff is the register-rename cascade of this one
copy-position choice (which then forces 0x151→r0 vs →r1).

### ROOT CAUSE confirmed via RTL dumps (this round, `old_agbcc -da`)

The copy is RTL `insn 20: (set reg28 reg23)`, emitted in SOURCE ORDER between the
slot read (insn 17) and the flag-check insns (25-37). CSE merges the two
`0x030065e0` const materializations so insn 20 becomes a register-to-register copy
`reg28 = reg23`. **No pass (cse, regmove, sched1/sched2, flow, lreg, greg) reorders
insn 20** — verified it stays at position 17→20→25 through every dump. So the copy's
final asm position is fixed at the C statement position of `gpsp = &gpSoundSystem;`.

The contradiction that makes this unmatchable from pure C:
- To get the COPY (not a fresh pool load) the two const refs must CSE -> gpsp's
  source ref must be EARLY enough that reg23 (slot const, r0) is still live.
- To SCHEDULE the copy LATE (after the flag check, like baserom) the `gpsp = ...`
  statement must be AFTER the flag check in source.
- But moving `gpsp = ...` after the flag check pushes it past the timer loop, which
  clobbers all scratch regs, so reg23 is dead there -> CSE fails -> fresh pool load
  into r5 (byte_diff 54) or no-copy (162). Caching `flags` in a temp to bridge the gap
  re-enables the `gp+0x118+0x39` fold (byte_diff 63-125).

So early-CSE and late-schedule are mutually exclusive in C statement order, and agbcc
never sinks the independent copy across the basic-block boundary. This is the genuine
sharp local-alloc/scheduling minimum described in CLAUDE.md ("a near-match can still be
a sharp register-coloring local minimum no single source shape escapes").

## Best-effort C (byte_diff 13, -fno-gcse)

```c
#include "sound.h"

u8 sub_08032148(void)
{
    SoundRequestSlot *slot = gpSoundSystem->slot;
    SoundSystem **gpsp = &gpSoundSystem;
    SoundSystem **gpsp2;
    SoundDrainEntry *drain;
    s32 i;
    s32 limit;
    s32 limit2;
    s32 acc;

    if (slot->flags & 2) {
        for (i = 0; i <= 15; i++) {
            if (slot->timers[i].cursor != NULL)
                return 1;
            if (slot->streams[i].cursor != NULL)
                return 1;
        }
    }

    i = 0;
    limit = (s32)(*gpsp)->count + 4;
    if (i < limit) {
        drain = (SoundDrainEntry *)slot->nextRegion;
        gpsp2 = gpsp;
        limit2 = limit;
        do {
            if (drain[i].live != 0)
                return 1;
            if ((*gpsp2)->channelSeqs[i].opPtr != NULL) {
                if (i <= 3) {
                    acc = (*gpsp2)->chanAcc[i];
                    if (acc <= 0xff)
                        goto found;
                } else {
                    acc = SOUND_SYSTEM_SW_SLOT(*gpsp2, i - 4)->accA;
                    if (acc > 0xff)
                        goto cont;
                found:
                    return 1;
                }
            }
        cont:
            i++;
        } while (i < limit2);
    }

    return 0;
}
```
