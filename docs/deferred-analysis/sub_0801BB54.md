# sub_0801BB54 — deferred analysis (round 54)

`sub_0801BB54(u8 kind)` at 0x0801BB54, 808 bytes, asm slice
`asm/disasm_0x0801bb54.s`, dest `src/engine/sub_0801bb54.c`.

## Semantics (fully reverse-engineered — the logic is SOLVED)

Top-of-screen status-banner show/clear. `kind` selects the message:
- 0 / >4 : blank the line (16 spaces at ROM 0x081be01c)
- 1 : localized "LEVEL CLEARED" (5-string table at 0x081bdff4, EN/FR/DE/ES/IT),
       per-language index = `gIwram_34B0._data`
- 2 : world-specific cleared message via table-of-tables at 0x083087b4,
       indexed by `gIwram_34B0._data` then `(gGameStuff.pendingMode/3 - 1)`;
       guarded by `pendingMode%3==0 && pendingMode!=0`, else `pendingMode==16`
- 3 : "YOU WIN"  (ROM 0x081be008)
- 4 : "YOU LOSE" (ROM 0x081be010)

Setup: copies the 5-ptr localized table to a stack array (ldmia/stmia struct
copy), calls `text_0800e76c()`, saves BG palette word at 0x050001da into r9
(restored at cleanup). `pendingMode==15` -> early epilogue (skip everything).
`yArg=10` (the BE7C `y` arg) held in r8 across the whole function.

Centering: scan the string counting displayable chars until `|` (0x7c);
a `[` (0x5b) control code advances the byte index by 4 instead of 1; then
`x = (30 - len) / 2`.

Wait loops (per case): pump `sub_08017000()` + `gIwram_5398 = sub_080004C4()`
until `sub_08032148()` falls / `gIwram_5398 != 0` / a frame-counter timeout
(`sub_08000900() - startFrame > 120` cases 1-2, `> 179` cases 3-4). Cases 1-2
have a two-phase wait gated by `gIwram_34B4._data[0]`; the call ORDER inside the
two phases differs between case 1 (17000 then 4c4) and case 2 (4c4 then 17000)
and case 2 has an extra discarded `sub_08000900()` after its BE7C draw — all
reproduced in the best-effort C below. The shared `done:` tail runs
`sub_08020BAC(); gStructAt3003570 |= 2;` before the cleanup blank-line draw.

All callees resolve to existing symbols: `text_0800e76c` (C), `sub_0801BE7C`
(text drawer, 7-arg `(str,len,x,y,278,14,3)` — established sibling signature),
`sub_080004C4` (u16 key/event read), `sub_08017000`, `sub_08032148` (u32),
`sub_08000900` (u32 frame counter), `sub_08020BAC`, and the in-ROM libgcc
helpers `__udivsi3`(0x08033ee4) / `__umodsi3`(0x08033f5c) for the `/3`,`%3`.
(The decomp_brief "UNPEELED" tags for 0x0800e76c / 0x08033f5c / 0x08033ee4 are
FALSE — all three already have linkable symbols; no peel is needed.)

## Drift

- best byte_diff: 637, diff_count: 191 (str pinned to r4). Without any pin:
  byte_diff 644 / 205. With `-ffixed-r1`: byte_diff 623 / 191 (no rodata, but
  still not 0 — and the flag is debt).
- The C is LOGICALLY CORRECT: there are NO structural opcode mismatches.
  Every remaining diff is a single, pervasive REGISTER-COLORING shift plus the
  branch-offset cascade from one extra `adds rN,r0,#0` shuffle instruction.
- ROOT CAUSE (the wall): the baserom compilation reserves FOUR low
  callee-saved registers `push {r4,r5,r6,r7,lr}`; agbcc (OLD_AGBCC default)
  reserves only THREE `push {r4,r5,r6,lr}` for every source shape I tried, and
  packs the string-scan vars (str/len/base) into scratch r1/r3 instead of
  spreading them across r4/r6/r7 the way the target does. The target keeps
  `str`=r4, `len`=r6, `base(&gIwram_34B0)`=r7, `pendingMode`=r5 simultaneously
  live in the scan; agbcc colors `str`=r4 (after the pin), `len`/`base` into
  scratch, and NEVER promotes a pseudo to hard r7 — an `asm("r7")` pin is
  treated as a caller-saved temp (reloaded), it does NOT add r7 to the saved
  push set. This is global register allocation (gcc_arm/global.c /
  local-alloc.c `QTY_CMP_PRI` priority = floor_log2(refs)*refs*size /
  liverange), a decision no C SHAPE I found reaches.

### Levers tried (all fail to promote r7 / reach 0)

- pin `kind`->r4 (helps: 654->644), then ALSO pin `str`->r4 sharing the dead
  `kind` range (helps: 644->637, str now matches r4). THIS IS THE BEST-EFFORT
  C below.
- pin `len`->r6 : WORSE (648/225).
- pin `base(&gIwram_34B0)`->r7 (struct-ptr local, live across the scan): r7
  used only as a reloaded TEMP, prologue still pushes 3 regs; byte_diff 661.
- nested-scope pin trio str(r4)/len(r6)/base(r7): WORSE (669/230); the high
  pins shove pendingMode to r6 and r7 is still a temp.
- pin `pendingMode`->r5 : no r7 promotion (653/217).
- cache vs re-read pendingMode: re-read gives lower byte_diff (636) but higher
  diff_count (221) and loses the top `ldrb r5,[r0,#10]`; cache is correct.
- compiler swap to newer AGBCC: WORSE (only 2 callee-saved, 649/219).
- flag sweep (default OLD_AGBCC): -fno-strength-reduce / -fno-gcse /
  -fcaller-saves / -fno-cse-follow-jumps / -fno-rerun-cse-after-loop / -O1 /
  -ffixed-r2 / -ffixed-r3 : all ~637-649, none promote r7.
  -fforce-addr -fno-expensive-optimizations -fno-gcse (dispatcher recipe):
  WORSE (649, drops to 2 callee-saved).
  -ffixed-r1 (or -ffixed-r1/-ffixed-r3 combos): byte_diff 623, diff_count 191,
  no rodata — the single most promising flag, but still not 0 and not r7.
- corpus history search for the `cmp rN,#124` (`|`) scan idiom: 0 hits.

extern u16 gIwram_5398;

#define BG_PAL_1DA (*(vu16 *)0x050001DA)

/* Five localized "LEVEL CLEARED|" strings (EN/FR/DE/ES/IT), copied to the
 * stack so the per-language pointer can be selected by gIwram_34B0._data. */

    const u8 *p[5];

#define LEVEL_CLEARED_TABLE (*(const MsgTable *)0x081BDFF4)

void sub_0801BB54(u8 kindParam)
{

    MsgTable msgs;
    register const u8 *str asm("r4");
    u8 len;
    u8 i;
    u8 x;
    u8 idx;
    u32 startFrame;
    u8 pendingMode;
    register u16 savedPal asm("r9");
    register u32 yArg asm("r8");

    kind = kindParam;
    msgs = LEVEL_CLEARED_TABLE;

    text_0800e76c();
    savedPal = BG_PAL_1DA;
    yArg = 10;
    pendingMode = gGameStuff.pendingMode;

    if (pendingMode == 15)

    switch (kind) {

        goto cleanup;

    case 1:

        i = 0;
        if (str[0] != '|') {
            do {
                i = (u8)((str[i] == '[') ? i + 4 : i + 1);
                len = (u8)(len + 1);
            } while (str[i] != '|');

        x = (u8)((30 - len) / 2);
        sub_0801BE7C(msgs.p[gIwram_34B0._data], len, x, yArg, 278, 14, 3);

                sub_08017000();
                gIwram_5398 = sub_080004C4();

        if (gIwram_5398 != 0)
            goto done;
        do {
            gIwram_5398 = sub_080004C4();
            sub_08017000();
            if (sub_08000900() - startFrame > 120)
                gIwram_5398 = 16;
        } while (gIwram_5398 == 0);

            if (pendingMode != 16)

        len = 0;
        i = 0;

                len = (u8)(len + 1);

        x = (u8)((30 - len) / 2);
