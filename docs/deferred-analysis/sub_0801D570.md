# sub_0801D570 — deferred analysis

Range `[0x0801D570, 0x0801D880)` (784 B, thumb). Dest `src/engine/sub_0801d570.c`.
classify_unmatchable verdict: **ATTEMPT_MATCH** (advisory: r8/r9 held across
`bl sub_080004C4`). NOT STRONG_UNMATCHABLE — do NOT ship NAKED.

## What it is

Credits-roll renderer. Walks the per-room state's tilemap-encoded text stream
(`state[12]` cursor into `sCreditsTilemapEng` = ROM 0x081BEE64), drawing one
column per step into the double-buffered OBJ tilemap at `state[20]` /
`state[36]`, blinking a cursor at `state[20]+0x6C` (0xE0E4 / 0) between draws,
polling `sub_080004C4()` -> `gIwram_5398` (0x03005398) for the advance/skip key
(16 = advance, 32 = skip). Stream markers:
- `0xFFFF` end-of-page (reset / page-flip / advance)
- `0xFFFE` page-wait (WAIT_A: always aborts on key)
- `0xFFFD` glyph-pair (look up two tiles from `sCreditsTilemapEng` at
  `(ch + 0xFFFF1F19)*3 + {1,2}`)
- `0xFFFC` (-4) / `0xFFFB` (-5) scene-command (WAIT_B): bump `*(u8*)0x03003541`,
  set `*(u32*)0x03003544` = 1/0, call `sub_0801D438` / `sub_0801D4CC`.
Returns `0xFE` on skip (abort path), `0` otherwise.
Page-flip (WAIT_C + pageflip) DMA-clears the old OBJ buffers via REG_DMA3
(cnt 0x81000017) at oldS20, oldS20+0x40, oldS36, oldS36+0x40.

Struct `state = (u8*)0x03006440`: +12 cursor(u16*), +20 dst-A, +36 dst-B,
+48 col(u16), +50 page-flip flag(u16). `gGameStuff._unk00` (0x03005330) is the
frame counter; redraw gate `frame - saved > 3`.

CONTROL FLOW + SEMANTICS fully solved and verified against the asm. The
Best-effort C below is structurally faithful and readable and COMPILES.

## Drift

Best **byte_diff 612-616** (size 664 vs target 668 = my build is 2 instructions
SHORT). diff_count ~377, but that count is INFLATED: most of it is branch-target
offset deltas caused by the 4-byte size difference, not independent mismatches.

Required prologue (proves the pin set): target does `mov r7,r9; mov r6,r8;
push {r6,r7}` — it saves BOTH r8 AND r9. So `out` (r9) and `outw` (r8) MUST be
two SEPARATE pinned values. A fully-unpinned build collapses them into one
register (`push {r7}` saving only r8) and can NEVER match. The 5-pin set
(state=r6, out=r9, outw=r8, saved=r5, tilemap=r7) IS required and IS correct.

### The one residual divergence (ROOT CAUSE, confirmed via instrumented agbcc)

`gGameStuff._unk00`'s base address (0x03005330) is read twice per wait loop
(for `frame - saved` and for `saved = frame`). The TARGET gives this base a
**caller-saved register (r2) that it SPILLS to `[sp,#4]` across the bl** — it
does this in ALL THREE wait loops (6 `[sp,#4]` refs). My build only spills in
ONE wait loop (WAIT_B); in WAIT_A and WAIT_C it instead **reuses r7** (the
tilemap register) to hold the base with no spill (2 `[sp]` refs).

Why: `gGameStuff` base spills to r2 only when ALL SIX callee-saved regs
(r4 toggle, r5 saved, r6 state, r7 tilemap, r8 outw, r9 out) are busy across
the bl. In the target r7 is busy in every wait loop:
- WAIT_A: r7 = tilemap (reserved by its global live interval [1d592,1d706],
  which physically spans WAIT_A even though tilemap is DEAD on WAIT_A's
  abort-only exit path).
- WAIT_B: r7 = a redundant SECOND copy of `state` (1d636), needed for the
  post-loop `c = *cursor` re-read.
- WAIT_C: r7 = `state` (1d7a0).
In MY build, agbcc's per-path liveness correctly proves tilemap DEAD in WAIT_A
(it exits to abort) and in WAIT_C (physically past the tilemap use at 1d706),
so the LOCAL allocator frees r7 and hands it to the gGameStuff base — no spill.

### Instrumented-agbcc evidence (private debug old_agbcc, AGBCC_DUMP_ALLOC)

global.c find_reg ASSIGN trace on my 616 build:
```
ASSIGN pseudo 27  -> hardreg 7 (refs=11 live_len=84)   # tilemap, owns r7 globally
ASSIGN pseudo 47  -> hardreg 7 (refs=5  live_len=60)   # gGameStuff base WAIT_A  (REUSES r7)
ASSIGN pseudo 171 -> hardreg 7 (refs=5  live_len=58)   # gGameStuff base WAIT_C  (REUSES r7)
ASSIGN pseudo 68  -> hardreg 2 (refs=5  live_len=60)   # gGameStuff base WAIT_B  (r2, MATCHES)
ASSIGN pseudo 29  -> hardreg 4 (refs=27 live_len=196)  # state
```
So the WAIT_B base (pseudo 68) already matches the target (r2). Only the WAIT_A
and WAIT_C bases (47, 171) diverge: they reuse the dead tilemap reg r7 instead
of spilling r2. To match, tilemap's r7 must be GLOBALLY reserved across WAIT_A
and WAIT_C even though those paths never use it — a CONSERVATIVE global
allocation this agbcc snapshot does not produce (it does precise per-path
liveness; the baserom compiler did not).

### Levers tried this session (none cracked it; all left byte_diff 608-620)
- Pin `saved=r5` (matches target's saved reg) instead of `cursor=r5`: 616, but
  gGameStuff base then grabs r7 (dead tilemap) in WAIT_A.
- `register u32 *frame asm("r2")` per wait loop to force the base caller-saved:
  608, but agbcc still didn't spill it across the bl in WAIT_A.
- `asm volatile("" ::"r"(tilemap))` keep-alive: after the bl, before the bl
  (loop top), and at the `abort:` label — NONE made tilemap occupy r7 across
  the WAIT_A bl (the no-op barrier rematerializes tilemap into a scratch reg).
- A `register u8 *s asm("r7") = state;` state-copy inside WAIT_B/WAIT_C (to
  mimic the target's r7=state-copy): 620, did not flip WAIT_C and broke WAIT_A.
- Volatile-laundered double gGameStuff reads (`*(volatile u32*)0x03005330`):
  616, forces fresh loads but does not change the base register class.
- Flag sweep on the private old_agbcc: `-fcaller-saves`, `-fno-caller-saves`
  (REMOVES spills, wrong way), `-fno-local-alloc`, `-fno-schedule-insns{,2}`,
  `-fno-cse-follow-jumps`, `-fno-thread-jumps`, `-fno-function-cse`,
  `-fno-omit-frame-pointer` — NONE raised the spill count from 2 to the
  target's 6.
- Compiler swap (newer AGBCC_BIN) tried in the prior session: 633, no change.
- Permuter UNAVAILABLE in worktree (no .venv, deps missing) AND 616 is far
  beyond its ~40 useful range (it mutates statement order/scope, not the
  allocator's global-vs-local liveness precision).

### Where the diff IS small
The pageflip/DMA-clear block (4x REG_DMA3 + buffer swap) is nearly
byte-identical. The WAIT_B wait loop (gGameStuff base = r2 + spill) matches.

## Next-attempt suggestions

  The genuine fix is to find a SOURCE shape where tilemap (or any 6th value) is

## Best-effort C

```c
#include "game.h"
#include "macros.h"
#include "types.h"

extern u16 sub_080004C4(void);
extern void sub_0801D438(u8 arg);
extern void sub_0801D4CC(u8 arg);

extern u16 gIwram_5398;
extern const u16 sCreditsTilemapEng[];

#define STATE ((u8 *)0x03006440)

/* Credits-roll renderer: walk state[12] cursor over sCreditsTilemapEng,
 * draw one column per step into the double-buffered OBJ tilemap
 * (state[20]/state[36]), blink a cursor (state[20]+0x6C) while polling
 * sub_080004C4 for the advance/skip key (gIwram_5398: 16=advance, 32=skip).
 * Markers: 0xFFFF end-page, 0xFFFE page-wait, 0xFFFD glyph-pair,
 * 0xFFFC/0xFFFB scene-command. Returns 0xFE on skip. */
u16 sub_0801D570(void)
{
    register u8 *state asm("r6");
    register u16 *out asm("r9");
    register u16 *outw asm("r8");
    register u32 saved asm("r5");
    register const u16 *tilemap asm("r7");
    u16 *cursor;
    u16 c;
    u8 toggle;
    u8 *cmd;
    u8 *dst;
    u16 col;
    u16 *tmp;

    state = STATE;
    out = &gIwram_5398;
    outw = out;

    cursor = *(u16 **)(state + 12);
    if (*cursor == 0xFFFF) {
        goto reset;
    }

    tilemap = sCreditsTilemapEng;

loop:
    cursor = *(u16 **)(state + 12);
    c = *cursor;

    if (c == 0xFFFE) {
        u16 k;

        saved = 0;
        toggle = 0;
        k = *out;
        if (k == 16 || k == 32) {
            goto abort;
        }
        for (;;) {
            if (gGameStuff._unk00 - saved > 3) {
                *(u16 *)(*(u32 *)(state + 20) + 0x6C) = toggle ? 0xE0E4 : 0;
                toggle = toggle ? 0 : 1;
                saved = gGameStuff._unk00;
                *outw = sub_080004C4();
            }
            k = *outw;
            if (k == 16 || k == 32) {
                goto abort;
            }
        }
    }

    if ((u16)(c + 5) <= 1) {
        u16 k;

        *outw = 0;
        saved = 0;
        toggle = 0;
        for (;;) {
            if (gGameStuff._unk00 - saved > 3) {
                *(u16 *)(*(u32 *)(state + 20) + 0x6C) = toggle ? 0xE0E4 : 0;
                toggle = toggle ? 0 : 1;
                saved = gGameStuff._unk00;
                *outw = sub_080004C4();
            }
            k = *outw;
            if (k == 16) {
                break;
            }
            if (k == 32) {
                goto abort;
            }
        }

        c = *cursor;
        if (c == 0xFFFB) {
            cmd = (u8 *)0x03003540;
            *(u32 *)(cmd + 4) = 0;
            cmd[1]++;
            sub_0801D4CC(cmd[1]);
            goto endcheck;
        }
        if (c == 0xFFFC) {
            cmd = (u8 *)0x03003540;
            *(u32 *)(cmd + 4) = 1;
            cmd[1]++;
            sub_0801D438(cmd[1]);
        }
        goto endcheck;
    }

    if (c == 0xFFFD) {
        u16 ch;
        u32 idx;

        cursor = *(u16 **)(state + 12);
        *(u16 **)(state + 12) = cursor + 1;
        dst = *(u8 **)(state + 20);
        col = *(u16 *)(state + 48);
        ch = cursor[1];
        idx = ch + 0xFFFF1F19;
        *(u16 *)(dst + col * 2) = tilemap[idx * 3 + 1];
        *(u16 *)(dst + col * 2 + 0x40) = tilemap[idx * 3 + 2];
        *(u16 **)(state + 12) = cursor + 2;
    } else {
        dst = *(u8 **)(state + 20);
        col = *(u16 *)(state + 48);
        *(u16 *)(dst + col * 2) = 0;
        *(u16 *)(dst + col * 2 + 0x40) = c;
        *(u16 **)(state + 12) = cursor + 1;
    }

    *(u16 *)(state + 48) = *(u16 *)(state + 48) + 1;
    if (**(u16 **)(state + 12) == 0xFFFF) {
        goto endcheck;
    }
    goto loop;

endcheck:
    cursor = *(u16 **)(state + 12);
    if (*cursor == 0xFFFF) {
        goto reset;
    }
    goto final_zero;

reset:
    *(u16 *)(state + 48) = 0;
    if (*(u16 *)(state + 50) != 0) {
        goto page2;
    }
    *(u16 *)(state + 50) = 1;
    tmp = *(u16 **)(state + 36);
    *(u16 **)(state + 36) = *(u16 **)(state + 20);
    *(u16 **)(state + 20) = tmp;

final_advance:
    *(u16 **)(state + 12) = *(u16 **)(state + 12) + 1;
final_zero:
    *out = 0;
    return 0;

page2:
    saved = 0;
    toggle = 0;
    {
        u16 k;

        k = *out;
        if (k == 16 || k == 32) {
            goto pageflip;
        }
        for (;;) {
            if (gGameStuff._unk00 - saved > 3) {
                *(u16 *)(*(u32 *)(state + 20) + 0x6C) = toggle ? 0xE0E4 : 0;
                toggle = toggle ? 0 : 1;
                saved = gGameStuff._unk00;
                *out = sub_080004C4();
            }
            k = *out;
            if (k == 32) {
                goto abort;
            }
            if (k == 16) {
                break;
            }
        }
    }

pageflip:
    {
        u8 *oldS20;
        u8 *oldS36;
        vu16 fill;
        vu32 *dma;

        *(u16 *)(state + 50) = 0;
        oldS36 = *(u8 **)(state + 36);
        oldS20 = *(u8 **)(state + 20);
        *(u8 **)(state + 36) = oldS20;
        *(u8 **)(state + 20) = oldS36;

        dma = (vu32 *)0x040000D4;

        fill = 0;
        dma[0] = (u32)&fill;
        dma[1] = (u32)oldS20;
        dma[2] = 0x81000017;
        (void)dma[2];

        fill = 0;
        dma[0] = (u32)&fill;
        dma[1] = (u32)(oldS20 + 0x40);
        dma[2] = 0x81000017;
        (void)dma[2];

        fill = 0;
        dma[0] = (u32)&fill;
        dma[1] = (u32)oldS36;
        dma[2] = 0x81000017;
        (void)dma[2];

        fill = 0;
        dma[0] = (u32)&fill;
        dma[1] = (u32)(oldS36 + 0x40);
        dma[2] = 0x81000017;
        (void)dma[2];
    }
    goto final_advance;

abort:
    *out = 0;
    return 0xFE;
}
```
