# sub_0801D570 — deferred analysis

Range `[0x0801D570, 0x0801D880)` (784 B, thumb). Dest `src/engine/sub_0801d570.c`.
classify_unmatchable verdict: **ATTEMPT_MATCH** (advisory: r8/r9 held across the
`bl sub_080004C4`). NOT a STRONG_UNMATCHABLE class — do NOT ship NAKED.

## What it is

Credits-roll renderer. Walks the per-room state's tilemap-encoded text stream
(`state[12]` cursor into `sCreditsTilemapEng` = ROM 0x081BEE64), drawing one
column per step into the double-buffered OBJ tilemap at `state[20]` /
`state[36]`, blinking a cursor at `state[20]+0x6C` (0xE0E4 / 0) between draws,
polling `sub_080004C4()` -> `gIwram_5398` (0x03005398) for the advance/skip key
(16 = advance, 32 = skip). Stream markers:
- `0xFFFF` end-of-page (reset / page-flip / advance)
- `0xFFFE` page-wait (wait then return 0xFE)
- `0xFFFD` glyph-pair (look up two tiles from `sCreditsTilemapEng` at
  `(ch + 0xFFFF1F19)*3 + {1,2}`)
- `0xFFFC` (-4) / `0xFFFB` (-5) scene-command: bump `*(u8*)0x03003541`, set
  `*(u32*)0x03003544` = 1/0, call `sub_0801D438` / `sub_0801D4CC`.
Returns `0xFE` on skip (out==16 abort path), `0` otherwise.

Struct: `state = (u8*)0x03006440`. Offsets: +12 cursor (u16*), +20 dst-A ptr,
+36 dst-B ptr (swapped on page flip), +48 column counter (u16, 0x30), +50
page-flip flag (u16, 0x32). `gGameStuff._unk00` (0x03005330+0) is the frame
counter; redraw gate is `frame - saved > 3`. Page-flip DMA-clears the old
buffers via REG_DMA3 (cnt 0x81000017 = 0x17 words) at oldS20, oldS20+0x40,
oldS36, oldS36+0x40 from a stack halfword of 0.

The CONTROL FLOW / SEMANTICS are fully solved and verified against the asm.
The Best-effort C below is structurally faithful and readable.

## Drift

Best **byte_diff 612** (size 664 vs target 668), diff_count ~400. The function
COMPILES and is structurally correct — the residual is a single, robust
**global register-coloring** divergence I could not defeat with any available
lever.

Register map the target uses (all 6 callee-saved-ish regs live across the
wait-loop `bl`): state=r6, cursor/saved=r5 (shared), toggle=r4, tilemap=r7,
out=r9 (home), out-copy=r8. Because all of r4-r9 are occupied, the
`&gGameStuff` address (read twice per wait iteration) has **no callee-saved
register** and is forced into caller-saved **r2, spilled to `[sp,#4]` across
the bl** in ALL THREE wait loops (1d606, 1d67a, 1d7de).

My build reproduces this in exactly ONE wait loop (WAIT_B / the 0xFFFB-0xFFFC
handler at offset 0xee — it leads back to `loop`, so tilemap is provably live
and r7 stays reserved). But in the other two wait loops:
- WAIT_A (0xFFFE handler -> always `goto abort`)
- WAIT_C (page2 handler -> `goto pageflip` -> return)
tilemap is **dead** (those paths never use it again), so agbcc's
path-sensitive liveness frees r7 and gives it to `saved`/`cursor`/gGameStuff
locally — `movs r7, #0` / `ldr r7,=gGameStuff` instead of spilling gGameStuff
to the stack. That single difference cascades the whole instruction stream.

Root cause: agbcc reserves r7 for `tilemap` only across its live range
(global.c `find_reg` honours per-path liveness); the baserom's allocator
reserved r7 for tilemap across the WHOLE loop region including the dead
0xFFFE/page2 paths. To match, tilemap must be globally reserved (live on every
path of the loop), which it is not because the 0xFFFE and page2 paths exit
without using it.

### Levers tried (none cracked it)
- Register pins, every combination: state=r6, out=r9, out-copy=r8 (outw),
  cursor=r5, saved=r5, tilemap=r7. Best combo (state=r6/out=r9/outw=r8/
  cursor=r5/tilemap=r7-pin, saved unpinned) -> **612**. Pinning saved=r5 too,
  or toggle=r4, regressed (648). A `register asm("r7")` pin does NOT globally
  reserve r7 — agbcc still reuses it on dead paths.
- Referencing the out cell as the global `gIwram_5398` directly (no `out` ptr):
  WORSE (731) — agbcc re-loads the address everywhere and never homes it in r9.
  The hoisted `out` pointer (r9) IS required.
- Per-block local re-derivation of bases; moving the `outw`/`tilemap` inits
  before/after the first `*cursor==0xFFFF` check; first check via STATE macro
  inline (folds STATE+12 into a 0x0300644C pool literal — WRONG, target keeps
  `[r0,#12]`). All ~616-633.
- Caching the poll result `k = *out` to a single read (matches the target's
  single-load/two-cmp pre-check & break-check) — this DID help, 633 -> 612, and
  is kept in the best-effort C.
- Codegen flags: -fno-gcse, -fno-caller-saves, -fno-cse-follow-jumps,
  -fno-expensive-optimizations, -fno-force-mem, -fno-strength-reduce — all 629.
- Compiler swap to the newer agbcc (AGBCC_BIN) — 633, no change.
- -3-branch index restructure (split idx*3+1 / idx*3+2 to raise tilemap
  ref-count so global-alloc gives it r7) — agbcc CSE-folds it back to
  base+offset, no ref-count gain.

### Where the diff IS small
The pageflip/DMA-clear block (offset 0x23e..0x276 vs target 1d80c..1d842) is
nearly byte-identical — the 4x REG_DMA3 setup + buffer swap is correct.

## Best-effort C

```c
#include "game.h"
#include "macros.h"
#include "types.h"

extern u16 sub_080004C4(void);
extern void sub_0801D438(u8 arg);
extern void sub_0801D4CC(u8 arg);

extern u16 gIwram_5398;
extern const u16 sCreditsTilemapEng[];

#define STATE ((u8 *)0x03006440)

/* Credits-roll renderer: walk the per-room state's tilemap-encoded text
 * stream (state[12] cursor), drawing one column per step into the
 * double-buffered OBJ tilemap at state[20] / state[36], blinking a cursor
 * (state[20]+0x6C) between draws while polling sub_080004C4 for the
 * advance/skip key (gIwram_5398: 16 = advance, 32 = skip). Stream markers:
 * 0xFFFF end-page, 0xFFFE page-wait, 0xFFFD glyph-pair, 0xFFFC/0xFFFB
 * scene-command (sub_0801D438 / sub_0801D4CC). Returns 0xFE on skip. */
u16 sub_0801D570(void)
{
    register u8 *state asm("r6");
    register u16 *out asm("r9");
    register u16 *outw asm("r8");
    register u16 *cursor asm("r5");
    u16 c;
    u32 saved;
    u8 toggle;
    u8 *cmd;
    u8 *dst;
    u16 col;
    u16 *tmp;
    register const u16 *tilemap asm("r7");

    state = STATE;
    out = &gIwram_5398;
    outw = out;

    cursor = *(u16 **)(state + 12);
    if (*cursor == 0xFFFF) {
        goto reset;
    }

    tilemap = sCreditsTilemapEng;

loop:
    cursor = *(u16 **)(state + 12);
    c = *cursor;

    if (c == 0xFFFE) {
        u16 k;

        saved = 0;
        toggle = 0;
        k = *out;
        if (k == 16 || k == 32) {
            goto abort;
        }
        for (;;) {
            if (gGameStuff._unk00 - saved > 3) {
                *(u16 *)(*(u32 *)(state + 20) + 0x6C) = toggle ? 0xE0E4 : 0;
                toggle = toggle ? 0 : 1;
                saved = gGameStuff._unk00;
                *outw = sub_080004C4();
            }
            k = *outw;
            if (k == 16 || k == 32) {
                goto abort;
            }
        }
    }

    if ((u16)(c + 5) <= 1) {
        u16 k;

        *outw = 0;
        saved = 0;
        toggle = 0;
        for (;;) {
            if (gGameStuff._unk00 - saved > 3) {
                *(u16 *)(*(u32 *)(state + 20) + 0x6C) = toggle ? 0xE0E4 : 0;
                toggle = toggle ? 0 : 1;
                saved = gGameStuff._unk00;
                *outw = sub_080004C4();
            }
            k = *outw;
            if (k == 16) {
                break;
            }
            if (k == 32) {
                goto abort;
            }
        }

        c = *cursor;
        if (c == 0xFFFB) {
            cmd = (u8 *)0x03003540;
            *(u32 *)(cmd + 4) = 0;
            cmd[1]++;
            sub_0801D4CC(cmd[1]);
            goto endcheck;
        }
        if (c == 0xFFFC) {
            cmd = (u8 *)0x03003540;
            *(u32 *)(cmd + 4) = 1;
            cmd[1]++;
            sub_0801D438(cmd[1]);
        }
        goto endcheck;
    }

    if (c == 0xFFFD) {
        u16 ch;
        u32 idx;

        cursor = *(u16 **)(state + 12);
        *(u16 **)(state + 12) = cursor + 1;
        dst = *(u8 **)(state + 20);
        col = *(u16 *)(state + 48);
        ch = cursor[1];
        idx = ch + 0xFFFF1F19;
        *(u16 *)(dst + col * 2) = tilemap[idx * 3 + 1];
        *(u16 *)(dst + col * 2 + 0x40) = tilemap[idx * 3 + 2];
        *(u16 **)(state + 12) = cursor + 2;
    } else {
        dst = *(u8 **)(state + 20);
        col = *(u16 *)(state + 48);
        *(u16 *)(dst + col * 2) = 0;
        *(u16 *)(dst + col * 2 + 0x40) = c;
        *(u16 **)(state + 12) = cursor + 1;
    }

    *(u16 *)(state + 48) = *(u16 *)(state + 48) + 1;
    if (**(u16 **)(state + 12) == 0xFFFF) {
        goto endcheck;
    }
    goto loop;

endcheck:
    cursor = *(u16 **)(state + 12);
    if (*cursor == 0xFFFF) {
        goto reset;
    }
    goto final_zero;

reset:
    *(u16 *)(state + 48) = 0;
    if (*(u16 *)(state + 50) != 0) {
        goto page2;
    }
    *(u16 *)(state + 50) = 1;
    tmp = *(u16 **)(state + 36);
    *(u16 **)(state + 36) = *(u16 **)(state + 20);
    *(u16 **)(state + 20) = tmp;

final_advance:
    *(u16 **)(state + 12) = *(u16 **)(state + 12) + 1;
final_zero:
    *out = 0;
    return 0;

page2:
    saved = 0;
    toggle = 0;
    {
        u16 k;

        k = *out;
        if (k == 16 || k == 32) {
            goto pageflip;
        }
        for (;;) {
            if (gGameStuff._unk00 - saved > 3) {
                *(u16 *)(*(u32 *)(state + 20) + 0x6C) = toggle ? 0xE0E4 : 0;
                toggle = toggle ? 0 : 1;
                saved = gGameStuff._unk00;
                *out = sub_080004C4();
            }
            k = *out;
            if (k == 32) {
                goto abort;
            }
            if (k == 16) {
                break;
            }
        }
    }

pageflip:
    {
        u8 *oldS20;
        u8 *oldS36;
        vu16 fill;
        vu32 *dma;

        *(u16 *)(state + 50) = 0;
        oldS36 = *(u8 **)(state + 36);
        oldS20 = *(u8 **)(state + 20);
        *(u8 **)(state + 36) = oldS20;
        *(u8 **)(state + 20) = oldS36;

        dma = (vu32 *)0x040000D4;

        fill = 0;
        dma[0] = (u32)&fill;
        dma[1] = (u32)oldS20;
        dma[2] = 0x81000017;
        (void)dma[2];

        fill = 0;
        dma[0] = (u32)&fill;
        dma[1] = (u32)(oldS20 + 0x40);
        dma[2] = 0x81000017;
        (void)dma[2];

        fill = 0;
        dma[0] = (u32)&fill;
        dma[1] = (u32)oldS36;
        dma[2] = 0x81000017;
        (void)dma[2];

        fill = 0;
        dma[0] = (u32)&fill;
        dma[1] = (u32)(oldS36 + 0x40);
        dma[2] = 0x81000017;
        (void)dma[2];
    }
    goto final_advance;

abort:
    *out = 0;
    return 0xFE;
}
```
