## Function summary

HBlank IRQ handler at 0x0800088C. Per scanline (while VCOUNT <= 0xe3 = 227):
- Looks up per-scanline BG0 scroll delta from byte table at 0x030053a0[scanline]
- Adds to base BG0 scroll from 0x03003550[0] → writes to REG_BG0HOFS (0x04000010)
- Looks up per-scanline BG1 scroll delta from byte table at 0x03003610[scanline]
- Adds to base BG1 scroll from 0x03003550[2] → writes to REG_BG1HOFS (0x04000014)
- Always writes REG_IF = 2 (acknowledge HBlank IRQ)

Classic per-line parallax raster effect.

## Root cause

old_agbcc's register allocator ALWAYS uses r4 (first callee-saved) as the temp
for the first pool constant load when r1, r2, r3 appear to be in use (r1=dst,
r2=bgScrollBase, r3=scanline). After `lsrs r3, r0, #24`, r0 IS dead but
old_agbcc doesn't detect this — it was the source for lsrs which means old_agbcc
keeps tracking it as "live" in its live-range analysis.

For block 2, old_agbcc successfully uses r0 for the pool constant (r3 is
overwriteable) but differs in which register gets the tbl ptr vs bgScrollBase value.

## Next lever to try (round 3)

The pattern is stubborn: old_agbcc won't choose r0 for the block 1 pool constant.

1. **Check old_agbcc's register allocator source** — look at `local-alloc.c` in
   tools/agbcc-src/. The rule that causes r4 to be preferred over r0 for pool
   constants when r3 is live may have a simple bypass.

2. **Block 1 pointer pre-computation in a volatile** — declare
   `volatile u8 *p = (u8*)0x030053a0 + scanline;` — the volatile may prevent
   old_agbcc from optimizing the pool load into r4.

3. **Inline asm barrier** — `asm volatile("" : : : "r0", "r4")` between the
   VCOUNT read and the block 1 expression to force old_agbcc to see r0 as
   clobbered and r4 as clobbered.

4. **Split into TWO functions** — if the two-block structure is compiled as two
   separate called functions, old_agbcc might allocate r0 for the pool constant
   in each (since they'd each be fresh allocation contexts).

```c
/* HBlank IRQ handler — per-scanline parallax raster effect for BG0/BG1. */
void sub_0800088C(void)
{
    u8 scanline;
    register vu16 *dst asm("r1");
    register u16 *bgScrollBase asm("r2");

    scanline = (u8)REG_VCOUNT;
    if (scanline > 0xe3) {
        REG_IF = IRQ_HBLANK;
        return;
    }
    dst = (vu16 *)0x04000010;
    bgScrollBase = (u16 *)0x03003550;
    *dst = bgScrollBase[0] + *(u8 *)(0x030053a0 + scanline);
    dst += 2;
    *dst = bgScrollBase[2] + *(u8 *)(0x03003610 + scanline);
    REG_IF = IRQ_HBLANK;
}
```
