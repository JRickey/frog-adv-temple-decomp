# sub_0801549C — deferred analysis (round 58)

Scene-transition state-machine dispatcher at 0x0801549c (340 bytes). A dense
`switch` over `gIwram_3610.state` (byte at IWRAM 0x03003610+0, cases 0..4) that
lowers to agbcc's casesi (`lsls #2; ldr =table; adds; ldr [r0]; mov pc, r0`) plus
an absolute `.word` jump table. ATTEMPT_MATCH (computed jump = switch, not NAKED).

The structure, logic, struct offsets, and cases 2/3/4 are CORRECT and match. The
function is a clean readable switch (no NAKED needed). The blocker is a single
agbcc cross-jump merge-boundary artifact in the case-0/case-1 region.

## What each case does
- Shared call: `sub_08013C60(*desc, ((u8*)desc)[2], buf)` where `desc` is a 16-byte
  `TransferDesc` and `desc[2]` (3rd byte of word0) is the mode argument.
- case 0: `desc = &table_07DA8[state]`; transfer to 0x030064c0.
- case 1: `sub_08012CAC()`; then same as case 0 (state re-read after the call).
- case 2: `desc = (TransferDesc*)0x08307d98`; transfer to 0x03006580.
- case 3: `desc = &table_07DA8[state]`; if transfer returns nonzero set state=0xff;
  then `sub_08011884()`.
- case 4: `sub_08012CAC()`; if `gGameStuff._unk00 - gQueue_64C0._seed > 7` push an
  OAM DMA from the 0x08306f08 anim-cfg block (frames[frame++], wrap at frameCount,
  REG_DMA3 16-bit transfer = byteCount>>1 | DMA_ENABLE); then transfer to 0x030064c0.

Data: table at 0x08307da8 (16-byte TransferDesc records, indexed by state), single
record at 0x08307d98, anim-cfg struct at 0x08306f08 (u16 frameCount; u16; const
void **frames; void *vramDst; u16 byteCount — see src/data/sprite_anim_block.c).

## Drift
- Best: **byte_diff 266, diff_count 88** with a `register TransferDesc *desc asm("r3")`
  pin (anchors `lsls r3,...; adds r3,r3,table` and table into r0, matching baserom
  case 0 exactly) + case-4 pins `scene asm("r4")`, `cfg asm("r5")` (forces
  `push {r4,r5,lr}` and the r4/r5 pair the baserom uses; without these case 4 colors
  scene=r3/cfg=r4 and the prologue drops r5). Case 4 then matches the baserom
  byte-for-byte; cases 2,3 match.
- Remaining divergence is ENTIRELY the cross-jump merge boundary in cases 0/1/2.
  Baserom: case 0 computes desc via the cached base ptr (r4) then `b T1` where
  T1 = `ldrb [r3,#2]; str sp0; ldr =buf; str sp4; ...bl` (shared 0/1, buf 0x030064c0).
  Case 2 keeps its OWN complete tail (buf 0x03006580, `b end`), separate from T1.
  Built: agbcc's final jump_optimize (JUMP_CROSS_JUMP, toplev.c:4099) merges the
  GENERIC suffix `str sp4; ldr args; bl` across cases 0,1,AND 2 into one block at
  the `str sp4` boundary — a MORE-aggressive merge than the baserom, which merged
  from `ldrb [r3,#2]` for 0/1 only. This shifts every case-body offset, so the jump
  table words (~5) + the case-0/1 region all diff and cascade.
- This is NOT controllable from C source shape (tried: direct-globals vs scene-ptr
  vs table-anchor vs ptr-add vs offset-expr vs dead-pointer-cast — all 260-289), and
  NOT a flag (cross-jump runs unconditionally at optimize>0; -fno-thread-jumps,
  -fno-cse-follow-jumps, -fno-cse-skip-blocks, -fno-expensive-optimizations,
  -fno-gcse all = 266/88; -fforce-addr bloats to 331; -ffixed-r3 shifts the whole
  allocation to 269/102; new agbcc = 266/159; -O1 = 287/129).
- Permuter: base score 5859 (inflated — make_permuter_target.py emits no $t/$d), ran
  ~500 iters, plateaued at 5250, NO convergence toward 0. Not permuter-tractable
  (statement-order/scope mutations don't reach the cross-jump pass).
- Next attempt: needs a way to make agbcc's cross-jump merge case 0/1 from
