# Deferred analysis: sub_080304F4

Sequencer "wait/delay" opcode handler (sound opcode table entry #4, address
0x080304f4, 332 bytes). `u32 sub_080304F4(s32 ch, SoundChannelSeq *seq)`.
Verdict from classify_unmatchable.py: **ATTEMPT_MATCH** (no structural
impossibility — one direct `bl sub_0802E3C8`, no inner fn-ptr BL, no high-reg
loop state, no libgcc-only prologue). NOT a NAKED candidate.

## Semantics (fully understood)

Opcode is a u32 `[op:u8, flags:u8, count:u16]`. On entry:
- `op = seq->opPtr` (SoundChannelSeq +0), `cursor = seq->cursor` (u16 +0xa).
- If `cursor == 0` (FRESH): read `count = *(u16*)(op+2)`. If 0 -> advance.
  flags = op[1]. Gate checks (each on a flag bit) can skip the wait -> advance:
    * flags&1 : gate flags & 0x100 (STOP-pending) set -> advance.
      gate flags = (ch<=3 ? ss->chFlags[ch] : SW_SLOT_FOR_CHANNEL(ss,ch)->flags)
    * flags&4 (ch>3 only): if !(SW_SLOT->flags & 0x200 RETIRE_PENDING) AND
      STREAM_TABLE(ss)[ch-4]==NULL -> advance.
  Then: flags&2 ? seq->cursor = sub_0802E3C8(count) (random) : seq->cursor = count.
  return 0.
- Else (COUNTDOWN): if count != 0xffff { cursor--; seq->cursor = cursor;
  if ((cursor & 0xffff)==0) { seq->opPtr = op+4; return 1; } }
  Then a SECOND flag-check block (mirror, but no 0x200 check; flags&4 path stores
  cursor=0 then advances; flags&1 path stores cursor=0 then advances).
- advance: seq->opPtr = (reload) +4; return 1.  clearAdvance: seq->cursor=0; advance.

1/2/4; struct SoundSeqWaitOp{u8 op,flags;u16 count;}; macro SEQ_WAIT_GATE_FLAGS.

## Drift

Best reached: **diff_count 60, byte_diff 141** (compile_and_view_assembly.py).
Structure is CORRECT — every instruction SHAPE matches the baserom; the 60 diffs
are register-coloring/CSE differences that cascade branch-target offsets. ~5 root
differences, each independent:

1. **Param copy order.** baserom `adds r2,r0 (ch); adds r4,r1 (seq)`; agbcc emits
   `adds r4,r1 (seq)` FIRST because op/cursor both derive from seq (r4) so agbcc
   copies seq before ch. Reordering `register` decls (cursor before op, ch first)
   did NOT change it — old_agbcc copies the multiply-used arg first.

2. **opHalf CSE / ip-stash.** baserom caches count in r7 (`ldrh r0,[r5,#2];
   adds r7,r0`) and RE-READS `[r5,#2]` for the random `sub_0802E3C8` arg (two
   un-CSE'd loads). old_agbcc CSEs the two identical `*(u16*)(op+2)` reads, then
   must stash the cached value to `ip` (`mov ip,r0` / `mov r0,ip`) to free a reg
   for the call. Net +2 instr, and load direction reversed (`ldrh r7` vs
   `ldrh r0; adds r7,r0`). Tried to defeat the CSE: `asm("":"+r"(op))` barrier
   (broke -> 206), re-read via `seq->opPtr` reload (heavy -> 282), struct-field
   cast (same memory, still CSE'd), -fno-gcse (worse, 206 — it's plain CSE not
   GCSE), u16 vs u32 opHalf (no change). This single CSE is the dominant blocker.

3. **flags intermediate-copy (x2 sites).** baserom `ldrb r1,[r5,#1]; adds r6,r1`
   (load to scratch, copy to callee-saved home r6). With `register flags asm("r6")`
   pin, agbcc loads direct `ldrb r6` (no intermediate). UNPINNING flags makes it
   collide with op's r5 pin (`ldrb r5,[r5,#1]` clobbers op) -> blows up to ~200.
   So flags must be pinned -> direct load -> 1-instr diff per site.

4. **streamTbl reg clobber.** baserom computes `STREAM_TABLE(ss)[ch-4]` index in
   r0/r1 preserving r2(ch): `ldr r1,[r0](auxTable); lsls r0,r2,#2; adds; subs r0,#16`.
   agbcc reuses r2(ch, now dead) as the index reg: `lsls r2,r2,#2; ...subs r2,#16`.
   Inlining the slot (dropping the `SoundSlot *slot` local) FIXED the sibling 0xc8
   swSlot path; the 0xc4 streamTbl path still clobbers r2. Byte-offset form
   `((ch-4)<<2)` changed the math (worse). ch is genuinely dead here so agbcc
   reuses its pinned reg.

Pins in best-effort: op→r5, ch→r2, cursor→r0, flags→r6 (opHalf cached, naturally r7).
Levers that WORKED (keep these): ternary `(ch<=3 ? small : big)` operand order
(fixes bgt/ble polarity); inline the SW_SLOT flags read (no `slot` local);
shared `u32 mask=0xffff` for both the `!=0xffff` cmp and the `&0xffff` mask;
two-entry advance label (`advance` reloads opPtr+4, countdown-expired jumps to a
shared `storeAdvance` with cached op+4).

## Best-effort C

```c
/* sub_080304F4 — sequencer "wait/delay" opcode handler (table entry #4).
 *
 * Each opcode is a u32: [op:u8, flags:u8, count:u16]. This handler arms a
 * frame countdown of `count` frames, optionally randomized, and yields the
 * channel (returns 0) while the countdown runs; when it hits zero it
 * advances seq->opPtr past the opcode and returns 1 so the dispatcher pulls
 * the next opcode the same frame.
 *
 * The flags byte gates the wait so a stopping/finished channel does not
 * stall on a delay:
 *   - bit 0 (0x1): skip the wait if the channel's STOP-pending bit (0x100)
 *     is set on its flag word (chFlags[ch] for ch<=3, the SoundSlot flags
 *     for ch>3).
 *   - bit 2 (0x4, ch>3 only): skip if the slot has retired (RETIRE_PENDING)
 *     OR its stream-table entry is NULL.
 *   - bit 1 (0x2): randomize the count via sub_0802E3C8 instead of using it
 *     verbatim.
 */

#define SOUND_FLAG_STOP_PENDING 0x100

#define SEQ_WAIT_SKIP_IF_STOPPING 0x1
#define SEQ_WAIT_RANDOMIZE        0x2
#define SEQ_WAIT_SKIP_IF_NO_STREAM 0x4

typedef struct SoundSeqWaitOp {
    u8 op;
    u8 flags;
    u16 count;
} SoundSeqWaitOp;

extern u32 sub_0802E3C8(u32 limit);

#define SEQ_WAIT_GATE_FLAGS(ch)                                                                                       \
    ((ch) <= 3 ? gpSoundSystem->chFlags[ch] : SOUND_SYSTEM_SW_SLOT_FOR_CHANNEL(gpSoundSystem, ch)->flags)

u32 sub_080304F4(s32 chArg, SoundChannelSeq *seq)
{
    register s32 ch asm("r2") = chArg;
    register u8 *op asm("r5") = (u8 *)seq->opPtr;
    register u32 cursor asm("r0") = seq->cursor;
    u8 *nextOp;

    if (cursor == 0) {
        u32 opHalf = *(u16 *)(op + 2);
        register u32 flags asm("r6");

        if (opHalf == 0)
            goto advance;

        flags = op[1];
        if ((flags & SEQ_WAIT_SKIP_IF_STOPPING) && (SEQ_WAIT_GATE_FLAGS(ch) & SOUND_FLAG_STOP_PENDING))
            goto advance;

        if ((flags & SEQ_WAIT_SKIP_IF_NO_STREAM) && ch > 3) {
            SoundSystem *ss = gpSoundSystem;
            if (!(SOUND_SYSTEM_SW_SLOT_FOR_CHANNEL(ss, ch)->flags & SOUND_SLOT_FLAG_RETIRE_PENDING) &&
                SOUND_SYSTEM_STREAM_TABLE(ss)[ch - 4] == NULL)
                goto advance;
        }

        if (flags & SEQ_WAIT_RANDOMIZE)
            seq->cursor = sub_0802E3C8(*(u16 *)(op + 2));
        else
            seq->cursor = opHalf;
        return 0;
    }

    {
        u32 mask = 0xffff;
        if (*(u16 *)(op + 2) != mask) {
            cursor--;
            seq->cursor = cursor;
            cursor &= mask;
            if (cursor == 0) {
                nextOp = op + 4;
                goto storeAdvance;
            }
        }
    }

    {
        register u32 flags asm("r6") = op[1];
        if ((flags & SEQ_WAIT_SKIP_IF_STOPPING) && (SEQ_WAIT_GATE_FLAGS(ch) & SOUND_FLAG_STOP_PENDING))
            goto clearAdvance;

        if ((flags & SEQ_WAIT_SKIP_IF_NO_STREAM) && ch > 3) {
            SoundSystem *ss = gpSoundSystem;
            if (SOUND_SYSTEM_STREAM_TABLE(ss)[ch - 4] == NULL)
                goto clearAdvance;
        }
    }
    return 0;

clearAdvance:
    seq->cursor = 0;
advance:
    nextOp = (u8 *)seq->opPtr + 4;
storeAdvance:
    seq->opPtr = (u32 *)nextOp;
    return 1;
}```
