VRAM screen-block flush of one 32x32 tilemap window.

`void sub_080100E4(u32 bank, const u16 *src, u16 *dst)` — copies a clipped
32x32 tile window from a packed EWRAM bank buffer into a VRAM screen block.
Destination wraps inside the 0x800-byte screen-block region (0x40-byte row
stride). Reads the scroll state block at `0x030060A0`: 32-byte record per
bank with `scrollX` at `+4`, `scrollY` at `+8`; global header fields
`tileRows` at `+0x18` and `tileCols` at `+0x1A` are read from the BASE
(`0x030060A0`), not per-record. Leaf, `ATTEMPT_MATCH` (no libgcc, no
`mov pc`), NOT STRONG_UNMATCHABLE. The control flow + arithmetic are
byte-for-byte the correct SHAPE — the residual is two sharp codegen local
minima (a high-reg density swap + a pointer-CSE fold), not a structural
mismatch. Confirmed struct field offsets against the asm AND against the
matched `SceneScrollState`-style accessors elsewhere; offsets are right.

### NEW finding (round 12): single `state asm("r8")` pin → exact size
Pinning ONLY `state` to r8 (no other pins) makes agbcc emit the SAME
instruction count as the target (376B exact, 187 insns) — the pin changes
the record-address folding so each scroll access re-derives `state + recOff
+ field` the way the target does (less CSE). This was not in the prior
note. It is the cleanest single lever, but byte_diff stays 328 because (a)
the low regs cascade (`bank`→sl not ip; `src`/`base` shift by one) and (b)
the down-wrap fold (below) is independent of register placement. Pinning
the cascaded low regs back relocates the divergence rather than removing it
(see table) — confirms the prior note's "pins are the wrong tool" verdict.

### Residual 1 — high-reg swap (state↔srcY in r8/r9), density tiebreak
Two long-lived pseudos compete for {r8,r9}: `state` (the 0x030060a0
pointer, ~10 body refs, whole-function range) and `srcY` (3 writes + 2
reads, dies early at `dstY = srcY & 31`; r9 is then REUSED for the outer
`row` counter — they are separate pseudos sharing one hard reg). Target
gives `state`→r8, srcY/row→r9. Clean build gives the SWAP (srcY→r8,
state→r9) because srcY's SHORT live range inflates its density
(`floor_log2(refs)*refs / live_length`, `gcc/global.c:allocno_compare`,
lower reg = higher priority). Lengthening srcY's range by reusing it as
`row` did NOT flip it (346/328, worse). Declaration reorder does nothing
(it's density, not the allocno-number tiebreak). The ONLY thing that wins
state→r8 cleanly is the pin.

### Residual 2 — down-wrap pointer-CSE fold (the bigger byte contributor)
Target down-wrap (0x101e4): `ldr =0xfffff800; adds dst; subs base; asr#1;
lsl#1; adds base` = `base + ((dst - 0x800 - base) >> 1 << 1)`, materializing
`-0x800` as a literal. EVERY clean shape agbcc instead folds to `dst -
rowEnd` (1 sub, rowEnd=base+0x800 already live in a reg) because basic CSE
proves `dst - 0x800 - base == dst - (base+0x800) == dst - rowEnd`. This
fold is unbreakable here: tried `>>1<<1` vs `&~1`, u16* vs u32-byte address
modelling throughout, staging `back = dst - 0x800/2` into a separate
pointer before rebasing — agbcc re-folds all of them. `-fno-gcse`,
`-fno-cse-follow-jumps`, `-fno-cse-skip-blocks`, `-fno-rerun-cse-after-loop`,
`-fno-thread-jumps` (and combos): none recover the literal. It is plain
local CSE, not gcse. This residual is INDEPENDENT of the register swap
(present in every variant above), so it must be cracked separately.

### Levers RULED OUT this pass (in addition to the prior note's list)
- `state asm("r8")` + every low-reg pin (src r5/base r4 via aliased
  locals): 372B/339. Full pin set diverges dataflow, does NOT converge.
- u32 byte-address loop modelling (cast to u16* only at `*dst=`): 324B/349.
- Down-wrap as `& ~1` byte math: 348B/343 (`negs #2; ands` — wrong, target
  is `asr#1;lsl#1`).
- Down-wrap staged via intermediate `back` pointer: 344B/356.
- `-fno-expensive-optimizations`: recovers 20B of size (356B) but byte_diff
  unchanged ~343; reshuffles bank→sl, adds a 2nd pool literal. Not a win.
- All CSE/jump flags above on the byte-unit down-wrap: no literal recovery.

(`fprintf` of refs/live_length in `gcc/global.c allocno_compare`). The

## Best-effort C (clean, no pins — byte_diff 345 / 336B; the reference)

```c
#include "types.h"

struct ScrollState {
    /* 0x00 */ u8 _pad00[4];
    /* 0x04 */ s32 scrollX;
    /* 0x08 */ s32 scrollY;
    /* 0x0C */ u8 _pad0C[12];
    /* 0x18 */ u16 tileRows;
    /* 0x1A */ u16 tileCols;
    /* 0x1C */ u8 _pad1C[4];
};

#define gScrollState ((struct ScrollState *)0x030060a0)

void sub_080100E4(u32 bankArg, const u16 *src, u16 *dst)
{
    struct ScrollState *state;
    u32 bank;
    u16 *base;
    u16 *rowEnd;
    s32 srcX;
    s32 srcY;
    s32 dstX;
    s32 dstY;
    s32 row;
    s32 col;
    u32 xSpan;
    u32 xCountdown;

    base = dst;
    bank = (u8)bankArg;
    srcX = 0;
    srcY = 0;
    state = gScrollState;

    if (*(s32 *)((u8 *)&state->scrollY + (bank << 5)) > 47) {
        if (*(s32 *)((u8 *)&state->scrollY + (bank << 5)) <= state->tileRows * 8 - 208)
            srcY = (u8)((*(s32 *)((u8 *)&state->scrollY + (bank << 5)) - 48) / 8);
    }
    if (*(s32 *)((u8 *)&state->scrollY + (bank << 5)) > state->tileRows * 8 - 208)
        srcY = (u8)((u8)state->tileRows - 32);

    if (*(s32 *)((u8 *)&state->scrollX + (bank << 5)) > 7) {
        if (*(s32 *)((u8 *)&state->scrollX + (bank << 5)) <= state->tileCols * 8 - 248)
            srcX = (u8)((*(s32 *)((u8 *)&state->scrollX + (bank << 5)) - 8) / 8);
    }
    if (*(s32 *)((u8 *)&state->scrollX + (bank << 5)) > state->tileCols * 8 - 248)
        srcX = (u8)((u8)state->tileCols - 32);

    src += srcY * state->tileCols + srcX;

    dstY = srcY & 31;
    dstX = srcX & 31;
    xSpan = (u8)(32 - dstX);
    dst += dstY * 32 + dstX;

    rowEnd = base + 0x800 / 2;

    row = 0;
    do {
        xCountdown = xSpan;
        col = 0;
        row++;
        do {
            if (dst >= rowEnd)
                dst = base + (dst - 0x800 / 2 - base);
            if (dst < base)
                dst = rowEnd - (base - dst);

            if (xCountdown == 0) {
                dst -= 0x40 / 2;
                if (dst < base)
                    dst = base + (0x800 - 0x40) / 2;
            }

            *dst++ = *src++;
            xCountdown = (u8)(xCountdown - 1);
            col = (u8)(col + 1);
        } while (col <= 31);

        src += state->tileCols - 32;
        if (xSpan != 32)
            dst += 0x40 / 2;
    } while ((u8)row <= 31);
}
```
