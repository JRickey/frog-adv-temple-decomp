# sub_080100E4 — deferred analysis

VRAM screen-block flush of one 32x32 tilemap window.

`void sub_080100E4(u32 bank, const u16 *src, u16 *dst)` — copies a clipped
32x32 tile window from a packed EWRAM bank buffer into a VRAM screen block.
Destination wraps inside the 0x800-byte screen-block region (0x40-byte row
stride). Reads the scroll state block at `0x030060A0`: 32-byte record per
bank with `scrollX` at `+4`, `scrollY` at `+8`; global header fields
`tileRows` at `+0x18` and `tileCols` at `+0x1A` are read from the BASE
(`0x030060A0`), not per-record. Leaf, `ATTEMPT_MATCH` (no libgcc, no
`mov pc`), NOT STRONG_UNMATCHABLE.

## Drift (round 17, Opus)

Re-derived the C from scratch (did not extend the prior plateau). Best
result: **byte_diff 305, diff_count 140, size 336B** (target 376B) from
CLEAN C — no pins/asm/volatile — using:
- `*(s32 *)((u8 *)&state->scrollY + (bank << 5))` addressing (re-derives
  the record byte-offset inline so `bank` stays long-lived in `ip` and the
  `+8`/`+4` field offset is the constant addend, matching the target's
  `add r0, (state+8), recOff` operand order), AND
- SEPARATE `dstX`/`dstY = srcX/srcY & 31` masked locals (instead of
  reassigning `srcX`/`srcY`). **This is the key new finding:** the separate
  masked vars shorten `srcY`'s live range and make agbcc emit the
  **correct prologue save-set** — `push {r4,r5,r6,r7,lr}; mov r7,sl;
  mov r6,r9; mov r5,r8; push {r5,r6,r7}` (3 high regs, byte-identical to
  target) — which NONE of the prior-pass shapes achieved without pins.

With this base the register placement is ALMOST entirely correct:
| value | target | best-effort | status |
| --- | --- | --- | --- |
| bank | ip | ip | ✓ |
| dst (write ptr) | r3 | r3 | ✓ |
| base (=dst copy) | r4 | r4 | ✓ |
| srcX | r7 | r7 | ✓ |
| src (read ptr) | r5 | r6 | ✗ (off by one low reg) |
| **srcY** | **r9** | **r8** | ✗ SWAP |
| **state** | **r8** | **r9** | ✗ SWAP |

**The entire residual is one register swap: `srcY` and `state` are
exchanged between r8 and r9.** Every subsequent `mov rN, r8`/`mov rN, r9`
in the body then disagrees, which is what inflates diff_count to 140 even
though the control flow + arithmetic are byte-for-byte the same shape.

### Root cause (named pass: global.c allocno_compare)
agbcc colours high regs by density `floor_log2(refs)*refs / live_length`
(`gcc_arm/global.c:allocno_compare`, lowest reg = highest priority). In my
compilation `srcY` out-prioritises `state` and grabs r8; the target gives
r8 to `state`. The hand estimate (state ~0.375 vs srcY ~0.33) says state
SHOULD win, so the actual agbcc ref/length counts differ from the estimate
— `srcY` is effectively denser in the emitted RTL.

### Levers RULED OUT this pass (do NOT repeat)
- Declaration/assignment reorder (`state` first) — does not flip the swap
  (it is density, not allocno-number tiebreak). 340B/311.
- `register struct ScrollState *state asm("r8")` + `srcY asm("r9")` pins —
  WIN the high regs but shove `src`/`dst` off their low regs (cascade),
  net WORSE: 372–380B, diff 158–178. Adding `bank asm("ip")` → 372B/158.
  Adding `src asm("r5")`/`dst asm("r3")` → 376B (size match!) but
  byte_diff 336 (data flow diverges under the pin set). Pins are the wrong
  tool here — they cannot fix the swap without breaking the low regs.
- Explicit `record` POINTER (caches addr, no per-block recompute): 312B/289.
- Explicit `recOff = bank<<5` byte-offset var: forces sl + 3-high-reg
  prologue but demotes `bank` out of ip; 336B/306.
- `pScroll` per-block pointer: 320B/308.
- Fully inlined `gScrollState` macro (no `state` local): base reloaded from
  pool twice; 344B/326. The `state` local IS needed.
- Byte/integer-address wrap math `((s32)dst - 0x800 - (s32)base) >> 1 << 1`
  to surface the `0xfffff800` pool constant: agbcc proves the u16 alignment
  and collapses it back to `dst - rowEnd` (1 sub) every time. The target's
  down-wrap (`ldr =0xfffff800; adds; subs base; asr#1; lsl#1`) is ~6 bytes
  the build never emits — a SECONDARY residual behind the swap. Likely
  needs `dst`/`base`/`rowEnd` modelled as `u32` integers throughout (cast
  to `u16*` only at the `*dst++` store) so agbcc loses the alignment proof.
- Newer `AGBCC_BIN` per-TU: identical 332B/300 (no help). `-fno-gcse`
  per-TU: no change (the CSE is local, not gcse).

### Next attack (for the reclamation pass)
1. The swap is a pure density tiebreak. Build a PRIVATE instrumented
   old_agbcc (copy, never touch the shared symlink) and add an
   `fprintf(stderr,...)` in `gcc_arm/global.c` right after the
   `qsort(allocno_order, ...)` (the existing `if (file)` dump came out
   EMPTY via `-dg` this pass — print to stderr unconditionally instead) to
   see the exact refs/live_length for the `srcY` and `state` pseudos, then
   find the minimal C edit that drops `srcY`'s density below `state`'s
   (e.g. one fewer `srcY` read, or a longer `srcY` range) so `state` wins
   r8 — WITHOUT disturbing the now-correct low regs.
2. Then fix the secondary `0xfffff800` down-wrap via `u32` integer address
   modelling.
3. With both fixed the function should match in pure C (this base is one
   swap away). It is NOT a permuter target yet (byte_diff 305 ≫ 40); the
   permuter only helps once steps 1–2 land it under ~40.

## Best-effort C (correct prologue save-set + low regs; one r8/r9 swap away)

```c
#include "types.h"

struct ScrollState {
    /* 0x00 */ u8 _pad00[4];
    /* 0x04 */ s32 scrollX;
    /* 0x08 */ s32 scrollY;
    /* 0x0C */ u8 _pad0C[12];
    /* 0x18 */ u16 tileRows;
    /* 0x1A */ u16 tileCols;
    /* 0x1C */ u8 _pad1C[4];
};

#define gScrollState ((struct ScrollState *)0x030060a0)

void sub_080100E4(u32 bankArg, const u16 *src, u16 *dst)
{
    struct ScrollState *state;
    u32 bank;
    u16 *base;
    u16 *rowEnd;
    s32 srcX;
    s32 srcY;
    s32 dstX;
    s32 dstY;
    s32 row;
    s32 col;
    u32 xSpan;
    u32 xCountdown;

    base = dst;
    bank = (u8)bankArg;
    srcX = 0;
    srcY = 0;
    state = gScrollState;

    if (*(s32 *)((u8 *)&state->scrollY + (bank << 5)) > 47) {
        if (*(s32 *)((u8 *)&state->scrollY + (bank << 5)) <= state->tileRows * 8 - 208)
            srcY = (u8)((*(s32 *)((u8 *)&state->scrollY + (bank << 5)) - 48) / 8);
    }
    if (*(s32 *)((u8 *)&state->scrollY + (bank << 5)) > state->tileRows * 8 - 208)
        srcY = (u8)((u8)state->tileRows - 32);

    if (*(s32 *)((u8 *)&state->scrollX + (bank << 5)) > 7) {
        if (*(s32 *)((u8 *)&state->scrollX + (bank << 5)) <= state->tileCols * 8 - 248)
            srcX = (u8)((*(s32 *)((u8 *)&state->scrollX + (bank << 5)) - 8) / 8);
    }
    if (*(s32 *)((u8 *)&state->scrollX + (bank << 5)) > state->tileCols * 8 - 248)
        srcX = (u8)((u8)state->tileCols - 32);

    src += srcY * state->tileCols + srcX;

    dstY = srcY & 31;
    dstX = srcX & 31;
    xSpan = (u8)(32 - dstX);
    dst += dstY * 32 + dstX;

    rowEnd = base + 0x800 / 2;

    row = 0;
    do {
        xCountdown = xSpan;
        col = 0;
        row++;
        do {
            if (dst >= rowEnd)
                dst = base + (dst - 0x800 / 2 - base);
            if (dst < base)
                dst = rowEnd - (base - dst);

            if (xCountdown == 0) {
                dst -= 0x40 / 2;
                if (dst < base)
                    dst = base + (0x800 - 0x40) / 2;
            }

            *dst++ = *src++;
            xCountdown = (u8)(xCountdown - 1);
            col = (u8)(col + 1);
        } while (col <= 31);

        src += state->tileCols - 32;
        if (xSpan != 32)
            dst += 0x40 / 2;
    } while ((u8)row <= 31);
}
```
