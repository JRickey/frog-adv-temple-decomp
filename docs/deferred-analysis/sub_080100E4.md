# sub_080100E4 — deferred analysis

VRAM screen-block flush of one 32x32 tilemap window.

Confirmed working model from callers (`sub_08012BC4`, `sub_08019DB4`,
`sub_08015A00`, `sub_08015B20`):

```c
void sub_080100E4(u32 bank, const u16 *src, u16 *dst);
```

The function copies a clipped 32x32 tile window from a packed EWRAM bank buffer
into a VRAM screen block. Destination wrapping is inside the 0x800-byte
screen-block region, with 0x40-byte row stride. It reads the scroll state block
at `0x030060A0`: each bank uses a 32-byte record, with `scrollX` at `+4` and
`scrollY` at `+8`; header fields at `+24/+26` are tile height/width.

Classifier after refreshing `tools/agent/.function_addresses.json`:
`ATTEMPT_MATCH`, not `STRONG_UNMATCHABLE`. No callee peeling is needed; this is
a leaf function.

## Drift

Best new result this pass: **byte_diff 287, diff_count 161**, from clean C with
a 32-byte `SceneScrollRecord_100E4` and no pins/asm/volatile. It is still far
from match and leaves the function 304 bytes versus the 376-byte target.

Newly ruled out / confirmed:

- A source-level `u8 bank` signature does **not** defeat old_agbcc's
  `(u8)bank * 32` fold; it still emits `lsrs r0, #19` rather than the target
  `lsls #24; lsrs #24; mov ip; lsls #5`.
- Rebuilding just this TU with newer `AGBCC_BIN` does **not** improve the
  allocator shape. It still saves only `r8/r9`, emits a different address-pool
  layout, and remains far from the target.
- Repeated raw `state + recordOffset + field` expressions force more
  recomputation but worsen allocation: **byte_diff 308, diff_count 184**.
- Whole-scope pins for `ip/r9/sl/r7` plus the bank-fold fence reproduce the
  high-register save set, but they move zero/base setup too early and can spill
  `srcX` into a bad stack-derived expression (`mov r6, sp; lsl ...`), leaving
  **byte_diff 301, diff_count 139** in this pass.
- Dropping the `r7` pin removes that specific spill but causes `src` and `dst`
  to leave the target registers (`r5`/`r3`), regressing to **byte_diff 308**.
- Corpus current-tree grep for the wrap idiom (`0xfffff800`, row-end/screen
  block wording) did not surface a pure-C analogue. History search produced no
  useful result in this worktree.

The remaining hard part is still old_agbcc `local-alloc`/`reload` lifetime
coloring. The baserom reuses high registers for disjoint lifetimes:

| reg | early value | loop value |
| --- | --- | --- |
| `ip` | truncated bank | x-span countdown seed |
| `r9` | `srcY` | row counter |
| `sl` | `bank << 5` record offset | row counter / row-end setup pressure |
| `r7` | `srcX` | wrap scratch |
| `r8` | `0x030060A0` state base | same state base |

Register pins model one whole-scope lifetime, not this reuse. The next useful
attack is likely a private instrumented old_agbcc build around
`local-alloc.c` quantity birth/death and `reload.c` reload register choice, or a
history hit from a decomp that replaced a similar high-register tilemap blit in
pure C.

## Best-effort C

```c
#include "types.h"

enum {
    TILEMAP_WINDOW_TILES = 32,
    TILEMAP_WRAP_BYTES = 0x800,
    TILEMAP_ROW_BYTES = 0x40,
    TILE_PIXELS = 8,
    SCREEN_TOP_MARGIN_PIXELS = 48,
    SCREEN_LEFT_MARGIN_PIXELS = 8,
    SCREEN_VISIBLE_HEIGHT_PIXELS = 208,
    SCREEN_VISIBLE_WIDTH_PIXELS = 248,
};

struct SceneScrollHeader_100E4 {
    u8 _pad00[24];
    u16 tileRows;
    u16 tileCols;
};

struct SceneScrollRecord_100E4 {
    u8 _pad00[4];
    s32 scrollX;
    s32 scrollY;
    u8 _pad0C[20];
};

#define SCENE_SCROLL_STATE_100E4 ((struct SceneScrollHeader_100E4 *)0x030060A0)

void sub_080100E4(u32 bankArg, const u16 *src, u16 *dst)
{
    u32 bank;
    struct SceneScrollHeader_100E4 *state;
    struct SceneScrollRecord_100E4 *record;
    u16 *base;
    u16 *rowEnd;
    u32 srcX;
    u32 srcY;
    u32 row;
    u32 col;
    u32 xCountdown;
    u32 xSpan;

    bank = (u8)bankArg;
    state = SCENE_SCROLL_STATE_100E4;
    record = (struct SceneScrollRecord_100E4 *)((u8 *)state + bank * sizeof(struct SceneScrollRecord_100E4));

    base = dst;
    srcX = 0;
    srcY = 0;

    if (record->scrollY > SCREEN_TOP_MARGIN_PIXELS - 1) {
        if (record->scrollY <= (state->tileRows * TILE_PIXELS) - SCREEN_VISIBLE_HEIGHT_PIXELS) {
            srcY = (u8)((record->scrollY - SCREEN_TOP_MARGIN_PIXELS) / TILE_PIXELS);
        }
    }
    if (record->scrollY > (state->tileRows * TILE_PIXELS) - SCREEN_VISIBLE_HEIGHT_PIXELS) {
        srcY = (u8)state->tileRows - TILEMAP_WINDOW_TILES;
    }

    if (record->scrollX > SCREEN_LEFT_MARGIN_PIXELS - 1) {
        if (record->scrollX <= (state->tileCols * TILE_PIXELS) - SCREEN_VISIBLE_WIDTH_PIXELS) {
            srcX = (u8)((record->scrollX - SCREEN_LEFT_MARGIN_PIXELS) / TILE_PIXELS);
        }
    }
    if (record->scrollX > (state->tileCols * TILE_PIXELS) - SCREEN_VISIBLE_WIDTH_PIXELS) {
        srcX = (u8)state->tileCols - TILEMAP_WINDOW_TILES;
    }

    src += (srcY * state->tileCols) + srcX;

    srcY &= TILEMAP_WINDOW_TILES - 1;
    srcX &= TILEMAP_WINDOW_TILES - 1;
    xSpan = (u8)(TILEMAP_WINDOW_TILES - srcX);
    dst += (srcY * TILEMAP_WINDOW_TILES) + srcX;

    rowEnd = (u16 *)((u8 *)base + TILEMAP_WRAP_BYTES);

    row = 0;
    do {
        xCountdown = (u8)xSpan;
        col = 0;
        row++;

        do {
            u16 *wrappedDst;

            wrappedDst = dst;
            if (dst >= rowEnd) {
                wrappedDst = (u16 *)((u8 *)dst - TILEMAP_WRAP_BYTES);
            }
            if (dst < base) {
                wrappedDst = (u16 *)((u8 *)rowEnd - ((u8 *)base - (u8 *)dst));
            }
            dst = wrappedDst;

            if (xCountdown == 0) {
                dst = (u16 *)((u8 *)dst - TILEMAP_ROW_BYTES);
                if (dst < base) {
                    dst = (u16 *)((u8 *)base + TILEMAP_WRAP_BYTES - TILEMAP_ROW_BYTES);
                }
            }

            *dst++ = *src++;
            xCountdown = (u8)(xCountdown - 1);
            col = (u8)(col + 1);
        } while (col <= TILEMAP_WINDOW_TILES - 1);

        src += state->tileCols - TILEMAP_WINDOW_TILES;
        if (xSpan != TILEMAP_WINDOW_TILES) {
            dst = (u16 *)((u8 *)dst + TILEMAP_ROW_BYTES);
        }
    } while ((u8)row <= TILEMAP_WINDOW_TILES - 1);
}
```
