# sub_080100E4 — deferred analysis

VRAM screen-block flush of one 32x32 tilemap window. Signature confirmed from
callers (sub_08012BC4, sub_08019DB4, sub_08015A00, sub_08015B20):
`void sub_080100E4(u32 bank, const u16 *src, u16 *dst)` — copies a clipped
32x32 tile window from a packed EWRAM bank buffer (`src`) into a VRAM
screen-block (`dst`), wrapping inside the 0x800-byte screen block per-row
(0x40-byte stride) and per-column.

Reads the scene-scroll state block at 0x030060A0: per-bank 32-byte records
(`rec = base + bank*32`) carry source pixel offsets f4 (x, +4) and f8 (y, +8);
the shared header carries clip extents clipH (+24) and clipW (+26). This is the
same block sub_080112C0 / sub_08012BC4 access (struct SceneScrollState /
BlitState in the engine).

## Drift

Best result: **byte_diff 298, diff_count 134** (370-byte / ~93-insn leaf).
`make check` would FAIL — far from a match. Verdict from
classify_unmatchable.py is ATTEMPT_MATCH (NOT STRONG_UNMATCHABLE), so NAKED is
not justified; the slice is left intact.

The control-flow / semantics are believed CORRECT (the srcY/srcX clip
computation and the per-row/per-column wrap loop reproduce the baserom block
structure). The residual is **register allocation**, specifically: the baserom
REUSES each high register for two different logical variables across disjoint
lifetimes —

| reg | prologue value      | loop value          |
|-----|---------------------|---------------------|
| ip  | bank (`(u8)`)       | xspan (32-srcX&31)  |
| r9  | srcY                | rowEnd (base+0x400) |
| sl  | recOff (bank<<5)    | row counter         |
| r7  | srcX                | (scratch)           |
| r8  | st (0x030060A0)     | st (held throughout)|

A `register T x asm("rN")` pin holds rN for the variable's ENTIRE scope, so it
cannot express "r9 = srcY early, r9 = rowEnd late". Whole-scope pins on the
prologue vars get the prologue close but leave the loop wrong (and over-pinning
spills srcX to the stack — `mov r6, sp` appears). Inner-block pins reusing the
regs for the loop vars add copy instructions and regress.

Other confirmed-correct-but-unreproduced micro-divergences (each cascades):
- agbcc schedules the `(u8)bank` truncation (`lsls#24; lsrs#24; mov ip`) AFTER
  the srcX/srcY zero-inits; baserom emits it first (at 0x100f6).
- baserom recomputes the full `&rec.f8 = base + 8 + (bank<<5)` address (and
  reloads rec.f8) at the SECOND f8 check (0x10134); a cached `rec` pointer or
  `recOff` var makes agbcc reuse the address instead of recomputing.
- the per-column backward wrap loads `-0x800` from the pool and ADDs
  (`ldr r7,=0xfffff800; adds r0,r3,r7; subs r0,r4; asr#1; lsl#1; add r4`) — the
  `asr#1; lsl#1` is a u16* pointer-difference→count→rescale round-trip that
  `base + (dst - 0x400 - base)` folds away in agbcc.

The `(u8)bank << 5` fold (`<<24 >>24 <<5` → `<<24 >>19`) WAS solved: truncate
into a pinned `bank asm("ip")`, then `asm("" : "=r"(bank) : "0"(bank))` fence
before `bank << 5`. That part reproduces baserom exactly.

## Levers tried (none reached < ~297)

- plain C, no pins → 301/151 (agbcc uses only low regs)
- prologue pins ip=bank, r9=srcY, sl=recOff, r7=srcX + fold-fence + rec ptr +
  wrap temp → **298/134 (best)**
- byte-offset access macro `*(s32*)(st + N + bank<<5)` (recompute each use) → 321
- inline `bank<<5` everywhere, drop recOff/sl pin → 342
- loop-only pins ip=xspan, r9=rowEnd, sl=row → 298/244 (loop body diverges hard)
- inner-scope loop pins reusing ip/r9/sl for loop vars → 308/152
- compiler swap to newer agbcc (`CC = $(AGBCC_BIN)`) → no change (297)
- `-fforce-addr` → no change; `-fno-schedule-insns` → unsupported by old_agbcc
- permuter NOT run (byte_diff 298 >> ~40 threshold; permuter mutates
  scope/ordering, won't bridge a 297-byte register-reuse gap)

Next attempt: the unsolved core is high-register REUSE across variable
lifetimes, which pins cannot express. Possible angles: (a) instrument agbcc's
local-alloc/reload to see WHY it won't reuse r9/sl for the loop vars from the
unpinned source; (b) find a source shape where srcY/recOff are provably dead at
the loop entry so agbcc colors rowEnd/row into r9/sl naturally; (c) corpus
HISTORY search (mirrors absent in this worktree) for a leaf blit-with-wrap that
reuses high regs across lifetimes.

## Best-effort C

```c
#include "types.h"

struct ScrollState {
    u8 _pad00[24];
    u16 clipH;
    u16 clipW;
};

struct ScrollRec {
    u8 _pad00[4];
    s32 f4;
    s32 f8;
    u8 _pad0C[20];
};

void sub_080100E4(u32 bankArg, const u16 *src, u16 *dst)
{
    register u32 bank asm("ip");
    register u32 srcY asm("r9") = 0;
    register u32 srcX asm("r7") = 0;
    register u32 recOff asm("sl");
    struct ScrollState *st;
    struct ScrollRec *rec;
    u16 *base = dst;
    u32 xspan;
    u32 row;
    u32 col;
    u32 countdown;
    u16 *rowEnd;
    u16 *p;

    /* Truncate to u8 in ip, then fence so agbcc does not fold (u8)bank<<5 into
     * a single lsrs#19 (baserom keeps lsls#24; lsrs#24; mov ip; lsls#5). */
    bank = (u8)bankArg;
    asm("" : "=r"(bank) : "0"(bank));

    st = (struct ScrollState *)0x030060A0;
    recOff = bank << 5;
    rec = (struct ScrollRec *)((u8 *)st + recOff);

    if (rec->f8 > 47) {
        if (rec->f8 <= (st->clipH << 3) - 208)
            srcY = (u8)((rec->f8 - 48) / 8);
    }
    if (rec->f8 > (st->clipH << 3) - 208)
        srcY = (u8)((u8)st->clipH - 32);

    if (rec->f4 > 7) {
        if (rec->f4 <= (st->clipW << 3) - 248)
            srcX = (u8)((rec->f4 - 8) / 8);
    }
    if (rec->f4 > (st->clipW << 3) - 248)
        srcX = (u8)((u8)st->clipW - 32);

    src += srcY * st->clipW;
    src += srcX;

    xspan = (u8)(32 - (srcX & 31));
    dst += (srcY & 31) << 5;
    dst += (srcX & 31);

    rowEnd = base + 0x400;

    row = 0;
    do {
        countdown = (u8)xspan;
        col = 0;
        row = (u8)(row + 1);

        do {
            p = dst;
            if (dst >= rowEnd)
                p = base + (dst - 0x400 - base);
            else if (dst < base)
                p = rowEnd - (base - dst);
            dst = p;

            if (countdown == 0) {
                dst -= 0x20;
                if (dst < base)
                    dst = base + 0x3e0;
            }

            *dst++ = *src++;
            countdown = (u8)(countdown - 1);
            col = (u8)(col + 1);
        } while (col <= 31);

        src += st->clipW - 0x20;
        if (xspan != 32)
            dst += 0x20;
    } while (row <= 31);
}
```
