# sub_08012798 — deferred analysis

Parameterless tilemap blit. Same idiom as the matched sibling **sub_08012BC4**
but with all blit parameters computed inline from a ROM descriptor + player
coords (rather than passed as args), and `srcIndex` fixed at 0 (so the final
`*(u8*)0x03003610 = 1` write is unconditional, not `if (index==0)`).

Semantics (fully understood):
- descriptor at ROM `0x08306E64`: `+4`=width(3), `+6`=rows(3), `+8`=flags(0x10;
  `>>4 & 1` selects EWRAM/VRAM bank 1), `+16`=ptr to src-row table `0x08306E48`.
- `dstX = (u16)(gEntities[30].x * 3)`, `dstY = (u16)(gEntities[30].y * 3)`
  (player coords at `0x03003720 + 0x692 / + 0x694`, signed-halfword read).
- blit `srcTable[0]` (rows × width halfwords) into bank base
  (`0x02000000` / `0x02010000`) at `state[13]*dstY + dstX`, stride = `*(u16*)0x030060A4`
  (struct at `0x030060A0`, offset 26).
- flush via `sub_080100E4(flags&1, bankBase, vramBase)` (vram `0x0600E000`/`0x0600E800`),
  then `*(u8*)0x030064CA = 0`, `*(u8*)0x03003610 = 1`.

## Drift

ATTEMPT_MATCH (classifier). Best reached: **diff_count 50 / byte_diff 111**
(was 73 with high-reg pins only; 65/52/50 with progressively more levers).

The function is a genuine **global register-allocation local minimum**. The
target's allocation has TWO coupled choices my (identical) agbcc won't reproduce
from any C shape tried:

1. **`srcTable` lives in r6**, time-shared with `flags`: target loads srcTable→r6
   early, derefs `src=srcTable[0]`→r1 after the dst math, then reuses r6 for the
   `flags` value across the loop/tail (`adds r6,r3,#0`). agbcc does this when
   srcTable is *callee-saved* — but in our build no call precedes the src read, so
   agbcc legitimately keeps srcTable in a *caller-saved* reg (r1) and reads src
   back into r2. This shifts srcTable/src/dst by +1 (mine r1/r2/r3 vs target
   r6/r1/r2). Pinning `srcTable asm("r6")` forces it there (fixes dst→r2) BUT the
   `register asm` pin reserves r6 for srcTable's whole *scope*, so `flags` can no
   longer reuse r6 late → flags spills to r7, and the only way to keep flags off
   early-r6 (re-reading `desc->flags` in the tail) keeps `desc` alive → desc=r7
   instead of r3, cascading width=r3, etc.

   Net: you can have **either** (desc=r3, width=r4, flags=r6 — but srcTable=r1,
   dst=r3 shifted; unpinned → 72) **or** (srcTable=r6, dst=r2 — but desc=r7,
   flags via re-read; pinned + re-read → 50). The single-pin language can't
   express the r6 *live-range* time-share the target uses.

2. **ldrsh zero-index uses r7** in the target (`movs r7,#0; ldrsh r0,[r0,r7]`,
   ×2), putting r7 in `live_regs_mask` so the prologue saves `{r4,r5,r6,r7}` and
   uses r6,r7 as the high-reg save temps (`mov r7,r9; mov r6,r8`). Our build picks
   the *just-freed* offset reg (r2) for the index → r7 never enters live_regs_mask
   → prologue saves only `{r4,r5,r6}` with r5,r6 temps. agbcc reload prefers the
   recently-used r2; the target instead keeps r2 reserved for the x-multiply
   destination. Pinning state=r5+srcTable=r6 (config "65") does coincidentally
   push r7 into live_regs_mask and **the prologue then matches** — but at the cost
   of #1's flags/desc cascade.

### Levers tried (all re-derivations, not tweaks)
- high-reg pins (r8=dstX, r9=rows, ip=dstY/loopState) — necessary baseline (73).
- + state asm("r5") + srcTable asm("r6") → 65, **prologue matches**.
- + tail re-read of `desc->flags` (frees early r6 for srcTable) → 52, then with
  explicit early `wideX = (x*3)<<16; dstX = wideX>>16` (defers the dstX narrow to
  match target's split lsls/lsrs) → **50** (current best).
- flagsTail = flags copy (instead of re-read), placed before/after the src read →
  62 (copy lands in r7, blocked by the srcTable=r6 pin holding r6).
- full target-register pin set (dst=r2,src=r1,row=r0,col=r3,width=r4) → 128–129:
  these regs double as coord-section scratch, and `register asm` makes them
  permanently live, distorting the whole prologue/coord block.
- newer AGBCC (vs default OLD_AGBCC) for this TU → identical 50/74; sub_08012664
  in the same TU stays byte-0 either way.
- CFLAGS sweep (`-fforce-addr -fforce-mem -fno-force-mem -foptimize-register-move
  -frerun-cse-after-loop -fno-gcse`) → all 50, no movement.
- permuter: **unavailable in worktree** (vendor/decomp-permuter has no .venv) and
  wrong tool here anyway — this is a *global allocation* divergence, not the
  statement-order/scope drift the permuter mutates.

### What a future attempt should try (a DIFFERENT lever)
- Instrument agbcc's reload/local-alloc (`gcc_arm/{local-alloc,reload,reload1}.c`)
  on a PRIVATE copy to learn WHY srcTable is colored caller-saved (r1) here but
  callee-saved (r6) in the original — likely a `reg_class`/`find_free_reg`
  preference triggered by some C-shape difference upstream. Then find the C shape
  that flips that single decision; everything else cascades back into place.
- Or express the r6 live-range time-share without a whole-scope pin: a construct
  that makes srcTable callee-saved (forces r6) while letting `flags` reuse r6 once
  srcTable is dead — e.g. a real intervening pseudo-call/barrier, or splitting the
  function so srcTable's range provably ends before flags' begins.

## Best-effort C

```c
extern void sub_080100E4(u32, void *, void *);

struct TilemapDescriptor {
    u32 _field_00;
    u8 width;       /* +0x04 */
    u8 _field_05;
    u8 rows;        /* +0x06 */
    u8 _field_07;
    u8 flags;       /* +0x08: bit 0x10 selects EWRAM/VRAM bank 1 */
    u8 _field_09[7];
    const u16 **srcTable; /* +0x10 */
};

struct BlitState {
    u8 _pad00[26];
    u16 stride;
};

/* Blits the entity[30] spawn tilemap (descriptor at 0x08306E64, src row 0)
 * into the active EWRAM bank at the player's tile position, then DMAs the
 * bank to the matching VRAM screenblock. Parameterless sibling of sub_08012BC4. */
void sub_08012798(void)
{
    register u32 dstX asm("r8");
    register u32 rows asm("r9");
    register u32 dstY asm("ip");
    u32 width;
    u32 flags;
    register const u16 **srcTable asm("r6");
    register struct BlitState *state asm("r5");
    u16 *dst;
    const u16 *src;
    u32 row;
    u8 col;
    struct TilemapDescriptor *desc;
    u8 *player;
    u32 wideX;
    u16 stride;
    u32 nextRow;
    void *flushSrc;
    void *flushDst;

    desc = (struct TilemapDescriptor *)0x08306E64;
    player = (u8 *)0x03003720;
    wideX = (*(s16 *)(player + 0x692) * 3) << 16;  /* defer dstX narrow (match split lsls/lsrs) */
    dstY = (u16)(*(s16 *)(player + 0x694) * 3);
    dstX = wideX >> 16;
    width = desc->width;
    rows = desc->rows;
    srcTable = desc->srcTable;

    if ((desc->flags >> 4) & 1) {
        dst = (u16 *)0x02010000;
    } else {
        dst = (u16 *)0x02000000;
    }

    state = (struct BlitState *)0x030060A0;
    stride = state->stride;
    dst += dstY * stride + dstX;
    src = srcTable[0];

    row = 0;
    if (row < rows) {
        register struct BlitState *loopState asm("ip") = state;

        do {
            col = 0;
            nextRow = row + 1;
            if (col < width) {
                do {
                    *dst++ = *src++;
                    col++;
                } while (col < width);
            }
            dst += loopState->stride - width;
            row = (u8)nextRow;
        } while (row < rows);
    }

    flags = desc->flags >> 4;  /* re-read frees early r6 for srcTable; see Drift */
    if (flags & 1) {
        flushSrc = (void *)0x02010000;
        flushDst = (void *)0x0600E800;
    } else {
        flushSrc = (void *)0x02000000;
        flushDst = (void *)0x0600E000;
    }
    sub_080100E4(flags & 1, flushSrc, flushDst);

    *(u8 *)(0x030064C0 + 10) = 0;
    *(u8 *)0x03003610 = 1;
}
```
