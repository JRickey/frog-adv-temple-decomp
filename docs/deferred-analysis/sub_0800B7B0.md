# sub_0800B7B0 — deferred analysis

Twin of `sub_0800BE18` (shipped NAKED) plus a `gGameStuff.pendingMode == 1`
branch that selects the 2nd argument (`b`) to the inner `sub_0800CB80` call
(1 when a mode change is pending, else 0). Resets the first N 8-byte collision
slots of `slots[]` and re-registers each as a collision point.

- Range: [0x0800b7b0, 0x0800b8a8) (248 bytes), `src/engine/sub_0800b7b0.c`.
- Single callee `sub_0800CB80(u8 a, u8 b, s16 c, s16 d, u8 e)` — already peeled
  & in C (`src/engine/sub_0800cb80.c`, compiled under `old_agbcc`).
- Data: `sEntityHitboxTable` (ROM 0x080c0b00, 31 x 12B; struct `{u32 count,
  u32 points, u32 flags}`). `count` read as `(s8)`; `points` is `const s16*`
  to (x,y) pairs; `flags` low byte is arg5.
- IWRAM: `gIwram_35E0._field_18` (offset 0x18 = arg1 xTile) and
  `gGameStuff.pendingMode` (offset 0xA).
- Classifier: ATTEMPT_MATCH (3 high regs r8/r9/sl pinned across the bl — the
  advisory; NOT a structural impossibility). So this is matchable in principle;
  do NOT ship NAKED.

## Drift

Best: **byte_diff 168, diff_count 93/~124, size 248 (exact)** — built under
`old_agbcc` (default agbcc gives 252/194; old_agbcc gives the exact 248-byte
frame). The C below is structurally correct: right control flow, right pool
entries (incl. the DUPLICATE 0x030035e0 pool word the two arms each
materialize), correct high-reg prologue/epilogue (`push {r4-r7,lr}; mov r7,sl;
mov r6,r9; mov r5,r8; push {r5,r6,r7}`), and the high-reg pins (table base in
r8, table+4/points in r9, table base copy in sl) DO emit.

The residual divergence is a single **register-allocation decision** that
cascades through the whole body:

1. Baserom **spills `(s8)type` to `[sp,#12]`** (`asrs r4,...; str r4,[sp,#12]`)
   before the loop and reads it back in the `else` arm, while the `if` arm uses
   a live `type<<24` copy. This 4th spill slot makes the frame `sub sp,#16`.
   My C keeps `(s8)type` in a register for both arms → no spill → `sub sp,#12`.
2. Because `(s8)type` is spilled, baserom frees **r1 for the loop counter `i`**
   (`movs r1,#0; cmp r1,r0`). My C puts `i` in **r3**. This single reg change
   cascades: the slot-index `i*8` fuses in baserom as `lsls r2,r1,#24; asrs
   r1,r2,#21` (sign-ext + <<3 in one `>>21`); mine needs 3 ops because `i` must
   move out of r3 first.
3. **Stack-slot order reversed**: baserom `slots→[sp,#4]`, `out→[sp,#8]`,
   `(s8)type→[sp,#12]`; mine `out→[sp,#4]`, `slots→[sp,#8]` (no type slot).
4. Baserom emits `movs r1,#0` (i=0) BEFORE the table-base pool load; mine loads
   the table base first (forced early by the `register asm("r8")=...` init),
   pushing `i` to r3.

All four trace to (1): if `(s8)type` spilled, r1 frees for `i` and the rest
falls into place. The blocker is that agbcc won't spill `(s8)type` from pure C
because my high-reg pins (r8/r9/sl) free up r4-r7, so there's no register
pressure forcing the spill.

## Levers tried (all DISTINCT structures — none beat 168)

- `s8 type` vs `u8 type` param (u8 gives the `lsrs r6` zero-extend baserom uses
  at the loop-back condition, but body got worse): 168 vs 189.
- Per-iteration `s8 typeIdx = (s8)type` local to force a spill: 189-208 (worse;
  agbcc recomputes per iter instead of spilling once).
- Dual-form (`s8 t = type` used in body, `type` in condition): 212 (CSE'd t and
  type together).
- `register u8 typeZ asm("r6")` pin (matches the baserom r6=(u8)type): 188.
- `register s8 i asm("r1")` pin (to force i into r1): 199 (allocator fought it).
- Asymmetric arms (`if` uses pinned r9/sl, `else` reloads `table[typeIdx]`
  fresh) to mirror the baserom's branch-local alloc: 168 (no better than the
  symmetric form; the asymmetry is agbcc's, not the source's).
- `tbl2`/`points` (= table, table+4) assigned INSIDE the loop body (recomputed
  per iter): THIS got size to exact 248 and diff to 168 — the current best.
  Assigning them once before the loop gives 224/185.
- `if`+`do-while` instead of `for`: 232/202 (worse).
- Flags: `-fno-strength-reduce` no change (168); default-agbcc 252/194 (worse,
  old_agbcc is required for the exact frame).
- Permuter: NOT run — 168 is far above the ~40 byte_diff / single-digit
  threshold the permuter needs (diff_count 93/124, not a shifted near-match).
  A wrong base wastes permuter time.

## Next lever to try (DIFFERENT from above)

The whole match hinges on making agbcc **spill `(s8)type` to `[sp,#12]`** once
before the loop while keeping `(u8)type` live in r6. Ideas NOT yet tried:
- Add MORE register pressure in the loop body via extra `register asm("rN")`
  pins on r4/r5/r7 (mirror baserom: r5 = `i<<24` live across the call, r7 =
  scratch) so the allocator is forced to spill `(s8)type`. Pin the *exact* live
  set baserom uses: r4=(s8)type(spilled), r5=i<<24, r6=(u8)type, r7=scratch,
  r8/r9/sl as now.
- Read the agbcc `local-alloc.c`/`reload.c` spill heuristic (around the
  "likely spilled" class at lines 59-60, 772-788) to learn what liveness
  pattern triggers the [sp,#12] spill, then shape the C to that.
- Try declaring `type` as `int` and masking, to change how the two extensions
  ((u8) for r6, (s8) for the index) are scheduled.

## Best-effort C (byte_diff 168, size exact 248, old_agbcc)

Requires `src/engine/sub_0800b7b0.s: CC = $(OLD_AGBCC_BIN)` in the Makefile.

```c
#include "game.h"
#include "iwram.h"
#include "macros.h"
#include "types.h"

typedef struct EntityHitbox {
    u32 count;
    u32 points;
    u32 flags;
} EntityHitbox;

extern const EntityHitbox sEntityHitboxTable[];
extern int sub_0800CB80(int xTile, int b, int x, int y, int flags);

void sub_0800B7B0(u8 *slots, u32 *out, s8 type)
{
    register const EntityHitbox *table asm("r8") = sEntityHitboxTable;
    register const u8 *points asm("r9");
    register const EntityHitbox *tbl2 asm("sl");
    s8 i;

    for (i = 0; i < (s8)table[type].count; i++) {
        u8 *slot = &slots[i * 8];
        const s16 *pt;

        tbl2 = table;
        points = (const u8 *)table + 4;

        slot[4] = 0;
        slot[5] = 0;
        slot[6] = 0;
        *(u32 *)slot = 0;

        if (gGameStuff.pendingMode == 1) {
            pt = (const s16 *)(i * 4 + *(u32 *)(type * 12 + (u32)points));
            sub_0800CB80(gIwram_35E0._field_18, 1, pt[0], pt[1],
                         ((const EntityHitbox *)(type * 12 + (u32)tbl2))->flags);
        } else {
            pt = (const s16 *)(i * 4 + *(u32 *)(type * 12 + (u32)points));
            sub_0800CB80(gIwram_35E0._field_18, 0, pt[0], pt[1],
                         ((const EntityHitbox *)(type * 12 + (u32)tbl2))->flags);
        }
    }

    out[0] = 0;
    out[1] = 0;
}
```
