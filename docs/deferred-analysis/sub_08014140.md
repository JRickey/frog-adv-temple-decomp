### Structural wins (KEEP THESE — they are correct)

- **p in r4 via alias, NOT -ffixed-r3.** `register struct AnimState *p asm("r4") = p0;`
  with the param renamed `p0`. This is the ONLY clean way to get p→r4 (the natural
  alloc parks p in r3, a caller-saved reg, which cascades wrong). `-ffixed-r3` also
  gets p→r4 AND fixes the p-copy ordering, but it forbids r3 (which the target uses
  for field_0b / oldField2c) and wrecks the early block (counter→r8 detour) — net far
  worse. The alias's only cost: the `adds r4,r0,#0` p-copy is scheduled AFTER the
  `lsls/lsrs` step zero-extend (target copies p FIRST), a 4-byte branch-offset shift
  on the two early returns. Not worth -ffixed-r3's damage.
- **counter pinned r2 + cached.** `register u32 counter asm("r2");` then
  `counter = gGameStuff._unk00;` read ONCE and reused at `p->field_04 = counter`.
  Without caching, agbcc CSEs the two gGameStuff reads into a callee-saved reg (r8)
  with two extra movs. The r2 pin keeps it caller-saved (no calls in the fn).
- **oldField2e as `u16 oldField2e[1]` (1-elem array).** Forces it to a HALFWORD
  stack slot (`strh [sp,#4]` / `ldrh`), matching the target. A plain u16 local stays
  in a register or word-spills (`str`/`ldr`), which is wrong.
- **f9 as `register int asm("r9")`** (NOT u32/u8). `int` makes the `mov r2,r9` read
  land in r2 (matching), and is required for the interleave below.
- **Sign-extend interleave via explicit temps.** Write
  `t34 = (s32)oldField34 << 16; t36 = (s32)oldField36 << 16; v34 = t34>>16; v36 = t36>>16;`
  (NOT `v34 = (s16)oldField34; v36 = (s16)oldField36;`). This makes agbcc emit both
  `lsls #16` THEN both `asrs #16` (target's combine ordering), instead of two
  serial lsls/asrs pairs. Big win (~10 byte_diff).
- **hi computed BEFORE the sign-extends** (`hi = (u8)f9 >> 4;` immediately before
  the `t34=...` lines, switch on the `hi` variable). The target evaluates the
  second-switch selector first.
- **flag store via a struct at base 0x03003610, byte +1** (`gBgFlag_14140.dirty=1`),
  not `*(u8*)0x03003611`. Matches the `ldr =0x03003610; strb r0,[r1,#1]` pool layout.
- **oldField34 pinned `sl`, rows pinned `ip`** (target high-reg allocation). old10
  lands in r8 NATURALLY (no pin needed — removing the r8 pin keeps diff 33).
- **`iw = &gBlitState_14140` LOCAL pointer** (not inlined `gBlitState_14140.stride`).
  The local makes agbcc keep the 0x030060A0 base in r7 across the loop (target caches
  it there). Inlining makes the loop RELOAD the literal each iteration (`ldr =…;
  ldrh` = +1 insn/iter), which is wrong.
- **v34 pinned r0, v36 pinned r3** + **src pinned r3** + **c (inner counter) pinned r2.**
  These get the asrs targets and most of the loop registers right.

## Remaining drift (the actual blockers — 3 clusters)

1. **Loop register 3-way rotation (~12 of the 33 diffs).** The nested copy loop is
   BYTE-IDENTICAL to the target except a clean 3-cycle of registers:
   target `(c, src, row+1) = (r2, r3, r1)`; best build `(r1, r2, r3)`.
   - The seed is the inner counter `c` wanting r1 (allocno priority:
     `floor_log2(refs)*refs/live_length` — c has the most refs in the inner loop, so
     it is colored first and grabs the lowest free reg r1; `row+1`, the outer
     induction update, has fewer refs and gets r2). The target has row+1 in r1, c in
     r2 — i.e. row+1 colored first.
   - PROOF it is reproducible: matched `src/engine/sub_080169bc` is the SAME nested
     blit loop and naturally emits `cmp counter,limit` with c in r2 (no pins). The
     difference is purely the surrounding pin pressure in THIS function.
   - PROOF of the fix shape: `-ffixed-r1` (forbid r1) makes the loop emit EXACTLY the
     target loop (`movs r2,#0` c→r2, `ldr r3,[r4,#12]` src→r3, no fold) — but it
     forbids r1 across the WHOLE fn and wrecks everything else (diff 160). We need r1
     free only in the loop, which `-ffixed` can't scope. This is the permuter's job
     (statement-reorder / scope changes to flip the coloring) — it was UNAVAILABLE
     this run.
   - Pinning `c asm("r2")` puts c in r2 but TRIGGERS the `0 < cols → cols != 0`
     cprop fold (`cmp r5,#0; beq` instead of target's `cmp r2,r5; bcs`) — see #2.
     So the c-pin trades the rotation for the fold; net diff 33 either way.

2. **Inner-loop `0 < cols` fold (~2 diffs).** With c pinned to r2, agbcc's CSE/cprop
   (`simplify_relational_operation` in tools/agbcc-src/gcc/cse.c) substitutes the
   known c=0 and folds `c < cols` to `cols != 0` (`cmp r5,#0; beq`). The target keeps
   `cmp c,cols; bcs`. The fold ONLY fires when c is PINNED to r2 (hard-reg constant
   visible to cprop); unpinned c does NOT fold but lands in r1 (the rotation). The
   matched sub_080169bc does NOT fold (c unpinned, naturally r2). So the fix is to get
   c→r2 WITHOUT a pin (permuter) — not a pin.

3. **hi `<<24>>28` idiom (~5 diffs incl. cascade).** Target extracts the high nibble
   as `lsls r0,r2,#24; lsrs r2,r0,#28` (the agbcc lowering of `(unsigned char)X >> 4`
   when X's high bits are UNKNOWN). Our f9 (from `t9 = p->field_09` ldrb, a clean u8)
   is value-range-tracked as ≤255, so EVERY tried form folds to `lsrs #4` + a dead
   `adds` copy: `(u8)f9>>4`, `f9>>4`, `(f9>>4)&0xF`, `(f9&0xF0)>>4`,
   `(u8)(f9<<24>>28)`, `((u32)(u8)f9<<24)>>28` all give `lsrs r1,r2,#4; adds r2,r1,#0`.
   The target's agbcc LOST the ≤255 range info across the `mov r9,r0` (store into a
   high callee-saved hard reg). agbcc 2.x's `nonzero_bits` is per-pseudo and our build
   preserves it through the pin; the ROM build did not. This `<<24>>28` vs `lsrs #4`
   is the SEED that puts hi in r1 (mine) vs r2 (target) and cascades through the second
   switch. Could not reproduce in pure C; likely needs the permuter or a stack
   round-trip of f9 (untried — would add insns).

Minor: the p-copy ordering shift (4 bytes, see "alias" above).

## Levers TRIED and rejected (do NOT repeat)

- `-ffixed-r3`: p→r4 + p-copy-first, but breaks the early block (counter→r8). Net worse.
- `-ffixed-r8` (with old10 unpinned): old10 NEEDS r8; breaks early block. diff 101.
- `-ffixed-r1`: makes the loop perfect but wrecks the rest. diff 160.
- `-fno-gcse`: did NOT undo the inner fold (it's CSE, not GCSE); regressed elsewhere.
- `-fforce-addr`: size 464, far worse.
- the newer `agbcc` (vs default old_agbcc): diff 131, much worse. old_agbcc is correct.
- pinning hi to r2: reorders hi-compute after the sign-extends, diff 59+. Worse.
- pinning v34 to r0 (alone, no save temp): keeps v34 low but PREVENTS the target's
  `adds r2,r0,#0` save (the multiply can't reuse r0), leaving the fn 4 bytes short.
- unpinning v34: spills to r8 (global promotes the cross-switch value). Worse.
- explicit `v34s asm("r2")` save temp: gets size 404 + src→r3, but pushes the iw base
  to r8 and the loop reads stride via r8 (worse iw handling). byte_diff 106 but uglier.
- moving v34/v36 compute AFTER the switch: diff 52+. They MUST be before (target).
- declaring c inside the outer loop / reordering declarations: no effect (alloc is
  priority-based, not declaration-ordered).
- `c < cols` vs `c != cols` vs while-loop vs split `c=0;`: all fold identically.

## Best-effort C
```c
#include "game.h"
#include "macros.h"
#include "types.h"

enum AnimStepMode {
    ANIM_STEP_DOWN = 1,
    ANIM_STEP_UP = 2,
    ANIM_STEP_RIGHT = 3,
    ANIM_STEP_LEFT = 4,
};

struct AnimState {
    u8 _pad00[4];
    u32 field_04; /* +0x04 */
    u8 idx;       /* +0x08 */
    u8 field_09;  /* +0x09 */
    u8 _pad0a;
    u8 field_0b;  /* +0x0b */
    u32 field_0c; /* +0x0c */
    u32 field_10; /* +0x10 */
    u8 _pad14[24];
    u16 field_2c; /* +0x2c */
    u16 field_2e; /* +0x2e */
    u16 field_30; /* +0x30 */
    u16 field_32; /* +0x32 */
    u16 field_34; /* +0x34 */
    u16 field_36; /* +0x36 */
};

struct BlitState_14140 {
    u8 _pad00[26];
    u16 stride; /* +0x1a */
};

#define gBlitState_14140 (*(struct BlitState_14140 *)0x030060A0)

struct BgFlag_14140 {
    u8 _pad00;
    u8 dirty; /* +0x01 */
};

#define gBgFlag_14140 (*(struct BgFlag_14140 *)0x03003610)

u8 sub_08014140(struct AnimState *p0, u8 step)
{
    register struct AnimState *p asm("r4") = p0;
    register u32 counter asm("r2");
    u16 oldField2e[1];
    u16 oldField2c;
    register u16 oldField34 asm("sl");
    u16 oldField36;
    u32 old10;
    register int f9 asm("r9");
    register u32 rows asm("ip");
    u8 cols;
    u8 mode;
    u8 t9;
    u8 hi;
    register s32 v34 asm("r0");
    register s32 v36 asm("r3");
    s32 t34;
    s32 t36;
    u16 *dst;
    register u16 *src asm("r3");
    struct BlitState_14140 *iw;
    u8 row;
    register u8 c asm("r2");

    counter = gGameStuff._unk00;
    if (counter - p->field_04 < p->field_0b) {
        return 0;
    }

    oldField2e[0] = p->field_2e;
    if ((s16)p->field_2e == 0) {
        return 1;
    }

    oldField2c = p->field_2c;
    if ((s16)p->field_2c == 0) {
        return 1;
    }

    p->field_04 = counter;
    oldField34 = p->field_34;
    oldField36 = p->field_36;
    old10 = p->field_10;
    p->field_0c = old10;
    t9 = p->field_09;
    mode = t9 & 0xF;
    f9 = t9;

    switch (mode) {
    case ANIM_STEP_DOWN:
        p->field_36 += step;
        p->field_2e = oldField2e[0] - step;
        rows = step;
        cols = (u8)oldField2c;
        p->field_10 = old10 + rows * p->field_30 * 2;
        break;
    case ANIM_STEP_UP:
        p->field_36 -= step;
        p->field_2e = oldField2e[0] - step;
        rows = step;
        cols = (u8)oldField2c;
        p->field_10 = old10 - rows * p->field_30 * 2;
        break;
    case ANIM_STEP_RIGHT:
        p->field_34 += step;
        p->field_2c = oldField2c - step;
        cols = step;
        rows = (u8)oldField2e[0];
        p->field_10 = old10 + (step << 1);
        break;
    case ANIM_STEP_LEFT:
        p->field_34 -= step;
        p->field_2c = oldField2c - step;
        cols = step;
        rows = (u8)oldField2e[0];
        p->field_10 = old10 - (step << 1);
        break;
    }

    gBgFlag_14140.dirty = 1;

    hi = f9 >> 4;
    t34 = (s32)oldField34 << 16;
    t36 = (s32)oldField36 << 16;
    v34 = t34 >> 16;
    v36 = t36 >> 16;

    switch (hi) {
    case 0:
        dst = (u16 *)0x02000000;
        break;
    case 1:
        dst = (u16 *)0x02010000;
        break;
    case 2:
        dst = (u16 *)0x02020000;
        break;
    }

    iw = &gBlitState_14140;
    dst += v34 + iw->stride * v36;
    src = (u16 *)p->field_0c;

    for (row = 0; row < rows; row++) {
        for (c = 0; c < cols; c++) {
            *dst++ = *src++;
        }
        dst += iw->stride - cols;
        src += p->field_30 - cols;
    }

    return 0;
}
```
