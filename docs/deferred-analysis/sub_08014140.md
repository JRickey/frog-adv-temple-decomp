# sub_08014140 — deferred analysis

2D tilemap-blit / scroll-step on the `struct AnimState` shared with
`sub_080140A0` (sub_08014078.c). Pure-C structure is **fully solved** — every
instruction is the correct opcode at the right place. The sole residual is a
single agbcc *combine* fold (the high-nibble `>>4`) that cascades into the
register coloring around the second `switch`. Best clean barrier-free pure C:
**byte_diff 105, diff_count 32, size 404 (correct)**.

## What it does
`u8 sub_08014140(struct AnimState *p, u8 step)`:
1. Frame gate: `if (gGameStuff._unk00 - p->field_04 < p->field_0b) return 0;`
2. Save `oldField2e = p->field_2e` (HImode stack spill at [sp,#4]); if
   `field_2e == 0` (signed `ldrsh`) → `return 1`. Same for `field_2c` ([sp])
   → `return 1`.
3. Commit: `field_04 = counter`, snapshot `field_34/36/10`, `field_0c = field_10`.
4. `switch (field_09 & 0xF)` (scroll mode 1..4): updates field_34/36/2c/2e and
   recomputes `field_10` (dest offset) by ± `step*field_30*2` or ± `step*2`.
   Also sets `cols`/`rows` (blit extents) and `*(u8*)0x03003611 = 1`.
5. `switch ((field_09 >> 4) & 0xF)` (dest bank 0/1/2) selects EWRAM base
   0x02000000 / 0x02010000 / 0x02020000.
6. `dst = base + (v34 + gIwram_60A0.stride*v36)*2`, `src = field_0c`; then a
   `rows × cols` u16 2D copy with src row-stride `field_30` and dest row-stride
   `gIwram_60A0.stride` (at gIwram_60A0 + 0x1a).
7. `return 0;`

## ROOT CAUSE — the keystone fold (CONFIRMED a toolchain divergence, NOT a C-shape problem)

The crux (offsets 0xf2..0xf6). Baserom keeps the high-nibble extraction as TWO
unmerged shifts:
```
    mov  r2, r9          @ r2 = f9 (= the full byte field_09, cached in r9)
    lsls r0, r2, #24
    lsrs r2, r0, #28     @ hi = (f9 << 24) >> 28   (in r2)
```
Our agbcc instead MERGES the two shifts into `lsrs r1, r2, #4` (then `adds
r2, r1, #0` to keep a copy), and lands `hi` in **r1** not r2 — which cascades
into all the `cmp r1,#X` vs `cmp r2,#X` of the second switch and frees r2
differently for v34/v36 and the loop.

### Why the merge is forced (read `combine.c`)
`gcc_arm/combine.c:simplify_shift_const` (the ASHIFT-inside-LSHIFTRT case, ~line
8699) ALWAYS merges `(x << 24) >> 28` into `(x >> 4) & mask` **when it can prove
the result's high bits are already zero** — and it can, because combine's
`nonzero_bits` of `f9` is 0xFF (f9 is single-def, traced back to the `ldrb
field_09` via `get_last_value`, combine.c:10911 — `REG_N_SETS(r9)==1` makes the
trace succeed across basic blocks). So the `& 0xF0`-redundant mask collapses
and only `lsr #4` remains.

### Empirically isolated (THE key new finding this round)
- A `u8` value whose `nonzero_bits` combine CANNOT prove 8-bit (e.g. a raw `u8`
  function *parameter*, or `f9` once its byte-trace is broken) keeps the
  UNFOLDED `lsl #24; lsr #28`. PROVEN with a standalone probe.
- In the real function the unfold IS reachable: deriving `mode` from `f9`
  (`switch (f9 & 0xF)` / `mode = f9 & 0xF`) forces agbcc to read r9 early
  (`mov r7,r9; ands r0,r7`), which **breaks combine's byte-trace of f9** →
  the nibble UNFOLDS (`lsls #24; lsrs #28`, with `counter` pinned to r2 it lands
  at byte_diff 168 / size 404, nibble correct).
- BUT that same early r9-read changes the FIRST-switch mask from the target's
  `movs r2,#15; ands r2,r0` (mask the *byte* r0) to `mov r0,#0xf; mov r7,r9;
  ands r0,r7` (mask via r9), AND reshuffles the frame (oldField36 → r8 instead
  of [sp,#0], dropping a stack slot to `sub sp,#4`). Net regression to 168/322.
- **The contradiction:** the baserom has BOTH `ands r2,r0` (mask reads the byte
  → f9 IS byte-traceable here) AND the unfolded nibble (→ f9 is NOT
  byte-traceable here). With our agbcc, f9 is single-def, so its byte-trace is
  either intact for the WHOLE function (→ correct mask + folded nibble = the
  105/32 base) or broken for the WHOLE function (→ wrong mask + unfolded nibble
  = 168/322). There is no pure-C lever that makes combine trace f9 at the mask
  but not at the nibble — that requires a different `subst_low_cuid` window than
  our agbcc produces. The original ROM's agbcc made that split; ours cannot.

This matches the prior corpus sweep's conclusion (`>>28` appears in ZERO of the
23 corpus mirrors). It is a genuine combine/version divergence on this single
fold, confirmed three independent ways this round: (1) combine.c source path,
(2) the mask/frame coupling above, (3) a fresh permuter run.

## Drift (best clean pure-C base: byte_diff 105 / diff_count 32 / size 404)
Three independent diff clusters, all downstream of the fold or pure coloring:
- **A — nibble fold + cascade** (0xf4,0xf6,0x104,0x108,0x10c, plus branch-byte
  shifts 0x20,0x3c,0x146): hi in r1 vs r2.
- **B — v34/v36 sign-extend interleave** (0xfc,0xfe,0x100,0x102): baserom emits
  both `lsls #16` then both `asrs #16` (more scheduled); ours does each
  `lsls;asrs` pair fully. Coupled to hi-in-r2 freeing r2.
- **C — loop base-cache + inner counter** (~18 diffs, 0x12e..0x16c): baserom
  keeps `&gIwram_60A0` in r1 for the initial stride read then caches it to r7
  (`adds r7,r1,#0`); the inner `c=(u8)(c+1)` is computed `adds r0,r2,#1; lsls;
  lsrs r2` (next into r0, back to r2). Ours loads base straight into r7 and
  increments c in place. Coupled to r2 availability (the hi-copy occupies r2).

## Levers TRIED this round (and prior) — pick a DIFFERENT one
- hi expression forms: `(u8)(((u32)f9<<24)>>28)`, `f9>>4`, `(f9&0xF0)>>4`,
  `(f9>>4)&0xF`, bitfield `hi:4` member, `f9/16` — ALL fold (or use asr).
- `register u8/u32 f9 asm("r9")`, `t9`-intermediate present/absent, f9 from a
  second `ldrb` — all keep the byte-trace → fold.
- mode/switch derived from f9 (breaks trace → unfold) → wrong mask + frame
  (168 with counter=r2 pin; 322 without). Net WORSE than 105.
- CFLAGS sweep (no effect on the fold): `-fno-schedule-insns(2)`, `-fno-gcse`,
  `-fno-cse-follow-jumps`, `-fno-rerun-cse-after-loop`, `-fno-expensive-
  optimizations`, `-fforce-addr`, OLD vs new agbcc — ALL still `lsr #4`.
- Permuter (barrier-free 105/32 base, correct $t/$d target via
  make_permuter_target.py, base score 1335 ≈ correct): 313 iters, NEVER beat
  base. Confirms statement/scope mutation cannot cross the fold/coloring wall.

## Next ideas (for a future attempt)
1. The split-trace is the whole game. The only remaining theoretical lever is
   to make `f9` MULTIPLY-DEFINED (`REG_N_SETS(r9) != 1`) so `get_last_value`
   returns 0 at BOTH sites — but then the mask would also lose the byte-trace.
   Unless a second def of f9 can be placed AFTER the mask but BEFORE the nibble
   that is (a) value-identical and (b) survives combine/CSE without adding an
   instruction. All self-assign / `|0` / `+0` attempts were optimized away.
   Worth probing: a second def whose RHS is opaque-but-equal (e.g. derived from
   a switch-case-set temp that always equals field_09) — risky, likely adds code.
2. Instrument agbcc (private debug copy — NEVER the shared symlink) with an
   `fprintf` at the `simplify_shift_const` ASHIFT/LSHIFTRT merge site and at
   `get_last_value`'s `subst_low_cuid` check, compile ONLY this TU, and confirm
   the exact CUID/window that differs. If the window genuinely cannot be moved
   by any C, this function is a true toolchain-divergence and a candidate for a
   documented `NON_MATCHING` ship (currently NOT done — classifier is
   ATTEMPT_MATCH, so the bar for NAKED is not met).
3. Do NOT re-run the corpus `>>28` search (confirmed absent across all mirrors)
   and do NOT re-run the permuter from the 105/32 base (confirmed stuck).

## Best-effort C (clean, barrier-free pure C — byte_diff 105, no asm / no NON_MATCHING)
```c
#include "macros.h"
#include "types.h"
#include "game.h"

struct AnimState {
    u8 _pad00[4];
    u32 field_04;
    u8 _pad08;
    u8 field_09;
    u8 _pad0a;
    u8 field_0b;
    u32 field_0c;
    u32 field_10;
    u8 _pad14[24];
    s16 field_2c;
    s16 field_2e;
    u16 field_30;
    u16 field_32;
    u16 field_34;
    u16 field_36;
};

struct IwramAt60A0 {
    u8 _pad00[26];
    u16 stride; /* +0x1a */
};

#define gIwram_60A0 (*(struct IwramAt60A0 *)0x030060A0)

u8 sub_08014140(struct AnimState *p, u8 step)
{
    u32 old10;
    register u8 f9 asm("r9");
    register u16 oldField34 asm("sl");
    register u32 rows asm("ip");
    register u16 *dst asm("r6");
    register u16 *src asm("r3");
    u32 counter;
    u16 oldField2e_a[1]; /* 1-elem array escapes PROMOTE_MODE -> HImode [sp,#4] spill */
    u16 oldField2c;
    u16 oldField36;
    s32 v34;
    s32 v36;
    u8 hi;
    u8 mode;
    u8 t9;
    u8 cols;
    u8 row;
    u8 *gpFlag;
    register struct IwramAt60A0 *iw asm("r7");

    counter = gGameStuff._unk00;
    if (counter - p->field_04 < p->field_0b)
        return 0;

    oldField2e_a[0] = p->field_2e;
    if (p->field_2e == 0)
        return 1;

    oldField2c = p->field_2c;
    if (p->field_2c == 0)
        return 1;

    p->field_04 = counter;
    oldField34 = p->field_34;
    oldField36 = p->field_36;
    old10 = p->field_10;
    p->field_0c = old10;
    t9 = p->field_09;
    mode = t9 & 0xF;
    f9 = t9;

    switch (mode) {
    case 1:
        p->field_36 += step;
        p->field_2e = oldField2e_a[0] - step;
        rows = step;
        cols = (u8)oldField2c;
        p->field_10 = old10 + rows * p->field_30 * 2;
        break;
    case 2:
        p->field_36 -= step;
        p->field_2e = oldField2e_a[0] - step;
        rows = step;
        cols = (u8)oldField2c;
        p->field_10 = old10 - rows * p->field_30 * 2;
        break;
    case 3:
        p->field_34 += step;
        p->field_2c = oldField2c - step;
        cols = step;
        rows = (u8)oldField2e_a[0];
        p->field_10 = old10 + ((u32)step << 1);
        break;
    case 4:
        p->field_34 = p->field_34 - step;
        p->field_2c = oldField2c - step;
        cols = step;
        rows = (u8)oldField2e_a[0];
        p->field_10 = old10 - ((u32)step << 1);
        break;
    }

    gpFlag = (u8 *)0x03003610;
    gpFlag[1] = 1;

    hi = (u8)(((u32)f9 << 24) >> 28); /* baserom keeps lsls#24;lsrs#28; our agbcc folds to lsr#4 */
    v34 = (s16)oldField34;
    v36 = (s16)oldField36;

    switch (hi) {
    case 0:
        dst = (u16 *)0x02000000;
        break;
    case 1:
        dst = (u16 *)0x02010000;
        break;
    case 2:
        dst = (u16 *)0x02020000;
        break;
    }

    iw = &gIwram_60A0;
    dst = (u16 *)((u32)dst + ((u32)(v34 + iw->stride * v36) << 1));
    src = (u16 *)p->field_0c;

    for (row = 0; row < rows; row++) {
        register u8 c asm("r2");
        for (c = 0; c < cols; c++) {
            *dst++ = *src++;
        }
        dst = (u16 *)((u32)dst + ((u32)(iw->stride - cols) << 1));
        src = (u16 *)((u32)src + ((u32)(p->field_30 - cols) << 1));
    }

    return 0;
}
```
