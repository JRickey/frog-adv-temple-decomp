# sub_0801288C — deferred analysis

Tile-block blit: copies a `width*height` halfword tile rectangle from a ROM
descriptor's pixel source into the EWRAM staging buffer at the player's tile
origin, padding each row to the grid stride, then queues the EWRAM->VRAM
upload via `sub_080100E4` and clears a dirty byte.

ATTEMPT_MATCH (classifier). Structurally fully decoded; blocked only by
agbcc register-coloring of `colBase` (ip vs r1), which cascades into pool
layout. NOT a structural-impossibility — do NOT ship NAKED.

## Data / address map (all verified against baserom bytes)

- ROM descriptor `sTileBlit_6e64` @ `0x08306e64` (inside sSpriteAnimBlock_06838):
  - `+0x1c` u8 `width`  (=3 in baserom)
  - `+0x1e` u8 `height` (=3)
  - `+0x20` u8 `flags`  (=0x10; `flags>>4 == 1` selects the EWRAM/VRAM pair)
  - `+0x28` u32 ptr table; entry `[1]` (i.e. `*(u32*)(ptr+4)`) = the u16 pixel source
  - Add `sTileBlit_6e64 = 0x08306e64;` to linker.ld (mirrors sAnimDesc_6e08 idiom).
- Player tile origin: `*(s16*)(&gIwram_3720 + 0x692)` (= rowBase*1/3 source) and
  `+0x694` (= colBase source); each multiplied by 3 then narrowed to u16.
  rowBase = `*0x692 * 3`, colBase = `*0x694 * 3`.
- Dest base: `(flags&1) ? 0x02010000 : 0x02000000` (EWRAM staging).
- **Stride** = `*(u16*)(0x030060A0 + 0x1A)`  (gIwram_60A0; NOT 0x030064c0 — easy
  to conflate, the two bases are distinct).
- dst offset (halfwords) = `colBase * stride + rowBase`.
- Row advance after each inner row = `stride - w` (so total per row = stride).
- Tail: `sub_080100E4(flags&1, ewram, vram)` where the EWRAM/VRAM args are
  `(0x02010000, 0x0600E800)` when `flags&1`, else `(0x02000000, 0x0600E000)`.
- Sentinel: `*(u8*)(0x030064C0 + 0x0A) = 0` (gIwram_64C0 dirty byte).

## Drift

- Best: **byte_diff 124, diff_count 69** (size 236 vs target 240; the 4-byte
  delta is the outer-loop h-compare form).
- The decode is correct. The whole residual flows from ONE allocator choice:
  the target keeps **colBase in `ip` (r12)** through the setup, frees it after
  the `muls`, and **time-shares `ip`** to cache the `0x030060A0` grid pointer
  across the loop (`ip = r4` once at loop entry). Our build narrows colBase
  into **r1** and instead parks the grid pointer in `ip`/r7 from the start, so
  no time-share — and the differing register names + the extra grid-pointer
  load shift the entire pool layout (hence the large nominal byte_diff for a
  near-correct function). Secondary: ldrsh zero-index reg is r6 here vs r7 in
  baserom; outer-loop counter lives in r3 vs r0 (target precomputes i+1 in r4).
- **Key matching levers already FOUND (keep these — they are correct):**
  - `register u32 rowBase asm("r8")` + `register u8 h asm("r9")` pins (REQUIRED:
    without them agbcc never allocates r8/r9 and the `push {r6,r7}` save of the
    high regs disappears — size drops to 224/228).
  - **Deferred u16 narrowing of rowBase**: compute it into a plain `u16 rb`
    FIRST, then `register u32 rowBase asm("r8") = rb;` LATER. This is what makes
    agbcc split rowBase's `<<16 ... >>16` around the colBase computation, exactly
    matching baserom (0x1288c+0x1c..0x32). Assigning the pin directly (no `rb`
    temp) does eager narrowing and regresses (146).
  - Passing literal `1`/`0` (not `flags&1`) as the `sub_080100E4` select arg in
    each branch dropped byte_diff 141 -> 124.

## Levers TRIED that did NOT close it (pick a DIFFERENT one next time)

- `register u16 ... asm("r8")` (u16, not u32): ELIDES the narrowing entirely
  (no `<<16>>16`) — wrong; u32-pin + `(u16)` cast on the `rb` temp is right.
- Unpinning rowBase / pinning only h->r9: agbcc puts neither in r8 (regresses to
  198/203).
- `register u16 colBase asm("ip")` to force colBase into r12: agbcc treats a
  NAMED ip pin as needing save/restore -> 244 bytes, byte_diff 225 (much worse).
- Held raw `u8 *grid = (u8*)0x030060A0` vs struct global `gIwram_60A0.stride`
  vs absolute `*(u16*)0x030060BA`: all park grid in ip/r7 from the start
  (124 / 127 / 144) — none reproduce the colBase-in-ip time-share.
- Swapping the multiply operand order (`stride * colBase`): no change (124).
- `int` vs `u8` outer loop counter `i`: no change (124).
- Per-TU `CC = OLD_AGBCC_BIN`: identical output (124) — not a compiler-version
  thing.
- **decomp-permuter** from the 141 base: 1473 iters, base score 4690, best 4520,
  NO score-0. The mutations (statement/scope shuffle) do not reach the colBase
  ip-vs-r1 coloring; permuter is the wrong tool for this one.

## What to try NEXT (untried structural ideas)

- Force colBase to vacate r1 so agbcc must use ip: add register pressure on the
  low bank during setup (e.g. a second pinned high-reg value, or cast a dead
  pointer to an index to pin its reg — the sub_0800A1C8 `p=(T*)(u32)p->f` trick).
- Read the agbcc `local-alloc.c`/`reload.c` pass to see WHY the u16-narrow of
  colBase targets r1 not ip, then shape the C so the narrow's destination is the
  multiplicand register that feeds `muls` (which the baserom sources from ip).
- Try making the outer loop `for (i=0; i<h; i++)` produce the i-in-r0 / i+1-in-r4
  precompute form (target hoists `i+1` before the inner loop) — possibly a
  `do{}while` or an explicit `i_next` temp.

## Best-effort C (byte_diff 124 — structurally faithful, register-coloring drift)

```c
#include "iwram.h"
#include "types.h"

typedef struct TileBlitDesc {
    u8 _pad00[0x1c];
    u8 width;
    u8 _pad1d;
    u8 height;
    u8 _pad1f;
    u8 flags;
    u8 _pad21[7];
    const u16 *const *src;
} TileBlitDesc;

extern const TileBlitDesc sTileBlit_6e64;   /* linker.ld: sTileBlit_6e64 = 0x08306e64; */

struct IwramAt64C0 {
    u8 _pad00[0x0a];
    u8 dirty;
};

extern void sub_080100E4(u32 select, void *ewram, void *vram);

void sub_0801288C(void)
{
    const TileBlitDesc *desc = &sTileBlit_6e64;
    u8 *flagsPtr = (u8 *)desc + 0x20;
    u8 *coord = (u8 *)&gIwram_3720;
    u16 rb = (u16)(*(s16 *)(coord + 0x692) * 3);
    u16 colBase = (u16)(*(s16 *)(coord + 0x694) * 3);
    register u32 rowBase asm("r8") = rb;          /* deferred-narrow via rb temp */
    u8 w = desc->width;
    register u8 h asm("r9") = desc->height;
    const u16 *const *ptr = desc->src;
    u8 *grid = (u8 *)0x030060A0;
    u32 flags = *flagsPtr >> 4;
    const u16 *src;
    u16 *dst;
    u8 i;

    dst = (flags & 1) ? (u16 *)0x02010000 : (u16 *)0x02000000;
    dst += colBase * *(u16 *)(grid + 0x1a) + rowBase;
    src = ptr[1];

    for (i = 0; i < h; i++) {
        u8 j;
        for (j = 0; j < w; j++)
            *dst++ = *src++;
        dst += *(u16 *)(grid + 0x1a) - w;
    }

    if (flags & 1)
        sub_080100E4(1, (void *)0x02010000, (void *)0x0600E800);
    else
        sub_080100E4(0, (void *)0x02000000, (void *)0x0600E000);

    ((struct IwramAt64C0 *)0x030064C0)->dirty = 0;
}
```
