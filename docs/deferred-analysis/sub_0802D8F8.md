# sub_0802D8F8 — deferred analysis

Sound-system slot/channel reset. Clears the active slot's flag byte
(`slot->flags` at +0x151), walks the channel-sequencer (+0x114) and
slot-pointer (+0x120) tables clearing each entry while silencing the
channel via `sub_0802E724`, then walks the dynamic-slot reset table
(+0xcc) and the software-slot array (+0xc8, 64-byte stride, active word
at +0x38) clearing each slot. Finally clears the +0x01 status byte and
tail-calls `sub_08030264`. Compiled with old_agbcc (sound cluster
convention). Callee `sub_08030264` was peeled as part of this attempt
(committed).

## Drift

Best base: **byte_diff 73, diff_count 20** (160 bytes built vs 164 target).
LOOP 1 matches PERFECTLY. All residual diffs are in LOOP 2 plus a
2-instruction register-class swap at the very top, and the bl-target
offsets (those resolve once the function is the correct 164-byte size —
they are a symptom of the 4-byte shortfall, not independent bugs).

The fundamental, uncracked drift is a **register-allocation preference in
loop 2** (same family as the documented "two-stage loop over shared
`*gpGlobal`" unmatchable class, but with low registers, not the `ip`
spill). The baserom redundantly keeps `&gpSoundSystem` in BOTH a survivor
callee-saved reg (r6, used for the post-loop `status=0` write) AND a
loop-carried copy (r5), and reloads `ss = *r5` into a scratch (r2) every
iteration, reading the loop-2 count from that cached scratch
(`ldrb r2,[r2]`) at the end-check:

```
58: ldr  r0, [pc]      ; &gSS
5a: ldr  r1, [r0]      ; ss (word)
5c: adds r6, r0, #0    ; r6 = &gSS  (survivor)
5e: ldrb r1, [r1]      ; count
...
64: adds r5, r6, #0    ; r5 = &gSS  (loop copy)
68: ldr  r2, [r5]      ; ss reload (body)
...
84: ldrb r2, [r2]      ; count re-read from CACHED ss in r2 (NOT via pool)
86: cmp  r4, r2 ; blt
8a: ldr  r1, [r6]      ; final status write via survivor r6
```

agbcc 2.x always COALESCES this — it keeps `&gpSoundSystem` in a single
callee-saved reg (no r5+r6 double copy) and reads the loop-2 count via
`(*pp)->count` (reload through the pool pointer) rather than from a cached
`ss`. That removes ~4 bytes of register shuffles, making the build 160
bytes vs the 164-byte target and shifting `sub_0802D99C` 8 bytes early.

## Levers already tried (try a DIFFERENT one next)

- Deref styles: all-macro (`gpSoundSystem` everywhere) → byte_diff 71 but
  diff_count 58 (reloads pool literal too often); single `pp` anchor → 128;
  **setup+loop1 via macro, loop2 via re-loaded `pp`** is the winner (73).
- `register u32 zero asm("r5")` (loop1) and `asm("r3")` (loop2) — these
  FIXED loop1 entirely (the zero/pool-ptr swap). KEEP these.
- Loop2 forms: for-loop (73, best), do-while + `if` guard (collapses to
  152 bytes), do-while with `ss->count` end-guard (collapses), pre-loop
  `ss = *pp` cache (collapses — agbcc reuses it).
- Count caching `new_var = (*pp)->count` (permuter's 765 variant) — did not
  force the r5/r6 double copy.
- Register pins on `ss` (r2), `i` (r4) — collapse further (144 bytes).
- Flags: `-fno-caller-saves` (no-op); default agbcc vs old_agbcc (identical
  129 base). `CALLER_SAVE_PROFITABLE` in local-alloc.c picks the same reg.
- Permuter: base score 1070, 50s / ~220 iters, best **765** (no zero).
  output-765 moved `sub_08030264()` into the loop (semantics-breaking,
  permuter doesn't preserve them) and cached the count — neither reached 0.

NEXT IDEAS NOT YET TRIED: force a second independent `&gpSoundSystem`
materialization for the post-loop `status=0` write (so loop2's pointer
need not survive, possibly freeing the allocator to mirror the baserom's
r5+r6 split); a `(T*)(u32)` index-recast on `ss` to force a scratch
reload in loop2's body; reading the loop-2 count from the cached body `ss`
via an `asm("")` barrier that blocks the pool-reload CSE.

## Best-effort C

```c
#include "types.h"

typedef struct SoundSlot {
    u8 _pad00[0x38];
    u32 active;
} SoundSlot;

typedef struct SoundSystem {
    u8 count;
    u8 status;
} SoundSystem;

#define gpSoundSystem (*(SoundSystem **)0x030065e0)

extern void sub_0802E724(s32 ch);
extern void sub_08030264(void);

void sub_0802D8F8(void)
{
    SoundSystem **pp;
    SoundSystem *ss;
    s32 i;

    *(u8 *)(*(u8 **)((u8 *)gpSoundSystem + 0x118) + 0x151) = 0;

    for (i = 0; i < gpSoundSystem->count + 4; i++) {
        register u32 zero asm("r5") = 0;
        ss = gpSoundSystem;
        ((u32 *)*(u32 **)((u8 *)ss + 0x114))[i * 4] = zero;
        ((u32 *)*(u32 **)((u8 *)ss + 0x120))[i] = zero;
        sub_0802E724(i);
    }

    pp = &gpSoundSystem;
    for (i = 0; i < (s32)(*pp)->count; i++) {
        register u32 zero asm("r3") = 0;
        ss = *pp;
        (*(u32 **)((u8 *)ss + 0xcc))[i] = zero;
        ((SoundSlot *)(*(u8 **)((u8 *)ss + 0xc8) + i * 0x40))->active = zero;
    }

    (*pp)->status = 0;
    sub_08030264();
}
```
