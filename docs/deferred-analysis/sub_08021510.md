# sub_08021510 — deferred (cross-jump tail-merge wall)

Range [0x08021510, 0x080217d4), 708 bytes. Thumb. `push {r4-r7,lr}` + r8/r9/sl saved.
classify_unmatchable verdict: **ATTEMPT_MATCH** (advisory: 3 high regs r8/r9/sl held
across `bl` — handled fine here). NOT a STRONG_UNMATCHABLE / NAKED candidate.

## What the function does

A loop over `i` in `[0, *pCount)` processing entity-pool slots
`gEntities[baseSlot + i]` (stride 0x38). Signature reverse-engineered as:

    void sub_08021510(u8 baseSlot, u8 *pCount, u8 kind, u8 unused, u8 bitBase)

(4th register arg `unused` is read into r3 then immediately overwritten by the 5th
stack arg `bitBase` at [sp,#48] — the 4th arg is genuinely dead; the 5th is the bit
base.) Stack frame: sp0=baseSlot, sp4=bitBase, sp8=firstSlot/anyProcessed (one var),
sp12=count. r8=gEntities(0x03003720), sl=gIwram_6110(0x03006110) held across the loop.

Per slot, skips if `status(+0x34) & 0x08`; if `status & 0x80`, dispatches on `kind`
(switch over {2,3,4,11,12,86,87}, physical/source order 3,12,2,11,4,86,87):
- case 3/2: `sub_08020C78(6)`, `status |= 0x0C` (two ORs), bump the s16 score counter
  at gIwram_35E0+2 capped at 998; case 2 also `gIwram_6110.flags64 |= (s64)(s32)(1<<(bitBase+i))`.
- case 12/11: `sub_08020C78(13)`, `status |= 0x0C`, bump the s8 counter at gIwram_35E0+0
  capped at 98; case 11 also `gIwram_6110.flags2 |= (1<<(bitBase+i))`.
- case 4: `sub_08020C78(gGameStuff.pendingMode==15 ? 123 : 7)`, `status |= 0x0C`,
  `gIwram_6110.flags0 |= (1<<(bitBase+i))`, `gIwram_35E0._data[4]++` (no cap).
- case 86/87: `sub_08020C78(0x3a/0x40)`, `sub_0800D2C0((s16)(x/24),(s16)(y/24))`
  via __divsi3, then gEntities[0].field_10 ++ / -- (87 decrements if >0).
- all (except 87 which has its own + goto): `sub_08016A40()` then fall to tail.
Tail (per processed slot): if firstSlot==0 set firstSlot=(u8)slot; `sub_0800696C((void*)0x03006110, slot)`;
break if `status & 2`; if `status & 0x8000` then `status = (status|2) & 0x7fff`.
Post-loop: if firstSlot != 0, `sub_08005D10(firstSlot, baseSlot+count-1)`.

## Drift — best byte_diff via objdiff 73.2% match (compile_and_view byte_diff inflated
to ~527 because the built fn is 56 bytes SHORTER, shifting every branch target).

The body, tail, loop-top, prologue, and case bodies ALL match the baserom byte-for-byte
after the levers below. The ONE residual blocker:

**agbcc cross-jumps (tail-merges) the identical counter tails that the baserom keeps
DUPLICATED.** Specifically:
- case 3's `if (counter@+2 <= 998) ++` tail is merged into case 2's identical tail
  (case 3 ends `b.n <case2-counter>`).
- case 12's `if (counter@+0 <= 98) ++` tail is merged into case 11's identical tail.
The baserom inlines all four separately (and even dumps a fresh per-case literal pool —
gIwram_35E0 ×5, 0x3e6 ×2 — because Thumb `ldr [pc]` is forward-only, so each case needs
its own forward pool entry; once the merge is gone the pools follow). The merge removes
~36 bytes of code + the duplicate pool words ≈ the full 56-byte deficit.

This is the SAME structural wall documented in docs/deferred-analysis/sub_0801C078.md
and sub_0802EB34.md: cross-jump grouping is decided in agbcc `gcc_arm/jump.c`
`jump_optimize`/`do_cross_jump`, runs UNCONDITIONALLY at `optimize > 0` (toplev.c
~line 4099, `jump_optimize(insns, JUMP_CROSS_JUMP, ...)`), has NO `-f` flag, and the
prior art proved it is NOT statement-reorderable and the PERMUTER cannot reach it
(it can't introduce the structural non-merge). `current_function_uses_expect` only adds
branch_predict_reorg, it does NOT gate cross-jump.

Secondary residual (smaller, also coloring): the `1 << (bitBase + i)` shift —
baserom puts the shift COUNT in r1 and `1` in r0 (`ldr r1,[sp,#4]; add r1,r9; movs r0,#1;
lsls r0,r1`); built swaps them (`ldr r0; add r0; movs r1,#1; lsls r1,r0`). A coloring tie
on the shift-count register, likely auto-fixes once the cross-jump alignment is gone.

## Levers that WORKED (keep these in the next attempt's base — they are correct)
- `register s32 idx asm("r0")` + `slot = idx` AFTER the `status & 8` test → makes the
  loop-top match EXACTLY (idx r0, product r1, status r2, mask r1, `adds r7,r0,#0` after
  the AND). Without the pin agbcc puts the held index in r1.
- `register u16 status asm("r2")` → status read once into r2, both `&8` and `&0x80` reuse it.
- `count` as `u32` → unsigned `bcc` loop test (signed `s32` gives `blt`).
- declare `firstSlot` BEFORE `count` → firstSlot→sp8, count→sp12 (baserom order).
- `entity = &base[baseSlot + i]` inline expression (NOT via `slot`) + separate `slot`
  var → the slot-copy `adds r7,r0,#0` pattern.
- `st = 8; st |= entity->status; entity->status = st | 4;` → the TWO-orr `status |= 0x0C`
  with `8` as accumulator (matches baserom; a single `8|x|4` folds to `movs #12; orr`).
- per-case `struct IwramAt35E0 *p35 = &gIwram_35E0; *(s16*)&p35->_data[2]` → keeps
  base 0x030035e0 + offset #2 in the load (a bare `*(s16*)&gIwram_35E0._data[2]` folds
  +2 into the pool literal 0x030035e2 and loads [r1,#0]).
- __divsi3 (not a sub_ name) for the `/24`; sub_0800D2C0(s16,s16); sub_0800696C(void*,s32).

## Levers that did NOT help (do not repeat)
- per-TU `CC = $(AGBCC_BIN)` (newer agbcc): identical output. old_agbcc is correct.
- `-fno-gcse`, `-fforce-addr`, `-fforce-addr -fno-expensive-optimizations`,
  `-fno-schedule-insns`: none change the cross-jump merge or the pool dedup.
- empty-then `if (counter > 998) {} else ++;` for case 3 to force the loose jump form:
  agbcc canonicalizes back to the tight form, still merges.
- per-case fresh `p35` pointers for cases 11/12/4 (to force fresh 35e0 loads): agbcc
  still dedups the constant pool entry (force_const_mem is per-function with dedup).

## Best-effort C
```c
#include "types.h"
#include "iwram.h"
#include "game.h"

extern void sub_08020C78(u32 effect);
extern void sub_08016A40(void);
extern int __divsi3(int num, int den);
extern void sub_0800D2C0(s16 tileX, s16 tileY);
extern void sub_0800696C(void *unused, s32 bit);
extern void sub_08005D10(s32 first, s32 last);

void sub_08021510(u8 baseSlot, u8 *pCount, u8 kind, u8 unused, u8 bitBase)
{
    u8 i;
    s32 firstSlot;
    u32 count;
    s32 slot;
    register s32 idx asm("r0");
    struct Entity *base;
    struct Entity *entity;
    register u16 status asm("r2");
    u16 st;
    struct IwramAt6110 *ctrl;

    firstSlot = 0;
    count = *pCount;

    for (i = 0; i < count; i++) {
        base = gEntities;
        ctrl = &gIwram_6110;

        idx = baseSlot + i;
        entity = &base[idx];
        status = entity->status;
        if (status & 0x08) {
            continue;
        }
        slot = idx;

        if (status & 0x80) {
            switch (kind) {
            case 3:
                sub_08020C78(6);
                st = 8;
                st |= entity->status;
                entity->status = st | 4;
                {
                    struct IwramAt35E0 *p35 = &gIwram_35E0;
                    if (*(s16 *)&p35->_data[2] <= 998) {
                        *(u16 *)&p35->_data[2] = *(u16 *)&p35->_data[2] + 1;
                    }
                }
                break;
            case 12:
                sub_08020C78(13);
                st = 8;
                st |= entity->status;
                entity->status = st | 4;
                {
                    struct IwramAt35E0 *p35 = &gIwram_35E0;
                    if ((s8)p35->_data[0] <= 98) {
                        p35->_data[0]++;
                    }
                }
                break;
            case 2:
                sub_08020C78(6);
                st = 8;
                st |= entity->status;
                entity->status = st | 4;
                ctrl->flags64 |= (s64)(s32)(1 << (bitBase + i));
                {
                    struct IwramAt35E0 *p35 = &gIwram_35E0;
                    if (*(s16 *)&p35->_data[2] <= 998) {
                        *(u16 *)&p35->_data[2] = *(u16 *)&p35->_data[2] + 1;
                    }
                }
                break;
            case 11:
                sub_08020C78(13);
                st = 8;
                st |= entity->status;
                entity->status = st | 4;
                ctrl->flags2 |= (1 << (bitBase + i));
                {
                    struct IwramAt35E0 *p35 = &gIwram_35E0;
                    if ((s8)p35->_data[0] <= 98) {
                        p35->_data[0]++;
                    }
                }
                break;
            case 4:
                if (gGameStuff.pendingMode == 15) {
                    sub_08020C78(123);
                } else {
                    sub_08020C78(7);
                }
                st = 8;
                st |= entity->status;
                entity->status = st | 4;
                ctrl->flags0 |= (1 << (bitBase + i));
                {
                    struct IwramAt35E0 *p35 = &gIwram_35E0;
                    p35->_data[4]++;
                }
                break;
            case 86:
                sub_08020C78(0x3a);
                sub_0800D2C0((s16)__divsi3(entity->x, 24), (s16)__divsi3(entity->y, 24));
                base->field_10++;
                break;
            case 87:
                sub_08020C78(0x40);
                sub_0800D2C0((s16)__divsi3(entity->x, 24), (s16)__divsi3(entity->y, 24));
                if ((s16)base->field_10 > 0) {
                    base->field_10--;
                }
                sub_08016A40();
                goto tail;
            default:
                goto tail;
            }
            sub_08016A40();
        }

    tail:
        if (firstSlot == 0) {
            firstSlot = (u8)slot;
        }
        sub_0800696C((void *)0x03006110, slot);
        if (base[slot].status & 2) {
            break;
        }
        if (base[slot].status & 0x8000) {
            base[slot].status = (base[slot].status | 2) & 0x7fff;
        }
    }

    if (firstSlot != 0) {
        sub_08005D10(firstSlot, baseSlot + count - 1);
    }
}
```
