## Drift

**Best byte_diff**: 40  
**Best diff_count**: 13

**Root cause**: agbcc 2.x chooses r7 as the intermediate register for loading gGameStuff
(0x03005330) into r9, EVEN when `register u32 fieldA asm("r7")` is active.

Target allocation:
- r5 = gIwram_6580 (pinned)
- r6 = stride (long-lived)
- r7 = fieldA (long-lived)
- r8 = tableBase (pinned)
- r9 = gGameStuff (pinned)
- ip = alias for fieldA (used for comparison + srcIndex push)
- gGameStuff loaded through r0 (not r7!)

Generated allocation:
- r5 = gIwram_6580 (pinned)
- r6 = stride (long-lived)
- r7 = fieldA (pinned to r7) → BUT agbcc steals r7 for gGameStuff load!
- r8 = tableBase (pinned)
- r9 = gGameStuff (pinned)
- ip = alias for fieldA (for comparison + srcIndex)
- gGameStuff loaded through r7 (wrong, clobbers fieldA)

Consequence: downstream effects cause 13 total diffs in the generated code.

## Key observations

1. The `register u32 fieldA asm("r7"); register u32 ipVal asm("ip"); ipVal = fieldA`
   pattern DOES produce `ldrb r7; mov ip, r7; mov r0, ip; cmp r0, #3` correctly.
   The first 52 bytes (0x34) match perfectly.

2. At the gGameStuff load point, agbcc considers r7 "dead" (fieldA value is in ip already)
   and reuses r7 as a temp for loading gGameStuff to r9.

3. This causes cascade effects:
   - Extra `mov r0, r9` instruction (since r0 no longer holds gGameStuff after mov r9, r7)
   - srcTable computed via `mov r7, r8; adds r4, r7, r6; ldr r4, [r4, #16]` instead of
     `mov r4, r8; adds r4, #16; adds r4, r6, r4; ldr r4, [r4, #0]`
   - field_a update (`adds r0, r7, #1`) uses wrong value (gGameStuff addr + 1 instead of fieldA + 1)
   - After-BL uses `mov r0, r9` instead of `mov r1, r9`

4. Approaches tried (all failed):
   - `register u32 fieldA asm("r7")` alone
   - `register u32 fieldA asm("r7"); register u32 ipVal asm("ip")`
   - Scoped ip declaration inside block
   - `asm volatile("" :: "r"(fieldA))` barrier
   - `register GameStuff *gsTmp asm("r0") = &gGameStuff; gs = gsTmp`
   - Declaration order changes (stride before fieldA, etc.)
   - `-ffixed-r6` CFLAGS (breaks prologue - r6 removed from push list)
   - Various C structure changes

5. Permuter: imported, base score 860, found score 850, never reached 0.
   The permuter is stuck in the same local minimum.
