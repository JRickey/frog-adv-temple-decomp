# sub_08034150 — deferred analysis

Soft-float **addition core** (Konami-custom decomposed float, NOT IEEE).
Caller: `sub_080342F8` (soft-float subtract) flips `b->sign` and calls this,
then packs the result with `sub_0803401C`. Operands/result use the same
`struct FloatComponents { u32 type; u32 sign; s32 exp; u32 mantissa; }` as the
neighbouring `sub_0803401C` / `sub_080340D4`.

Range [0x08034150, 0x080342cc), 380 bytes. classify_unmatchable: **ATTEMPT_MATCH**
(advisory: r8 held across a "bl" — bogus; this is a leaf, r8 holds `signB`).
No corpus prior art (custom soft-float; corpus only has IEEE tool sources).

Semantics are fully understood and verified against the asm:
- `type` dispatch: 0/1=NaN → return that operand; 2=zero → return the other
  (both-zero: `*out = *a; out->sign = a->sign & b->sign`); 4=inf → return inf,
  inf+(-inf) returns the IWRAM scratch NaN at `0x03003440`.
- finite (type 3) path: abs(expA-expB); if >31 the smaller mantissa underflows
  to 0; else sticky right-shift the smaller mantissa to align exponents
  (`m = (m>>1)|(m&1)` loop run `|expA-expB|` times). Same sign → add mantissas;
  different sign → subtract (signA!=0 ? mantB-mantA : mantA-mantB), set result
  sign from the difference's sign, then a normalise-UP loop
  `while ((u32)(mant-1) <= 0x3FFFFFFE) { mant<<=1; exp--; }`
  (== `mant>0 && mant<0x40000000`). Common tail: `out->type=3`, and a final
  sticky-down if `(s32)mant < 0` (`mant=(mant&1)|(mant>>1); exp++`).

## Drift

Best result: **byte_diff 265, diff_count 164** (size 372/380 right) with the
param-pinned + flag-pinned variant below plus `src/game/sub_08034150.s: CFLAGS +=
-mno-thumb-interwork`. The structure (control flow, dispatch order, sticky
loops, normalise loops, the `flag=0;if()flag=1;if(flag)` materialised-boolean
idiom) is faithful — the remaining diff is **pure global register allocation**.

Target register file: `a→r6, b→r7, out→r5, signA→r6 (reuses a), signB→r8
(mov r8,r7 from b->sign), mantB→r4, loop constant 1→ip (r12, reloaded each
iter via "mov r7,ip")`. Prologue saves r8: `push{r4-r7,lr}; mov r7,r8; push{r7}`.

The wall — every lever tried fails the SAME way:
- **No pins**: agbcc puts `b→ip` (alloc order prefers r12) and FOLDS every
  `flag=0;if()flag=1;if(flag)` into a bare `if()` → size 316, the materialised
  booleans vanish. So the flag idiom REQUIRES a register pin to survive.
- **flag=r1 + flag0=r0 pins** (materialise the booleans correctly: first check's
  bool → r0, all linear checks → r1, nested checks → r0): brings the dispatch
  region close BUT params still mis-allocated.
- **signB=r8 pin** is the ONLY thing that makes agbcc use r8 / emit the
  `mov r7,r8;push{r7}` prologue (size→380). BUT it **coalesces b into r8 at
  entry** (`mov r8, r1`), giving the off-by-one `a→r7, b→r8, out→r6` (target is
  `a→r6, b→r7, out→r5`). Could not break this coalescing: signB's only
  callee-saved consumer is b->sign, so agbcc binds b→r8 from the start. Target
  keeps b in r7 the whole function and only spills signB→r8 because the
  alignment LOOP reuses r7 (the `1` constant lives in ip and r7 becomes the loop
  temp) — that eviction is what frees r8 for signB. I could not get agbcc to put
  the loop constant in ip from plain C, so b never gets evicted from its slot.
- **param-copy pins** `register T *a asm("r6")=_a; b asm("r7"); out asm("r5")`
  + signB=r8 + flag/flag0: prologue + param regs now EXACTLY match (best, 269),
  but agbcc then **spills `_b`'s fields** — reads b->type/sign/exp/mant from
  `[sp,#N]` (overlapping the saved-register area, no `sub sp`) because the copy
  approach keeps `_b` separate and reuses r7 for a->exp at the arithmetic. The
  spills are the bulk of the remaining 164 insn diffs.
- **`-fno-gcse`**: no effect on the spill. **`-fforce-addr
  -fno-expensive-optimizations`**: worse (323), kills r8. **newer AGBCC
  (`CC=$(AGBCC_BIN)`)**: identical allocation (269 / 308), no help.
- **Clean C, no pins**: size 308; explicit materialised-boolean source shape
  improves to size 360/356 with `-mno-thumb-interwork`, but agbcc still assigns
  `a→r7, b→ip, out→r6` and folds/reorders several dispatch tests.
- **Separate declaration then assignment for hard-reg params** improves the
  prior best from 269 to **265**, but still reloads `_b` fields from `[sp,#N]`.
  This is not a real match candidate because the stack slot overlaps the saved
  register area; it only proves the desired prologue can be forced.
- **Parameter-level hard-reg syntax** (`register T *a asm("r6")` in the
  parameter list) is rejected by agbcc's parser, so it cannot avoid the `_b`
  copy pseudo.
- **Hard-pinning `b` without `signB=r8`** still reloads b fields from `[sp,#N]`;
  the stack artifact is caused by hard-pinning `b` itself, not only by the r8
  sign pin.
- **No hard `b`, `signB=r8`** avoids the bogus stack loads but coalesces the
  incoming b pointer into r8 at entry (`mov r8, r1`) and emits size 384 /
  byte_diff 314. Adding `-ffixed-r12` does not change that allocation.
- **Split pointer shape** (`b` plus `bSign` used only for sign loads) makes the
  no-hard-b case worse: agbcc emits `mov r8, r1; mov r4, r8`.
- **`register stickyBit asm("ip") = 1`** proves the sticky loops can emit the
  desired `mov rN, ip` inside the loop, but it inserts an early `mov ip, #1`
  before dispatch and still leaves the `_b` stack spill. It is not a viable
  standalone lever.
- **`CC=$(AGBCC_BIN)`** on the no-hard-b/signB-r8 shape is identical to
  old_agbcc for the relevant allocation (still `mov r8, r1`, byte_diff 314).
- **Corpus check**: current-tree asm has many `mov r[0-7], ip` hits, but the
  local `tools/agent/corpus-mirrors/` directory is absent, so history pairing
  cannot be run in this worktree. Current C grep for sticky `>> 1` / `& 1`
  did not reveal a comparable soft-float alignment loop.
- Permuter NOT attempted: byte_diff 265 ≫ the ~40 threshold; permuter only fixes
  last-mile coloring on a near-match, not a 269-byte global-allocation gap.

Next idea for whoever resumes: the whole thing hinges on getting agbcc to put
the loop's `1` constant into **ip** (so b is forced out of ip→r7 globally and
signB lands in r8 without coalescing). Investigate `tools/agbcc-src/gcc_arm/
{local-alloc,global,reload}.c` for what drives ip selection for a loop-invariant
constant under pressure, or find a C shape for the sticky loop that makes the
`1` invariant get hoisted to ip (target reloads it every iter via `mov r7,ip`,
which is the "constant in ip, copied to a low reg for the Thumb `ands`" pattern).

## Best-effort C

```c
#include "types.h"

struct FloatComponents {
    u32 type;
    u32 sign;
    s32 exp;
    u32 mantissa;
};

#define gNanResult ((struct FloatComponents *)0x03003440)

/* Param-copy pins make the prologue + a/b/out register mapping match the
 * baserom exactly; flag0(r0)/flag(r1) pins keep the dispatch booleans
 * materialised; signB(r8) forces the r8 save. Reaches byte_diff 269 — the
 * residual is b's fields spilling to [sp] (see Drift). */
struct FloatComponents *sub_08034150(struct FloatComponents *_a, struct FloatComponents *_b,
                                     struct FloatComponents *_out)
{
    register struct FloatComponents *a asm("r6");
    register struct FloatComponents *b asm("r7");
    register struct FloatComponents *out asm("r5");
    s32 expA;
    s32 expB;
    u32 mantA;
    u32 mantB;
    u32 signA;
    register u32 signB asm("r8");
    s32 diff;
    s32 mant;
    register u32 flag asm("r1");
    register u32 flag0 asm("r0");

    a = _a;
    b = _b;
    out = _out;

    flag0 = 0;
    if (a->type <= 1) {
        flag0 = 1;
    }
    if (flag0) {
        return a;
    }

    flag = 0;
    if (b->type <= 1) {
        flag = 1;
    }
    if (flag) {
        return b;
    }

    flag = 0;
    if (a->type == 4) {
        flag = 1;
    }
    if (flag) {
        flag0 = 0;
        if (b->type == 4) {
            flag0 = 1;
        }
        if (!flag0) {
            return a;
        }
        if (a->sign == b->sign) {
            return a;
        }
        return gNanResult;
    }

    flag = 0;
    if (b->type == 4) {
        flag = 1;
    }
    if (flag) {
        return b;
    }

    flag = 0;
    if (b->type == 2) {
        flag = 1;
    }
    if (flag) {
        flag0 = 0;
        if (a->type == 2) {
            flag0 = 1;
        }
        if (!flag0) {
            return a;
        }
        *out = *a;
        out->sign = a->sign & b->sign;
        goto done;
    }

    flag = 0;
    if (a->type == 2) {
        flag = 1;
    }
    if (flag) {
        return b;
    }

    expA = a->exp;
    expB = b->exp;
    mantA = a->mantissa;
    mantB = b->mantissa;

    diff = expA - expB;
    if (diff < 0) {
        diff = -diff;
    }

    if (diff > 31) {
        if (expA > expB) {
            mantB = 0;
        } else {
            expA = expB;
            mantA = 0;
        }
        signA = a->sign;
        signB = b->sign;
    } else {
        signA = a->sign;
        signB = b->sign;
        if (expA > expB) {
            diff = expA - expB;
            do {
                mantB = (mantB >> 1) | (mantB & 1);
            } while (--diff != 0);
            expB = expA;
        }
        if (expB > expA) {
            diff = expB - expA;
            do {
                mantA = (mantA >> 1) | (mantA & 1);
            } while (--diff != 0);
            expA = expB;
        }
    }

    if (signA == signB) {
        out->sign = signA;
        out->exp = expA;
        out->mantissa = mantA + mantB;
        goto tail;
    }

    if (signA != 0) {
        mant = mantB - mantA;
    } else {
        mant = mantA - mantB;
    }

    if (mant < 0) {
        out->sign = 1;
        out->exp = expA;
        out->mantissa = -mant;
    } else {
        out->sign = 0;
        out->exp = expA;
        out->mantissa = mant;
    }

    while ((u32)(out->mantissa - 1) <= 0x3FFFFFFE) {
        out->mantissa <<= 1;
        out->exp -= 1;
    }

tail:
    out->type = 3;
    if ((s32)out->mantissa < 0) {
        out->mantissa = (out->mantissa & 1) | (out->mantissa >> 1);
        out->exp += 1;
    }

done:
    return out;
}
```
