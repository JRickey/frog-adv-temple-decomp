## Best pure-C (byte_diff 2, 0 pins)

Residual: the second `gEntities` pool load lands in r2 instead of r1
(`ldr r2,[pc,#12]; adds r0,r0,r2` vs target `ldr r1,...; adds r0,r0,r1`).
Reloading `base` at the tail makes it a global pseudo colored r2 by the
first block's tie; using a fresh `sum = (u32)gEntities` at the tail fixes
the tail (r1) but then the FIRST half regresses to 9 diffs (base becomes
block-local and local-alloc ties `entity` with `offset` instead of `base`).
Copy-propagation folds every `sum = (u32)base` bridge. Permuter plateaued
at score 10 for 37k iterations (pure low-reg coloring class).

```c
#include "game.h"
#include "iwram.h"
#include "types.h"

extern u32 sub_0802D448(void);
extern void Entity_Update(void *entity);

u32 sub_0802D350(u8 a, u8 b)
{
    u32 sum;
    u8 * base;
    u32 offset;
    u32 maskedStatus;
    struct Entity *entity;
    u16 status;

    base = (u8 *)gEntities;
    sum = a + b;
    offset = sum << 3;
    offset -= sum;
    offset <<= 3;
    entity = (struct Entity *)(base + offset);

    if (entity->state != 0) {
        entity->state = 0;
        entity->status |= 2;
    }

    status = entity->status;
    if ((status & 0x8000) != 0) {
        maskedStatus = 8;
        maskedStatus |= status;
        maskedStatus &= 0x7FFF;
        entity->status = maskedStatus;
        if (sub_0802D448() != 0) {
            return 1;
        }
    }

    sum = a + b;
    offset = sum << 3;
    offset -= sum;
    offset <<= 3;
    base = (u8 *)gEntities;
    Entity_Update((void *)(base + offset));
    return 0;
}
```
