# sub_0800A458 (deferred)

Single-step pathfinding helper at [0x0800a458, 0x0800a4d0) (120 bytes), the
second function in the `asm/disasm_0x0800a3d0.s` peel slice (the first,
`sub_0800A3D0`, is now a true pure-C match in `src/game/dispatch_helpers.c`).
Kept as an `.incbin` asm slice (`asm/disasm_0x0800a458.s`) so `make check`
stays green while this one is deferred.

## Semantics (fully understood)

`u8 sub_0800A458(u16 x, u16 y)` — "can I step one tile toward (x, y)?".

- If the cached tile coords already equal the target
  (`(u16)gIwram_35E0._field_8 == x && (u16)gIwram_35E0._field_A == y`),
  return 1 (already there).
- Otherwise pick the single axis/direction that still differs and ask
  `sub_0800A3D0(dir, coord)`:
    - `(s16)x < field_8`  -> dir 4, coord = (s16)x
    - `(s16)x > field_8`  -> dir 8, coord = (s16)x
    - `(s16)y < field_A`  -> dir 1, coord = (s16)y
    - `(s16)y == field_A` -> return 0 (aligned)
    - `(s16)y > field_A`  -> dir 2, coord = (s16)y   (SEPARATE bl site)
  Result map (both call sites): `sub_0800A3D0(...) == 1 ? 0xff : 0`.

The first equality check compares the `<<16` forms: baserom keeps `x<<16` in
r0 (from the prologue `lsls r0,r0,#16`, never shifted back) and shifts
`field_8` to match (`ldrh; lsls; cmp r2,r0`). field_A vs y is a plain u16
compare. The magnitude checks use `ldrsh` (`(s16)` via `lsls;asrs`), and the
call arg reuses the already-computed `(s16)x`/`(s16)y` in r1. Note the
baserom has TWO `bl sub_0800A3D0` sites: dir 4/8/1 share one tail
(at 0xa4a2), dir 2 is separate (at 0xa4b8).

## Drift

Best clean attempt: **byte_diff ~82** (of 120), structure 100% correct — the
entire residual is register allocation, not logic. Built vs baserom prologue:

```
baserom:  lsrs r4,r1,#16 (y->r4); ldr r1,=base; lsrs r5,r0,#16 (x->r5);
          ldrh r3,[r1,#8]; lsls r2,r3,#16; adds r3,r1,#0 (base->r3); cmp r2,r0
built:    lsrs r4,r1,#16 (y->r4); ldr r5,=base; ldrh r1,[r5,#8];
          lsls r1,r1,#16; lsrs r2,r0,#16 (x->r2); cmp r1,r0
```

Baserom puts **x in r5, base in r1->r3** (callee-saved, via an `adds r3,r1,#0`
copy); the build puts base in r5 and x in r2. x/y land in callee-saved r4/r5
in the baserom — they are live across the if/else dispatch chain before the
`bl`. Everything downstream (the ldrsh dispatch + the two call sites) is
byte-identical *modulo* that base/x register swap, so the ~82 is mostly the
register-rename cascading, not independent diffs.

## Best-effort C (byte_diff ~82, structure correct, readable)

```c
u8 sub_0800A458(u16 x, u16 y)
{
    struct IwramAt35E0 *p = &gIwram_35E0;
    u8 dir;
    s16 v;

    if ((int)((u16)p->_field_8 << 16) == (int)(x << 16) && (u16)p->_field_A == y)
        return 1;

    if ((s16)x < p->_field_8) {
        dir = 4;
        v = (s16)x;
    } else if ((s16)x > p->_field_8) {
        dir = 8;
        v = (s16)x;
    } else {
        if ((s16)y < p->_field_A) {
            dir = 1;
            v = (s16)y;
        } else {
            if ((s16)y <= p->_field_A)
                return 0;
            if (sub_0800A3D0(2, (s16)y) == 1)
                return 0xff;
            return 0;
        }
    }

    if (sub_0800A3D0(dir, v) == 1)
        return 0xff;
    return 0;
}
```
