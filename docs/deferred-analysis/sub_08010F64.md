# sub_08010F64 — deferred analysis (round 15, Opus escalation)

Scroll-blit driver at 0x08010F64 (804 bytes / ~401 Thumb insns). Re-derived
from scratch this pass. Cracked several blockers the prior note plateaued on
(the `+12`-on-base form, the index load/operand order, AND a controllable
reproduction of the case-3/4 dead `[sp]` spill that drives `sub sp,#4`). Still
NOT byte-matching: the residual is the SETUP-region register coloring, which is
coupled to agbcc's reload round-robin in a way where every source change that
fixes one setup mismatch perturbs another. Best byte_diff this pass: **659**
(prior note: 653; but this pass's structure is materially more correct — see
"Solved" — so the next attempt should START from the C below, not the prior).

## What it does (verified from the asm — unchanged from prior note, confirmed)

`void sub_08010F64(void *records, u8 n)` — see the prior note's "What it does"
section; that model is correct. Briefly: bit-test `scroll->active` (byte +2 at
0x03006540) `>> n`; look up `dirLut = gFrameCellTable_08307EAC[pendingMode-1]`
(field +12); `rec = &records[dirStep[n] + dirLut[n*2]]` (24-byte records);
`switch (rec->kind & 0xf)` cases 1..4 do a row/column tile blit; advance
`dirStep[n]` (call sub_08010DD8) or reset + clear active; refresh tail
(sub_08020DC4/E7C/C78, sub_080100E4, gIwram_35E0 flag clear).

`gFrameCellTable_08307EAC` is the existing linker symbol at 0x08307EAC
(linker.ld). `gIwram_60A0` (0x030060a0[13] = row stride at +26) likewise.

## SOLVED this pass (carry these forward — they ARE in the C below)

1. **`+12`-on-base form** (prior crux #3). The baserom forms `(romTable+12)` as
   a held field-column base, then `+pm1*20`, then `ldr [,#0]`. Reproduced with:
   ```c
   const u8 *const *col = (const u8 *const *)((char *)romTable + 12);
   dirLut = *(const u8 *const *)((char *)col + pm1 * 20);
   ```
   **REQUIRES romTable pinned to r4** (`register ScrollModeEntry *romTable
   asm("r4") = gFrameCellTable_08307EAC;`). With a plain symbol pointer the
   `+12` folds back into the load (`ldr [,#12]`). The field-column cast +
   r4-pin together give the exact `adds r1,r4,#0; adds r1,#12; adds r0,r0,r1;
   ldr [r0,#0]`.

2. **Index load + operand order** (prior crux #5/#6). The baserom does
   `lsls r3,r0,#1; adds r1,r3,r1` (n2 FIRST) then loads `dirStep[dir]` BEFORE
   `dirLut[n2]` and sums `adds r1,r0,r1`. Reproduced EXACTLY with:
   ```c
   u32 n2tmp = dir << 1;
   const u8 *lutEnt = (const u8 *)(n2tmp + (u32)dirLut);  /* index-first cast */
   u8 *stepEnt = step + dir;
   rec = &((ScrollRecord *)recordsReg)[*lutEnt + *stepEnt];  /* lut + step ORDER */
   ```
   The `*lutEnt + *stepEnt` order (lut first in source) is what makes agbcc
   load `dirStep[dir]` first then `dirLut[n2]` and emit `adds r1,r0,r1`.
   (Counter-intuitive but verified at the instruction level.)

3. **Case-3/4 dead `[sp]` spill → `sub sp,#4`** (prior crux #1 — the big one).
   The baserom spills `gIwram_60A0[13]<<1` to `[sp,#0]` inside the case 3/4
   inner loops, a DEAD store (never reloaded). Reproduced controllably with a
   **volatile dummy**:
   ```c
   volatile u32 spillSlot;  /* function scope */
   ...
   u32 stride = gIwram_60A0[13] << 1;
   *(u16 *)dst = *(u16 *)src;
   spillSlot = stride;   /* forces str rN,[sp] — a DEAD store, value still in reg */
   dst += stride;        /* uses the register value, NO reload */
   ```
   This emits the exact `str rN,[sp,#0]; adds dst,dst,rN` (dead store, no
   `ldr [sp]` reload) — unlike `volatile u32 stride` which ALSO forces a
   reload. The volatile-dummy is a HACK (debt) but is the only lever found that
   reproduces the artifact; it is NOT in the byte_diff-659 C below (that C uses
   the inline `((u16*)gIwram_60A0)[13]` form and accepts the col2 CSE-spill as
   its `sub sp` source instead). The next attempt should decide between (a) the
   clean field-column + col2-CSE-spill path (659, wrong [sp] location) or (b)
   the volatile-dummy dead-store path (correct [sp] location, but symbol romTable
   → worse setup coloring, ~687-694).

## The REMAINING blocker — setup-region register coloring (NOT yet solved)

All ~30 residual mismatches are in 0x0..0x90 (setup/dispatch). The case bodies
(0x90+) align. The coupled, mutually-defeating issues:

1. **scroll r2→r6 copy.** Baserom: `ldr r2 => scroll; ldrb r0,[r2,#2]; ...;
   adds r6,r2,#0` (read active via scratch r2, THEN copy to the callee-saved
   r6). With `register scroll asm("r6")` agbcc loads straight into r6 (no copy).
   Unpinning scroll → it colors to r5 and the WHOLE body uses r5 (worse).
   Could not produce the "scratch-then-copy-to-r6" shape from C.

2. **romTable(r4)/gGameStuff(r5) load order + col-base copy.** Baserom loads
   romTable into r4 FIRST (after the early-return), gGameStuff into r5, and the
   col-base is `adds r1,r4,#0; adds r1,#12` (COPY r4, preserve romTable). With
   the r4-pin + eager init, romTable loads BEFORE the active check and the
   col-base does `adds r4,#12` (DESTROYS r4 in place). Lazy `romTable =` after
   the early-return made byte_diff WORSE (691).

3. **rec register r7 (baserom) vs r5 (mine)** — pure coloring downstream of 1/2.

These are `local-alloc.c` quantity-ordering + `find_free_reg` decisions,
coupled to the `reload1.c` round-robin (see codegen-notes "register asm("ip")
pin can DESYNC reload's round-robin"). Removing the `dir asm("ip")` pin did NOT
help (agbcc puts dir in ip naturally) but is cleaner, so the C below omits it.

## Levers TRIED this pass (what does NOT work — don't repeat)

- Per-TU CFLAGS sweep (`-fno-schedule-insns{,2}`, `-fforce-addr`,
  `-fno-cse-follow-jumps`, `-fno-expensive-optimizations`, `-fno-strength-reduce`,
  `-fno-gcse`, `-ffixed-r5`): ALL no change to the spill / coloring.
- Compiler swap to newer `agbcc` (vs default old_agbcc): no change (696).
- Fully unpinned: agbcc DOES use r8/r9/sl/ip naturally (prologue push matches!)
  but assigns records→r8 not r9, no `sub sp` (686).
- Pin only records→r9: 684, no `sub sp`.
- Function-scope non-volatile `stride` shared by case 3/4: optimized into a reg,
  no spill.
- `volatile u32 stride` (store+reload): gets the spill but adds a dead RELOAD
  the baserom doesn't have. The `volatile u32 spillSlot` dummy (store only) is
  the fix for that — see Solved #3.
- Lazy `romTable =` after early-return: 691 (worse).
- Plain advance-block access to break col2 CSE: removed `sub sp` entirely (698)
  OR with dead-store added gave `sub sp,#12` (724).

## Best-effort C (byte_diff 659; diff_count 338 — LOWEST achieved. r4-pinned
## romTable + field-column +12-base + index-order fix; `sub sp` via col2-CSE

```c
#include "game.h"
#include "iwram.h"
#include "types.h"

/* One per-axis blit record in the array passed in as `records`. Only the
 * per-axis step and the direction tag are read here. */
typedef struct ScrollRecord {
    u8 _pad00[4];
    u16 step; /* +0x04 */
    u8 _pad06[2];
    u8 kind; /* +0x08, low nibble selects the scroll direction (1..4) */
    u8 _pad09[15];
} ScrollRecord;

/* Scroll-blit bookkeeping block at IWRAM 0x03006540. */
typedef struct ScrollState {
    u8 startBuf;  /* +0x00 */
    u8 _pad01[1];
    u8 active;    /* +0x02, per-direction enable bitmask */
    u8 _pad03[1];
    u32 lastTick; /* +0x04 */
    u8 mirror;    /* +0x08, selects the off-screen blit buffer pair */
    u8 _pad09[2];
    u8 delay;     /* +0x0B */
    u32 srcRead;  /* +0x0C */
    u32 srcBase;  /* +0x10 */
    u32 dstRead;  /* +0x14 */
    u32 dstBase;  /* +0x18 */
    u8 _pad1C[16];
    s16 colsLeft; /* +0x2C */
    s16 rowsLeft; /* +0x2E */
    u16 height;   /* +0x30 */
    u16 width;    /* +0x32 */
} ScrollState;

/* romTable[pendingMode-1] (20-byte stride). +0 points at the scroll record
 * array (also passed in as `records`), +12 is the per-direction step lut:
 * u8 pairs [n*2] = start index, [n*2+1] = limit. */
typedef struct ScrollModeEntry {
    void *records;    /* +0x00 */
    u8 _pad04[8];
    const u8 *dirLut; /* +0x0C */
    u8 _pad10[4];
} ScrollModeEntry;

extern void sub_08010DD8(void *records, u8 n, u32 arg2);
extern void sub_080100E4(u32 mirror, void *src, void *dst);
extern void sub_08020C78(u32 sound);
extern void sub_08020DC4(u8 idx);
extern void sub_08020E7C(u8 idx);

extern u16 gIwram_60A0[];
extern ScrollModeEntry gFrameCellTable_08307EAC[];

void sub_08010F64(void *records, u8 n)
{
    register void *recordsReg asm("r9") = records;
    u32 dir = n;
    register ScrollState *scroll asm("r6") = (ScrollState *)0x03006540;
    register u8 *dirStep asm("sl");
    register u32 n2 asm("r8");
    register ScrollModeEntry *romTable asm("r4") = gFrameCellTable_08307EAC;
    const u8 *dirLut;
    ScrollRecord *rec;
    u32 pm1;
    int kind;
    u8 i;

    if (((scroll->active >> dir) & 1) == 0)
        return;

    pm1 = gGameStuff.pendingMode - 1;
    {
        /* Form (romTable + 12) as a held field-column base before adding the
         * scaled index, matching the baserom's `adds r1,#12; adds r0,r0,r1`. */
        const u8 *const *col = (const u8 *const *)((char *)romTable + 12);
        dirLut = *(const u8 *const *)((char *)col + pm1 * 20);
    }
    {
        u32 n2tmp = dir << 1;
        const u8 *lutEnt = (const u8 *)(n2tmp + (u32)dirLut);
        u8 *step = (u8 *)0x030063f0;
        u8 *stepEnt = step + dir;
        rec = &((ScrollRecord *)recordsReg)[*lutEnt + *stepEnt];
        kind = rec->kind & 0xf;
        n2 = n2tmp;
        dirStep = step;
    }

    switch (kind) {
    case 1:
        if (gGameStuff._unk00 - scroll->lastTick >= scroll->delay) {
            scroll->dstRead = scroll->dstBase;
            scroll->dstBase += gIwram_60A0[13] << 1;
            scroll->srcRead = scroll->srcBase;
            scroll->srcBase += rec->step << 1;
            if (scroll->rowsLeft != 0) {
                for (i = 0; i < scroll->height; i++) {
                    *(u16 *)scroll->dstRead = *(u16 *)scroll->srcRead;
                    scroll->srcRead += 2;
                    scroll->dstRead += 2;
                }
                scroll->rowsLeft--;
                scroll->lastTick = gGameStuff._unk00;
            }
        }
        if (scroll->rowsLeft != 0)
            goto refresh;
        break;
    case 2:
        if (gGameStuff._unk00 - scroll->lastTick >= scroll->delay) {
            scroll->dstRead = scroll->dstBase;
            scroll->dstBase -= gIwram_60A0[13] << 1;
            scroll->srcRead = scroll->srcBase;
            scroll->srcBase -= rec->step << 1;
            if (scroll->rowsLeft != 0) {
                for (i = 0; i < scroll->height; i++) {
                    *(u16 *)scroll->dstRead = *(u16 *)scroll->srcRead;
                    scroll->srcRead += 2;
                    scroll->dstRead += 2;
                }
                scroll->rowsLeft--;
                scroll->lastTick = gGameStuff._unk00;
            }
        }
        if (scroll->rowsLeft != 0)
            goto refresh;
        break;
    case 3:
        if (gGameStuff._unk00 - scroll->lastTick >= scroll->delay) {
            scroll->dstRead = scroll->dstBase;
            scroll->dstBase += 2;
            scroll->srcRead = scroll->srcBase;
            scroll->srcBase += 2;
            if (scroll->colsLeft != 0) {
                ScrollState *s = scroll;
                u32 src = s->srcRead;
                u32 dst = s->dstRead;
                for (i = 0; i < s->width; i++) {
                    *(u16 *)dst = *(u16 *)src;
                    dst += ((u16 *)gIwram_60A0)[13] << 1;
                    src += s->height << 1;
                }
                s->srcRead = src;
                s->dstRead = dst;
                scroll->colsLeft--;
                scroll->lastTick = gGameStuff._unk00;
            }
        }
        if (scroll->colsLeft != 0)
            goto refresh;
        break;
    case 4:
        if (gGameStuff._unk00 - scroll->lastTick >= scroll->delay) {
            scroll->dstRead = scroll->dstBase;
            scroll->dstBase -= 2;
            scroll->srcRead = scroll->srcBase;
            scroll->srcBase -= 2;
            if (scroll->colsLeft != 0) {
                ScrollState *s = scroll;
                u32 src = s->srcRead;
                u32 dst = s->dstRead;
                for (i = 0; i < s->width; i++) {
                    *(u16 *)dst = *(u16 *)src;
                    dst += ((u16 *)gIwram_60A0)[13] << 1;
                    src += s->height << 1;
                }
                s->srcRead = src;
                s->dstRead = dst;
                scroll->colsLeft--;
                scroll->lastTick = gGameStuff._unk00;
            }
        }
        if (scroll->colsLeft != 0)
            goto refresh;
        break;
    default:
        goto refresh;
    }

    {
        const u8 *const *col2 = (const u8 *const *)((char *)romTable + 12);
        const u8 *lut2 = *(const u8 *const *)((char *)col2 + (gGameStuff.pendingMode - 1) * 20);
        if (dirStep[dir] < lut2[n2 + 1] - 1) {
            dirStep[dir]++;
            sub_08010DD8(recordsReg, dir, 0);
            goto refresh;
        }
    }
    dirStep[dir] = 0;
    scroll->active = 0;

refresh:
    if (gGameStuff.pendingMode != 11)
        sub_08020DC4(11);

    if (scroll->active == 0) {
        if (gGameStuff.pendingMode != 11) {
            sub_08020E7C(11);
            sub_08020C78(0x82);
        }
        scroll->startBuf = 0;
        gIwram_35E0._field_10 &= 0xfffe;
        gIwram_35E0._field_12 = 0;
    }

    if (scroll->mirror != 0) {
        scroll->srcRead = 0x02010000;
        scroll->dstRead = 0x0600e800;
    } else {
        scroll->srcRead = 0x02000000;
        scroll->dstRead = 0x0600e000;
    }

    sub_080100E4(scroll->mirror, (void *)scroll->srcRead, (void *)scroll->dstRead);
}
```
