# sub_08010F64 — deferred analysis

Scroll-blit driver at 0x08010F64 (804 bytes / ~401 Thumb insns). Reached a
near-match but plateaued on a sharp register-coloring local minimum. The
documented escape (vendor/decomp-permuter) was UNAVAILABLE in the worktree
(broken submodule symlink + missing `attr` dep), so this is deferred for a
pass that has the permuter, or codex.

## What it does (verified from the asm)

`void sub_08010F64(void *records, u8 n)`:

- `scroll = (ScrollState *)0x03006540`; bit-test `if (((scroll->active >> n) & 1) == 0) return;`
  (`active` = byte at scroll+2).
- `romTable = (ScrollModeEntry *)0x08307eac`, 20-byte stride. `romTable[pendingMode-1].dirLut`
  (field at +12) is a per-direction `u8` lut of pairs `[n*2]=startIdx, [n*2+1]=limit`.
- `dirStep = (u8 *)0x030063f0` (per-direction current step, indexed `[n]`).
- `rec = &((ScrollRecord *)records)[dirStep[n] + dirLut[n*2]]` — 24-byte record;
  `rec->kind` (low nibble of byte +8) selects the scroll direction; `rec->step` (u16 +4).
- `switch (rec->kind & 0xf)` cases 1..4 (1=horiz+, 2=horiz-, 3=vert+, 4=vert-):
  each, if `gGameStuff._unk00 - scroll->lastTick >= scroll->delay`, advances the
  src/dst read cursors (scroll fields srcRead@0x0C, srcBase@0x10, dstRead@0x14,
  dstBase@0x18) and copies a row/column of u16 tiles. `0x030060a0[13]` (halfword at
  +26) is the BG row stride; `rec->step` the horizontal step. rowsLeft@0x2E / colsLeft@0x2C
  / height@0x30 / width@0x32 drive the loops. Cases 1/2 share the copy loop+tail; 3/4 likewise.
- "advance" block (shared by the case-fallthroughs): bump `dirStep[n]`; if `< dirLut[n*2+1]-1`,
  call `sub_08010DD8(records, n, 0)`; else reset `dirStep[n]=0` and clear `scroll->active`.
- "refresh" tail (label 0x11200): if `pendingMode != 11` call `sub_08020DC4(11)`. If
  `scroll->active == 0`: maybe `sub_08020E7C(11); sub_08020C78(0x82)`; `scroll->_unk00 = 0`;
  `gIwram_35E0._field_10 &= 0xfffe; gIwram_35E0._field_12 = 0`. Then pick the off-screen blit
  buffers from `scroll->_unk08` (`0x02010000/0x0600e800` vs `0x02000000/0x0600e000`) and call
  `sub_080100E4(scroll->_unk08, srcRead, dstRead)`.

Callees (all peeled/declared): sub_08010DD8, sub_080100E4, sub_08020C78, sub_08020DC4, sub_08020E7C.
Caller: sub_08010A44 passes `records = romTable[pendingMode-1].field0`, `n = loop counter`.

## Drift (best byte_diff 653 / 30 insn mismatches; size 748 vs target 804)

ALL 30 remaining mismatches are in the setup/dispatch prologue (0x0..0x80); the case
bodies (0x80+) align. Two configs bracket the minimum:

- romTable PINNED to r4 (`register ScrollModeEntry *romTable asm("r4")`): byte_diff 653,
  but agbcc emits `sub sp,#8` (an extra spill slot) where the target has `sub sp,#4`.
- romTable NOT pinned: byte_diff 664, but the correct `sub sp,#4`.

Specific unresolved divergences (responsible agbcc pass in parens):

1. **`sub sp,#4` + dead `[sp]` spills** (local-alloc/reload.c). The target spills the row-stride
   `0x030060a0[13]<<1` to `[sp,#0]` INSIDE the case 3/4 inner loops (0x11124, 0x1118c) — two
   spills, both effectively dead. INDUCING the spill required (a) `u8` loop counter `i` (the
   `(u8)(i+1)` truncation adds pressure) and (b) a scroll-COPY local `s = scroll` used for
   `s->width`/`s->height` inside the case 3/4 loops (so `0x030060a0` is forced into a scratch
   reload, raising pressure). That DOES produce `sub sp,#4` — but agbcc then spills the WRONG
   value: a `(u8)dir` (`dir<<24`) in the SETUP region (0x5e) rather than the row-stride in the
   loops. Getting the spill to land on the row-stride in cases 3/4 is the crux.

2. **`(u8)dir` re-extension / spill** (local-alloc). `dir` is `register u8 asm("ip")`. The advance
   block needs `(u8)dir` for `dirStep[dir]` and the `sub_08010DD8(...,dir,...)` arg; the target
   uses `ip` directly (`mov r1,ip`) trusting it already holds `(u8)n`, but agbcc materializes a
   separate `dir<<24>>24` early and spills/reloads it. Making `dir` `u32` removes the spill but
   ALSO removes the needed `sub sp,#4`. Tried: caching `nn=dir` and reusing it (worse, 675);
   removing the `nn` cache (worse, 675).

3. **dirLut field address `+12` form** (cse.c/addressing). Target: `adds r1,r4,#0; adds r1,#12;
   adds r0,r0,r1; ldr [r0,#0]` (field offset added to the held table base). Mine: `adds r0,r0,r4;
   ldr [r0,#12]` (offset in the load). Pinning romTable to r4 got the base held but not the
   `+12`-on-base. Tried flat-pointer-array casts (`((const u8 *const *)((u8*)romTable+12))[pm1*5]`)
   — folds to a single pool literal `table+12`, still not the held-base form.

4. **rec register** r4/r5 (mine) vs r7 (target) — pure coloring.

5. **pointer-add operand order**: `adds r1,r1,r3` (mine) vs `adds r1,r3,r1` (target) for
   `dirLut + n*2`. Swapping the `+` in the rec expression fixed the integer sum order but the
   pointer+int order is agbcc's choice.

## Levers that WORKED (keep these)
- `register void *records asm("r9")`, `register u8 dir asm("ip")`,
  `register ScrollState *scroll asm("r6")` → prologue (push {r4-r7,lr}+r8/r9/sl saves) matches exactly.
- `register u32 dir2 asm("r8")`, `register u8 *dirStep asm("sl")` ASSIGNED via low-reg temps
  AFTER the kind extraction → deferred `mov r8/sl` placement matches target (0x10fc0/0x10fc2).
- Explicit `u32 pm1 = gGameStuff.pendingMode - 1;` → `subs r1,#1` (defeats the `(pm-1)*20`
  constant-fold-into-pool).
- `extern u16 gIwram_60A0[];` (linker symbol, 0x030060a0) → defeats the `0x030060ba` adjacent-base
  CSE-fold; gives `ldr =0x030060a0; ldrh [r,#26]`.
- `u8 i` loop counters (truncated each iteration), scroll-copy `s` in case 3/4 → induces `sub sp,#4`.

## Next-lever suggestions
- decomp-permuter from the byte_diff-653 base (set `next_tier=permuter`): the deltas are pure
  statement-order / spill-placement / coloring — exactly its wheelhouse. Confirm `attr`+`toml`
  installed and the submodule symlink is real before running.
- Or instrument agbcc local-alloc/reload to see WHY the `(u8)dir` value is chosen for the spill
  instead of the case-3/4 row-stride.

## Best-effort C (byte_diff 653; romTable pinned to r4 — gives `sub sp,#8`. Drop that pin for the
## `sub sp,#4` variant at byte_diff 664)

```c
#include "game.h"
#include "iwram.h"
#include "types.h"

/* Per-direction scroll record carried in the entity-record array passed in
 * as `records`. Only the per-axis step and the kind tag are touched here. */
typedef struct ScrollRecord {
    u8 _pad00[4];
    u16 step; /* +0x04 */
    u8 _pad06[2];
    u8 kind; /* +0x08, low nibble selects the scroll direction */
    u8 _pad09[15];
} ScrollRecord;

/* Scroll-blit bookkeeping block at IWRAM 0x03006540. */
typedef struct ScrollState {
    u8 _unk00;
    u8 _pad01[1];
    u8 active; /* +0x02, per-direction enable bitmask */
    u8 _pad03[1];
    u32 lastTick; /* +0x04 */
    u8 _unk08;
    u8 _unk09;
    u8 _unk0A;
    u8 delay; /* +0x0B */
    u32 srcRead; /* +0x0C */
    u32 srcBase; /* +0x10 */
    u32 dstRead; /* +0x14 */
    u32 dstBase; /* +0x18 */
    u8 _pad1C[16];
    s16 colsLeft; /* +0x2C */
    s16 rowsLeft; /* +0x2E */
    u16 height; /* +0x30 */
    u16 width; /* +0x32 */
} ScrollState;

/* romTable[pendingMode-1] is a 20-byte record; +0 points at the scroll
 * record array (also passed in as `records`), +12 is the per-direction step
 * lut (u8 pairs: [n*2] = start index, [n*2+1] = limit). */
typedef struct ScrollModeEntry {
    void *records; /* +0x00 */
    u8 _pad04[8];
    const u8 *dirLut; /* +0x0C */
    u8 _pad10[4];
} ScrollModeEntry;

extern void sub_08010DD8(void *records, u8 n, u32 arg2);
extern void sub_080100E4(u32 mode, void *src, void *dst);
extern void sub_08020C78(u32 sound);
extern void sub_08020DC4(u8 idx);
extern void sub_08020E7C(u8 idx);

extern u16 gIwram_60A0[];

void sub_08010F64(void *records, u8 n)
{
    register void *recordsReg asm("r9") = records;
    register u8 dir asm("ip") = n;
    register ScrollState *scroll asm("r6") = (ScrollState *)0x03006540;
    register u8 *dirStep asm("sl");
    register u32 dir2 asm("r8");
    register ScrollModeEntry *romTable asm("r4") = (ScrollModeEntry *)0x08307eac;
    const u8 *dirLut;
    ScrollRecord *rec;
    u32 pm1;
    int kind;
    u8 i;

    if (((scroll->active >> dir) & 1) == 0)
        return;

    pm1 = gGameStuff.pendingMode - 1;
    dirLut = romTable[pm1].dirLut;
    {
        u32 nn = dir;
        u32 n2 = nn << 1;
        const u8 *lut = dirLut + n2;
        u8 *step = (u8 *)0x030063f0;
        rec = &((ScrollRecord *)recordsReg)[*lut + step[nn]];
        kind = rec->kind & 0xf;
        dir2 = n2;
        dirStep = step;
    }

    switch (kind) {
    case 1:
        if (gGameStuff._unk00 - scroll->lastTick >= scroll->delay) {
            scroll->dstRead = scroll->dstBase;
            scroll->dstBase += gIwram_60A0[13] << 1;
            scroll->srcRead = scroll->srcBase;
            scroll->srcBase += rec->step << 1;
            if (scroll->rowsLeft != 0) {
                for (i = 0; i < scroll->height; i++) {
                    *(u16 *)scroll->dstRead = *(u16 *)scroll->srcRead;
                    scroll->srcRead += 2;
                    scroll->dstRead += 2;
                }
                scroll->rowsLeft--;
                scroll->lastTick = gGameStuff._unk00;
            }
        }
        if (scroll->rowsLeft != 0)
            goto refresh;
        break;
    case 2:
        if (gGameStuff._unk00 - scroll->lastTick >= scroll->delay) {
            scroll->dstRead = scroll->dstBase;
            scroll->dstBase -= gIwram_60A0[13] << 1;
            scroll->srcRead = scroll->srcBase;
            scroll->srcBase -= rec->step << 1;
            if (scroll->rowsLeft != 0) {
                for (i = 0; i < scroll->height; i++) {
                    *(u16 *)scroll->dstRead = *(u16 *)scroll->srcRead;
                    scroll->srcRead += 2;
                    scroll->dstRead += 2;
                }
                scroll->rowsLeft--;
                scroll->lastTick = gGameStuff._unk00;
            }
        }
        if (scroll->rowsLeft != 0)
            goto refresh;
        break;
    case 3:
        if (gGameStuff._unk00 - scroll->lastTick >= scroll->delay) {
            scroll->dstRead = scroll->dstBase;
            scroll->dstBase += 2;
            scroll->srcRead = scroll->srcBase;
            scroll->srcBase += 2;
            if (scroll->colsLeft != 0) {
                ScrollState *s = scroll;
                u32 src = s->srcRead;
                u32 dst = s->dstRead;
                for (i = 0; i < s->width; i++) {
                    *(u16 *)dst = *(u16 *)src;
                    dst += gIwram_60A0[13] << 1;
                    src += s->height << 1;
                }
                s->srcRead = src;
                s->dstRead = dst;
                scroll->colsLeft--;
                scroll->lastTick = gGameStuff._unk00;
            }
        }
        if (scroll->colsLeft != 0)
            goto refresh;
        break;
    case 4:
        if (gGameStuff._unk00 - scroll->lastTick >= scroll->delay) {
            scroll->dstRead = scroll->dstBase;
            scroll->dstBase -= 2;
            scroll->srcRead = scroll->srcBase;
            scroll->srcBase -= 2;
            if (scroll->colsLeft != 0) {
                ScrollState *s = scroll;
                u32 src = s->srcRead;
                u32 dst = s->dstRead;
                for (i = 0; i < s->width; i++) {
                    *(u16 *)dst = *(u16 *)src;
                    dst += gIwram_60A0[13] << 1;
                    src += s->height << 1;
                }
                s->srcRead = src;
                s->dstRead = dst;
                scroll->colsLeft--;
                scroll->lastTick = gGameStuff._unk00;
            }
        }
        if (scroll->colsLeft != 0)
            goto refresh;
        break;
    default:
        goto refresh;
    }

    if (dirStep[dir] < romTable[gGameStuff.pendingMode - 1].dirLut[dir2 + 1] - 1) {
        dirStep[dir]++;
        sub_08010DD8(recordsReg, dir, 0);
        goto refresh;
    }
    dirStep[dir] = 0;
    scroll->active = 0;

refresh:
    if (gGameStuff.pendingMode != 11)
        sub_08020DC4(11);

    {
        u8 active = scroll->active;
        if (active == 0) {
            if (gGameStuff.pendingMode != 11) {
                sub_08020E7C(11);
                sub_08020C78(0x82);
            }
            scroll->_unk00 = active;
            gIwram_35E0._field_10 &= 0xfffe;
            gIwram_35E0._field_12 = active;
        }
    }

    if (scroll->_unk08 != 0) {
        scroll->srcRead = 0x02010000;
        scroll->dstRead = 0x0600e800;
    } else {
        scroll->srcRead = 0x02000000;
        scroll->dstRead = 0x0600e000;
    }

    sub_080100E4(scroll->_unk08, (void *)scroll->srcRead, (void *)scroll->dstRead);
}
```
