### The exact asm idiom that diverges
There are THREE coupled register-coloring clusters, all the SAME shape — **the target funnels two field-loads through ONE scratch register (forced by register pressure); agbcc spreads them across two free scratches:**

1. **Outer compare** `(s5&0xff)==(s6&0xff)` (+0x36..0x3c): target reuses **r6** for BOTH `ldrh` (`ldrh r6,[r3,#38];ands r1,r6;ldrh r6,[r3,#40];ands r0,r6`); built spreads across r4 then r7.
2. **Inner bit-extraction** `on=(s5>>i)&1; off=(s6>>i)&1` (+0x52..0x66): target loads s5 DIRECTLY into the pinned dest **r7** (`ldrh r7,[r2,#38];asrs r7,r2;movs r3,#1;ands r7,r3`), keeps `i` in r2 and CSE's the const `1` in r3 reused by the second extraction (`asrs r0,r2;ands r0,r3`). Built loads s5 into r0 (a scratch), ties the const into r7 (`movs r7,#1;ands r7,r0`), and **re-materializes** the `1` for the second extraction (`movs r4,#1;ands r0,r4`).
3. **accumPin RMW** `*accumPin |= bit` (+0x82..0x8c): target reloads sl into a fresh low reg per access (`mov r1,sl;ldrb;...;mov r2,sl;strb`). Doc's base batched both `mov rN,sl` together.

This is why the permuter (per the doc: 1200+ iters, base 8035, stuck 7215, never 0) could never converge: it mutates source forms, which cannot change pool layout.
