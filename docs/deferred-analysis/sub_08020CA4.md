# sub_08020CA4 — deferred analysis (round 17)

Range `[0x08020ca4, 0x08020cdc)` (56 bytes, Thumb). Destination
`src/engine/sub_08020c78.c` (sits right after the already-matching sibling
`sub_08020C78`). Both callees (`sub_0802D9EC`, `sub_0802DC1C`) are peeled.

This is the simple core of the sibling `sub_08020DC4` (which shipped NAKED for
the `entries[]` CSE-fold). `sub_08020CA4` does NOT touch `entries[]`, so that
blocker does NOT apply — it is a near-match (byte_diff 2) and should be
reclaimable with the right register-coloring lever.

## What the function does

Returns -1 unless bit 4 (`0x10`) of the `0x03003570` flags byte (offset 0) is
set. When set, it (re)starts `sound` via `sub_0802D9EC(sound, 0xff, 0xff,
0xff)`, captures the returned handle, then pans it via `sub_0802DC1C(handle,
gStructAt3003570.c & 0x7f)` (offset 2, masked 0x7f), and returns the handle.

Target asm (baserom):
```
push {r4, r5, lr}
adds r1, r0, #0        ; r1 = sound (snd)
movs r4, #1; negs r4   ; r4 = -1 (result default)
ldr  r5, =0x03003570   ; r5 = base pointer p
movs r0, #0x10         ; mask
ldrb r2, [r5, #0]      ; flags
ands r0, r2
cmp  r0, #0
beq  0x20cd0
adds r0, r1, #0        ; r0 = sound
movs r1,#0xff; r2,#0xff; r3,#0xff
bl   sub_0802D9EC
adds r4, r0, #0        ; r4 = handle (result), r0 STILL holds handle
movs r1, #0x7f         ; pan mask FIRST
ldrb r5, [r5, #2]      ; <-- byte read REUSES dead base r5
ands r1, r5            ; pan = 0x7f & c
bl   sub_0802DC1C      ; r0 = handle (untouched since adds r4,r0,#0)
0x20cd0:
adds r0, r4, #0        ; return handle/result
pop  {r4, r5}; pop {r1}; bx r1
```

## Drift

Best reached: **byte_diff 2, diff_count 2** — single instruction.
Everything else (prologue, both calls, handle handling, return path, the
`movs r1,#0x7f` mask-first ordering) is byte-identical.

The ONLY mismatch, at +0x0024 / +0x0026:
```
target:  ldrb r5, [r5, #2]   ; reuse dead base reg r5 as ldrb destination
         ands r1, r5
built:   ldrb r2, [r5, #2]   ; agbcc picks a fresh caller-saved scratch r2
         ands r1, r2
```

agbcc 2.x refuses to alias the loaded byte onto the dying base register r5.
The baserom does the destructive in-place read (`ldrb r5,[r5,#2]`); this is
the "Sequential reads of the same field reuse the base register" peephole in
`docs/codegen-notes.md` (line 361) — but that peephole only fires for the
documented **two separate `if`-with-`cmp`-test** form. Here the byte feeds an
arithmetic AND into a pinned argument register (r1), and agbcc allocates a
fresh r2 instead of reusing the dead base. The `&` into a pinned `pan asm("r1")`
seems to be what blocks the reuse.

## Levers already tried (try a DIFFERENT one)

- Pointer anchor (`StructAt3003570 *p = &gStructAt3003570;`) + register pins
  `snd asm("r1")`, `p asm("r5")`, `handle asm("r0")`, `pan asm("r1")`,
  mask accumulated as `pan = 0x7f; pan &= p->c` (mask-first). → **byte_diff 2 (best, current best-effort C below).**
- Separate value var `register u32 c asm("r5"); c = p->c; pan &= c;` (both p and c
  pinned to r5, or p left unpinned) → still picks r2 (conflict: p is the ldrb
  source at that instruction so agbcc won't write the result back to it).
- Plain-local pointer (no asm pin on p) → still r2.
- `handle asm("r4")` (collapse handle/result into r4) → REGRESSED to byte_diff 22
  (reloads handle into r0 for the 2nd call + extra copy; size grew to 60).
- Absolute-address reads (`*(u8*)0x03003570` / `*(u8*)0x03003572`) → REGRESSED
  (re-materializes 0x03003572 from a 2nd pool word + extra ldrb).
- `pan = p->c & 0x7f` (field-first) → byte_diff 5 (loses mask-first ordering).
- OLD_AGBCC_BIN per-TU override (`src/engine/sub_08020c78.s: CC=$(OLD_AGBCC_BIN)`)
  → identical byte_diff 2, same r2-vs-r5 choice. (Reverted; would needlessly
  route the already-matching sub_08020C78 through old_agbcc.)
- decomp-permuter, -j4 --stop-on-zero --better-only, ~50s / 400+ iterations.
  base score 10; never reached score 0 (lowest hit = base 10). Default weights.

## Best-effort C (byte_diff 2)

```c
#include "types.h"

typedef struct {
    u8 flags;
    u8 b;
    u8 c;
    u8 d;
} StructAt3003570;

#define gStructAt3003570 (*(StructAt3003570 *)0x03003570)

extern u32 sub_0802D9EC(u32 sound, u32 a, u32 b, u32 c);
extern void sub_0802DC1C(u32 handle, u8 val);

u32 sub_08020CA4(u32 sound)
{
    register u32 snd asm("r1");
    register StructAt3003570 *p asm("r5");
    register u32 handle asm("r0");
    register u32 pan asm("r1");
    u32 result;

    snd = sound;
    result = -1;
    p = &gStructAt3003570;
    handle = 0x10;
    handle = handle & p->flags;
    if (handle != 0) {
        handle = sub_0802D9EC(snd, 0xff, 0xff, 0xff);
        result = handle;
        pan = 0x7f;
        pan &= p->c;            /* target: ldrb r5,[r5,#2] (reuse dead base) — agbcc emits ldrb r2 */
        sub_0802DC1C(handle, pan);
    }
    return result;
}
```
