# sub_08006830 — deferred analysis

`s64 sub_08006830(void *unused, s32 lo, s32 hi)` — reads bit-range `[lo, hi]`
out of the 128-bit flag bank at IWRAM `0x03006110` (the same bank
`sub_0800696C`/`sub_080069BC` set/clear, two s64 halves at offsets 0x14/0x18
and 0x1c/0x20), shifts the selected bits down so bit `lo` lands at bit 0, and
returns them as a 64-bit value. First arg (the base ptr the callers pass) is
ignored — the function reloads `0x03006110` from its own pool.

Lives in `src/game/sub_0800679c.c` (appends after the matched `sub_0800679C`).
Callee `__lshrdi3` (libgcc 64-bit logical right shift at 0x08033de0) was peeled
in this round; `__ashldi3` (0x08033ca4) was already peeled.

Classifier verdict: **ATTEMPT_MATCH** (no structural impossibility). This is a
matchable function — do NOT ship NAKED.

## Drift

Best reached: **byte_diff 155 / diff_count 77** (the both-pins variant), or
**byte_diff 157 / diff_count 73** (the `bankval >>= shift` split variant in
"Best-effort C" below). The C is STRUCTURALLY CORRECT — prologue, the three
loading branches, the shared `applyMask` merge (single `__lshrdi3` + 64-bit
AND), and the spanning branch (`__ashldi3` + `adds`/`adcs`) all line up with
baserom. The residual is a single global-register-allocation difference that
cascades:

**Root drift — `mask` spill-vs-callee-saved.** Baserom computes `mask` into r0,
SPILLS both halves to the stack (`str r0,[sp,#0]; asrs r0,#31; str r0,[sp,#4]`),
then loads the bank base into r0 and reads the u64 hi-then-lo
(`ldr r1,[r0,#24]; ldr r0,[r0,#20]`), and at the merge re-reads `mask` from the
stack for the AND (`ldr r0,[sp,#0]; ldr r2,[sp,#8]; ands ...`). Our build keeps
`mask` in callee-saved **r4/r5** across the `__lshrdi3` call instead of spilling
(`adds r4,r0,#0; asrs r5,r0,#31`), and so the bank base lands in r7 and the u64
loads in natural lo-then-hi order. Everything downstream (the merge ANDs, the
`sub sp,#16` vs `#8` frame size) follows from this one choice.

Confirmed in the agbcc source: `local-alloc.c` excludes `call_used_reg_set` for
a pseudo that crosses a call (`qty_n_calls_crossed[qty] > 0`), so `mask`
competes for r4-r7; whether it then wins a callee-saved reg or is spilled to
memory is decided by `global.c`'s priority/cost model. It is NOT controlled by
the `-fcaller-saves`/`-fno-caller-saves`/`-fno-expensive-optimizations`/
`-fno-cse-follow-jumps` flags (all tried, no change). The next agent should read
`tools/agbcc-src/gcc_arm/global.c` (`reg_allocno` priority / `find_reg`) to see
what tips the cost toward a stack spill, then find the C that lowers `mask`'s
allocation priority (fewer/cheaper references, or a different live-range shape).

## Best-effort C (diff_count 73)

```c
/* Reads bit-range [lo, hi] out of the 128-bit flag bank at 0x03006110. */
s64 sub_08006830(void *unused, s32 loIn, s32 hiIn)
{
    register s32 lo asm("r3") = loIn;
    register s32 hi asm("r7") = hiIn;
    u8 count = hi - lo + 1;
    s64 mask;
    s32 shift;
    unsigned long long bankval;
    unsigned long long *bank;
    s64 result;

    if (hi <= 63) {
        mask = (unsigned long long)(s32)((1 << (s8)count) - 1);
        bank = (unsigned long long *)0x03006110;
        bankval = *(unsigned long long *)((char *)bank + 20);
        shift = lo;
        goto applyMask;
    }

    if (lo > 63) {
        mask = (unsigned long long)(s32)((1 << (s8)count) - 1);
        bank = (unsigned long long *)0x03006110;
        bankval = *(unsigned long long *)((char *)bank + 28);
        shift = lo - 64;
    applyMask:
        bankval >>= shift;
        result = mask & bankval;
        goto done;
    }

    {
        s32 lowCount = 64 - lo;
        s64 lowMask = (unsigned long long)(s32)((1 << lowCount) - 1);
        s64 highMask;
        unsigned long long lowBits;
        s64 highBits;

        bank = (unsigned long long *)0x03006110;
        lowBits = *(unsigned long long *)((char *)bank + 20) >> lo;
        lowBits &= lowMask;
        highMask = (unsigned long long)(s32)((1 << (hi - 63)) - 1);
        highBits = *(s64 *)((char *)bank + 28) & highMask;
        highBits = (unsigned long long)highBits << lowCount;
        result = lowBits + highBits;
    }

done:
    return result;
}
```
